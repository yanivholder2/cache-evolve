# H02

Select eviction victims from a small window of LRU items rather than always the head, targeting the minimum-frequency item within recent history to improve victim quality.

## Parent

baseline

## Changes

In `src/tiny_lfu/mod.rs`, replace the victim selection at lines 89–90 with a windowed scan. Instead of:

```rust
let victim_idx = self.head.expect("TinyLfuCache: full cache has no victim");
```

Implement a helper method `find_min_freq_victim(&self, window_size: usize) -> usize` that:
1. Starts from `self.head` and walks the linked list forward for up to `window_size` nodes (e.g., 4 or 8).
2. Tracks the node index with the minimum frequency estimate.
3. Returns that index.

Call this helper instead of always using `self.head`. This preserves the LRU ordering constraint (still prefers older items) while improving victim discrimination by not evicting hot items that happen to be near the head. Tune window_size empirically; start with 4.

# H01

Relax the admission threshold to allow admission when incoming frequency equals victim frequency, improving hit rate on traces with many equally-popular items.

## Parent

baseline

## Changes

In `src/tiny_lfu/mod.rs` at line 93, modify the admission condition from strict greater-than to greater-than-or-equal. Change:

```rust
if incoming_freq > victim_freq {
```

to:

```rust
if incoming_freq >= victim_freq {
```

This reduces the admission barrier for items tied in frequency with the victim, allowing more competitive items to be cached when their popularity estimates are equal. The rest of the put() logic remains unchanged. This targets workloads where many items have similar access patterns, where the strict inequality may unnecessarily reject items with equal merit.

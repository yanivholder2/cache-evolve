# H02

Replacing v002's SipHash `DefaultHasher` with a cheap multiply-xorshift hasher for the single base hash drives per-op-time below v002's 50ns p50.

## Parent

cycle/0001/v002

## Changes

v002 already pays only one hash per op, so the remaining per-op cost is
the SipHash `DefaultHasher` inside `base_hash()`. Replace it with a small
non-cryptographic hasher implemented locally in the module:

- Add a `struct FastHasher { state: u64 }` implementing
  `std::hash::Hasher`. In `write(&mut self, bytes: &[u8])` fold the bytes
  into `state` using an FxHash-style step (for each chunk:
  `state = (state.rotate_left(5) ^ word).wrapping_mul(0x517cc1b727220a95)`),
  and have `write_u64`/`write_usize` feed the whole word in one step so
  integer keys take a single multiply. `finish()` returns `state` after a
  final xorshift (`state ^ (state >> 32)`) to improve avalanche of the
  high bits used by `position_for`.
- In `base_hash()`, construct `FastHasher` (seeded with a fixed nonzero
  constant) instead of `DefaultHasher`, hash the key, and return
  `finish()`.

Keep `position_for()` double-hashing, the `depth`/`width` geometry,
`u32` counters, and all admission/eviction logic unchanged. Preserve the
inline tests. Risk to watch: weaker avalanche could correlate the two
derived column streams and dent hit-rate — claim is the per-op-time gain
outweighs any marginal hit-rate cost.

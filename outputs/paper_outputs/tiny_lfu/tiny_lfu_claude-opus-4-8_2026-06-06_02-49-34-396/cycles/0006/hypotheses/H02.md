# H02

Switch the sketch to conservative-update (minimal-increment) counting to sharpen the frequency estimate and raise hit-rate on the narrow factor-4 sketch.

## Parent

cycle/0005/v003

## Changes

v003 runs the cheapest, narrowest sketch (factor-4 width, depth 4), where
counter collisions — and therefore overestimation of cold keys — are highest of
the winners. Sharpen the estimate without changing geometry by adopting the
classic conservative-update rule in `CountMinSketch::increment`:

- First compute the current minimum counter value across the `depth` rows for
  the key (the same per-row scan `estimate` already does).
- Then increment only those row counters whose value equals that minimum,
  leaving rows that are already above the minimum untouched (still respecting
  the `MAX_COUNT` saturation cap).

Leave `estimate`, `base_hash`, `position_for`, the depth/width-factor geometry,
`SAMPLE_VICTIMS = 10`, and the eviction path unchanged. Conservative update
reduces the systematic over-count that collisions inject into a narrow sketch,
producing tighter frequency estimates that feed both the admission test
(`incoming_freq > victim_freq`) and the sampled-coldest victim choice. Target is
hit-rate; the only added cost is one min-scan per increment (the same pattern
already on the hot path in `estimate`), so per-op-time should move marginally.

## Rationale (optional)

Cycle 5 concluded the sketch *estimate*, not sample depth, is the binding
constraint on eviction quality. Conservative update attacks exactly that
constraint and is a pure signal-sharpening edit — the lever class that has
repeatedly won — applied where collision noise is worst.

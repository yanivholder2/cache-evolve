# H03

Implement dynamic percentile adjustment based on cold-cohort size to adapt the frequency threshold to workload pressure and improve hit-rate.

## Parent

baseline

## Changes

In the victim-selection logic within the `put()` method, replace the fixed 25th-percentile threshold with a dynamic threshold that adapts based on the cold-cohort size:

1. Remove the fixed percentile computation (lines 142-147 in cycle/0008/v001):
   ```
   let percentile_25_idx = (frequencies.len() * 25) / 100;
   let percentile_25 = ...
   ```

2. Implement dynamic percentile computation:
   ```
   let mut frequencies: Vec<u32> = (0..self.nodes.len())
       .map(|i| self.sketch.estimate(&self.nodes[i].key))
       .collect();
   frequencies.sort_unstable();
   
   // Compute target percentile dynamically
   let cold_cohort_target = (self.nodes.len() / 10).max(1); // Target 10% of cache
   let mut percentile = 25; // Start with baseline
   
   // Binary search for percentile that yields ~10% of cache
   let cold_count_at_25 = frequencies.iter().filter(|&&f| f <= frequencies[(frequencies.len() * 25) / 100]).count();
   if cold_count_at_25 < cold_cohort_target / 2 {
       percentile = 35; // Expand if too few cold items
   } else if cold_count_at_25 > cold_cohort_target * 2 {
       percentile = 15; // Contract if too many cold items
   }
   percentile = percentile.max(10).min(40); // Clamp to reasonable bounds
   
   let percentile_idx = (frequencies.len() * percentile) / 100;
   let cold_threshold = if percentile_idx < frequencies.len() {
       frequencies[percentile_idx]
   } else {
       0
   };
   ```

3. Use `cold_threshold` instead of `percentile_25` in the first-pass filtering condition.
4. Keep the fallback pass, scoring formula (age/(freq+2)), and admission gate unchanged.

## Rationale

Cycle 0009 confirmed the 25th percentile is locally optimal for the current workload, but the cross-cycle insights raise the question: "Does the 25th-percentile optimum generalize to other workloads, cache sizes, and admission-gate thresholds, or is it trace-specific?" While cycle 0010 targets the same trace, dynamic adaptation provides a mechanism to handle workload phase changes and admission-gate interactions. If the cold cohort becomes too small (fewer than ~5% of cache), victim selection falls back frequently, incurring scan costs. If too large (>20%), selectivity degrades. By keeping the cold cohort in a target band (10-20% of cache), this variant maintains both availability and selectivity without sacrificing the proven 25-percentile baseline when conditions are normal.

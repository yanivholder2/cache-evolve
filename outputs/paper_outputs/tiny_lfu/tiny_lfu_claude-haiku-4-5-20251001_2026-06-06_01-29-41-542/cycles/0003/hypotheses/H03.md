# H03

Implement a dual-tier frequency structure that fast-tracks hot items into a separate high-frequency pool to reduce sketch collision noise on the hot working set and increase hit-rate.

## Parent

baseline

## Changes

Replace the monolithic Count-Min sketch with a two-tier frequency tracking system: a fast-path tier that tracks the top K most-recently-promoted items in a simple hash set (bypassing the sketch entirely), and a sketch-based tier for the remainder. When an item is accessed, check the fast-path set first; if found, it stays in the hot tier. If not found, look it up in the sketch. On admission decisions, items in the fast-path set are treated as definitively hot (always admitted), while sketch-based items use the existing strict gate logic. This concentrates sketch capacity on distinguishing cold items, reducing the collision noise that affects the baseline's mid-frequency items. Set K to 5-10% of cache capacity. Preserve all other logic (eviction ordering, gate threshold) from the baseline.

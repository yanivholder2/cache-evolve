# H02

Apply super-linear weighting to age via exponent to exponentially penalize very old items and improve hit-rate on temporally-clustered workloads.

## Parent

cycle/0004/v001

## Changes

Modify the victim-selection scoring formula in the `put()` method's victim-finding loop to apply a power-law exponent to the age term. Replace `let score = (age as f64) / ((victim_freq as f64) + 1.0);` with `let age_weighted = (age as f64).powf(1.5); let score = age_weighted / ((victim_freq as f64) + 1.0);`. This applies age^1.5 scaling, amplifying the penalty for items not accessed for long periods while keeping frequency weighting linear. Keep the frequency offset at 1.0, the admission gate logic unchanged, and all sketch parameters unchanged.

## Rationale

Cycle 0004 tested sub-linear frequency scaling (sqrt, v002) and found it regressed performance. Age has not yet been systematically explored with exponents. Super-linear age weighting (^1.5 instead of ^1.0) tests whether the workload's temporal locality is steep enough that exponential age decay better captures value patterns than linear age. The cycle-0004 insight notes that v002 lost because "linear frequency weighting is still optimal," leaving open whether age scaling is a productive direction. This orthogonal direction to H01 explores parameter space on a different term.

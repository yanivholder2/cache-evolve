# H01

Increase the frequency offset constant to better discriminate between moderately-frequent and rarely-accessed items in victim selection and improve hit-rate.

## Parent

cycle/0004/v001

## Changes

Modify the eviction victim-selection scoring formula in the `put()` method's victim-finding loop. Replace the current denominator offset of 1.0 with 2.0: change `let score = (age as f64) / ((victim_freq as f64) + 1.0);` to `let score = (age as f64) / ((victim_freq as f64) + 2.0);`. This increases the baseline protection for all items and widens the score differences between items with frequencies 1, 2, and 3+. Keep the age numerator linear (unchanged), the admission gate logic unchanged, and all sketch parameters unchanged.

## Rationale

The cycle-0004 insight explicitly identifies parameter tuning as a frontier: "Can the winning formula be further tuned with different constants...to extract additional gains?" The current offset of 1.0 was inherited without systematic exploration. Testing offset=2.0 dampens the frequency signal's absolute effect (larger denominator means smaller score differences), which may improve discrimination if the working set contains many items with low (1-3) frequencies where relative differences matter most. This is a low-risk refinement orthogonal to both cycle-0004 v002's frequency scaling and v003's normalization.

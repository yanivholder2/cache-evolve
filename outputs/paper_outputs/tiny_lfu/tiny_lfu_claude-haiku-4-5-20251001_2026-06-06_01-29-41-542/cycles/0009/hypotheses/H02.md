# H02

Layer age partitioning first, then apply frequency-age scoring within the oldest cohort to compound orthogonal signals and improve hit-rate.

## Parent

cycle/0008/v001

## Changes

In the victim-selection loop within the `put()` method, restructure the partitioning to use age as the primary filter and frequency-age scoring as the secondary discriminator within that partition:

1. Compute the age (current_time - last_access_time) for all cached items.
2. Partition items into age cohorts, specifically identifying the oldest 25% of items by age.
3. In the first pass, iterate only through items in the oldest-25% age cohort (instead of the frequency-based cold cohort).
4. Within the oldest cohort, compute the eviction score using the existing formula: `(age as f64) / (victim_freq + 2.0)`.
5. Select the item with the highest score from the oldest cohort as the victim.
6. Keep the fallback pass: if the oldest cohort is empty (should not occur), scan all items using the same scoring formula.
7. Keep the admission gate logic unchanged: `incoming_freq > victim_freq`.

Preserve the burstiness tracking and LRU ordering from v001.

## Rationale

Cycle 0008 established that both frequency-cohort (v001) and age-cohort (v002) partitioning independently improve hit-rate, and the cross-cycle insight confirms that age and frequency are orthogonal signals. The open question explicitly asks whether frequency and age partitioning can be combined hierarchically. This hypothesis tests age-first layering: using age as the primary coarse filter (stale items must be evicted first) and then applying the frequency-age scoring formula within that oldest cohort to fine-grain the selection. This contrasts with v002's uniform age-tiering by focusing victim selection on only the single oldest cohort, leveraging frequency discrimination within it to compound the two signals' effectiveness.

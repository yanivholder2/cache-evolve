# H01

Integrate frequency-recency eviction victim scoring into the best sketch configuration to improve hit-rate.

## Parent

cycle/0003/v001

## Changes

Add frequency-recency hybrid victim selection to the optimized sketch from cycle/0003/v001. In the eviction path (when the cache is full and a new item must be admitted), replace pure LRU ordering with a scoring function that selects the victim with the highest score = (current_time - last_access_time) / (sketch_frequency + 1). Iterate through all cached items, compute this score for each, and evict the item with the maximum score. This balances age and frequency, protecting recently-accessed hot items while preferring cold long-lived items as victims. Keep all sketch parameters (16x width, counter recycling, depth of 4), the admission gate logic (incoming_freq > victim_freq), and related infrastructure from cycle/0003/v001 unchanged.

# H01

Increase sketch width to reduce hash collisions and improve frequency estimate accuracy, raising hit rate on Zipfian traces.

## Parent

baseline

## Changes

Replace `SKETCH_WIDTH_FACTOR` (currently 4) with 8 in src/tiny_lfu/mod.rs line 9.
This increases the count-min sketch table width, reducing hash collisions and improving the
accuracy of frequency estimates for incoming items. The wider table allows the sketch to
distinguish between truly high-frequency and low-frequency keys more reliably, leading to
better admission decisions when the cache is full. The tradeoff is increased sketch heap
memory (line 64), but metadata-size fitness allows this comparison.

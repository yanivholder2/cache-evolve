# H01

Adding periodic sketch aging (halve all counters every `capacity × 10` increments) will raise hit rate by preventing stale high-frequency counts from blocking admission of newly-popular keys.

## Parent

baseline

## Changes

Modify `CountMinSketch` in `src/tiny_lfu/mod.rs`:

1. Add two new fields to the struct:
   ```rust
   total_increments: u64,
   reset_threshold: u64,
   ```

2. Update `CountMinSketch::new(width: usize)` to accept a second parameter
   `reset_threshold: u64` (or compute it internally). Initialize
   `total_increments: 0` and `reset_threshold` as passed in.

3. In `TinyLfuCache::try_new`, derive the threshold and pass it when
   constructing the sketch:
   ```rust
   let reset_threshold = (capacity as u64) * 10;
   sketch: CountMinSketch::new(width, reset_threshold),
   ```

4. In `CountMinSketch::increment`, after updating the row counters, increment
   `self.total_increments`. Then check:
   ```rust
   if self.total_increments >= self.reset_threshold {
       for row in self.counts.iter_mut() {
           for cell in row.iter_mut() {
               *cell >>= 1;
           }
       }
       self.total_increments = 0;
   }
   ```

No changes to `put()`, `get()`, the LRU linked-list structure, or the admission
gate logic (`incoming_freq > victim_freq`). The invariants P1–P3 are unaffected
because aging only reduces counter magnitudes — it never inserts phantom keys or
causes capacity to be exceeded.

# H02

Reintroducing light frequency-ranked victim sampling on top of the accurate conservative-update sketch lifts hit-rate, because victim choice and estimator accuracy are independent durable levers that were never combined.

## Parent

cycle/0003/v002

## Changes

Start from v002 (conservative-update sketch, `SKETCH_WIDTH_FACTOR = 16`). Modify only the eviction branch of `put()` (currently lines that take `victim_idx = self.head` and compare a single candidate). Replace the single-head victim with a small forward scan: starting at `self.head`, walk up to `SAMPLE = 5` nodes along `next`, compute `sketch.estimate` for each candidate's key, and select the candidate with the lowest estimate as `victim_idx` (break ties toward the one nearest the head, i.e. the most-LRU). Then run the existing `incoming_freq > victim_freq` admission test against that chosen victim and perform the same in-place slot overwrite (`map.remove`/`unlink`/key+value rewrite/`push_back`/`map.insert`) already in v002.

This is the SAMPLE=5 victim scan from cycle 0001/v003 (which gave a real but slim gain) layered onto the accurate sketch — a pairing that has never been built, since the cycle-3 incumbents descend purely from the width/CU accuracy lineage and use the strict LRU head. Invariants to preserve: never sample past the tail (stop early if `next` is `None`); the sampled set must all be resident nodes; capacity and value handling are untouched because eviction still overwrites exactly one slot. Keep `SAMPLE` as a named constant so it can be retuned. Existing unit tests must still pass.

# H01

Gating protected-tier *entry* on a frequency floor that is evaluated pre-increment so it can actually fire raises hit-rate by reserving protected slots for keys with demonstrated prior reuse.

## Parent

cycle/0006/v002

## Changes

This corrects cycle 0006's inert entry-floor (v003), which never engaged
because `get()`/`put()` increment the sketch *before* calling `promote()`, so
the promotee's estimate already included the current access and the floor was
trivially satisfied.

Thread the pre-increment estimate into the promotion path:

1. In `get()` (around lines 86–91), capture `let prior = self.sketch.estimate(key);`
   *before* `self.sketch.increment(key)`, and pass `prior` into `self.promote(idx, prior)`.
2. In `put()`'s re-hit branch (around lines 95–99), do the same: capture the
   estimate before the `self.sketch.increment(&key)` at line 94 (or compute it
   before that increment) and pass it into `promote`.
3. Change `promote(&mut self, idx: usize)` to `promote(&mut self, idx: usize, prior_freq: u32)`.
4. In the spare-room branch (line 158, `if self.protected_len < self.protected_cap`),
   make the unconditional promotion conditional on `prior_freq >= PROMOTE_FLOOR`
   where `const PROMOTE_FLOOR: u32 = 2;` (the key must have been observed at least
   twice *before* this access — genuine reuse, not a first-touch). When
   `prior_freq < PROMOTE_FLOOR`, do NOT promote: re-insert the node at the
   probationary tail via `push_back_prob(idx)` (recency refreshed) and leave
   `protected_len` unchanged.

Preserve every other behaviour exactly: the already-protected re-hit fast path
(lines 147–153), the full-protected promotion contest and `sample_prot_demotee`
demotion (lines 169–193), and the invariant that `protected_len` is incremented
only when a node actually enters the protected segment. The floor only affects
promotions that would otherwise have entered protected for free, so it cannot
under-fill probation or remove the always-present probationary victim.

## Rationale (optional)

Cycle 0006 flagged this as the single most promising remaining hit-rate probe:
a floor that fires reserves protected capacity for proven keys in a way the
current always-true entry does not, attacking the "warming probationary key
promoted too cheaply" case the prior gate could not reach.

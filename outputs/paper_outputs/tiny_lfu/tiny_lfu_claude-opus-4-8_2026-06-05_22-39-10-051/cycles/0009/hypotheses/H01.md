# H01

Replace the static protected/probationary split with an online hill-climbing controller that adapts `protected_cap` to the trace's phases, raising hit-rate above the flat static-sizing plateau.

## Parent

cycle/0008/v001

## Changes

Every static `protected_cap` sweep (0.5 .. 0.9) has tied — but all were
*fixed* for the whole trace. Make the split adaptive instead, so it can
track phase changes within workload-a that no single constant captures.

In `TinyLfuCache`, add three fields: `hits: u64`, `accesses: u64`, and a
signed `step: i64` (initialised to `+1`), plus `prev_hit_rate: f64`
(initialised `-1.0`). Keep `protected_cap` mutable.

- In `get`, increment `accesses`; increment `hits` when `self.map.get(key)`
  is `Some`. In `put`, increment `accesses` (treat an existing-key put as a
  hit, a miss otherwise) to keep the ratio consistent.
- After each access, when `accesses` reaches a window of `16 * capacity`,
  compute `rate = hits as f64 / accesses as f64`. If `prev_hit_rate >= 0.0`,
  hill-climb: when `rate < prev_hit_rate`, flip `step = -step` (the last
  move hurt, reverse); then apply `new_cap = protected_cap as i64 +
  step * (capacity / 100).max(1)`. Clamp `new_cap` into
  `[capacity / 2, capacity - 1]` so a victim always exists in probation and
  the protected tier stays the majority. Store `prev_hit_rate = rate`, then
  reset `hits = 0`, `accesses = 0`.
- When `new_cap < protected_cap` and `protected_len > new_cap`, demote the
  excess: while `protected_len > new_cap`, take `prot_head`, `unlink` it,
  `push_back_prob` it, and decrement `protected_len`. When `new_cap >
  protected_cap`, no migration is needed — future promotions fill the new
  slack. Assign `protected_cap = new_cap`.

Preserve all existing invariants: protected/probationary remain disjoint
chains, `protected_len` stays exactly the count of protected nodes, and the
probationary segment is never emptied while the cache is full. Leave the
sketch, `PROMOTE_FLOOR`, and the eviction contest unchanged so the only
moving part is the segment boundary.

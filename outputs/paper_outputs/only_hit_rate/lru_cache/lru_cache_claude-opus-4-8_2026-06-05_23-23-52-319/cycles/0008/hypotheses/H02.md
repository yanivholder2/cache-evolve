## Changes

Rebuild `src/lru_cache/mod.rs` as a from-scratch ARC (Adaptive Replacement
Cache) over the existing HashMap + arena doubly-linked-list machinery, keeping
the `framework::Cache<K, V>` impl, the public `new`/`try_new`/`get`/`put`
signatures, the `pub mod lru_cache_jni;` line, and the capacity contract
(resident entries never exceed `capacity`) unchanged. Do not touch
`lru_cache_jni.rs`.

Maintain four arena-backed LRU lists and one adaptation parameter:

- `t1`: resident keys seen once (recency).
- `t2`: resident keys seen 2+ times (frequency).
- `b1`: ghost list of keys recently evicted from `t1` (key only, no value).
- `b2`: ghost list of keys recently evicted from `t2` (key only, no value).
- `p`: target size for `t1`, in `[0, capacity]`, initialized to 0.

Implement the canonical ARC operations:
- `get`/hit in `t1` or `t2`: move the key to `t2` MRU.
- `get`/`put` miss with key in `b1`: increase `p` by
  `max(1, |b2| / |b1|)` (clamped to `capacity`), `replace`, then insert into
  `t2` MRU and drop the `b1` ghost.
- miss with key in `b2`: decrease `p` by `max(1, |b1| / |b2|)` (clamped to 0),
  `replace`, then insert into `t2` MRU and drop the `b2` ghost.
- pure miss (`put` of a wholly new key): if `|t1| + |b1| == capacity`, evict
  from `t1` or `b1` as ARC specifies; if `|t1| + |t2| + |b1| + |b2| >= capacity`
  trim a ghost; `replace`, then insert into `t1` MRU.
- `replace(in_b2)`: if `t1` is non-empty and (`|t1| > p`, or `in_b2` and
  `|t1| == p`), demote `t1`-LRU to `b1`; else demote `t2`-LRU to `b2`.

Bound `|t1| + |t2| <= capacity` (resident bound) and `|b1| + |b2| <= capacity`
(ghost bound) exactly per the standard ARC invariants; reuse arena slots in
place for resident demotions/admissions and store ghosts in a separate
key-set + small ring so they hold no value payload. Carry over the existing
unit tests, adjusting only the comments that assert SLRU-specific segment
behavior; the externally observable LRU/eviction contract tests must still pass.

## Rationale (optional)

This is the one mainstream replacement skeleton never tried here. It is distinct
from the disconfirmed cycle-0007 adaptive-boundary probe: that floated an SLRU
prob/prot split on one-sided ghost feedback within `[0.90, 0.98]`, whereas ARC
separates recency (T1) from frequency (T2) and steers `p` from *two* balanced
ghost lists (B1 and B2). If ARC also fails to beat 0.7313, that is strong
evidence the incumbent is a converged optimum on this trace.

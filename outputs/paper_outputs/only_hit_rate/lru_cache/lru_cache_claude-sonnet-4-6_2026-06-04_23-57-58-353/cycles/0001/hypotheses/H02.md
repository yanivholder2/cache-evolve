# H02

Replacing doubly-linked-list eviction with a CLOCK second-chance sweep will raise hit rate by granting one access-reprieve to entries that were touched after entering the LRU end of the cache.

## Parent

baseline

## Changes

Rewrite the eviction and promotion machinery in `src/lru_cache/mod.rs` to use a circular clock instead of a moving-pointer doubly-linked list.

**Remove from `LruCache`:**
- `head`, `tail` fields
- `unlink`, `push_back` methods

**Add to `LruCache`:**
- `clock_hand: usize` — index of the next candidate slot to inspect during eviction; starts at 0; wraps modulo `capacity`
- `len: usize` — current number of resident entries (replaces the implicit `nodes.len() < capacity` check)

**Change on `Node`:**
- Remove `prev: Option<usize>` and `next: Option<usize>`
- Add `referenced: bool` — cleared to `false` on insertion, set to `true` on any subsequent `get` or `put`-update

**`get`:**
Look up `idx` in `map`. If present, set `nodes[idx].referenced = true`; return `Some(&nodes[idx].value)`. No structural movement.

**`put` (existing key):**
Update `nodes[idx].value`. Set `nodes[idx].referenced = true`. Return.

**`put` (new key, arena not full):**
Push a new `Node` with `referenced = false` onto `nodes`. Increment `len`. Insert into `map`.

**`put` (new key, arena full — eviction path):**
Sweep forward from `clock_hand`:
```
loop {
    if nodes[clock_hand].referenced {
        nodes[clock_hand].referenced = false;  // give second chance
        clock_hand = (clock_hand + 1) % capacity;
    } else {
        // evict this slot
        map.remove(&nodes[clock_hand].key);
        nodes[clock_hand] = Node { key: key.clone(), value, referenced: false };
        map.insert(key, clock_hand);
        clock_hand = (clock_hand + 1) % capacity;
        break;
    }
}
```
The sweep always terminates because at most one full revolution clears all reference bits, guaranteeing an unreferenced victim exists.

**Invariants:**
`len` never exceeds `capacity` (exactly one slot is reused per eviction), so P1 holds. Values are written atomically before the map is updated, preserving P2 and P3.

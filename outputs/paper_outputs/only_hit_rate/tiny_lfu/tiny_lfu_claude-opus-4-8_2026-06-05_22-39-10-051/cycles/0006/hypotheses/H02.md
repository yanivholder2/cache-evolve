# H02

Choosing the coldest protected node by frequency when the protected tier overflows, instead of always demoting its LRU head, retains more genuinely-hot keys in the protected tier and raises hit-rate.

## Parent

cycle/0005/v002

## Changes

In the winner v002, the only path that removes a key from the protected tier is
the overflow branch of `promote()`: when the protected tier is full and a hotter
probationary promotee wins the frequency contest, the protected **LRU head**
(`prot_head`) is demoted to probationary unconditionally. This change replaces
that fixed LRU-head choice with a frequency-ranked demotion victim drawn from a
small protected-LRU window.

Concretely:
- Add a module constant `const DEMOTE_SAMPLE: usize = 5;`.
- Add a helper `fn sample_prot_demotee(&self) -> usize` that starts at
  `prot_head` and walks up to `DEMOTE_SAMPLE` nodes along the protected `next`
  chain (LRU → MRU direction), returning the index with the lowest
  `sketch.estimate`, ties broken toward the most-LRU node via a strict `<`. The
  walk stays within the protected list because the two segments are separate
  chains.
- In the overflow branch of `promote()` (the `promotee_freq > head_freq` arm),
  keep the existing contest **against the protected LRU head** to decide whether
  the promotee is admitted at all (do not change the admission test). But once
  the promotee wins, demote `sample_prot_demotee()` instead of `head_idx`: unlink
  that sampled node, `protected_len -= 1`, `push_back_prob` it, then
  `push_back_prot(idx)` and `protected_len += 1` as before.

Preserve invariants: `protected_len` accounting stays exact, the demoted node is
always a real protected node (so probationary/protected membership flags stay
consistent), and the non-overflow promotion path and the `put()` eviction path
are untouched.

## Rationale (optional)

v002 already gates *entry* to the protected tier by frequency; this applies the
same sharp-sketch signal to the *exit* decision. Recency order and frequency
correlate on this trace, so the win may be marginal — but the protected-tier exit
is a structural lever not yet tested in isolation.

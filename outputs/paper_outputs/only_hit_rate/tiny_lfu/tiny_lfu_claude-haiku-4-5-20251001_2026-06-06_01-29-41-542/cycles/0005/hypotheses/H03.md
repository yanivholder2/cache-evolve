# H03

Simplify victim selection to rely solely on frequency estimates without age, testing whether frequency precision is sufficient to discriminate the working set on this workload.

## Parent

baseline

## Changes

Implement frequency-only eviction victim selection, removing age from the decision metric entirely. In the victim-finding loop within the `put()` method, replace the hybrid frequency-recency scoring with pure frequency-based selection: iterate through all cached items and compute `let score = 1.0 / ((victim_freq as f64) + 1.0);` for each (inversely proportional to frequency), selecting the item with the highest score (coldest item by frequency estimate alone). Do not reference `last_access_time` in the eviction decision. The admission gate, sketch parameters, depth, and width remain unchanged from baseline.

## Rationale

Cycles 0003-0004 validated that frequency-age hybrids improve over pure-LRU eviction. However, this assumes both signals are necessary. The cross-cycle insights note that "frequency precision is a high-ROI bottleneck" and suggest that improved sketch estimates (via Cycles 0001-0002's width/depth tuning) reduce measurement noise substantially. This hypothesis tests the null case: if the count-min sketch provides sufficiently precise frequency estimates, age may add more noise than signal. Removing age entirely tests whether the discrimination comes from frequency alone. This is distinct from H01/H02 because it eliminates a major signal dimension rather than refining existing formula parameters.

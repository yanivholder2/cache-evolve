# H03

Improve admission-gate frequency estimates by detecting and correcting for hash-collision patterns in the Count-Min sketch, improving hit-rate by sharpening the frequency signal without relaxing the strict admissions threshold.

## Parent

baseline

## Changes

In the admission logic within the `put()` method (where the incoming frequency is estimated), modify the frequency estimation step to detect collision patterns and apply a corrective adjustment.

After computing `incoming_freq = self.sketch.estimate(&key)` using the current approach (minimum across all depth rows), collect all individual estimates from each sketch row into a vector: `let all_estimates: Vec<u32> = (0..self.depth).map(|row| self.counts[row][pos]).collect()`. 

Compute the coefficient of variation (CV) of these estimates: `cv = stddev(all_estimates) / mean(all_estimates)`. If `cv > 0.15`, indicating likely collision spread across rows, use the 25th percentile of `all_estimates` instead of the minimum. Otherwise, use the minimum as before.

Replace the use of `incoming_freq` in the admission gate comparison `if incoming_freq > victim_freq {` with this collision-aware estimate. The strict admission gate threshold (`>`) and all other victim-selection logic remain unchanged. Sketch width, depth, and saturation handling are unmodified.

## Rationale

Cycle 0001 showed that sketch precision improvements (width tuning) were productive early on; Cycles 0001–0002 gained +0.0047 from width doubling. However, Cycle 0006 confirmed that further tuning sketch parameters has saturated. This hypothesis takes a different angle: instead of changing the sketch structure, improve the estimate quality at read-time by detecting collision patterns. When the coefficient of variation is high, it signals that different hash functions are returning very different counts, indicating collision noise. In such cases, using the 25th percentile (more robust than minimum to outlier collisions while more conservative than mean) provides a better estimate without changing the sketch itself. This keeps the strict admission gate's selectivity intact while sharpening the frequency signal it uses for discrimination, potentially unlocking gains that were blocked by noisy estimates.

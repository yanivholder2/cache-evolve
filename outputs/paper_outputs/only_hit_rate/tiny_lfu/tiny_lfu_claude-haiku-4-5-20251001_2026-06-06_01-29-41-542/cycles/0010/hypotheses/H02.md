# H02

Use burstiness window activity as a primary filter to identify truly dormant items and improve hit-rate.

## Parent

cycle/0008/v001

## Changes

In the victim-selection logic within the `put()` method, incorporate burstiness_window as a strong signal:

1. Keep the 25th-percentile frequency-cohort partitioning.
2. In the first-pass loop, add a two-tier preference:
   - Tier 1: Prefer items with `burstiness_window == 0` (no activity in current burstiness window). Rank these by age/(freq+2).
   - Tier 2: If no Tier 1 candidates exist, fall back to items with `burstiness_window > 0`, ranked by age/(freq+2).
3. Implement the two-tier loop:
   ```
   // Tier 1: burstiness_window == 0 items only
   while let Some(idx) = current_idx {
       let victim_freq = self.sketch.estimate(&self.nodes[idx].key);
       if victim_freq <= percentile_25 && self.nodes[idx].burstiness_window == 0 {
           let age = self.current_time - self.nodes[idx].last_access_time;
           let score = (age as f64) / (victim_freq as f64 + 2.0);
           if score > best_score {
               best_score = score;
               best_victim_idx = Some(idx);
           }
       }
       current_idx = self.nodes[idx].next;
   }
   // Tier 2: all cold-cohort items (backfill)
   if best_victim_idx.is_none() { ... existing logic ... }
   ```
4. Keep the fallback full-cache scan and admission gate unchanged.

## Rationale

Burstiness window tracking exists in the implementation but is not currently used in victim selection. Items with `burstiness_window == 0` indicate zero activity during the current reset window (typically capacity/10 operations), signaling they have transitioned out of the active set. This provides a window-biased recency signal orthogonal to the Count-Min Sketch frequency estimate. By prioritizing these dormant items first within the frequency-cold cohort, we target items with demonstrable recent inactivity, which is a strong eviction candidate signal mentioned in the cross-cycle open questions as a secondary partitioning criterion.

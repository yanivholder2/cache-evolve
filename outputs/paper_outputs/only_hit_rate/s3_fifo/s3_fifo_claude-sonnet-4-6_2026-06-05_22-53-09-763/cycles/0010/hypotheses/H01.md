# H01

Combining the capacity/20 small-queue (cycle/0009/v001) with unconditional move-to-front on all main-queue hits will compound two orthogonal confirmed wins into a higher hit rate than either mechanism achieves alone.

## Parent

cycle/0009/v001

## Changes

The parent (cycle/0009/v001) already has `small_size = capacity / 20` and the eager-promotion logic.
Its main-queue `get()` path does an in-place freq increment without repositioning (lines 111-114 in the v001 overlay):

```rust
// --- main queue: in-place increment, no relocation ---
if let Some(entry) = self.main.iter_mut().find(|e| &e.key == key) {
    entry.freq = (entry.freq.saturating_add(1)).min(MAX_FREQ);
    return Some(&entry.value);
}
```

Replace that block with the MTF variant taken from cycle/0009/v002 (lines 112-118 of that overlay):

```rust
// --- main queue: freq increment + move-to-front ---
if let Some(pos) = self.main.iter().position(|e| &e.key == key) {
    self.main[pos].freq = (self.main[pos].freq.saturating_add(1)).min(MAX_FREQ);
    let entry = self.main.remove(pos).unwrap();
    self.main.push_front(entry);
    return self.main.front().map(|e| &e.value);
}
```

No other changes: keep `small_size = capacity / 20`, MAX_FREQ = 5, the eager-promotion block, `evict_main()` threshold at `freq > 1`, `evict_small()` logic, and ghost size at `main_size / 2`.

Update the block-comment header to add an H04 note describing this combination. Also copy the MTF-specific tests from v002 (`main_queue_mtf_on_get`, `main_queue_mtf_value_correct`) into the `#[cfg(test)]` section and update their capacity comment (small_size is now capacity/20, not capacity/14) so they remain correct.

## Rationale

cycle/0009/v001 gains from tightening the cold-admission filter (small-queue sizing); cycle/0009/v002 gains from preventing positional drift of hot residents (MTF). The cross-cycle insights explicitly flag the combination at the ~5% small-queue base as unexamined. Both improvements are statistically confirmed and target distinct failure modes, so their combined effect should be measurable and additive.

# H03

Dynamically increase small-to-main promotion threshold when main queue is under capacity pressure to filter cold items and reduce eviction churn, improving hit rate during high-load phases.

## Parent

baseline

## Changes

Modify the `evict_small()` method in `/src/s3_fifo/mod.rs` to make the promotion condition dynamic based on main queue utilization. Replace the fixed promotion check `if tail.freq > 1` (line 113) with a conditional that computes main queue load: if `self.main.len() * 100 >= self.main_size * 80`, require `tail.freq >= 2` for promotion; otherwise, use the baseline condition `tail.freq > 1`. This increases promotion selectivity when main queue exceeds 80% capacity, preventing weak (single-access) items from flooding into main during memory pressure. The effect is to keep small-queue items longer under congestion, allowing them to accumulate more frequency evidence before promotion, thereby filtering out transient accesses and improving hit rate during high-load workload phases.

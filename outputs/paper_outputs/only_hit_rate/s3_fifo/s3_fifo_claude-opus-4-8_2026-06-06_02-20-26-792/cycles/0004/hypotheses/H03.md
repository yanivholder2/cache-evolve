# H03

Promoting a main-queue entry to the front of main on each hit (recency reordering) raises hit-rate by making the resident queue LRU-aware rather than pure FIFO, better matching the LIRS workload's recency structure.

## Parent

cycle/0003/v001

## Changes

This is the "different mechanism entirely" the cross-cycle insights call for:
instead of tuning retention via sizing or frequency thresholds, change the
*ordering discipline* of the main queue itself. Today main is strict FIFO with
a frequency-based second chance — a hot key's only protection is the `freq`
counter; its physical position drifts monotonically toward the tail regardless
of how recently it was used.

Change `get()` so that a hit on an entry residing in `main` moves that entry to
the front of `main` (most-recently-used position), in addition to the existing
`freq` bump. Specifically, restructure `get()` to:

1. First search `small`; if found, bump `freq` (clamped to `MAX_FREQ`) and
   return the value reference as today (do NOT reorder small).
2. Otherwise search `main` by position; if found, remove that entry from its
   current position, increment its `freq` (clamped to `MAX_FREQ`),
   `push_front` it onto `main`, and return a reference to the now-front entry.
3. On no match, return `None`.

This keeps `evict_main()`'s tail-based second-chance decrement unchanged, so the
coldest-by-recency entries now sit at the tail and are evicted first, while
frequently/recently reused keys cluster at the front. Do not change the
partition ratio (`capacity / 24`), ghost sizing, the ghost re-admission path,
or `put()`. Preserve the capacity-bound, value-fidelity, and no-phantom
invariants — reordering never changes resident count or stored values.

## Rationale (optional)

The freq counter is a coarse, cheap approximation of recency; on a LIRS trace
true move-to-front recency may retain hot keys that FIFO position would have
pushed out before their next reuse. It is orthogonal to every lever tried so
far (all of which kept main strictly FIFO), making it the cohort's bolder bet.

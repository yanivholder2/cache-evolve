# H03

Weight the momentum controller's step by how recently the hit ghost record was evicted (its position in the ghost queue), so a front-of-ghost hit drives a larger split move than a deep one, sharpening the steering signal to raise hit-rate.

## Parent

cycle/0009/v001

## Changes

In `S3Fifo::put`, in the in-ghost branch, the controller currently reads
`from_main`, then sets `step` purely by direction agreement (`self.step =
(self.step * 2).min(4)` when `desired == self.last_dir`, else `1`). Augment the
step computation with a *recency weight* derived from `pos` (the matched ghost
index, 0 = freshest/front, `ghost.len()-1` = oldest/back), captured before
`self.ghost.remove(pos)`. Compute a boolean `fresh = pos < self.ghost.len() / 2`
(front half = a key evicted very recently, i.e. the partition is only just too
small — a strong, fresh imbalance signal). Then:

- If `desired == self.last_dir`: set `self.step = (self.step * 2).min(4)` as
  today, but additionally bump to the `.min(4)` cap immediately when `fresh`
  (a fresh, agreeing signal jumps straight to the max step instead of ramping).
- If `desired != self.last_dir`: set `self.step = if fresh { 2 } else { 1 }`
  (a fresh reversal still commits a slightly larger move than a deep reversal,
  since the trace's imbalance is monotone signal, not noise).

Leave everything else — the `desired` derivation from `from_main`, the
`small_lower()/small_upper()` clamp, `last_dir` update, and
`main_size = capacity - small_size` — unchanged. Keep the step capped at 4.

## Rationale (optional)

Cycle 0009 established the controller is "under-reaching, not mis-aimed," that
the trace "wants a lower commitment threshold, not a wider accumulation band,"
and that hysteresis (throttling) was the wrong medicine because the signal isn't
noisy. This change is the opposite of hysteresis: it answers the open "smarter
steering signal" question by amplifying response to *fresh* ghost hits (the
strongest evidence the split is currently wrong) while still moving on deep
hits. It modulates step by signal quality, not by accumulating agreement, so it
should respond faster to real drift without re-tuning raw magnitudes.

# H02

Raising the frequency clamp `MAX_FREQ` from 3 to 5 lets hot keys earn more second-chance passes in v002's enlarged main queue, improving hit-rate by retaining genuinely hot residents longer.

## Parent

cycle/0001/v002

## Changes

Change the module constant `const MAX_FREQ: u8 = 3;` to
`const MAX_FREQ: u8 = 5;`. This is the ceiling applied in `get`
(`entry.freq = entry.freq.saturating_add(1).min(MAX_FREQ)`), so frequently
reaccessed entries can accumulate up to 5 instead of 3. Because
`evict_main` decrements `freq` by one per rotation and only evicts at
`freq == 0`, a higher ceiling grants hot main entries more survival passes
before eviction; small-queue entries promoted into main also carry a
higher residual `freq`. Do not change the `evict_small` promotion gate
(keep `freq > 1`), the small/main partition (keep v002's `capacity / 10`),
ghost sizing, or the direct-to-main ghost re-admission path. Only the
constant changes.

## Rationale (optional)

v002 enlarged the main queue but kept the same shallow second-chance depth;
deepening retention is a distinct lever that compounds with the larger main
capacity rather than re-tuning the same partition knob.

# H02

Adding mid-point insertion to cycle/0004/v002's narrow-geometry cold-first + LFU warm-fallback configuration will improve hit-rate by keeping scan insertions away from the MRU tail, reducing cold pool exhaustion frequency before the LFU fallback is even needed.

## Parent

cycle/0004/v002

## Changes

Add a new `src/associative_cache/associative_cache_bucket.rs` overlay while keeping
cycle/0004/v002's `src/shared/eviction_policy.rs` overlay completely unchanged.

The new `associative_cache_bucket.rs` overrides only the `put()` method with mid-point
insertion, following the same pattern as cycle/0003/v003's bucket overlay:

```rust
fn put(&mut self, item: Item<K, V>) -> (&Item<K, V>, Option<Item<K, V>>) {
    // Existing-key update path: unchanged.
    if let Some(position) = self.get_position(&item.key) {
        self.items[position].value = item.value;
        let pushed_item = self.get_from_position(position);
        return (pushed_item, None);
    }
    // Evict first so midpoint is computed on post-eviction size.
    let evicted_item = if self.is_full() { self.evict_item() } else { None };
    // Insert at midpoint: new items land in the middle of the recency order.
    let mid = self.items.len() / 2;
    self.items.insert(mid, item);
    (&self.items[mid], evicted_item)
}
```

No `evict_item` override in the bucket — the default trait implementation delegates to
`eviction_candidate_index`, which v002's `eviction_policy.rs` implements as cold-first
with LFU minimum-counter fallback. No geometry overlay (retains the baseline 128 × 16
narrow layout inherited from v002's baseline parent).

## Rationale

cycle/0004/v002 showed that cold-first + LFU warm-fallback on narrow 128 × 16 geometry
already beats the pure-LRU baseline (0.7231 vs 0.661). The LFU fallback fires whenever
the cold pool is exhausted. Mid-point insertion reduces how often that exhaustion
happens: landing new items at `len/2` rather than the MRU back prevents scan traffic
from pushing warm items toward the eviction front, keeping more counter-0 items alive
per bucket at any given time. The two mechanisms are complementary — one reduces the
eviction trigger rate, the other improves quality when it fires. cycle/0003/v003
confirmed mid-point insertion adds value on narrow geometry; this hypothesis tests
whether it stacks additively with the LFU fallback that v002 introduced on the same
geometry.

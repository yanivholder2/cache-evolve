# H02

Replacing uniform counter-decay with selective decay that decrements only items at the current minimum counter value will improve hit-rate by restoring cold candidates while preserving relative frequency ordering among the warmer items.

## Parent

cycle/0005/v003

## Changes

Modify only `src/associative_cache/associative_cache_bucket.rs`; leave `src/shared/geometry.rs` and `src/shared/eviction_policy.rs` unchanged from cycle/0005/v003.

In `evict_item()`, replace the warm-lock fallback (Step 2) — currently lines 101–108:

**Before (v003):**
```rust
// Step 2: warm-lock — all items have lfu_counter >= 1.
// Apply one-shot counter decay to break the warm-lock.
for item in self.items.iter_mut() {
    item.lfu_counter -= 1;
}
// Evict the LRU front (index 0); it is now cold (or near-cold) after decay.
Some(self.remove_at(0))
```

**After (this variant):**
```rust
// Step 2: warm-lock — all items have lfu_counter >= 1.
// Selective decay: only items at the minimum counter value are decremented to 0.
// This creates cold candidates while preserving relative frequency ordering
// among items with strictly higher counters.
let min_counter = self.items.iter().map(|i| i.lfu_counter).min().unwrap_or(1);
for item in self.items.iter_mut() {
    if item.lfu_counter == min_counter {
        item.lfu_counter = 0;
    }
}
// Evict the first newly-cold item; index-order favours the earliest insertion.
let cold_idx = self.items.iter().position(|i| i.lfu_counter == 0).unwrap_or(0);
Some(self.remove_at(cold_idx))
```

`min_counter` is guaranteed ≥ 1 (all items are warm at this point), so the `unwrap_or(1)` path is unreachable in practice. After selective decay, items that were at `min_counter` become cold (0); items at `min_counter + 1` through 4 retain their counter values unchanged.

Everything else is unchanged from cycle/0005/v003:
- Wide-bucket geometry (factor-4 repartition): unchanged.
- `ClassicLRU::get_from_position` counter increment capped at 4: unchanged.
- Mid-point insertion in `put()`: unchanged.
- Cold-first scan (Step 1) looking for `lfu_counter == 0`: unchanged.
- Counter cap at 4: unchanged.

## Rationale

Cycle 0005 showed that uniform decay compresses inter-item counter differences to near-zero: after a single pass every counter drops by 1, so an item with counter 3 and one with counter 1 both survive or perish at the same relative disadvantage. The minimum-counter scan that follows then becomes noise-limited. Selective decay targets only the boundary items (those at the minimum) and demotes them to cold status while leaving all strictly warmer items untouched. The result: after each warm-lock event the frequency ranking among items at counters 2–4 is fully preserved, and only the genuinely least-accessed items (those already at the floor) are made evictable. This is the smallest possible intervention needed to restore cold supply.

# H01

Applying position-weighted counter decay during warm-lock in v003 — decaying older (lower-index) bucket items by 2 and recently-accessed (upper-index) items by 1 — raises hit rate by preserving frequency signal for hot items while still breaking warm-lock.

## Parent

cycle/0008/v003

## Changes

Modify only `src/associative_cache/associative_cache_bucket.rs`. In `evict_item()`, replace the
current uniform bulk-decay loop (Step 2, warm-lock path):

```rust
for item in self.items.iter_mut() {
    item.lfu_counter = item.lfu_counter.saturating_sub(2);
}
```

with a position-split loop:

```rust
let mid = self.items.len() / 2;
for (i, item) in self.items.iter_mut().enumerate() {
    if i < mid {
        // Lower half: older items closer to eviction front — decay aggressively (rate 2)
        item.lfu_counter = item.lfu_counter.saturating_sub(2);
    } else {
        // Upper half: newer / recently-accessed items — decay conservatively (rate 1)
        item.lfu_counter = item.lfu_counter.saturating_sub(1);
    }
}
```

Everything else in `associative_cache_bucket.rs` is unchanged from v003:
- Step 1 (cold-first scan for `lfu_counter == 0`) is untouched.
- The warm-lock fallback eviction remains `self.remove_at(0)`.
- Mid-point insertion in `put()` is untouched.

`eviction_policy.rs` (ClassicLRU with counter cap at 4) and `geometry.rs` (factor-4
wide-bucket repartition) are carried forward **without modification** from v003.

**Invariants to preserve:** capacity conservation in geometry; no underflow on
`saturating_sub`; cold-first eviction fires before decay (Step 1 before Step 2).

## Rationale

v003 improved hit rate by decaying all items by 2 rather than 1, converting the
"counter==2 lukewarm tier" to cold in one pass. However, uniform decay collapses
counter differences across the whole bucket, eroding the frequency signal for recently
promoted items (high index, high counter) that are genuinely hot. Position is already
a reliable recency proxy under mid-point insertion (index 0 = oldest). Applying a
gentler decay to the upper half preserves those items' counter values while still
creating cold candidates from the older lower half — the exact portion that warm-lock
has shown to be under-turned.

# H01

Replace FIFO stash eviction with LRU-ordered stash to improve hit rate by preserving recently-accessed evictions longer than stale ones.

## Parent

cycle/0001/v001

## Changes

Modify the stash mechanism in AssociativeCache to track access timestamps rather than using FIFO eviction. Add a `last_accessed` timestamp field to track when each stashed item was last accessed (both on initial eviction and on stash hits). When adding a new item to a full stash, evict the stashed item with the oldest `last_accessed` timestamp rather than removing the first item. Update `get_and_update_item()` to record the current timestamp when a stash hit occurs, ensuring recently re-accessed evictions stay in the stash longer. This preserves working-set items with temporal re-use patterns while discarding truly cold evictions more aggressively.

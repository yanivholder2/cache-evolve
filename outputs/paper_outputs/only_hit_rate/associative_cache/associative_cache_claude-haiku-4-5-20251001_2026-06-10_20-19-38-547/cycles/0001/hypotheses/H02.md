# H02

On bucket overflow, probe neighboring buckets and displace less-accessed items instead of evicting locally, raising hit rate by redistributing collision load across buckets.

## Parent

baseline

## Changes

Modify the AssociativeCache::put() method to intercept overflow events before items are discarded. When a bucket reaches capacity and would evict (i.e., when the target bucket's put() returns Some(evicted_item)), before discarding that victim, iterate through neighboring bucket indices: [bucket_id - 1, bucket_id + 1] mod num_buckets. For each neighbor:

- If the neighbor has free space, place the victim there instead of discarding.
- If the neighbor is also full, identify its least-accessed item (using lfu_counter as the primary key, or timestamp as secondary) and consider displacing it. If displacing improves local load balance, swap the neighbor's victim into the primary bucket and place the primary victim in the neighbor.

If no suitable neighbor is found, discard as normal. This allows hot items in congested primary buckets to migrate to less-populated neighbors, raising hit rate by preventing useful data loss during collisions.

## Rationale

Cuckoo hashing principles suggest that victims can often find space in nearby hash positions. By redistributing rather than discarding, we keep more items in the cache and allow dynamic load-balancing across buckets.

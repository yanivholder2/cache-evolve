# H03

Consolidate the entire 25% stash capacity into a single unified tier to test whether the two-tier structure adds unnecessary complexity without measurable performance benefit.

## Parent

cycle/0007/v001

## Changes

Replace the two-tier stash (hot_stash and cold_stash) with a single unified_stash of 25% total capacity.

**Data structure** (in `AssociativeCache<K, V>`): Remove `hot_stash: Vec<Item<K, V>>`, `hot_stash_capacity: usize`, `cold_stash: Vec<Item<K, V>>`, and `cold_stash_capacity: usize`. Add a single field `unified_stash: Vec<Item<K, V>>` and `unified_stash_capacity: usize`.

**Initialization** (in `try_new`): Calculate `unified_stash_capacity = std::cmp::max(1, total_capacity * 25 / 100)`. Initialize `unified_stash` with this capacity.

**Eviction logic** (in `put`): When bucket eviction occurs, add the evicted item to `unified_stash` using FIFO logic (remove oldest if at capacity).

**Lookup logic** (in `get_and_update_item`): After primary bucket miss, search the unified stash linearly. On hit, remove the item from the stash (or keep it), but do not promote between tiers. Return the value.

**Remove** the `promote_cold_to_hot()`, `add_to_cold_stash()` methods and all associated promotion logic.

This simplification eliminates the promotion overhead and two-tier management complexity entirely. The unified stash acts as a simple FIFO victim cache with no learning or differentiation.

## Rationale

The cross-cycle patterns show that "simple unconditional mechanisms outperform complex selective ones." The two-tier structure with promotion-on-hit adds complexity (conditionals, promotion overhead, partition management). This hypothesis tests whether that complexity yields measurable benefit or whether a simple unified FIFO stash, with the same 25% capacity but no tiering overhead, achieves comparable or better results. If this regresses significantly, it validates that the two-tier distinction is essential; if it improves or matches, it suggests the partition tuning (H01) is the real lever, not the organizational structure.

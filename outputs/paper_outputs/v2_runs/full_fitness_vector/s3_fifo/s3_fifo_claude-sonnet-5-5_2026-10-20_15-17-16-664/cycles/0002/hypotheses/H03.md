# H03

Pairing the baseline's 10%-style small queue with a separate main-eviction ghost of bounded size recovers ghost recycling's benefit without weakening the one-hit-wonder filter, raising hit rate.

## Parent

baseline

## Changes

In the overlay source, keep the baseline small/main/ghost structure and promotion threshold, but set the small-queue ratio to 10% as in v002. Do not insert main-evicted keys into the existing ghost. Instead, add a second small ghost FIFO (capacity about 25% of the main-queue capacity, using the same key-only entry representation as the existing ghost, so per-entry metadata does not grow) that records keys evicted from main. On a miss, if the key is found in the main-ghost, insert it directly into main (like a ghost hit); the original ghost continues to handle small-queue demotions only. Preserve all existing invariants (no duplicate keys across queues, capacity bounds).

## Rationale (optional)

Cycle 1's v003 recycled main evictions into the shared ghost, which diluted the demotion filter and lowered hit rate; a separate ghost redesigns that idea as suggested by the cycle insight.

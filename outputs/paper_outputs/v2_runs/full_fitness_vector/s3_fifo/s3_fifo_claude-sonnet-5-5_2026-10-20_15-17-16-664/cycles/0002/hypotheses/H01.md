# H01

Lowering the small-to-main promotion threshold to freq>=1 on top of v002's 10% small queue raises hit rate.

## Parent

cycle/0001/v002

## Changes

In the S3-FIFO overlay source (the file defining the small-queue eviction routine), find the branch that decides whether a small-queue tail object is promoted to main or demoted to ghost. Change the promotion condition from the baseline threshold (freq > 1 / freq >= 2) to `freq >= 1`. Keep v002's 10% small-queue ratio constant unchanged. Do not change the main-queue reinsertion logic, the freq cap, the ghost handling or the metadata layout (metadata-size must stay 24).

## Rationale (optional)

Retries the promotion-threshold idea that was lost to an infrastructure failure (Maven 429) in cycle 1, now combined with the best-known ratio.

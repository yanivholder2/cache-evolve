# H01

Lowering the small-to-main promotion threshold from freq>1 to freq>=1 in `evict_small` raises hit rate on workload-a by promoting once-reused entries.

## Parent

baseline

## Changes

In `src/s3_fifo/mod.rs`, `evict_small()`: change the condition `tail.freq > 1` to `tail.freq >= 1`. Reset `tail.freq = 0` before pushing into `main` so the entry must earn its main-queue residency afresh. Leave `get`, `put`, `evict_main`, capacity partition and ghost handling untouched. Preserve invariants: small.len()+main.len() <= capacity, ghost.len() <= main_size. Existing unit test `small_eviction_promotes_to_main_after_multiple_hits` must still pass.

## Rationale (optional)

Baseline requires two hits to graduate; LIRS-style traces with loops/reuse likely have many one-hit-reuse keys that get ghosted then re-admitted at a cost.

# H03

Recording main-queue evictions in the ghost queue and giving ghost-hit re-admissions a starting freq of 1 raises hit rate by letting premature main evictions recover into main.

## Parent

baseline

## Changes

In `src/s3_fifo/mod.rs`:
1. `evict_main()`: when the loop breaks on a tail with `freq == 0`, instead of dropping that entry silently, push its key onto `self.ghost` front (first `pop_back` the ghost if `ghost.len() >= main_size`). Borrow-check by taking the popped entry's key out before pushing.
2. `put()` ghost-hit branch: construct the entry via `Entry::new(key, value)` then set `entry.freq = 1` before `main.push_front`, so a freshly readmitted key survives one main sweep.
Keep `evict_small` logic and the small/main/ghost sizing unchanged. Invariants: ghost.len() <= main_size; a key must not be in both ghost and resident queues (ghost retain on hit already removes it before reinsertion). Note evict_main is also called from evict_small's promotion path; the ghost insertion applies there too.

## Rationale (optional)

Baseline forgets main-evicted keys entirely, so a mistaken eviction costs a full cold re-admission through small.

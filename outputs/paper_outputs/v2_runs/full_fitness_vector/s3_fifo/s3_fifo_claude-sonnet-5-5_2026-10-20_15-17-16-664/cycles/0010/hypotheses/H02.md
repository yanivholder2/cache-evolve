# H02

Admitting a ghost hit to main only when the ghost entry is recent (within the newest half of the ghost ring) will raise hit rate without loosening the small-queue filter for stale ghosts.

## Parent

cycle/0009/v001

## Changes

Keep the ghost ring and its split ghost map. Where `put` checks whether the incoming key is in the ghost and, if so, inserts it directly into main, add an age check. Compute the ring distance between the ghost's current write position and the key's recorded position, using a sequence number stored in the ghost map value. Insert into main only if the distance is below `ghost_capacity / 2`. Otherwise treat the key as a fresh miss and insert into small. Do not change the ghost capacity, and do not change the insertion of evicted small keys into the ghost. This adds a `u32` or `u64` sequence field to the ghost map value and a monotonic counter to the cache struct. Preserve capacity invariants.

## Rationale (optional)

This is the "ghost-policy idea that keeps main admission strict" open question from the insights file. Stale ghost re-admits are the likeliest source of weak main entries.

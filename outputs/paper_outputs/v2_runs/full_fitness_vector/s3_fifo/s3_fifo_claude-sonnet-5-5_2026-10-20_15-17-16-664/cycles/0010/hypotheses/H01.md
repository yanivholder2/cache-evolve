# H01

Resetting an object's frequency to zero when it is promoted from the small queue to main will raise hit rate by making main admission stricter.

## Parent

cycle/0009/v001

## Changes

In the small-queue eviction path (where an entry with freq above the promotion threshold is moved to main), set `slot.freq = 0` and `in_main = true` on promotion, rather than carrying over the accumulated small-queue freq. Leave the promotion threshold, small ratio, freq cap, ghost, and the single `resident.get_mut` lookup unchanged. Main-eviction reinsertion logic (decrement and rotate) stays as is. Invariant: the cache never exceeds capacity, and `get` and `put` semantics are otherwise unchanged.

## Rationale (optional)

Cross-cycle insights say loosening main admission hurts. A promoted object with stale high freq stays in main longer. Resetting it tightens retention without touching the one-hit-wonder filter.

# H01

Replace the default SipHash hasher in the membership index with a cheap multiplicative (Fx-style) hasher to lower per-op-time at unchanged hit rate.

## Parent

cycle/0004/v001

## Changes

In the overlay's S3-FIFO source (src/s3_fifo/ overlay file), every hash-index/`HashMap`/`HashSet` used for small/main/ghost membership is currently built with the std `RandomState` (SipHash). Add a small private `BuildHasherDefault<FxLikeHasher>` type implemented in the same file (no new crates; Cargo.toml is off limits): `write_u64` does `self.0 = (self.0.rotate_left(5) ^ x).wrapping_mul(0x517cc1b727220a95)`, with the generic `write` folding bytes the same way. Switch all index maps to this hasher and create them with `with_capacity_and_hasher` sized to the cache capacity so no rehash happens on the `put` path. Do not change eviction, promotion, queue sizes, or the reported metadata size. Hit/miss sequence must remain identical to the parent.

## Rationale (optional)

v001 showed hash lookups dominate the median op once scans were removed; hashing cost is the next constant factor.

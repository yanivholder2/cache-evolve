# H02

Give objects re-entering from the main-eviction ghost an initial frequency of 1 to raise hit rate on workload-a.

## Parent

cycle/0003/v001

## Changes

Starting from v001 (scan-consolidated, behavior-preserving), reintroduce a separate bounded main-eviction ghost (as in the cycle-2 design: a distinct FIFO of keys evicted from main, sized to main capacity, kept apart from the small-queue demotion ghost so the shared ghost stays clean). On `put` of a key found in this main ghost, insert it directly into main (not small) with freq set to 1, so it survives its first eviction rotation. Keys found in the normal small-queue ghost keep baseline behavior. Remove the key from the main ghost when re-admitted; trim the main ghost by FIFO when exceeding its bound. Do not alter the promotion threshold (baseline retained) and do not add a rotation cap. Use the scan-consolidated lookup helpers from v001 for the ghost membership check.

## Rationale (optional)

Cross-cycle notes ask whether the main-ghost needs a freq head start on re-entry.

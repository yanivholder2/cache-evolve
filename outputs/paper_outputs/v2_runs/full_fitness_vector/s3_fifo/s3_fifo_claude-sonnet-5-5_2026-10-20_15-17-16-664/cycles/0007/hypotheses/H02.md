# H02

Admitting a main-evicted key to a small, separate O(1) tagged "recent-main" filter that only influences small-queue eviction ties (not main admission) will raise hit rate.

## Parent

cycle/0004/v001

## Changes

Keep the existing main admission, promotion threshold and ghost unchanged. Add a bounded ring (about 10% of capacity) plus membership flag recording keys evicted from main. When a key in this filter is re-inserted via `put`, it still goes into the small queue exactly as now (no freq head start, no ghost bypass), but when small-queue eviction pops a candidate with freq 0 that is present in the filter, it is given one reinsertion to the small queue tail (clearing the filter flag) instead of being evicted, bounded to one retry per entry. Everything else stays identical. Implement the filter membership through the existing index tags if available to avoid extra hash probes; otherwise a single extra map lookup only on small-eviction of freq-0 entries.

## Rationale (optional)

Hit-rate ideas that loosen main admission failed; this one leaves admission untouched and only gives a second chance in small.

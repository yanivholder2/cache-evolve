# H01

Replace the Vec/linear ghost trimming in the put path with an O(1) ring-buffer ghost to cut per-op-time without changing hit rate.

## Parent

cycle/0004/v001

## Changes

In the S3-FIFO overlay source (the file implementing put/evict/ghost handling), keep v001's hash-index membership. Change the ghost queue to a fixed-capacity ring buffer (VecDeque or array with head/tail) holding key hashes, with the same capacity as v001's current ghost bound. Ghost trimming must be a single pop_front when over capacity, never a scan or `remove(0)`-style shift. Ghost membership uses the existing index (or a hash set kept in sync on push/pop). Keep admission, promotion threshold, small-queue ratio and eviction order exactly as in v001, so the hit/miss sequence is identical. Preserve per-entry metadata size (24).

## Rationale (optional)

Cycle 0004 found the put tail comes from eviction and ghost trimming, not membership checks.

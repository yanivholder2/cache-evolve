# H02

Replace v003's stamped key-cloning ghost with a fixed-size ring buffer of 64-bit key fingerprints to cut per-op-time while leaving hit-rate unchanged.

## Parent

cycle/0002/v003

## Changes

All edits are in `src/s3_fifo/mod.rs`. Policy decisions must stay identical to v003: the same adaptation triggers, the same clamps, and the same graduation rule (`freq > 1`).

1. **New ghost representation.** Remove `ghost: VecDeque<(K, u64)>`, `ghost_set: FxHashMap<K, u64>`, `ghost_stamp`, and the `retain` compaction. Replace them with:
   - `ghost_ring: Vec<u64>`, preallocated to exactly `ghost_cap` slots. Each slot holds a fingerprint, with `0` reserved for "empty".
   - `ghost_head: usize`, the next write position. The ring wraps.
   - `ghost_map: FxHashMap<u64, u32>`, mapping a fingerprint to its ring position.
   - Keep `ghost_live` for the test invariants.

   Compute the fingerprint as `fp(key) = FxHasher` over the key, finished, then `| 1` so it is never 0. Hash with the same `FxBuildHasher` already defined.

2. **`ghost_push(key)`**: compute `f = fp(&key)`. If `ghost_ring[ghost_head] != 0`, remove that old fingerprint from `ghost_map`, but only if the map still points at `ghost_head`, and decrement `ghost_live`. Write `f` at `ghost_head`, insert `(f, ghost_head)` into `ghost_map` (if `f` was already present, overwrite it and clear its old ring slot to 0 so it is not counted twice), increment `ghost_live`, and advance `ghost_head = (ghost_head + 1) % ghost_cap`. Keys are never cloned into the ghost, so `ghost_push` no longer needs `K: Clone` on this path.

3. **`ghost_take(&key)`**: compute `f`. If `ghost_map.remove(&f)` returns position `p`, set `ghost_ring[p] = 0`, decrement `ghost_live`, and return true. Delete `ghost_pop_oldest_live`. FIFO order is now implicit in the ring: overwriting the head slot evicts the oldest record.

4. **Hot-path tightening for `get`**, which is what the per-op-time summary measures. Keep `slots: Vec<Option<Entry>>`. In `get`, have the lookup return the slot index and access `self.slots[i as usize]` once, matching on it directly, with no second `index` probe. Make sure `get` and `put` are `#[inline]`. Do not use `unsafe`.

5. **Tests.** Update `adaptive_split_keeps_bounds` to assert `ghost_live <= ghost_cap` and `ghost_live == ghost_map.len()`, and drop the `ghost_phys_bound` assertion along with the function. Update `index_tracks_residency` to check that `!ghost_map.contains_key(&fp(&e.key))` for residents. That check can give a false failure only if two 64-bit fingerprints collide, which is negligible in these tests.

## Rationale (optional)

Every miss in v003 clones `K` into two structures and maintains stamps. Once the deque passes 2×`ghost_cap`, the next push also runs an O(ghost_cap) `retain` compaction, which drives `put` p99. A fixed ring removes the clones, the stamps, and the compaction, and bounds ghost memory at `ghost_cap * 8` bytes plus the map. Fingerprint collisions could produce a spurious ghost hit at a rate of roughly `ghost_cap / 2^64`, so hit-rate should stay at 0.7282 to four decimal places. If it does not, the ring's FIFO semantics differ from the lazy-deletion ghost, and the implementer should check whether a re-pushed key is double-counted.

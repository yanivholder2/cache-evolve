# H01

Lowering the adaptive split's minimum small-queue clamp from `capacity/16` to `capacity/64` will raise hit-rate on workload-a by letting ghost hits keep growing main past the current floor.

## Parent

cycle/0004/v003

## Changes

One lever: the lower clamp on `small_size`. Everything else stays byte-identical to the parent. That includes the upper clamp `capacity / 2`, the graduate-while-main-full grow-small trigger, `freq > 1` graduation, `MAX_FREQ`, and the ghost ring. Ghost size must stay pinned. `ghost_cap` and `ring_len` are still set from the *initial* `main_size` in `try_new` (1536 at capacity 2048) and must not be tied to the new clamp.

- In `put`, ghost-hit branch: change the guard
  `self.small_size > (self.capacity / 16).max(1)` to
  `self.small_size > (self.capacity / 64).max(1)`.
  Make the floor a named constant or helper (e.g. `fn small_floor(&self) -> usize { (self.capacity / 64).max(1) }`) so the experiment is clearly a single edit. The fix-up evictions after the shrink stay as they are (`evict_small_inner(false)`, then `evict_main` if over).
- Keep the invariants checked by `adaptive_split_keeps_bounds`: `small_size + main_size == capacity`, `small_size >= 1`, `main_size >= 1`, `ghost_live <= ghost_cap`.

Instrumentation, which cycles 1–4 asked for and never got: add `#[cfg(test)]` counters, or a `pub fn split(&self) -> (usize, usize)` accessor, plus an in-file `#[cfg(test)]` test. The test replays a Zipf-like synthetic stream at capacity 2048 and prints the settled `small_size` and how often the floor guard blocked a shrink. Run it for both the parent's clamp and the new one, and state both values in the variant notes. If the parent never hits the `capacity/16` floor (128), report that, because it shows this lever is inert. Do not edit `tests/` or `src/bin/`.

## Rationale (optional)

Cycle 0004 found that the clamps absorb ghost-length changes. If the split is pinned at the floor, the clamp is the binding constraint and loosening it is the only way to find out whether more main would help. If the split never reaches the floor, the result is still informative: hit-rate stays flat and the settled-`small_size` report finally answers the open question.

# H03

Weaken ghost readmission so a ghost-hit key re-enters the small queue with freq 1 instead of going straight to main, to raise hit-rate by keeping long-reuse-distance keys out of main.

## Parent

cycle/0008/v001

## Changes

This is a single policy lever on the ghost-hit branch of `put` in `src/s3_fifo/mod.rs`. Leave the split adaptation, the floor, the ghost sizing and the layout unchanged.

- **Keep the adaptation.** In the `if self.ghost_take_fp(f)` branch of `put`, keep the full adaptation block as it is: shrink small by one when above `small_floor()`, the `evict_small_inner(false)` and `evict_main` fix-ups, and the `floor_blocks` stats.
- **Insert into small instead of main.** Replace the tail of the branch, which today is `if self.main.len() >= self.main_size { self.evict_main(); }` followed by `alloc_with_key` and `self.main.push_front(i)`:
  - If `self.small.len() >= self.small_size`, call `self.evict_small()`. This uses the normal adaptive path, the same as a cold miss.
  - Allocate with `alloc_with_key`, set the packed word to `FREQ_ONE | i` (freq 1) through the returned slot's index entry, and `self.small.push_front(i)`.

  The key then graduates to main only if it receives at least one real `get` while in small, reaching `freq > 1`. Otherwise it is evicted from small and ghosted again.
- **Adjust the existing test.** `ghost_hit_promotes_back_to_main` must change. After the ghost re-put, assert that the key is resident in small with freq 1. Then call `get` on it once, push enough new keys to evict it from small, and assert that it is now in main.
- **Add a test.** Add a test showing that a ghost-hit key with no further `get` is evicted from small and does not enter main.
- **Reporting.** Keep `h01_split_report`, and also print `settled_small` and `floor_blocks` in the insight so the split effect is visible.

## Rationale (optional)

Every change that made the ghost path stronger has lost hit-rate: ghosting main victims (0002), readmission with extra freq credit (0005), and a full-capacity ghost (0008). Each time, the cause was keys with a long reuse distance displacing proven main residents. This takes the opposite direction, which is untested: a ghost hit now only earns one credit toward graduation. The split adaptation still fires, so main still grows on ghost evidence, but main is filled only with keys whose reuse has been confirmed. Hit-rate above 0.7309 would confirm that direct ghost-to-main admission was costing hits. A loss would show that direct readmission is part of what makes the incumbent policy work.

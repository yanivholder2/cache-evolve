# H03

Lowering the adaptive split's upper clamp on `small_size` from `capacity/2` to `capacity/4` keeps main at least 75% of the cache during grow-small bursts, and so raises hit-rate on workload-a.

## Parent

cycle/0008/v001

## Changes

This is a single policy-bound lever and is the counterpart of the `capacity/64` floor change in 0005. Add `const SMALL_CEIL_DIV: usize = 4;` and a helper `fn small_ceil(&self) -> usize { (self.capacity / SMALL_CEIL_DIV).max(self.small_floor()) }`. Under `#[cfg(test)]`, the helper reads an override field `ceil_div` that defaults to `SMALL_CEIL_DIV`, mirroring the existing `floor_div` pattern. In `evict_small_inner`, replace the grow-small guard `self.small_size < self.capacity / 2` with `self.small_size < self.small_ceil()`.

For `capacity/4` to bind, `try_new` must not start small above the ceiling. The initial `(capacity / 4).max(1).min(capacity - 1)` already equals the ceiling, so leave it as is.

Keep everything else unchanged:
- the ghost ring length and `ghost_cap`, which stay pinned to the initial main size
- the shrink step
- the floor
- the graduation rule
- `MAX_FREQ` and decrement drain
- the `get`/`put` code paths outside that guard

Add a `#[cfg(test)]` counter `stats.ceil_blocks`, incremented when a graduate-while-main-full would have grown small but the ceiling blocked it. Extend `h01_split_report` to sweep `ceil_div ∈ {2, 4}` and print `settled_small`, `max_small` (a new stat tracked alongside `min_small`), `grows` and `ceil_blocks`. Extend `adaptive_split_keeps_bounds` to assert `small_size <= small_ceil()`.

## Rationale (optional)

Hit-rate has only moved through the policy's bounds (0005 floor) or its depth (0008 `MAX_FREQ`), never through trigger rates. The lower bound has been probed but the upper bound never has. If the lopsided grow trigger lets small swell past its starting quarter during scan or loop phases of the LIRS trace, capping it protects main's long-reuse residents. If hit-rate stays at 0.7309 to the fourth decimal, the ceiling never binds on workload-a. That would settle the question for the last remaining untested bound.

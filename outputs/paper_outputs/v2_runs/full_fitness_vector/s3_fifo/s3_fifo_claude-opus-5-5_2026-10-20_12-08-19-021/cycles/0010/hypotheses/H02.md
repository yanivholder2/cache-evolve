# H02

Resetting a small-queue graduate's packed freq to 0 when it moves into main stops it from getting free second-chance laps for hits it earned in small, and so raises hit-rate on workload-a.

## Parent

cycle/0008/v001

## Changes

Change only the graduation branch of `evict_small_inner` (the `if (*self.packed_mut(i) >> FREQ_SHIFT) > 1` branch). The graduation test still reads freq, and freq > 1 is still required. Immediately before `self.main.push_front(i)`, clear the frequency bits of the graduate's packed index entry and keep its slot id: `let e = self.packed_mut(i); *e &= SLOT_MASK;`. To avoid a second hash probe, keep the `&mut u32` from the graduation test, or re-read it once and use it for both the test and the reset, so the extra cost is one store.

Everything else stays the same:
- the `main_full` / `evict_main` ordering
- the grow-small adjustment and its `capacity/2` clamp
- the ghost path, including readmitted keys still entering main at freq 0
- `MAX_FREQ = 3` with decrement drain
- the `get` path

Add a unit test in `src/s3_fifo/mod.rs`. It puts a key, `get`s it 3 times, forces it to graduate through `evict_small`, and asserts that `index[&key] >> FREQ_SHIFT == 0` and that the key is in main. Also update `small_eviction_promotes_to_main_after_multiple_hits` if it checks freq. Print `main_rotations` in `h01_split_report` so the change in drain work can be seen.

## Rationale (optional)

In the parent, a graduate enters main with freq 2–3, which buys it 2–3 laps even if it is never touched again. Ghost readmits enter at 0. Graduation into main is already the reward for reuse in small, as with readmission (0005 showed that extra credit on readmit hurts). Main residency should then depend only on hits taken while in main, which is the original S3-FIFO intent. This is a single lever that has not been tested: the 0003 test bundled it with a static split and a looser graduation rule. It should also shorten CLOCK drains on `put`. If hit-rate falls below 0.7309, early-small hits predict reuse in main and the credit is worth keeping.

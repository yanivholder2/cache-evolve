# H01

Packing the 2-bit `freq` counter into the top bits of the `u32` slot id stored in `index` removes the separate `freqs` array, cutting `get` per-op-time while keeping the 8-byte `Entry`.

## Parent

cycle/0007/v001

## Changes

Policy-neutral layout refactor of 0007 v001. Delete the `freqs: Vec<u8>` field.
Store the frequency in the hash-index value, so a hit touches the bucket it has
already probed and then `slots[i].value`, with no second array access.

- Change `index: FxHashMap<K, u32>` so the value packs `(freq << 30) | slot`.
  Add `const SLOT_MASK: u32 = (1 << 30) - 1` and `const FREQ_SHIFT: u32 = 30`.
  `MAX_FREQ = 3` fits exactly in 2 bits. Tighten `try_new` to reject
  `capacity > SLOT_MASK as usize + 1` (it currently checks `u32::MAX`), and log
  an error the same way as the existing check.
- `get`: use `let e = self.index.get_mut(key)?;`. Read `f = *e >> FREQ_SHIFT`.
  If `f < MAX_FREQ`, write `*e += 1 << FREQ_SHIFT`. Return
  `&self.slots[(*e & SLOT_MASK) as usize].value`. Only one hash probe is allowed.
- `put` hit path (`index.get(&key)`): mask with `SLOT_MASK` before indexing
  `slots`. Do not touch freq here; the parent doesn't either.
- `alloc_with_key`: insert `i` with freq 0, so the packed value is just `i`.
  Remove both `freqs` writes.
- `evict_main`: for each popped slot `i`, look up its packed entry with
  `self.index.get_mut(self.keys[i].as_ref().unwrap())`. If freq > 0, decrement
  by `1 << FREQ_SHIFT` and rotate to the front. Otherwise call `release(i)`.
  The decision sequence must match the parent's exactly.
- `evict_small_inner`: get the graduation test `freq > 1` the same way, from
  the index entry of `keys[i]`.
- `release`: unchanged. It already removes by key, and the stored freq goes
  with it.
- Test helpers: `alloc(key, value, freq)` sets the packed freq through
  `index.get_mut`. `repeated_get_clamps_frequency` reads the freq from
  `index[&1] >> FREQ_SHIFT`. Update `adaptive_split_keeps_bounds` to drop the
  `freqs.len()` assertion. Keep `entry_is_8_bytes`. Add an assertion that
  `size_of::<(u64, u32)>() == 16`, so the bucket does not widen.

Invariants: hit-rate must match 0007 v001 and 0006 v002 bit for bit. The
`h01_split_report` replay must still print the same `settled_small`. Expected
trade: `get` gets faster (one structure touched per hit). `put` and eviction pay
one extra hash probe for each examined main or small victim. Accept that,
because the summary per-op metric tracks `get`.

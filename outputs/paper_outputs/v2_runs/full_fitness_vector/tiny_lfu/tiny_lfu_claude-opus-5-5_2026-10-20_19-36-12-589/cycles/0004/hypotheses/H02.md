# H02

Adding periodic counter halving (a TinyLFU reset every 10×capacity increments) on top of conservative update will raise hit rate by letting stale frequencies decay.

## Parent

cycle/0003/v003

## Changes

All edits are in `CountMinSketch` and its construction in `src/tiny_lfu/mod.rs`.

1. Add two fields to `CountMinSketch`: `additions: u32` and `sample_size: u32`. Pass `sample_size` to `CountMinSketch::new(width, sample_size)` from `TinyLfuCache::try_new` as `(capacity * 10).min(u32::MAX as usize / 2) as u32`, with a floor of 16.
2. In `increment_hash`, keep v003's conservative-update logic unchanged. After the write-back, add `self.additions += 1; if self.additions >= self.sample_size { self.reset(); }`. The branch should be predictably not-taken. Mark `reset` as `#[cold] #[inline(never)]` so the hot path stays small.
3. `fn reset(&mut self)` halves every counter in place (`*c >>= 1` over `counts`, a simple loop the compiler can vectorise). It then sets `self.additions /= 2`, which matches Caffeine's behaviour of keeping about half the sample's weight.
4. Keep `u32` counters and `MAX_COUNT = u32::MAX`. Do not lower the counter cap. Cycle 0002's aging failure came from a coarse 4-bit cap creating ties. This hypothesis isolates decay alone, paired with conservative update.
5. Keep admission strict (`incoming_freq > victim_freq`, ties go to the victim). Do not touch the list or `Node`. `Node` must stay 24 bytes.

Add unit tests. One checks that after `sample_size` increments every counter has been halved. One checks that a key with estimate 1 drops to 0 after a reset.

## Rationale (optional)

The cross-cycle open question is whether aging helps once conservative update limits overestimation. In cycle 0002, aging failed alongside a 4-bit cap and plain CountMin increments. With full-width counters and conservative update, halving should mainly remove frequency that hot-then-cold keys built up long ago, so a newly hot key can displace them sooner. The extra per-op cost is one increment, one compare and one rarely taken branch. Reject the hypothesis if hit rate does not exceed v003's 0.7401.

# H01

Key the index map by the already-computed 64-bit `key_hash` with an identity hasher, so every `get` and `put` hashes the key exactly once, cutting per-op-time with hit rate unchanged.

## Parent

cycle/0006/v001

## Changes

Today `get` calls `key_hash(key)` for the sketch and then `self.map.get(key)` hashes the
key again with `FxLikeHasher`. A steady-state full-miss `put` re-hashes three times on the
map side: the `map.get(&key)` hit check, `map.remove(&old_key)` and `map.insert(key, ..)`.
Separately, it hashes the victim key once more for `estimate_hash`.

1. Add a zero-cost `IdentityHasher` (a `Hasher` whose `write_u64` stores the value and
   whose `finish` returns it. Other `write*` methods can fall back to an FxLike mix or
   `unreachable!`, because only `u64` is fed in). Change `map` to
   `HashMap<u64, u32, BuildHasherDefault<IdentityHasher>>`, keyed by `key_hash(&key)`.
   `fmix64` output is already avalanched, so SwissTable's top-7-bit tag and its low-bit
   bucket selection both stay well distributed.
2. `get`: compute `let h = key_hash(key)` once, call `self.sketch.increment_only(h)`, then
   `let &idx = self.map.get(&h)?`. Verify `self.nodes[idx as usize].key == *key` and
   return `None` if it doesn't match. The verification is a 64-bit-hash collision guard
   and must never return a wrong value. Set the ref bit only on a verified hit.
3. `put`: reuse `h` everywhere.
   - Fill phase: `map.entry(h)`.
   - Full-phase hit check: `map.get(&h)` plus key verification.
   - Victim: compute `let vh = key_hash(&self.nodes[victim].key)` once and use it for
     both `estimate_hash(vh)` and, on admission, `map.remove(&vh)`. Then call
     `map.insert(h, victim_idx)`.
4. Collision policy: if a different resident key already owns hash `h`, treat the
   newcomer as rejected (return without touching the map). This keeps map ↔ slot
   consistency (`map[hash(nodes[i].key)] == i` for every slot) and has no measurable
   effect on hit rate at these capacities.

Keep the following unchanged so that hit rate stays identical bit for bit:
- sketch increment order
- the CLOCK sweep
- hand movement
- the strict `>` duel

Do not add fields to `TinyLfuCache`. Update the in-file tests that index
`cache.map[&slot.key]` to index by `key_hash(&slot.key)`. `Node` must stay 16 bytes.

## Rationale (optional)

The cycle 0007 insights point at the steady-state full-miss map path as the remaining
latency target, and they ask about reusing `h` across the get/remove/insert calls. std's
`raw_entry` is unstable, so keying the map by the hash is the stable way to get one
hash per op. Unlike cycle 0006's v002 index-only table, SwissTable keeps the full key
(here, the hash) inline, so probing doesn't touch `nodes`. Only the verified hit loads
the node, and that load is needed anyway to return the value.

# H02

Re-lay out the `CountMinSketch` as a blocked sketch, putting all of a key's per-row counters inside one 64-byte cache line, to cut per-op-time with identical admission semantics.

## Parent

cycle/0002/v002

## Changes

Restructure the flat `counts` table inside `CountMinSketch` so that one key's
`depth` counters all sit in a single 64-byte-aligned block, instead of
`depth` separate rows spread across memory:

- Treat `counts` as `num_blocks` blocks of 64 bytes each. With the existing
  counter type, a block holds `64 / size_of::<Counter>()` counters. Round
  `num_blocks` to a power of two so that the total counter count is at least
  the current `depth × width`. The sketch's heap size must not grow by more
  than that rounding.
- From the single 64-bit hash that `key_hash` already produces, take the
  block index from the high bits (`(h >> 32) & (num_blocks - 1)`). Take each
  row's slot within the block from a different, non-overlapping slice of the
  low bits, one small bit-field per row. Do not compute any extra hash call.
- In `increment_hash` and the estimate function, compute the block base
  address once, then do the `depth` increments or reads as offsets from it.
  Keep the increment and min-reduction logic identical to v002, including the
  saturation behaviour. Do not add a new saturation check.
- Allocate `counts` 64-byte aligned, for example as a `Vec` of a
  `#[repr(align(64))]` block struct, so that one block never straddles two
  cache lines.
- Leave the cache list, the `u32` links, `put`/`get` control flow and the
  admission comparison unchanged.

## Rationale (optional)

Hashing was the dominant cost, and cycle 0001 fixed it. With one hash per op,
the next cost is likely the `depth` scattered cache misses into the sketch on
every get and put. A blocked layout turns those into one miss and adds no
branches, so it follows the one pattern that has reliably won here (layout-only
changes). Hit rate should stay within noise. A small drift is possible because
collisions are now correlated within a block.

# H01

Replacing the per-row mixing in the public sketch indexing with a const table of premixed per-row seeds will cut per-op-time below the parent's 93 ns while keeping hit-rate at 0.7379 and metadata-size at 32 (per-op-time).

## Parent

cycle/0005/v001

## Changes

Target the sketch row-index derivation that cycle/0005/v003 restored to the public per-row seeded mixing, which costs per-row work on both get and put. Keep the single precomputed hash per key from the parent. Replace the per-row call to the public seeded mixing function with a per-row step that uses a `const` array of premixed seed constants (one entry per sketch row, defined at module level, not stored per instance). Each row index should be computed as one xor with the row's premixed constant followed by the same reduction the public path applies (for example a multiply and shift, or the same modulus), so that the output equals the public per-row index for every key.

Before relying on the change, add a temporary `debug_assert!` in the overlay (not committed as a test, since `tests/` is out of scope) that compares the new index with the public per-row index on each call, run the workload once with it enabled, then remove it. The index equivalence must hold for all keys, not only in aggregate.

Do not change eviction order, the admission gate, the segmentation logic, the packed flag layout, or the `Node` and `TinyLfuCache` fields. Do not add per-instance storage for the seeds.

Accept only if hit-rate is 0.7379 (matching the public-path index result), metadata-size stays at 32, and get and put p50 fall below the parent's values. Use at least three repeated runs on workload-a at size 2048.

## Rationale (optional)

cycle/0005/v003 showed that the public per-row indexing restores admission fidelity but gives back most of the speed. Cycle 0005's insight names as its open question whether the same indices can be produced with less per-row work. Premixing the seed into a constant moves the mixing out of the hot loop while keeping the public index function.

# H02

Packing the sketch counters into 8-bit saturating cells with a cap of 255 (no nibble) is already in place, so halving the Node's remaining fields by dropping the stored key-hash cache will reduce metadata-size below 24 on the v001 lineage.

## Parent

cycle/0004/v001

## Changes

Inspect the Node struct in the overlay. Remove any cached per-node field that can be recomputed cheaply with the cheap map hasher (e.g. a stored hash or frequency copy), and recompute the hash from the key only on the eviction path (when the victim's sketch estimate is needed). Keep the hit path, which uses the map lookup and MRU short-circuit, unchanged so no hot-path work is added. Preserve admission semantics (strict greater-than, LRU-head victim) so hit-rate stays at 0.7406. If Node has no removable field, instead reorder fields and use u32 for any remaining u64 non-key field to shrink padding. Target metadata-size below 24 bytes.

## Rationale (optional)

Metadata-size tracks Node size only; this is the only remaining footprint lever without touching counters.

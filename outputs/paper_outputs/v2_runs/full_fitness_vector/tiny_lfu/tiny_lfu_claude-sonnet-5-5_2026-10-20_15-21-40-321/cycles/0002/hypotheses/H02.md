# H02

Add a periodic counter halving to v003's sketch with a long period (about 10x cache capacity in accesses) to raise hit-rate if the trace has frequency drift.

## Parent

cycle/0001/v003

## Changes

In v003's sketch, add one `u32` access counter in the sketch struct (not in Node). Increment it inside the sketch's `increment` path only. When it reaches `10 * capacity` (min 1024), halve every u8 counter with `c >>= 1` in one sweep and reset the counter. This is a much longer period than the cycle-0001 aging attempt (v001) so it does not hurt stable-frequency traces. Leave the hit path (`get`) untouched, with no extra work. Keep the single hash, conservative update, and strict-greater admission as is.

# H03

Pack two 4-bit saturating counters per byte in the baseline's sketch with a single hash to shrink the sketch footprint and cut cache misses in per-op-time.

## Parent

baseline

## Changes

Rewrite the baseline sketch to use a `Vec<u8>` where each byte holds two 4-bit counters (cap 15), indexed by one hash mixed once per op (splitmix64 finalizer, power-of-two mask). Use conservative update: increment only counters equal to the current minimum. Estimate is the minimum across the slots read. Size the table to the next power of two at or above the capacity, in nibbles. Keep the admission rule and Node layout unchanged. This tests whether a 4-bit cap (as in the original TinyLFU) costs hit-rate compared to v003's u8, in return for a smaller footprint.

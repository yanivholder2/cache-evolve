# H01

Replace the multi-step hash derivation in v003's sketch with a single 64-bit mix whose bit-slices pick the counter slots, to lower per-op-time.

## Parent

cycle/0001/v003

## Changes

In the sketch's index computation (the function that maps a key hash to counter indexes for `increment` and `estimate`), compute one multiply-xorshift mix (splitmix64 finalizer) of the key hash once per operation. Derive all row indexes from disjoint bit-slices of that result, using a power-of-two mask instead of modulo. Cache the computed hash from `get` so the following `put` on a miss does not recompute it, if the struct layout allows without adding Node fields. Keep the u8 saturating counters and conservative update unchanged. Keep the admission rule (strict greater) unchanged. Preserve the public API and Node size (48).

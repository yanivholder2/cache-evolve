# H01

Porting cycle/0002/v003's 24-byte logical-tick `Item` onto v002's merged-bucket SLRU cuts metadata-size from 40 to 24 bytes while keeping v002's ~0.718 hit rate.

## Parent

cycle/0002/v002

## Changes

Keep v002's `associative_cache_bucket.rs` and `mod.rs` (merged pair bucket, SLRU split at `len0`, 3/4 protected cap) exactly as they are. Bring over only the metadata shrink from cycle/0002/v003:

- Replace `src/shared/item.rs` with cycle/0002/v003's version: `timestamp: u32` (logical tick from a thread-local `CLOCK: Cell<u32>`), `lfu_counter: u32`, field order `key, value, timestamp, lfu_counter`, plus the `tick()`, `now()` and wrap-safe `is_newer()` helpers. `Item<u64,u64>` must be exactly 24 bytes. Keep the `item_u64_u64_is_24_bytes` unit test.
- Port every other `src/shared/` change v003 made so the crate compiles with the new field types. That covers each eviction policy in `src/shared/eviction_policy*` and its helpers that read `timestamp` (e.g. `Instant` comparisons become `is_newer(a, b)`, `Instant::now()` becomes `tick()`) or `lfu_counter` (widen/narrow arithmetic to `u32`, use saturating adds). Copy v003's code for these files. Do not redesign them.
- The SLRU path (`slru == true`) does not read `timestamp`, so `AssociativeCacheBucket::hit` and `pair_put` stay as they are, with no `tick()` calls. `Item::new` still stamps `tick()` once, so the non-ClassicLRU fallback policies keep working.

Invariants: P2 slot legality (each key only in `buckets[hash % len]`), capacity conservation, and the existing `slru_second_hit_protects` test all hold unchanged. No wall-clock reads anywhere on the hot path.

## Rationale (optional)

The cycle-0002 insight says the merged SLRU base and the 24-byte item are independent and should combine. This hypothesis tests that combination by itself, with no policy or layout change. A smaller `Item` also cuts the bytes moved by SLRU's `rotate_left`/`insert`/`remove` shifts, so expect a small put/get-p99 gain too. That latency effect is secondary. The claim being tested is metadata 24 with hit rate ≥ 0.715.

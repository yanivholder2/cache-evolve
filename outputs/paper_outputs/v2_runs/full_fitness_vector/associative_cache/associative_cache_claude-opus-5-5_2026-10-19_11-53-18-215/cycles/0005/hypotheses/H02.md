# H02

Raising SLRU's fixed protected fraction from 3/4 to 7/8 (with a floor of two probation slots) will raise hit rate above 0.7242 on the LIRS workload by strengthening scan resistance.

## Parent

cycle/0004/v003

## Changes

Change only how `protected_cap` is computed in
`AssociativeCacheBucket::with_layout` (`src/associative_cache/associative_cache_bucket.rs`):

```rust
let min_probation = 2.min(max_size);          // keep >= 2 probation slots when possible
let protected_cap = (max_size * 7 / 8).min(max_size.saturating_sub(min_probation));
```

For 1-slot buckets this gives `protected_cap == 0`, so the existing
`protected_cap == 0` branch in `hit()` still applies. For 2- and 3-slot
buckets it gives 0 and 1, which must not panic.

Keep everything else from v003 unchanged:
- the ghost ring and its length, `(max_size + 1) / 2`
- cold-key insertion at `len0 / 2`, and ghost-hit insertion at probation MRU
- the probation-only short-rotate eviction
- the forward `find`
- the demote-on-overflow rule in `hit()`

Do not add any adaptive resizing. The fraction is a fixed constant.

Update the unit tests that hard-code the 3/4 split:
- the `bucket8()` comment and `check_structure` expectations
- `slru_second_hit_protects` in `mod.rs`, which assumes protected cap 3 in a 4-slot bucket (it becomes 2 with the 2-slot probation floor)

Adjust these to the new caps. Do not touch anything under `tests/`.

Add a short doc note recording the chosen fraction. If the implementer wants
a quick sanity check, the constant can sit in one `const PROTECTED_NUM: usize = 7; const PROTECTED_DEN: usize = 8;`
pair, but only 7/8 is evaluated.

## Rationale (optional)

Every cycle so far shows that anything strengthening protected helps on this
trace and anything weakening it hurts (cycle 3 ghost-to-protected, cycle 4
adaptive cap). After four cycles the fixed fraction is still untested. The
2-slot probation floor keeps the ghost and mid-probation placement working:
with `len0 >= 2`, `len0 / 2 >= 1`, so cold keys still enter above probation
LRU.

# H03

A CLOCK-style second-chance victim selection with one reference bit per slot will capture part of the frequency hit-rate gain at a fraction of v003's put-side cost, targeting per-op-time while keeping hit-rate above baseline's 0.661.

## Parent

baseline

## Changes

Replace the recency-ordered victim choice in the baseline's eviction routine with a CLOCK (second-chance) scan. Do not move items within a bucket.

- Add one reference bit per slot, stored in a per-bucket byte or bitmask alongside the existing bucket state. Set it on every get hit. Clear nothing on get.
- Add a per-bucket clock hand (a small index, one byte). On a put into a full bucket, start at the hand, and for each slot: if its reference bit is set, clear the bit and advance; if it is clear, evict that slot, set the hand to the next position, and stop. The scan is bounded by one full revolution, so it always terminates.
- Initialise reference bits to clear on insert, so a freshly inserted item is evictable on the next pass unless it is hit again before the hand reaches it.
- Keep the baseline's insert, get-miss, and key-lookup code unchanged. Do not add the fingerprint prefilter or ghost memory. Do not change bucket width.
- Do not use per-slot counters. This hypothesis is deliberately a one-bit approximation, so it is a different mechanism from v003's frequency counters.

Expected test: hit-rate on workload-a should land above baseline's 0.661, though probably below v003's 0.728. Put p50 should stay near or below baseline's put cost, because the hand usually stops within a few slots and the clear-bit pass is cheap. Get p50 should rise only by the bit write on hit.

## Rationale (optional)

v003 showed that retaining re-referenced keys through one-shot bursts helps hit-rate, but its full-bucket minimum scan is the cost. CLOCK captures the "re-referenced keys survive" signal with amortised O(1) victim search. It also comes from the baseline, so the cohort gets a second route to the same signal that does not depend on v003's counter write on every hit.

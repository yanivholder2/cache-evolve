# H03

Replacing the baseline's recency-ordered victim choice with a 2-bit SRRIP-style re-reference value per slot will raise workload-a hit-rate above baseline's 0.661 by inserting new items at a distant re-reference value so one-shot bursts evict each other, targeting hit-rate.

## Parent

baseline

## Changes

Replace the recency ordering with a re-reference prediction value (RRPV) per slot. Do not move items within a bucket, and do not add counters, ghost memory, or fingerprints.

- Store a 2-bit RRPV per slot, packed into one `u64` per bucket (32 slots × 2 bits). Keep it in the bucket's existing per-bucket state.
- On insert, set the new slot's RRPV to 2 (long but not maximal re-reference interval). A fresh one-shot insert therefore stays evictable sooner than an item that has been hit.
- On a get hit in `get_position()`, set that slot's RRPV to 0. Nothing else on the get path changes.
- On a put into a full bucket, select the victim in the baseline's victim-selection routine as follows: scan the slots for one with RRPV equal to 3. If one exists, evict the first such slot in slot order. If none exists, add 1 to every slot's RRPV (saturating at 3), and repeat the scan. The loop always terminates within three aging rounds.
- Keep the baseline's insert placement, get-miss, key-lookup, and promotion code unchanged.

Expected test: hit-rate on workload-a should exceed baseline's 0.661, and the gain should come from one-shot inserts evicting each other rather than re-referenced items. Put p50 should stay near baseline's, since the scan is bounded and touches only the packed word. Get p50 should rise only by the RRPV write on hit.

## Rationale (optional)

Both cohort-level winners so far rely on one idea: re-referenced keys should survive one-shot bursts. The second-chance bit (cycle 0003) and frequency counters (cycle 0002) each implement it with a single retention level. This hypothesis tests a multi-level retention scheme with an explicit insertion depth, which is a different mechanism from either. It also comes from the baseline, so it is a fresh route to the same signal rather than a stack on the current winners.

# H03

Fill the first empty slot before evicting and overwrite the victim in place on baseline to test whether placement alone improves hit rate.

## Parent

baseline

## Changes

In the baseline put-miss path, scan the target bucket for an empty slot first; if found, write the new entry there and then swap it into the len/4 position (swap-based, O(1)). If the bucket is full, overwrite the tail victim directly with the new entry and swap it to the len/4 slot, instead of shifting elements. Keep get/promotion as baseline LRU move-to-front-by-one (transpose). This isolates the fixed-position control for the adaptive-insertion gain and the placement behaviour seen unintentionally in an earlier variant. No metadata growth.

## Rationale (optional)

Addresses open questions about the missing fixed-position control and deliberate first-empty-slot fill.

# H02

Add a CLOCK-style reference bit on top of v003's low-position insertion so hits set a bit instead of reordering, targeting hit rate and per-op time.

## Parent

cycle/0002/v003

## Changes

In v003's overlay, keep insertion at ~len/4. Replace move-to-MRU on hit with setting a per-entry reference bit, stored without growing the struct's reported metadata (pack it into the top bit of an existing field such as a stored hash/tag, or a single per-bucket u8/u16 bitmask if that fits within the current 40-byte metadata). On eviction, scan from the LRU end: if the entry's bit is set, clear it and skip (second chance); otherwise evict it. If all are set after one pass, evict the last slot. Newly inserted entries have bit clear. Preserve get/put semantics and the capacity.

## Rationale (optional)

Cross-cycle notes list "do the scan-resistant gains stack" as open; the reference bit cut put/get-tail cost earlier.

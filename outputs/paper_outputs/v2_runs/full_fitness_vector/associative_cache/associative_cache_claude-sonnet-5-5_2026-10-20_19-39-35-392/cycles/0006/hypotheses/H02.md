# H02

Aligning the bucket storage to 64 bytes on top of swap insertion reduces per-op put time without hurting hit rate.

## Parent

cycle/0004/v001

## Changes

Add `#[repr(align(64))]` to the bucket/set struct (or the allocation of the bucket array) so each bucket starts on a cache-line boundary. Make no change to the replacement policy, insertion index, or hashing. Verify metadata-size does not grow beyond 40 (if alignment would add padding counted as metadata, align only the data array allocation instead).

## Rationale (optional)

Open question: whether plain 64-byte alignment improves put tail latency and stacks with swap insertion.

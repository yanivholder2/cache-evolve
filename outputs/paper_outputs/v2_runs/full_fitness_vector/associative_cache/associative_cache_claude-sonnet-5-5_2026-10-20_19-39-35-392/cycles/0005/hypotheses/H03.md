# H03

Aligning each bucket to a 64-byte cache line boundary on the baseline's bucket storage will cut get latency without changing hit rate.

## Parent

baseline

## Changes

In the cache's storage overlay, wrap the bucket storage in a `#[repr(align(64))]` struct (or allocate the bucket array with 64-byte alignment) so that each bucket's slots start on a cache-line boundary and do not straddle lines where the bucket size permits. Leave the replacement policy, hashing, and indexing untouched, so hit rate must be identical to baseline. Do not add per-slot metadata; if padding counts toward metadata-size, keep it only as allocation alignment rather than stored fields. Test whether get time (the only dimension this targets) moves, to separate layout effects from earlier noise.

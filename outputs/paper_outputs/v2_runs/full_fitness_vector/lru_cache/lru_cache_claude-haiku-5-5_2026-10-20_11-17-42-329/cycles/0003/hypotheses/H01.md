# H01

Giving referenced protected-segment nodes one rotation before demotion raises hit-rate on the LIRS workload-a trace while keeping metadata-size unchanged.

## Parent

cycle/0002/v001

## Changes

Keep v001's SLRU layout, `Node` fields, `REFERENCED`/`PROTECTED` flags, `unlink`, `push_back`, and `select_victim` logic unchanged. Modify only `demote_prot_head()`.

Current behaviour: `demote_prot_head()` unconditionally moves `prot_head` to the probationary tail and clears its `REFERENCED` bit, so a protected node that was hit since it was last promoted loses its protection on the first demotion.

New behaviour: at the top of `demote_prot_head()`, if `self.nodes[self.prot_head].flags & REFERENCED != 0`, clear that bit, `unlink` the node, and `push_back(node, true)` so it moves to the protected MRU end. Do this at most once per call (a single rotation, no loop). After that rotation, demote the new `prot_head` exactly as today: clear its `REFERENCED` bit, `unlink` it, and `push_back(idx, false)`. If the protected segment holds only one node, the rotation returns it to the same position and it is then demoted, so the segment never deadlocks.

Keep the `debug_assert!(self.prot_len <= self.protected_cap())` in `select_victim` valid: the rotation does not change `prot_len`, and the demotion still reduces it by one, as the caller expects.

Do not touch `get()` or `put()`. Hits still only set `REFERENCED`, so the hit path cost is unchanged. The added cost falls only on the miss path, and only when a demotion occurs, at most one extra unlink and push.

Update the test `slot_reuse_after_promotion_and_re_eviction` only if its expectations change. Do not edit `tests/`.

## Rationale (optional)

v001 (cycle 0002) reached hit-rate 0.7057, down from 0.724 for cycle/0001/v001, which uses the same SLRU idea with immediate protected-segment promotion. The v001 insight attributes the hit-rate loss to lazy referencing and the single rescue, which discards protection from frequently hit protected keys on demotion. This hypothesis tests whether a bounded second chance on the protected side recovers part of that loss at a small miss-path cost.

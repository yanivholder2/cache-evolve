# H03

Switch the baseline's node links to u32 sentinel indices with an Fx hasher plus a final avalanche fold to reduce metadata-size and get p99 per-op-time.

## Parent

baseline

## Changes

Re-attempt cycle 0001 H01 (which failed only from build infrastructure). In the baseline arena, change the `prev`/`next` links from `usize`/`Option<usize>` to `u32` with `u32::MAX` as the NIL sentinel, and change the free list the same way. Enforce capacity <= u32::MAX - 1. Replace the hasher with a multiply-based Fx hasher followed by a `h ^ (h >> 32)` fold step to avoid weak low bits (v003's p99 regression). Add a head-already-front early return in the touch path. Preserve the public API and eviction order exactly.

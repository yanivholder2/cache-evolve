# H02

Replacing recency relinking on get with a second-chance reference bit on the plain u32-link LRU will raise hit-rate on scan traces while keeping per-op-time near the fastest incumbent.

## Parent

cycle/0002/v003

## Changes

In `src/lru_cache/lru_cache.rs`, make `get` not relink: instead set a one-bit `referenced` flag on the node (use a spare bit of the packed prev link, or a `bool` if it fits in existing padding so `Node` size is unchanged). New entries are inserted at the head with the bit clear. In eviction, inspect the tail: if `referenced` is set, clear it and move the node to the head (second chance) and retry, bounded by the cache length; else evict it. Keep the u32 links, folded Fx hasher and move-based eviction as they are. Capacity and public API unchanged.

## Rationale (optional)

Get becomes a hash lookup plus a bit write, and one-hit scan items are evicted before reused ones, which gives scan resistance without segment bookkeeping.

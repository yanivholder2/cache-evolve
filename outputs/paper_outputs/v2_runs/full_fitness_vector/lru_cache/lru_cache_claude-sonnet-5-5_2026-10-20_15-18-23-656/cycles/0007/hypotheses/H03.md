# H03

Remove the evicted-key clone in `put` by moving the old key out of the reused slot with `mem::replace`, lowering per-op-time with no hit-rate change.

## Parent

cycle/0006/v002

## Changes

In `src/lru_cache/mod.rs`, in the eviction branch of `put`, replace `let evicted_key = self.nodes[victim].key.clone(); self.map.remove(&evicted_key); ... self.nodes[victim].key = key.clone();` with `let old = std::mem::replace(&mut self.nodes[victim as usize].key, key.clone()); self.map.remove(&old);` (order: remove from map using `old`, then unlink, assign value). This eliminates one K clone per evicting put. Also hoist the `self.nodes[victim as usize]` lookup into a single `let node = &mut self.nodes[victim as usize];` for key/value assignment to avoid repeated bounds checks, after calling `unlink(victim)`. Touch nothing else: policy, protected_cap, hasher, and layout stay identical to the parent, so hit-rate and metadata-size must match the parent and only per-op-time is under test.

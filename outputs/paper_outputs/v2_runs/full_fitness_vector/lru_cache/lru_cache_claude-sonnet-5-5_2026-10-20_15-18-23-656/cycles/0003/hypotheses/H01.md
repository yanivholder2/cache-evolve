# H01

Converting the fast segmented LRU's prev/next links to u32 sentinel indices will cut metadata-size from 56 toward ~32 bytes while keeping hit-rate 0.7241 and per-op-time near 28.

## Parent

cycle/0002/v001

## Changes

In the v001 overlay (segmented LRU with fast hasher, head-touch early return, move-based eviction), replace the `usize`/`Option<usize>` prev/next fields in `Node` and the head/tail fields of both segments (probation and protected) with `u32` indices using `u32::MAX` as NIL. Keep the segment flag as a separate `bool`/`u8` field (no bit packing, so no mask/accessor cost on link access); it should fit in the padding freed by narrower links. Apply the cycle-0002 v003 avalanche fold to the Fx hash. Keep promotion/demotion order, segment size ratio and eviction order identical to v001 so hit-rate is unchanged. Assert capacity < u32::MAX at construction. Convert indices with `as usize` only at arena access sites.

# H03

Skipping ghost writes for victims evicted during the probation LRU end when protected is full, and skipping ghost work during warm-up, will lower put time without losing hit-rate.

## Parent

cycle/0007/v002

## Changes

In `put` of v002, (1) guard the ghost lookup/clear (`ghost_slot(&key)` and the `seen` check) with `self.nodes.len() >= self.capacity`; during warm-up the ghost table is empty, so `seen = false` and no hash is needed. (2) In the eviction branch, hash the victim only once: replace the separate `map.remove(&evicted_key)` plus `ghost_slot(&evicted_key)` with a single `ghost_slot` call on a borrowed reference to the victim key, remove from the map using that same key reference, and avoid `evicted_key = ....key.clone()` by using `std::mem::replace` to swap in the new key (move the new key into the node, clone it only once for `map.insert`). Preserve all policy behavior (seen keys go to probation MRU, unseen to LRU end) so hit-rate stays identical and only per-op-time changes.

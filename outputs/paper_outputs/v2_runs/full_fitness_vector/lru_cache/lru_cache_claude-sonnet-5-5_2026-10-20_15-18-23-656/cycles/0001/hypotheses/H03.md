# H03

Skipping the unlink/relink when the hit node is already MRU, and removing the redundant key clone and double hashing on the eviction path, will lower per-op-time.

## Parent

baseline

## Changes

In `src/lru_cache/mod.rs`:

1. Add a `touch(idx)` helper that returns immediately if `self.tail == Some(idx)`. Otherwise it does a fused unlink and push_back (read prev/next once, patch neighbours, then attach at the tail). Use it in `get` and in the existing-key branch of `put`.
2. In the eviction branch of `put`, remove the old key via `self.map.remove(&self.nodes[head_idx].key)` without `clone()`. Use `std::mem::replace` on the node's key to move the new key in.
3. Clone the new key only once, for the map insert.
4. Replace the `map.get` followed by `map.insert` pair with a single `map.entry`, or reorder to minimize hashing.
5. Replace `HashMap::with_capacity(capacity)` with a faster hasher, an inline FxHash-style multiplicative `BuildHasher` defined in `mod.rs` (no external crates).

Keep strict LRU order and the public API unchanged.

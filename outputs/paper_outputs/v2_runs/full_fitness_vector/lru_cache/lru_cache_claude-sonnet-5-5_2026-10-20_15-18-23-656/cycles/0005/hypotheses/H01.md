# H01

Port v003's fold-free hasher into v002's reference-bit get path to keep v002's hit-rate and cheaper get while cutting put time.

## Parent

cycle/0004/v002

## Changes

Start from v002's source (second-chance reference bit set on get, no relink on hit). Replace the hash function with v003's: a single multiply by the Fx constant plus a rotate, with the avalanche fold removed. Copy the hasher code exactly as in cycle/0004/v003's overlay. Do not change the reference-bit logic, eviction walk, segment layout or node struct. Eviction order must stay identical to v002, so hit-rate must match v002 (0.6754).

## Rationale (optional)

Cycle 0004 left open whether the two Winners' gains compose. This tests only that composition, with one change.

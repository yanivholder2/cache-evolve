# H02

Add a per-put cap on referenced nodes passed during eviction to cut put p99 latency in the fold-free segmented LRU.

## Parent

cycle/0004/v003

## Changes

In v003, add a second-chance reference bit (set on get, replacing relink-on-hit for probationary-segment hits only; protected hits keep the existing move-to-head). In the eviction path, walk from the tail and, for nodes with the bit set, clear it and move them to the head, passing at most K = 2 such nodes per put. After K passes, evict the current tail node regardless of its bit. Keep the u32 links and the fold-free hasher unchanged. Do not add any new fields beyond the one bit, which should reuse the existing segment flag byte or padding so metadata-size stays 24. Invariant: capacity bound and get/put correctness are preserved.

## Rationale (optional)

v002 moved work from get to the eviction walk and worsened put p99. A bounded walk limits the tail while keeping most of the hit-rate gain.

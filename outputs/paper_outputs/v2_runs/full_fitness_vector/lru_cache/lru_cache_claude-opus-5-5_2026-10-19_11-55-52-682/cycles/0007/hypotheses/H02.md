# H02

Admitting ghost-hit keys into main at the SIEVE hand position instead of the main tail, so they must earn a hit before the next main eviction reaches them, will raise hit-rate by keeping main capacity for proven-reuse keys.

## Parent

cycle/0005/v003

## Changes

In `src/lru_cache/mod.rs`, `put` miss path: when `to_main` is true, call a new
`insert_at_hand_main(idx)` instead of `push_back_main(idx)`. Leave the small-queue path, the
promotion of visited small heads (still `push_back_main`), the ghost and `small_target` unchanged.

`insert_at_hand_main(idx)` splices the node in so that it becomes the next node the hand examines:

- If main is empty (`head == NIL`), behave like `push_back_main`: head = tail = idx, and leave
  hand/hand_prev at NIL.
- If `hand == NIL` (the hand will start at head), insert at the head: `nodes[idx].next = head`,
  `head = idx`. Leave hand/hand_prev NIL. The new node is now first in line.
- Otherwise insert between `hand_prev` and `hand`: `nodes[idx].next = hand`. If
  `hand_prev == NIL`, set `head = idx`; otherwise `nodes[hand_prev].next = idx`. Then set
  `hand = idx` and keep `hand_prev` unchanged. `tail` does not change, because `hand` is non-NIL
  and so the new node is never last.

The node enters with `visited = false` and `small = false`, as today. When it is accessed before the
hand arrives, the hand clears its bit and moves past it, and from then on it behaves like any main
node. When it is not, it is the next main victim. Note that this can make a not-yet-reused ghost
returner the immediate victim of the very next main eviction, which is the intended "soft
admission".

Add a unit test: fill the cache, cause a small eviction into the ghost, re-put that key, and
assert that it is at the hand position (or at head when the hand is NIL). Then trigger a main
eviction without touching it and assert that it is the victim. Extend `check_structure`'s
hand/hand_prev checks if needed. All existing structural invariants must hold.

## Rationale (optional)

Cycle 0006 showed that more ghost recall (larger or associative ghost) hurt: ghost returners took
main slots from keys with proven reuse. This is the "softer admission" open question. A ghost hit
still skips probation, but it gets only one hand-cycle of protection instead of a full lap.
Refuted if hit-rate does not exceed 0.7306. Expect put p99 to stay flat, since the splice is O(1).

# H02

Moving S3-FIFO's link, visited, and small-queue state into a packed `u32` side array will cut metadata-size from 24 to 16 bytes per node while keeping hit-rate unchanged.

## Parent

cycle/0005/v003

## Changes

Port cycle/0005/v001's side-array representation onto v003's S3-FIFO in `src/lru_cache/mod.rs`. The eviction order must stay bit-for-bit identical to v003.

- `Node<K, V>` becomes just `{ key: K, value: V }` (16 bytes for u64/u64). Remove the `next`, `visited`, and `small` fields.
- Add `links: Vec<u32>` parallel to `nodes`, sized `with_capacity(capacity)`. Bit 31 is `VISITED`, bit 30 is `SMALL`, and the low 30 bits are the forward link, with `LINK_MASK = (1 << 30) - 1` and `NIL = LINK_MASK`. In `try_new`, reject `capacity >= NIL as usize` (30-bit range).
- Add `#[inline]` helpers: `next(i)`, `set_next(i, n)` (preserves the flag bits), `set_visited(i)`, `clear_visited(i)`, `is_small(i)`, and `set_small(i, bool)`. Rewrite these to use the helpers: `get`, the existing-key branch of `put`, `push_back_main`, `push_back_small`, the small-head pop/promote branch of `evict`, the main-victim unlink, and `find_victim`. In `find_victim`, use v001's tight loop over `&mut self.links` only: when a node is visited, store `l & !VISITED` back so the SMALL bit is kept (it is always clear in main).
- On a new key, push both `nodes` and `links`. When reusing an evicted slot, set `links[x] = NIL | (if small { SMALL } else { 0 })`, with visited clear.
- Use v001's key swap on eviction: instead of `map.remove(&nodes[x].key)` followed by `nodes[x].key = key.clone()`, have `evict()` return the slot without removing it from the map. Then in `put`, do `let old = std::mem::replace(&mut self.nodes[x].key, key.clone()); self.map.remove(&old);`. Compute the ghost fingerprint of the victim inside `evict()` before the swap, as v003 does now.
- Keep the ghost table, Fx hasher, `small_target = capacity/10`, and all policy branches unchanged.

Tests: change `node_is_24_bytes` to assert `size_of::<Node<u64,u64>>() <= 16`. Change `check_structure` and the `main_keys`/`small_keys` helpers to read links and flags from `links`, and add `assert_eq!(c.links.len(), c.nodes.len())`. Every behavioural test (promotion, ghost hit, scan, capacity one, randomized) must pass with unchanged expectations.

## Rationale (optional)

In cycles 3–5, changes to representation alone kept eviction order and moved metadata without risk. v001 reached 16 bytes on SIEVE, but v003 (the hit-rate leader) is still at 24. The SMALL flag fits in a second spare high bit, so the S3-FIFO state costs nothing extra. Per-op-time is a secondary check: v001 showed that the side array helps put p99 but does not move get.

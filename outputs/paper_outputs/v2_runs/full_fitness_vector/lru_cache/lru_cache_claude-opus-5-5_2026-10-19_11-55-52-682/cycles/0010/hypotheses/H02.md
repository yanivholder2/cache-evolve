# H02

Making the S3-FIFO small-queue target adapt ARC-style to which queue a ghost hit came from will raise hit-rate over the fixed 10% split.

## Parent

cycle/0009/v001

## Changes

All edits go in `src/lru_cache/mod.rs`.

1. **Tag the ghost source.** Replace `fingerprint(h)` with a base fingerprint that always has bit 1 set and bit 0 clear: `(((h >> 32) as u32) | 2) & !1`. It can never be 0. When `evict` records a small-head eviction, store `base`. When it records a main (SIEVE) eviction, store `base | 1`. In `put`, a ghost lookup matches when `(self.ghost[gslot] & !1) == base`, and bit 0 of the stored value tells you where the key was evicted from. Clear the slot on a hit, as the parent does.
2. **Adapt `small_target` on ghost hits.** This runs in `put`, before `evict()` is called.
   - Small-sourced hit (bit 0 = 0): the key was evicted from probation too early. Set `small_target = min(small_target + 1, max_small)`.
   - Main-sourced hit (bit 0 = 1): main was too short. Set `small_target = max(small_target - 1, min_small)`.
   - Bounds, computed once in `try_new` and stored in new `usize` fields: `min_small = (capacity / 50).max(1)` and `max_small = (capacity * 2 / 5).max(1)`. The start value stays `(capacity / 10).max(1)`.
3. Leave the admission decision (ghost hit goes to the main tail, unvisited), the eviction loop condition `s_len >= small_target || head == NIL`, `find_victim`, the ghost size and all layout unchanged. Because the condition reads `small_target` on every iteration, shrinking it below `s_len` just drains small over the next few evictions. No bulk move is needed.
4. Update the in-file tests. Make `in_ghost` use the masked comparison. Add a test where a small-evicted key returns and `small_target` goes up by one. Add another where a main-evicted key returns and it goes down by one, clamped at the bounds. Run `check_structure` throughout the randomized test, plus the assertion `min_small <= small_target <= max_small`.

## Rationale (optional)

Fixed-ratio tuning of the small queue has been flat for four cycles. Wider static splits lost because main capacity is scarce on average, but workload-a may have phases where loops and scans favour a different split. ARC-style adaptation driven by the two ghost sources is a structurally new signal, not another static knob. It reuses the existing ghost with no extra heap and no extra probes, only one compare and one add on ghost hits. The test fails if hit-rate is at or below 0.7314. It also fails if `small_target` just pins to a bound, since that means a static split would have done the same job.

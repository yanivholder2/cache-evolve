# H03

Admitting ghost returners to the main tail with VISITED already set will let them survive one SIEVE hand pass and raise hit-rate.

## Parent

cycle/0009/v001

## Changes

All edits go in `src/lru_cache/mod.rs`.

1. In `put`, on the miss path, when `to_main` is true (the ghost fingerprint matched), call `self.vbit_set(idx)` after `self.push_back_main(idx)`. Do this after the slot-reuse code's `self.vbit_clear(x)` or `self.vbit_clear(idx)` has run, so the bit really ends up set. Small-queue admissions keep starting unvisited.
2. No other behaviour changes. The ghost entry is still cleared on a hit. Ghost size and inputs (small-head and main evictions, half-size table) stay as they are, and so do `find_victim`, the small-queue promotion rule (a promoted node enters main with VISITED cleared), and the layout.
3. Update the in-file tests. `ghost_hit_admits_straight_to_main` and `main_evicted_key_returns_straight_to_main` currently assert `!cache.is_visited(i)` for the returner. Change them to assert `cache.is_visited(i)`. Add a small-capacity test showing that a ghost returner survives the next main eviction while an older unvisited main node is evicted instead. `check_structure` and the randomized test must still pass.

## Rationale (optional)

Cycle 0007 found that weakening ghost admission (placing returners at the hand) cost hit-rate, and concluded that a ghost hit is a strong reuse signal. The opposite direction, strengthening admission, has never been tested. Today a returner enters main with no credit. If the hand reaches it before its next reuse, it gets evicted and ghosted again, which is the same churn that main-eviction ghosting was meant to break. One pre-set bit gives returners one extra pass, the same credit a promoted small key earns by being hit. It adds no state, no hashes and no latency. Ghost size and inputs are closed, but admission strength is a separate, untested axis. The test fails if hit-rate is at or below 0.7314. If it falls, returners on workload-a are mostly one-shot and the ghost is over-admitting.

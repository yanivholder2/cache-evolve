**Changes, as H02 specifies:**
1. **Frequency sketch.** I added a 4-row count-min sketch (`sketch: Vec<u64>`) of 4-bit counters, 16 per word. Each row has `next_power_of_two(capacity).max(16)` counters, which is 4 KiB at capacity 2048. Row indices use the mixing formula from the hypothesis. `freq_incr` adds 1 to each counter, stopping at 15. After `10 × capacity` increments it halves every counter (`(w >> 1) & 0x7777…`) and halves `sample`. `freq_est` returns the smallest of the 4 counters.
2. **Where it counts.**
   - In `put`, a miss counts using the hash already computed for the ghost lookup.
   - A key also counts when its VISITED bit goes from 0 to 1, inside `set_visited`, so repeated hits on an already-visited key do no sketch work.
3. **The duel.** An unvisited small-queue head, when main is not empty, is compared with the main victim that `find_victim()` picks.
   - **Small key's estimate is strictly higher:** the main victim is removed and ghosted, and the small key moves to the main tail.
   - **Otherwise:** the small key is evicted and ghosted as before. The hand is left on the victim, which stays in main (`find_victim` doesn't move the hand itself).
   - The main-unlink code is now a shared `unlink_main` helper.
4. **Unchanged:** the ghost and its sizing, ghosting of main evictions, the VISITED bitset, the packed `links`, the 16-byte `Node`, and `factory.rs`.

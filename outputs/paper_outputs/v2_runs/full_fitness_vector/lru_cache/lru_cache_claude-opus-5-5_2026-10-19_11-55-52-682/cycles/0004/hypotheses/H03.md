# H03

Splitting singly-linked SIEVE's per-node policy state (`next` link plus `visited` bit) out of `Node` into a parallel packed `Vec<u32>` will shrink `Node<u64,u64>` from 24 to 16 bytes of metadata-size while preserving the exact eviction order and hit-rate.

## Parent

cycle/0003/v001

## Changes

Edit `src/lru_cache/mod.rs` only.

1. Reduce `Node<K, V>` to `{ key: K, value: V }`. Update the `node_is_24_bytes` test into `node_is_16_bytes`, asserting `size_of::<Node<u64,u64>>() <= 16`.
2. Add `links: Vec<u32>` to `LruCache`, parallel to `nodes` (same index, pushed together in the arena-push branch of `put`). Each entry packs the forward link in the low 31 bits and the visited flag in bit 31: `const VISITED: u32 = 1 << 31; const LINK_MASK: u32 = VISITED - 1;`. Use `NIL = LINK_MASK` (0x7FFF_FFFF) for the null link, and change the `try_new` capacity bound to `capacity >= NIL as usize` with that new `NIL`. Update `capacity_too_large_rejected` to match.
3. Add small inline helpers: `next(i) -> u32 { links[i] & LINK_MASK }`, `set_next(i, n)` (preserves the visited bit), `is_visited(i)`, `set_visited(i)`, `clear_visited(i)`.
4. `get`: look up `idx`, call `links[idx] |= VISITED`, and return `&nodes[idx].value`. The in-place-update branch of `put` does the same.
5. `find_victim`: walk using `links` only, testing and clearing bit 31 and following `& LINK_MASK`. It reads no `Node` at all during the sweep, so the sweep touches a dense 4-byte-per-entry array. The rest of the logic (hand, `hand_prev`, wrap to head) is unchanged.
6. Eviction and `push_back`: replace every `nodes[x].next` / `.visited` access with the helpers. A freshly reused or pushed slot gets `links[idx] = NIL` (link NIL, visited clear).
7. Update the test helpers (`check_structure`, `keys_in_order`, and the test asserting `!visited`) to read through `links`.

Invariants: eviction order is bit-for-bit identical to v001, so hit-rate must be 0.7264. No `unsafe`. `links.len() == nodes.len()` always.

## Rationale (optional)

Representation-only rewrites are the one change that has never cost hit-rate in this lineage (cycle 0003 insight), and metadata-size is measured on `Node<u64,u64>`. v001 removed the back-link; the remaining 8 bytes are a 4-byte link plus a bool padded to a word. Packing both into a side-array `u32` cuts the node by a third. The secondary, testable side effect is on per-op-time: the hand sweep now scans a cache-dense `u32` array instead of striding over 24-byte nodes, while `get` gains a second memory touch. The cohort will show which effect dominates.

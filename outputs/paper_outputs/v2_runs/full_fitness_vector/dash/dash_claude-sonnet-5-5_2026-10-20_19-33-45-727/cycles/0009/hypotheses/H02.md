# H02

Replace the two-probe doorkeeper in the cycle 0008 v001 filter with a single probe and a higher aging threshold to cut put-side latency while holding hit-rate.

## Parent

cycle/0008/v001

## Changes

In the one-cache-line doorkeeper of cycle 0008 v001, use a single bit probe (one index from the hash, 9 bits) instead of two. Raise the aging threshold to ~192 set bits (about 37% fill) to compensate for the higher false-positive rate per bit being offset by fewer bits set per key. Skip the second-bit test/set code entirely. Leave get paths, eviction, promotion and item layout untouched; metadata-size stays 40.

## Rationale (optional)

Halving the probe work on every put miss reduces put cost; the filter is sparse enough that one probe may suffice.

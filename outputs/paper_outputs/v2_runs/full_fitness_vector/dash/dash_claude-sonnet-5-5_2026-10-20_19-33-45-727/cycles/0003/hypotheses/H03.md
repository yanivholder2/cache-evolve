# H03

Use a one-bit recency ("referenced since last cascade") bit in spare Item bits to choose cascade victims on the v001 base, raising hit-rate by keeping recently touched items out of demotion.

## Parent

cycle/0002/v001

## Changes

On the cycle 0002 v001 base, add a second packed bit (same spare bits as the hit flag; item stays 40 bytes) with helpers `item_ref` / `set_item_ref`. Set it on every get hit. When a cascade or eviction must pick a victim in a bucket, prefer the first slot from the eviction end whose ref bit is clear, clearing the ref bit of slots skipped (CLOCK-style second chance), bounded to one pass over the bucket. If all bits are set, fall back to the existing victim. Leave admission (second-hit) logic and insert positions unchanged.

# H02

Admit a first-touch key unconditionally while a segment still has free slots, applying the second-hit filter only once full, to raise hit-rate during cache warm-up without adding hot-path work.

## Parent

cycle/0005/v001

## Changes

In the put/insert path of cycle 0005 v001, locate the second-hit admission check. Add a single condition up front: if the target segment/bucket has a free slot (the code already finds this during insertion, so reuse that result and add no extra scan), skip the second-hit check and insert the item normally. When there is no free slot (eviction would be needed), apply the existing second-hit filter unchanged. Do not alter the get path, the item struct, or the filter's bit-packing. Metadata-size must remain 40.

## Rationale (optional)

The filter only matters when an insert forces an eviction. Rejecting first touches into empty space loses hits for nothing. This tests whether the hit-rate ceiling is partly warm-up loss.

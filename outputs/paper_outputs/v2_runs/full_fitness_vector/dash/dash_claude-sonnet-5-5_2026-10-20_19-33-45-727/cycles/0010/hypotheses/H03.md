# H03

Make baseline's eviction prefer slots whose second-hit flag is unset (never re-referenced) over flagged slots to raise hit-rate without a doorkeeper.

## Parent

baseline

## Changes

In the baseline DASH segment eviction function, when choosing a victim among candidate slots in the target and neighbouring buckets, do a single pass: select the first slot whose recency/"seen again" bit is clear; if every slot is flagged, clear all flags in the scanned slots and evict the first one (one-bit CLOCK-like second chance restricted to the scanned bucket group). Set the flag on get hit. Pack the flag into existing spare metadata bits so metadata-size stays 40. Do not add any admission filter, locks, or lookup-path branches beyond setting the bit on hit.

## Rationale (optional)

Tests whether eviction-side second-hit signalling alone can match admission-side gains; a different mechanism from the incumbent's doorkeeper.

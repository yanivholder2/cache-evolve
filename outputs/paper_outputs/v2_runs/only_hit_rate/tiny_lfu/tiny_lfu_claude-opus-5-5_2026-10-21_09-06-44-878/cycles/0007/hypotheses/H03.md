# H03

Shrinking the SLRU protected segment from 80% to 50% of capacity will raise hit-rate on workload-a, because admitted newcomers get a longer probation trial in which to earn the second hit that promotes them.

## Parent

cycle/0006/v003

## Changes

In `src/tiny_lfu/mod.rs`, change the size of the protected segment in `try_new` from `(capacity * 8 / 10).max(1)` to `(capacity / 2).max(1)`. To keep this easy to sweep, add a const `PROTECTED_NUM: usize = 5` / `PROTECTED_DEN: usize = 10` and compute `(capacity * PROTECTED_NUM / PROTECTED_DEN).max(1)`.

Everything else stays exactly as in the parent:
- strict `>` admission
- dedup of the get-miss-then-put increment
- the 16× sketch
- probation-only 8-way min-estimate victim sampling in `select_victim`
- frequency-aware demotion over the 4 oldest protected entries in `select_demotion`

Update the unit tests that hard-code the 80% ratio. `protected_overflow_demotes_to_probation` uses capacity 5 → `protected_cap` 2. `protected_overflow_spares_hot_head_and_demotes_colder_entry` uses capacity 10 → `protected_cap` 5. Adjust their expected `prot_len`, and the keys whose promotion causes overflow, so the tests keep checking the same behaviour: overflow demotes the lowest-estimate entry among the oldest protected entries, falling back to LRU on ties. `check_structure` invariants must still hold.

## Rationale

The windows tried earlier failed because they skip admission and give only about 20 slots of recency trial. Probation is different: it is behind the frequency gate, so only keys that won the contest get the longer trial. At capacity 2048, an 80% protected cap leaves about 410 probation slots. A newcomer that won admission is then sampled for eviction after about 410 further admissions, which may be shorter than the reuse distance of LIRS-trace keys. The probation ratio was raised as an open question in cycle 5 and has never been tested. Unlike the demotion and window tweaks, it changes how long newly admitted keys survive, not only the order of entries in the protected segment.

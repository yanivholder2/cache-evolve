- **Constant:** added `VICTIM_SAMPLE = 8`.

A warm newcomer should evict key 2, which is colder and newer, where v003 would have rejected the newcomer. That test could fail spuriously if its keys happen to share sketch counters. That is unlikely at this sketch width, but I couldn't run it to confirm.

The structural invariant suite only checks the capacity bound, that values read back correctly, and that keys never put return nothing. Evicting from mid-list doesn't affect any of those, so I expect it to pass.

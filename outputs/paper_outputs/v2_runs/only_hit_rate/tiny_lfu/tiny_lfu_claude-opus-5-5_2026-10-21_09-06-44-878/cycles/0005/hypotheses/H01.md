# H01

Splitting the resident LRU of cycle/0004/v001 into an SLRU probation segment (20%) and protected segment (80%), with victims sampled only from probation, will raise hit-rate on workload-a by shielding re-referenced keys from newcomers now that sketch estimates are clean.

## Parent

cycle/0004/v001

## Changes

Edit `src/tiny_lfu/mod.rs` only (the inline `#[cfg(test)]` tests there may be adjusted; do not touch `tests/` or the JNI file).

- Add a `segment: u8` field to `Node` (0 = probation, 1 = protected), and replace the single `head`/`tail` pair with two intrusive lists: `prob_head/prob_tail` and `prot_head/prot_tail`, plus `prot_len: usize`. Add `protected_cap = max(1, capacity * 8 / 10)`. Generalise `unlink(idx)` / `push_back(idx)` to operate on the list given by `nodes[idx].segment`.
- New insertions (fill path and admitted newcomers that reuse the victim slot) go to the MRU end of **probation**.
- On a hit (`get` hit, or `put` on an existing key):
  - probation node → unlink, mark protected, push to protected MRU, `prot_len += 1`; if `prot_len > protected_cap`, demote the protected LRU head back to probation MRU (`prot_len -= 1`).
  - protected node → move to protected MRU.
- `select_victim()` keeps the `VICTIM_SAMPLE = 8` min-estimate scan with strict `<`, but walks from `prob_head`. If probation is empty (possible only transiently), fall back to scanning from `prot_head`.
- Keep everything else from v001 unchanged: 16× wide sketch, `pending_miss_hash` dedup, strict `incoming_freq > victim_freq` contest with keep-victim-on-tie, no aging.
- Invariants: `map.len() == nodes.len() <= capacity`; every node lives in exactly one list; `prot_len` equals protected list length.
- Update the inline test `victim_is_min_frequency_among_oldest_not_lru_head` if needed so it still holds under the segmented layout (e.g. key 1, hot via gets, is now protected and simply not a candidate); other inline tests should pass as-is.

## Rationale (optional)

The cross-cycle open question is whether structural levers pay off on clean, honest estimates. SLRU was never tested; the c1 window test used a noisy sketch and only a 1% window. Restricting the contest to probation means a once-seen newcomer competes against other once-seen keys, not against proven-reused residents that drifted to the LRU head. Compare directly with v001 (0.7439).

# H03

Make protected-overflow demotion frequency-aware by demoting the lowest-estimate entry among the 4 oldest protected entries, instead of always demoting the protected LRU head, to raise hit-rate on workload-a.

## Parent

cycle/0005/v001

## Changes

Edit `src/tiny_lfu/mod.rs` only. Keep probation victim sampling (`select_victim`, `VICTIM_SAMPLE = 8`), the sketch, dedup and the strict `>` contest unchanged.

- Add `const DEMOTE_SAMPLE: usize = 4;`.
- Add `fn select_demotion(&self) -> Option<usize>`. Starting at `prot_head`, walk up to `DEMOTE_SAMPLE` protected entries via `next` and return the index with the smallest `self.sketch.estimate(&node.key)`. On equal estimates keep the entry closest to the head (strict `<`), so the result falls back to plain LRU demotion when all estimates are equal.
- In `on_hit`, in the `self.prot_len > self.protected_cap` overflow branch, replace `if let Some(demote) = self.prot_head` with `if let Some(demote) = self.select_demotion()`. The demoted node still goes to probation MRU, its `segment` becomes `SEG_PROBATION`, and `prot_len` is decremented. Make sure the node just promoted (now at protected MRU) can only be chosen if the protected list is shorter than `DEMOTE_SAMPLE`. That case only arises at tiny capacities, and choosing it there is acceptable.
- Update the in-file `protected_overflow_demotes_to_probation` test so its expectation matches the new rule. All keys there have equal estimates, so the LRU-head tie-break should still demote key 0. Also add a test where a hotter protected head (with extra `get`s) survives overflow and a colder second-oldest protected entry is demoted instead.

## Rationale (optional)

Earlier, widening the *probation* victim sample hurt: without aging, the lowest estimate there marks the youngest resident, because newly admitted keys have small lifetime counts. The protected segment is different. Every entry in it has already been hit at least once since admission, so the youngest-equals-lowest bias is much weaker. Pure-LRU demotion can push a long-lived hot key (one with a large lifetime count that just had a gap in its reuse) into probation, where the next contest can evict it. This lever is untested. It is distinct from probation-side sampling, the window (H01) and sketch sizing (H02), and it costs at most 4 extra estimates per probation→protected promotion, and only when protected is full.

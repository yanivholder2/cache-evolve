# H03

Add a doorkeeper bloom filter in front of the baseline sketch so one-hit keys are not counted, improving hit-rate and sketch accuracy.

## Parent

baseline

## Changes

In the baseline sketch overlay, add a small bit-array doorkeeper (about 8 bits per cache entry, 2 hash probes derived from the existing key hash). On `increment(key)`: if the doorkeeper does not contain the key, set its bits and return without touching the counters. Otherwise increment the counters as before. The `estimate` function adds 1 if the doorkeeper contains the key. Clear the doorkeeper whenever the sketch counters are halved, and add that halving if the baseline lacks it (every 10 * capacity increments). Leave admission and eviction logic unchanged.

# H03

Replacing the baseline's separate sketch row storage with a flat u8 array and single-hash index derivation, with a 2x wider table, will match or beat baseline hit-rate at lower per-op cost.

## Parent

baseline

## Changes

In the baseline sketch, store all rows in one contiguous `Vec<u8>` of depth*width bytes (width = 2x baseline width, power of two). Derive the row indices from one 64-bit hash via double hashing (`h1 + i*h2`, masked per row). Keep conservative update, saturating u8 counters, halving reset, window/segment structure, and admission rule exactly as in baseline. Scaling direction: wider (2x) than baseline; cost goal is fewer hash computations and one allocation.

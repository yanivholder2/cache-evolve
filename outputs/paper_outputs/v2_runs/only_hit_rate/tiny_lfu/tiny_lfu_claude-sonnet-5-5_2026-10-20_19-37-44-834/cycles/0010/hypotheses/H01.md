# H01

Doubling the count-min sketch row width on top of v002 will raise hit-rate slightly, since width is the only lever that has moved hit-rate monotonically.

## Parent

cycle/0009/v002

## Changes

In the sketch constructor, double the per-row counter count (round up to a power of two, update the index mask/shift accordingly) relative to the current width. Keep depth, u8 counters, conservative update, the admit threshold, and v002's `touched_in_window` tie-break unchanged. Scaling direction: wider (2x) than v002, not narrower. Sketch aging/reset sample size should stay tied to cache capacity, not width.

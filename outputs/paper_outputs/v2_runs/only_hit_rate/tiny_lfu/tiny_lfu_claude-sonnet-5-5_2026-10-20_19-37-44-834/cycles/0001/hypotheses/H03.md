# H03

Replace the 4-row u32 sketch with a flat 4-bit-saturating-style u8 counter table using one hash computation per key to cut metadata size and per-op time.

## Parent

baseline

## Changes

In `src/tiny_lfu/mod.rs`, rewrite `CountMinSketch` to store a single flat `Vec<u8>` of `depth*width` counters saturating at 15 (conservative: counters are small because aging-free frequencies only need to discriminate small counts). Compute ONE 64-bit hash per key (single `DefaultHasher` pass, or a cheap multiply-xorshift mix of a hashed u64) and derive the four row positions from different 16-bit slices of it, instead of building a new `DefaultHasher` per row. Use conservative update in `increment` (only increment rows whose counter equals the current minimum). Update `heap_bytes` to `depth * width * size_of::<u8>()`. Keep the width derivation and admission logic unchanged so only sketch cost/size changes.

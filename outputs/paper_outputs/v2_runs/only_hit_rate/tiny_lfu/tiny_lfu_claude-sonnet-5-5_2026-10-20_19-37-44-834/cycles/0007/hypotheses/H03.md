# H03

Choosing the admission victim as the lower-frequency of the two oldest probation entries (instead of the probation LRU alone) will keep hotter entries and raise hit-rate.

## Parent

cycle/0003/v002

## Changes

In `src/tiny_lfu/mod.rs`, in the full-cache branch of `put`, after selecting `victim` as `head[PROBATION]`, also read `self.nodes[victim].next` (the second-oldest probation node, if it exists and is still in PROBATION). Estimate both with the sketch and take the one with the lower estimate as `victim` (ties keep the LRU one). Then run the existing candidate-vs-victim admission rule unchanged. If probation is empty, fall back to the protected LRU as now. The unlink/push_back logic already works with any node index, so only the victim selection changes. This must preserve list invariants and capacity bounds.

## Rationale (optional)

Sampled eviction approximates LFU within probation, which fits a frequency-driven trace, and it costs one extra sketch estimate per miss.

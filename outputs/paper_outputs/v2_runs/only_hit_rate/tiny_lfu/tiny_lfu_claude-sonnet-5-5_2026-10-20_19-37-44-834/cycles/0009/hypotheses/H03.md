# H03

Making the sketch width 8 (the 0008/v003 variant's setting) cheaper by packing it from the baseline will cut metadata-size while holding hit-rate, via a combination of baseline layout with a flat u8 counter array.

## Parent

baseline

## Changes

In the sketch file, store counters in a single flat `Vec<u8>` (one byte per counter, saturating at the existing max count) rather than the baseline's current counter type/layout, indexed as `row * width + col` using single-hash indexing (derive each row's column from one 64-bit hash by taking different bit slices). Keep the baseline's width factor, rows, admission rule, window and segment sizes unchanged, and keep conservative update. Goal: reduce metadata-size and per-op-time (one hash, contiguous memory) with hit-rate unchanged within noise. Invariant: counters never exceed the baseline saturation value.

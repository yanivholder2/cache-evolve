# H02

Biasing admission by recency (admit a window candidate on ties only if it was just re-referenced while in the window) on cycle 0008/v001 will raise hit-rate on workload-a.

## Parent

cycle/0008/v001

## Changes

In the admission path (where the window victim, the candidate, duels the main-region probation victim using sketch estimates), add a per-entry boolean "touched_in_window" set when an entry gets a hit while resident in the window and cleared on insertion. Keep v001's threshold and tie-admit rule for the comparison, but when the estimates are equal, admit the candidate only if touched_in_window is true; when candidate estimate is strictly greater, admit as before; when strictly lower, reject as before. Store the flag in the existing entry struct (use a bool field; no new maps). Do not alter window size, protected share, or sketch.

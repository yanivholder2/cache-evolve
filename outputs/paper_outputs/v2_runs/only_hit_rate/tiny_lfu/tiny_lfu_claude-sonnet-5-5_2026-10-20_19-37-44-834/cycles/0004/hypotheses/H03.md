# H03

Deriving all sketch row indices from one 64-bit hash computation per access will cut per-op-time without changing hit-rate.

## Parent

baseline

## Changes

In the baseline sketch's `increment` and `estimate` paths, replace the per-row hash call with a single 64-bit mix of the key per operation. Derive each row index from a different 16-bit slice of that mix, with a per-row odd multiplier or rotation so the rows stay decorrelated, which 4-bit v003 did not do. Keep the counter width, update rule and aging behaviour identical to baseline. Compute the hash once per `get`/`put` and reuse it for the admission-time estimate instead of rehashing. Counter semantics must not change, so hit-rate should match baseline within noise.

## Rationale (optional)

Per-op-time is unmeasured so far. This targets it directly on the baseline path, which holds the best per-op-time of 132.

# H01

Halving the u8 conservative-update sketch's table width on top of the tie-admit duel will cut metadata-size with no more than 0.002 hit-rate loss.

## Parent

cycle/0003/v002

## Changes

In the sketch module of the v002 overlay, reduce the number of counters per row to half the current width (round to a power of two, keep the mask-based indexing). Keep u8 counters, conservative update, and each row's independent hash seed. Do not add aging, a doorkeeper or 4-bit packing, since those lost hit-rate in earlier cycles. Leave the tie-admit duel (`>=` for repeat keys with estimate >= 2, strict `>` for one-hit keys) and the empty-probation fallback to the protected LRU unchanged. Any aging/reset threshold stays tied to the original sample size.

## Rationale (optional)

Cycle 1 found the u8 sketch over-provisioned. This tests how far the width can shrink, which shows up in metadata-size.

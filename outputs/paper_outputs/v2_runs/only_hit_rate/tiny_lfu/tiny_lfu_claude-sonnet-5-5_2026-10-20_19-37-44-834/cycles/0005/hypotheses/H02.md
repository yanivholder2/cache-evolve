# H02

Shrinking the sketch width by a gentle 25% (instead of the failed 50%) will cut metadata-size while holding hit-rate within noise.

## Parent

cycle/0004/v002

## Changes

In the sketch construction code, change the per-row width computation (currently a power-of-two or capacity-multiple width) so that the row width becomes ~75% of the current value (round to the nearest multiple of 8; if the code requires a power-of-two mask, instead use modulo indexing `h % width` for the rows). Keep u8 counters, conservative update, depth, and sampling/reset behaviour unchanged. Keep the tie-admit duel and segment split of the parent. Invariant: no change to admission or eviction logic; only sketch memory footprint shrinks.

## Rationale (optional)

Cycle 4 v001 showed 2x halving loses hit-rate; the smaller step tests where the loss threshold lies, targeting metadata-size.

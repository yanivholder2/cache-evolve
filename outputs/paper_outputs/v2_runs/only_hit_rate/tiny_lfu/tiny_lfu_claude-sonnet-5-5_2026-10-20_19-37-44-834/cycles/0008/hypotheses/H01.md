# H01

Counting each access once while lowering the tie-admit threshold from `>= 2` to `>= 1` on the wide sketch will match or beat the hit-rate of the double-count design.

## Parent

cycle/0007/v001

## Changes

Starting from v001 (SKETCH_WIDTH_FACTOR=16), remove the second sketch increment on the get-miss followed by put path, so each access increments the sketch once. In the admission duel, change the tie-admit rule so the candidate is admitted when its estimate >= victim's estimate (ties admit) and the candidate's absolute estimate threshold is lowered from 2 to 1, compensating for the removed double count. Leave segment logic, window size and sketch layout untouched. Read the existing code first to find the exact threshold comparison.

## Rationale (optional)

Cycle 7 v002 lost because removing the double count made the unchanged threshold too strict; the two knobs are coupled.

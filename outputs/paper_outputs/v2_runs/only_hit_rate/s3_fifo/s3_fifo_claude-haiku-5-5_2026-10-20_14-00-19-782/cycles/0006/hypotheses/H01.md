# H01

Folding resident-key membership into the existing per-slot state will lower metadata-size below the baseline's 24 bytes per entry while leaving hit-rate unchanged.

## Parent

cycle/0005/v001

## Changes

Remove the separate resident-key structure used for membership checks. Store the resident bit in the existing per-slot queue-state field (the same field that already tracks queue membership) so that `contains_resident()` reads that bit directly instead of probing a side table. Keep the miss-path probe removal from the parent. Update every writer of the queue-state field (insert, promote, evict, ghost re-admit) so the resident bit is set on insert and cleared on eviction, and keep eviction order, promotion bar (two hits), and ghost window exactly as they are. Do not change `evict_one()` victim selection. Report hit-rate, metadata-size, and per-op-time for the variant.

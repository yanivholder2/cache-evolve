# H01

Swapping the default SipHash on the `resident` index of cycle/0007/v001 for a cheap multiplicative hasher lowers per-op-time, with hit-rate unchanged because no eviction decision depends on hash iteration order.

## Parent

cycle/0007/v001

## Changes

Keep the keyed `resident` index that cycle/0007/v001 introduced in `src/s3_fifo/mod.rs`. Change only the hasher used by that map.

- Add `use std::hash::{BuildHasherDefault, Hasher};` next to the existing `use std::hash::Hash;`.
- Add a private hasher type `struct MulHasher(u64);` with `#[derive(Default)]`. Implement `Hasher` for it:
  - `fn finish(&self) -> u64 { self.0 }`
  - `fn write(&mut self, bytes: &[u8])` folds each byte with `self.0 = (self.0.rotate_left(5) ^ b as u64).wrapping_mul(0x517c_c1b7_2722_0a95);`
  - `fn write_u64(&mut self, i: u64)` folds `i` the same way.
- Change the field type to `resident: HashMap<K, Slot<V>, BuildHasherDefault<MulHasher>>`.
- In `try_new`, replace `HashMap::with_capacity(capacity)` with `HashMap::with_capacity_and_hasher(capacity, BuildHasherDefault::default())`.
- Do not change `get`, `put`, `evict_main`, `evict_small`, the `small`/`main`/`ghost` queues, `small_size`/`main_size` sizing, or `MAX_FREQ`.
- Do not iterate over `resident` anywhere. Eviction order depends only on the queues and the `freq` values, so the hasher cannot change which key is evicted.
- Invariants to preserve: the key set in `resident` equals `small ∪ main` at every step; the eviction sequence on any trace is identical to cycle/0007/v001; the existing inline tests pass unchanged.

Report per-op-time, metadata-size, and hit-rate. Expected direction: per-op-time goes down because `get` and `put` hash every call; metadata-size is flat or slightly lower because the hasher holds no state.

## Rationale (optional)

cycle/0007/v001 replaced the queue scans with a `HashMap` keyed by `K`, but it kept the default SipHash, which is expensive for small keys on the hot path. This is a constant-factor cost change on the one cost-side direction the cycle 0007 insight ranked as the lead candidate. It is kept separate from the eviction-policy hypotheses in this cohort.

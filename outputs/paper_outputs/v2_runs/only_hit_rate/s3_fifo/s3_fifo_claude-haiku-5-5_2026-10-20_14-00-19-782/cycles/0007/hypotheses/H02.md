# H02

Dropping the `ghost_set` HashSet mirror and checking ghost membership by scanning the ghost queue lowers metadata-size while leaving eviction order and hit-rate unchanged.

## Parent

cycle/0006/v001

## Changes

Remove the `ghost_set` mirror from the S3-FIFO in `src/s3_fifo/mod.rs`. Keep everything else from the parent, including the resident bit folded into the per-slot state byte and the `last_miss` probe reuse.

- Delete the `ghost_set: HashSet<K>` field from the `S3Fifo` struct and its `HashSet::with_capacity(main_size)` initialisation in `try_new`.
- In `put`, replace `let in_ghost = self.ghost_set.contains(&key);` with `let in_ghost = self.ghost.iter().any(|ghost_key| ghost_key == &key);`. Keep the `retain` on `ghost` that follows; delete the `self.ghost_set.remove(&key);` line.
- In `evict_small`, remove the ghost-capacity block that pops from `ghost` and calls `ghost_set.remove(&old)`. Replace it with `if self.ghost.len() >= self.main_size { self.ghost.pop_back(); }`. Remove the `self.ghost_set.insert(tail.key.clone());` line. Keep `tail.clear_resident();` and the `self.ghost.push_front(tail.key);` line.
- Remove the `HashSet` import from `use std::collections::{HashSet, VecDeque};`, leaving `use std::collections::VecDeque;`. Keep `use std::hash::Hash;` because the impl bounds still use `Hash`.
- Delete the test `ghost_set_mirrors_ghost_queue`, since its subject no longer exists. Keep `resident_bit_mirrors_queues` and `miss_then_put_matches_direct_put` unchanged.
- Invariants to preserve: the ghost queue holds the same keys in the same order as the parent at every step; a key is found in ghost iff the parent would find it there; the `last_miss` path and resident-bit logic are untouched.

Report metadata-size and per-op-time alongside hit-rate. Expected direction: metadata-size goes down by the HashSet overhead, and per-op-time may rise because ghost membership becomes a linear scan over up to `main_size` keys on the miss path.

## Rationale (optional)

The parent folds the resident bit into the state byte. That removes one side table. `ghost_set` is the remaining side table, and it is only consulted on the miss path. Removing it trades a constant-time check for a smaller footprint, and the cost trade-off can only be read once the cost dimensions are reported.

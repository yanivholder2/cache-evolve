# H02

Resetting a key's frequency to 0 when it graduates from the small queue into main, so graduates must earn a fresh main hit to survive their first hand pass, will raise hit-rate by filtering one-burst keys out of main sooner.

## Parent

cycle/0008/v001

## Changes

Separate the graduation signal from the main retention signal. Only the promotion branch of `evict_small()` changes.

- In `evict_small()`, in the `if self.entry_mut(idx).freq > 1` branch, set `self.entry_mut(idx).freq = 0` right before `self.main_push_head(idx)`, after the possible `evict_main()` call. The graduation threshold stays `freq > 1`. Small-queue hits still count up to `MAX_FREQ = 7` in `get()`. The counter is cleared only at the moment of promotion, so main retention depends only on hits received while in main.
- Keep `evict_main()` as it is (clear-on-pass SIEVE). Keep ghost re-admission (head, freq 0), the ghosting of main victims, the fingerprint ring and the 5% split.
- Make the same change in the in-file reference: in `RefS3Fifo::evict_small`, set `tail.freq = 0` before `self.main_push_front(tail)`. The full-state comparison test then still pins the behaviour exactly.
- Fix the unit tests that read a graduate's freq after promotion. In `main_eviction_uses_frequency_second_chance`, key 5 enters main with freq 0 and the expected key order is unchanged. Add one new test: put a key in small, `get` it twice, force `evict_small()`, and assert that the key is in main with `freq_of == Some(0)`.
- Update the header comment.

## Rationale

Under SIEVE with clear-on-pass, a graduate currently enters main carrying freq 2–7, so it survives its first hand pass automatically. A ghost re-admission enters with 0 and does not. Cycle 8 found that protecting newcomers longer hurts and that quick demotion near the hand does useful filtering. Graduates are the remaining newcomers that get free protection. The FIFO-era evidence against a frequency reset (cycle 1) was confounded with a lower graduation threshold and was measured under FIFO reinsertion, so it does not settle the question under SIEVE. The prediction is that this beats cycle/0008/v001 by more than ±0.001. If it regresses instead, small-queue hits are real evidence that main should keep honouring.

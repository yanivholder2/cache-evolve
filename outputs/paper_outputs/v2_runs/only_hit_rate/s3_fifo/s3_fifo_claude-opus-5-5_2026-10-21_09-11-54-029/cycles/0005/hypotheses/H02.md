# H02

Lowering the small-to-main graduation threshold from freq > 1 to freq > 0, with no frequency reset, will raise hit-rate on workload-a, because with a 5% small queue a single reuse inside the short probation window is enough evidence to graduate.

## Parent

cycle/0004/v001

## Changes

In `src/s3_fifo/mod.rs`, in `S3Fifo::evict_small`, change the graduation condition `if self.entry_mut(idx).freq > 1` to `if self.entry_mut(idx).freq > 0`. Put the threshold in a named constant `GRADUATE_MIN_FREQ: u8 = 1` with the comparison `freq >= GRADUATE_MIN_FREQ` so later cycles can tune it.

The graduating entry keeps its accumulated `freq` unchanged when it moves to `main.push_front`. Do NOT reset it to 0. That reset was the confound in cycle 0001's v002.

Keep everything else identical to v001:
- `MAX_FREQ = 7`.
- The 5% split.
- The slab, index and lazy-ghost structure.
- Ghost re-admission at the front of main with freq 0.
- `evict_main` decrement rotation.
- The ghost cap at `main_size` and the compaction.

Make these test changes:
- Update the in-file reference `RefS3Fifo::evict_small` to use `tail.freq > 0`, so that `matches_v003_reference_on_pseudo_random_streams` still checks the indexed structure step by step against a linear model of the new policy.
- Add a unit test showing that a small entry hit exactly once is promoted to main on eviction, not ghosted.
- Add a unit test showing that a small entry with zero hits is still ghosted.

## Rationale (optional)

Cross-cycle insights list "decoupling the graduation threshold from the cap, threshold changed alone with no frequency reset" as an open question. Cycle 0001's v002 changed the threshold and a reset together, so its result couldn't be attributed. With a 5% small queue, the probation window is very short (~102 slots). A single hit inside that window may be stronger evidence of reuse than it was at a 10–25% split, so the old result may not carry over. Parenting on v001 (cap 7, indexed) follows cycle 0004's Continuation, which names it the effective baseline. It also keeps the comparison clean against 0.7289 without the cap-15 tie.

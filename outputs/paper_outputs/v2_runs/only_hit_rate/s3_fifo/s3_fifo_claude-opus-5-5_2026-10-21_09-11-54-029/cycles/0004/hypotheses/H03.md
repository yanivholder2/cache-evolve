# H03

Sending ghost-hit keys back into the small queue with one banked reuse credit, instead of straight into main, will raise hit-rate on workload-a by making them prove a second reuse within an access-count probation window before they take main capacity.

## Parent

cycle/0003/v003

## Changes

In `src/s3_fifo/mod.rs`, change only the ghost-hit branch of `S3Fifo::put`.

Current behaviour: after `self.ghost.retain(...)`, the key is evicted from main if main is full and then pushed onto `main.push_front(Entry::new(key, value))` at freq 0.

New behaviour: after removing the key from `ghost`, treat it like a new small-queue insert with `freq = 1`:
- Run `if self.small.len() >= self.small_size { self.evict_small(); }`.
- Then run `let mut e = Entry::new(key, value); e.freq = 1; self.small.push_front(e);`.

`evict_small` stays unchanged, which produces the following outcomes:
- If the key gets at least one more hit while it is in small, its freq becomes 2 or more and it graduates to main on reaching the small tail (`freq > 1`). It carries its banked credits with it, clamped by `MAX_FREQ = 7`.
- If it gets no hit during its small residency of about `small_size` = 102 insertions, its freq is still 1. It fails graduation and goes back into the ghost queue, so a later re-access can retry.

Keep everything else unchanged:
- `MAX_FREQ = 7`
- the 5% split
- `evict_main`
- the ghost capacity of `main_size`
- the cold-insert path, which stays at freq 0

Tests:
- Update `ghost_hit_promotes_back_to_main` so that it asserts the re-accessed key lands in `small` with freq 1.
- Add a test: a ghost-readmitted key that is then hit once is in `main` after it reaches the small tail.
- Add a test: a ghost-readmitted key with no further hit is back in `ghost` after it reaches the small tail.
- Keep `capacity_bound_never_exceeded` as it is.

## Rationale (optional)

Cycle 0003's insight says tail insertion did not test "require a second reuse signal", because its deadline was the next main insertion rather than a span of the access stream. This variant tests that signal directly, with a probation window that is a real span of accesses (the small queue's FIFO residency). Main capacity is then spent only on keys with two reuse signals: the ghost hit plus a hit while in small. Every past winner has favoured protecting proven reuse, which supports this. If it loses, that confirms the bare ghost hit is already enough evidence, and that front-of-main is the right re-admission point.

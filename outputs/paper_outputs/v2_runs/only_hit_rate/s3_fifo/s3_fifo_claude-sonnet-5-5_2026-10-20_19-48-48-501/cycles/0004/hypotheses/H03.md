# H03

Making ghost hits insert into main only when the ghosted key was evicted from small with freq > 0 will raise hit-rate by tightening the ghost-hit admission rule.

## Parent

cycle/0003/v001

## Changes

Extend the ghost entry metadata to record whether the key had been re-accessed (freq > 0) at the time it was evicted from small (a bool or a bit packed into the existing ghost record; main-victim ghosting from the current line stays). On a miss that hits the ghost, insert directly into main only if this flag is set; otherwise insert into small as for a cold miss (and remove the ghost entry). Keep small queue ratio capacity/20, ghost length, promotion gate, and main eviction unchanged. Keep memory growth minimal (one bit per ghost entry).

## Rationale (optional)

Untested stricter ghost-hit rule; targets hit-rate without touching ageing, which has lost every time.

# H02

Requiring freq >= 2 (instead of the current gate) for promotion from small to main will raise hit-rate by filtering weakly reused keys.

## Parent

cycle/0003/v001

## Changes

In the small-queue eviction path (where the tail of small is either promoted to main or evicted to ghost), tighten the promotion condition by one level: promote only if the item's access frequency counter is >= 2 (if the current gate is already >= 2, make it >= 3 but keep the freq cap at its current value so the gate is reachable). Items failing the gate go to the ghost as before. Keep the small queue ratio (capacity/20), ghost length, and main eviction unchanged. Do not alter the ghost-hit admission path.

## Rationale (optional)

Stricter admission has been the recurring winner; this is the untested stricter-promotion lever.

# H02

Make hit-path promotion fire at freq 3 instead of 2 and insert the promoted entry with freq reset to 1, to improve hit rate by keeping weakly reused keys out of main.

## Parent

cycle/0008/v003

## Changes

In the hit-path promotion branch added by the parent, raise the promotion threshold from freq >= 2 to freq >= 3. On promotion, set the entry's freq to 1 rather than carrying the count over, so main's second-chance scan gives it one reprieve rather than several. Leave the sizing, the ghost handling and the main eviction scan untouched. If the threshold is already parameterised, change only the constant.

## Rationale (optional)

Tests whether the promotion threshold and the carried-over freq matter. Earlier cycles showed loosening admission loses, so a stricter gate with a reset count is the natural direction.

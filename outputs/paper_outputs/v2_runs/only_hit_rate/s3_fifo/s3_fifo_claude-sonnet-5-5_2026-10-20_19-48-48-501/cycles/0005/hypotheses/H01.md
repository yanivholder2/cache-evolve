# H01

Reinserting main-queue victims with freq>0 at the main tail (with freq decremented) only when a ghost-hit flag was set on admission will raise hit-rate.

## Parent

cycle/0004/v001

## Changes

In the overlay's main-queue eviction loop (the function that pops from main, checks `freq`, and either reinserts with `freq-1` or evicts), add a one-bit per-entry "ghost-admitted" marker set when an entry enters main directly via a ghost hit. Entries carrying the marker get one extra reinsertion chance: when popped with freq==0 and the marker set, clear the marker and reinsert once at the tail with freq 0 instead of evicting. Entries promoted from small (no marker) behave exactly as in the parent. Keep the ghost length (capacity/2), small ratio and promotion threshold unchanged. The ghost-hit admission path stays permissive. If a per-entry bool changes the metadata size, pack it into the existing freq byte's spare high bit.

## Rationale (optional)

Cross-cycle notes say ghost hits are strong reuse evidence; this protects them slightly longer without loosening admission.

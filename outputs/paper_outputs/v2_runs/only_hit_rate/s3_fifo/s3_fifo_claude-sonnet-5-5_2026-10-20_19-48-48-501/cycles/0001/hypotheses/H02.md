# H02

Recording keys evicted from the main queue into the ghost queue will raise hit-rate by letting recently evicted main residents be re-admitted directly to main.

## Parent

baseline

## Changes

In `src/s3_fifo/mod.rs`, `evict_main()`: when the loop breaks on a tail with `freq == 0`, instead of silently dropping that entry, push its key to `self.ghost.push_front(key)`, first popping from `ghost.back()` if `ghost.len() >= main_size` (same bound as `evict_small`). Restructure the loop so the victim is moved out (not dropped) and its key cloned/moved into ghost. Do not change `evict_small` or `put`'s ghost-hit path. Ghost must contain no duplicate keys and never exceed `main_size`.

## Rationale (optional)

Baseline ghost only tracks small-queue rejects; main-queue victims are forgotten, so a premature main eviction cannot be corrected.

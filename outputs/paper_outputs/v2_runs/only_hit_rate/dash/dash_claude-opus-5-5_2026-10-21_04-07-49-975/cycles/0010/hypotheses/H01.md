# H01

Shrinking the recency-gated ghost table once more, from half to a quarter of the cache's entry count, cuts metadata-size while hit-rate stays within 0.002 of 0.7307, which shows where direct-mapped collisions start to cost hits.

## Parent

cycle/0009/v002

## Changes

Start from cycle/0009/v002: a direct-mapped ghost table of about `capacity / 2` fingerprints, ghost hits with age ≤ 4 epochs go to stash MRU, no BIP, and fresh keys go to stash LRU.

- Halve the ghost table entry-count constant again, from about `capacity / 2` to `capacity / 4`. If the table is allocated per segment, halve the per-segment count instead. Keep the count a power of two, and update the index mask or shift so the fingerprint hash spreads over the whole smaller table. Do not just mask off high bits of an index that was computed for the old size.
- Keep the epoch length, measured in evictions, unchanged, and keep the age ≤ 4 cutoff unchanged. The gate must keep the same meaning in eviction distance. Only the table gets smaller.
- Keep the per-entry layout (fingerprint width and epoch-tag width) as it is in v002. Change only the entry count, so the result isolates the effect of collisions.
- Update any metadata-size accounting (any function or constant that reports the cache's metadata footprint) so it reflects the new table size.
- Leave unchanged: the gated ghost-hit → stash MRU path, fresh-key LRU insertion, demotion MRU re-entry with pre-credit, the stash→target threshold, the second-chance scan, and Front landing.

## Rationale (optional)

The cycle-0009 continuation asks for exactly one further shrink to find where shrinking stops being free. At a quarter size, each slot is overwritten about twice as fast as in v002. That is roughly every quarter-window of evictions, which falls inside the 4-epoch gate. If hit-rate holds, the gate is not the binding limit and collisions still mostly remove stale entries. If hit-rate drops by more than about 0.002, recent evidence is being overwritten, and v002's size is the floor for a direct-mapped design.

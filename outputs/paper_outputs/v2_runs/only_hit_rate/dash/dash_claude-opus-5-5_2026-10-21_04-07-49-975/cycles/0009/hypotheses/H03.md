# H03

Moving slot capacity from the normal tier into the stash, at a constant total slot count, raises hit-rate, because the stash's evidence-filtered victim cache now does most of the useful retention.

## Parent

cycle/0008/v001

## Changes

Start from cycle/0008/v001 (recency-gated ghost, no BIP). Find the per-segment layout constants that set how many normal buckets and how many stash buckets (or stash slots) a segment holds, and the slots per bucket. These are in the overlay's dash table/segment module, not in `src/factory.rs`. Do not edit `factory.rs`. If the total capacity is derived there from these constants, keep the per-segment total slot count identical so the cache's overall capacity is unchanged.

- Move the equivalent of **one normal bucket's worth of slots per segment** into the stash. Either decrease the normal-bucket count by 1 and add the same number of slots to the stash (one more stash bucket, or wider stash buckets), or apply the nearest equivalent the layout allows while keeping the total per segment exactly equal.
- Update every place that derives from these constants: the bucket index mask/modulo used for hashing into normal buckets (it must stay correct when the count is not a power of two; use modulo or `hash % n` if the mask assumption breaks), the stash bucket selection, the probing-neighbour wraparound, and any per-segment metadata arrays (bitmaps, counters, overflow fingerprints) sized from them.
- Keep the split/resize trigger semantics unchanged. A segment is still "full" when all its normal and stash slots are full.

Leave unchanged: all stash policy (LRU-end fresh insert, gated ghost MRU, demotion MRU re-entry with pre-credit, the second-chance scan), the stash→target threshold, Front landing, and the ghost table size and gate.

## Rationale (optional)

The cross-cycle open questions name the stash-to-normal slot ratio as the main untried structural lever now that in-stash levers are exhausted. Since 0003 the evidence has been that the normal tier's cascade damage no longer matters and that the stash's protected region is zero-sum. That suggests a stash slot is worth more than a normal slot. If this gains, the next step is to try a second shift. If it loses, normal-tier hits (Front-landed, frequency-coupled) carry more value than the stash's victim-cache role, and the ratio should be tested in the opposite direction.

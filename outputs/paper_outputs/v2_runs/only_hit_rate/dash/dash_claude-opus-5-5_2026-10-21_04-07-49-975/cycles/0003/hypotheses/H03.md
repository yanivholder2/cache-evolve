# H03

Send items evicted from a full normal bucket straight to the stash, with no cross-bucket demotion cascade into a neighbour's target bucket, to increase hit-rate.

## Parent

cycle/0002/v003

## Changes

In v003, when a promotion or insert into a full normal bucket evicts a resident whose true target is a different bucket (a foreign resident in a probing slot), the cascade path pushes that resident back into its own target bucket. If that bucket is full too, its LRU item is demoted. One normal-tier eviction can therefore cost a hit-rate-relevant resident in a neighbouring bucket. Change the routing like this:

- In the cascade path, do not reinsert the evicted foreign resident into its true target bucket. Demote it directly to the stash using the same code as the direct `true_target == source_idx` demotion path: place it at `DEMOTE_TO_STASH_POS = Back` (MRU) and pre-credit it with `PROMOTE_THRESHOLD - 1`, so one return hit promotes it back to its target through the normal promotion path.
- Exception: if the foreign resident's true target bucket has a free slot, keep the current behaviour and move it there. That move evicts nobody, so it stays.
- The direct `true_target == source_idx` demotion path, Front landing, the target one-more-chance retry with the incoming `insert_pos`, and `PROMOTE_THRESHOLD = 2` all stay unchanged.
- Make sure the stash insert for the demoted item goes through the stash's normal full-bucket eviction, so the stash's capacity invariant holds and no key is duplicated across tiers. Remove the key from its normal slot before inserting it into the stash, and keep any fingerprint or overflow metadata consistent with the existing demotion helper.

## Rationale (optional)

The cross-cycle insights say each normal-tier eviction starts a demotion cascade that hurts neighbouring buckets, and that eviction/cascade routing is the main lever not yet explored. Since v003, the stash works as a victim cache that brings ex-residents back cheaply, so sending cascaded items there costs little. It also spares the neighbour's LRU resident, which would otherwise lose its slot without having done anything. Fewer multi-bucket moves per insert should also lower per-op-time.

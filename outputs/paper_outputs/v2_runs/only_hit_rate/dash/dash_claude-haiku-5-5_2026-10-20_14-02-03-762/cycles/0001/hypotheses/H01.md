## Changes

Edit `promotion_get()` in `src/dash/segments/dash_segment.rs`. Today the
probing-bucket branch (the `core.buckets[probing_idx].get_position(key)` block
near lines 182-185) returns the item in place via `get_from_position`. Replace
that branch so a hit in the probing bucket is treated as proof of reuse:

- Remove the item from `core.buckets[probing_idx]` with `remove_at(item_idx)`.
- Re-insert it through the existing `promote_to_target(core, data,
  InsertPosition::Back)` helper, so it lands at the MRU end of its true target
  bucket (`target_idx`). Any item evicted from the target flows through
  `demote_from_normal_bucket` exactly as it does today.
- Look the key up again in `core.buckets[target_idx]` (the same
  `unreachable!`-guarded pattern used by the stash branch) and return a
  reference to it.

Leave the stash branch, the target-hottest promotion branch, the
`promote_to_target` / `promote_to_probing` / `demote_from_normal_bucket`
helpers, and the `DashSegment::get` entry point unchanged. Update the
in-file test `probing_hit_touches_in_place` so it asserts the new behaviour
(the key moves to the target bucket). Keep the `EvictionPolicy` trait and
`ClassicLRU` implementation untouched.

# H03

Make the second-sighting admission filter bypass keys that hit the ghost table twice to raise hit-rate through adaptive admission strictness.

## Parent

baseline

## Changes

Starting from the baseline cache, add an adaptive admission gate: maintain a small global counter of recent admitted-then-never-hit evictions versus admitted-then-hit evictions over a window of 4096 evictions. When the fraction of never-hit evictions exceeds 0.5, require second-sighting (a one-bit bit-array filter indexed by key hash, set on first miss, cleared on admit); otherwise admit every miss directly. Keep a one-bit reuse flag per slot (set on hit) used to prefer unflagged victims. Reset window counters each window. The filter is a fixed-size bit array of 8x the slot count with no aging beyond clearing on admit.

## Rationale (optional)

Earlier cycles showed unconditional admission filtering helped; this tests whether making it workload-adaptive does better, which also addresses generalization to other traces.

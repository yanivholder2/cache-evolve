# H03

Add a segment-level doorkeeper Bloom-style bit array on the baseline insert path, reset periodically, to raise hit-rate by admitting only keys seen twice within a window.

## Parent

baseline

## Changes

In the baseline DashSegment insert path, add a fixed 256-bit doorkeeper per segment (array of four u64). Hash the key with two independent hash functions derived from the existing key hash (low and high halves). On a miss that needs eviction, if both bits are set, admit the key and clear nothing; otherwise set both bits and reject the insert (return without storing). When the number of set bits exceeds 50% of the array, clear the doorkeeper entirely. Do not change hit-path promotion or victim selection. When the segment has free slots, always admit. This tests an independent admission design from v002's, with periodic reset instead of a persistent filter.

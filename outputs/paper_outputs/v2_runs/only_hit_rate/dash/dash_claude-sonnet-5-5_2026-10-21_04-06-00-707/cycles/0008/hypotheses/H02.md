# H02

Replacing per-scan counter aging with a global periodic decay (halve all counters every N evictions) will raise hit-rate by keeping counters from being decremented by scan position.

## Parent

cycle/0007/v001

## Changes

In the cycle 7 v001 eviction code, make the victim scan non-mutating: it selects the first slot with counter 0, and if none is found in the scanned window, selects the slot with the minimum counter (ties broken by first found), without decrementing others. Add an eviction counter (relaxed atomic u32); every N = capacity/2 evictions, the evicting thread performs a decay pass that shifts every counter in the table right by one bit (3 to 1, 2 to 1, 1 to 0), done incrementally over a bounded number of buckets per eviction if a full pass is too slow. Hit path (saturating increment to 3) and the admission filter remain unchanged. Invariant: counters stay in 0..3 and only live entries are touched.

## Rationale (optional)

Per-scan aging penalises entries by where the scan starts rather than by actual idleness. A time-based decay tied to eviction pressure is the TinyLFU-style reset applied to residents.

# H01

Replace the one-bit reference flag with a two-bit saturating reuse counter that is aged during victim scans, to raise hit-rate beyond 0.7199.

## Parent

cycle/0006/v001

## Changes

In the overlay's eviction path (the function that picks the victim by scanning the target bucket and stash for the first unreferenced slot), widen the per-slot referenced flag to a 2-bit counter stored in the same spare metadata bits (use the spare bits already used for the flag plus one adjacent spare bit; if only one bit is truly free, pack the counter into the low bits of existing per-slot metadata without growing the slot). On hit: saturating increment (max 3). On insert: set to 0. On eviction: scan the bucket+stash for the first slot with counter == 0; if none found, decrement the counter of every scanned slot by 1 (CLOCK-style aging) and then evict the slot that reached 0 first (or the first slot if none). Keep the second-sighting admission filter and MRU-on-hit promotion unchanged. Invariant: no change to lookup results, only to which entry is evicted.

## Rationale (optional)

The one-bit reuse signal broke the plateau; a graded signal distinguishes hot from once-reused entries and ages stale ones.

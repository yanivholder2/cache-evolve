# H03

Skip the second-sighting admission filter for keys whose insertion would displace only an unreferenced victim, to test whether the filter is redundant given reuse-bit eviction, targeting hit-rate.

## Parent

cycle/0006/v001

## Changes

In the v001 overlay's insert path, where the one-bit second-sighting filter decides whether a new key is admitted: when the target bucket (or stash) contains an empty slot, admit immediately without consulting or requiring the filter bit (still record the key in the filter). When the bucket is full, keep the existing behaviour: require a second sighting before evicting a victim. Leave the eviction logic (first unreferenced slot) and promotion unchanged. Invariant: filter memory size is unchanged; only the admission condition depends on slot availability.

## Rationale (optional)

Admission only matters when it forces an eviction; with free space, delaying admission just loses a hit. Tests whether the filter and reuse-bit eviction interact rather than stack.

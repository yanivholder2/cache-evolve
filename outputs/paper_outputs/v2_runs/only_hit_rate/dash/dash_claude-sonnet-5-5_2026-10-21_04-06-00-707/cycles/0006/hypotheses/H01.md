# H01

Evict the slot that has not been hit since insertion (a one-bit CLOCK-style referenced flag) instead of the current victim, to raise hit-rate on top of the second-sighting filter.

## Parent

cycle/0005/v001

## Changes

In the overlay's eviction/victim-selection function (the one called when a bucket and its stash are full and the admitted key must displace an entry), add a per-slot "referenced" bit. Store it in spare bits of the existing slot metadata so metadata-size does not grow. Set the bit in the hit path (the same place that does MRU promotion). Clear it on insert. When choosing a victim, scan the bucket slots, and if the stash is probed, scan those too. Pick the first slot with referenced==0. If every slot is referenced, clear all bits and fall back to the existing victim choice. Leave the second-sighting filter (and its 4x capacity) unchanged. First confirm the victim path is live: the new code must sit on the call path that actually evicts. Do not add item movement.

## Rationale (optional)

Earlier victim-selection tweaks tied their parent exactly, so they were probably dead edits. This one uses a real reuse signal instead of position.

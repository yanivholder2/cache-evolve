# H03

Replace blind admission with a frequency-comparison admission (admit a candidate only if its count-min estimate beats the would-be victim's) to raise hit-rate with a different admission signal.

## Parent

baseline

## Changes

In the baseline insert path, add a small 4-bit-counter count-min sketch (4 rows, power-of-two width of about 4x the cache entry count, indexed by independent hashes of the key). Increment it on every get/lookup and insert attempt for the key. Halve all counters after a number of increments equal to 10x the capacity (aging). When an insert would require evicting, compare estimate(candidate) against estimate(victim). Victim here is whatever the existing eviction code selects. Admit the candidate only if its estimate is strictly greater, otherwise drop it. When there is a free slot, always admit. Do not use a one-bit second-sighting filter, so this is a distinct mechanism from the incumbent. Keep the sketch in the overlay's own structure and make it thread-safe with relaxed atomics.

## Rationale (optional)

A frequency signal measures how valuable the victim is, which a context-free second-sighting filter cannot. Earlier counter variants were stacked on the filter, so this tests it alone.

# H02

Make the admission filter bypass-free but scan-resistant by clearing the second-sighting filter bits of a bucket's region when the eviction scan finds no victim with counter 0, to raise hit-rate on scan-like phases.

## Parent

cycle/0008/v001

## Changes

In the overlay's victim-selection function, track whether the scan found any slot with counter 0 (or reuse bit unset). If every slot in the bucket was hot (all counters > 0 before decrement), treat this as a scan/pressure signal: do not insert the new key (drop it, leaving its filter bit set so a third sighting is needed) — i.e. require the incoming key to be seen again before displacing a bucket full of reused entries. Otherwise behave exactly as v001. Do not touch ghost table logic except to skip ghost restoration for dropped keys.

## Rationale (optional)

Protects a fully-hot bucket from displacement by a once-reseen key; tests an untried scan-resistance lever.

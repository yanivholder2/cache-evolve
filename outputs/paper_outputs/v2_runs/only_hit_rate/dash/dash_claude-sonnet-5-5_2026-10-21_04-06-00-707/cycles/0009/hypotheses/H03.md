# H03

Shrink per-slot metadata and per-op cost of the baseline-plus-admission design by dropping to a one-bit reuse eviction with the admission filter stored compactly, targeting metadata-size and per-op-time at near-equal hit-rate.

## Parent

baseline

## Changes

Starting from the baseline, add only: (1) a one-bit "hit since insertion" flag per slot (pack it into an existing spare bit of the slot's fingerprint/metadata word rather than a new field); (2) victim selection that prefers the first slot in the bucket with flag clear, falling back to the baseline victim if all are set, clearing flags on the scan only for the slot examined; (3) a second-sighting admission filter implemented as a fixed-size bit array sized to the table's slot count (single hash, no counters, no aging). No ghost table, no counters, no tiers. Goal: retain most of the 0.7 hit-rate gain with no added per-slot bytes beyond bits.

# H01

Insert newly admitted items at the MRU end of their bucket (in addition to MRU promotion) to raise hit-rate on recency-skewed traces.

## Parent

cycle/0001/v001

## Changes

In the segment insert path (`DashSegment` insert / the code that places a brand-new key into its target bucket, and any displacement path that moves a victim from target to probing or stash), pass `InsertPosition::Back` (the MRU end, as v001 uses in `get`) instead of the current default position. Keep v001's `get` promotion unchanged. Do not alter eviction victim selection, bucket capacity, or metadata layout.

## Rationale (optional)

v001 showed MRU placement on hit-promotion helps; new inserts likely suffer the same cold placement.

# H02

Add a one-hit-wonder admission filter that skips inserting a key on its first miss, to raise hit-rate on workload-a.

## Parent

cycle/0002/v001

## Changes

In the DashSegment insert entry point, add a small fixed-size admission filter held in the segment. The filter is an array of 64 to 256 u8 or u16 slots, indexed by a hash of the key. On a miss-driven insert, if the segment is full enough that an eviction would be needed, check the filter first. If the key's slot has not been seen, record the key and skip the insert. If it has been seen, admit the key and clear the slot. Always admit when there is a free slot, so the cache fills normally. Do not change the hit path or promotion. Reset the filter on segment split or rehash. Keep the added state to at most 256 bytes per segment.

## Rationale (optional)

Admission has not been tried in any cycle. Skipping one-hit-wonders should protect useful entries from being evicted. The cost is extra metadata, which the implementer should report.

# H01

Swapping cycle 9 v001's key-cloning ghost (`ghost_q` + `ghost_set`) for cycle 9 v003's u64 fingerprint ring will keep hit-rate at 0.7387 (within ±0.0002) and remove every per-slot ghost key clone, cutting `metadata-size`.

## Parent

cycle/0009/v001

## Changes

Start from cycle/0009/v001's `src/lru_cache/mod.rs`. Keep `MAX_FREQ = 7`, `small_target = max(1, capacity / 80)`, `ghost_cap = max(1, 13 * capacity / 80)`, the `node.freq -= 1` carryover in `evict_one()`'s `small` branch, and the whole `main` branch exactly as they are. Only the ghost representation changes, and it should match cycle/0009/v003:

- In `LruCache`, replace `ghost_q: VecDeque<K>` and `ghost_set: HashMap<K, ()>` with `ghost_ring: Vec<u64>` (preallocated as `vec![0u64; ghost_cap]`, where 0 means an empty slot), `ghost_head: usize`, `ghost_count: HashMap<u64, u32>` (fingerprint -> live occurrences) and `ghost_hasher: RandomState`.
- Add `fn fingerprint(&self, key: &K) -> u64`, which returns `ghost_hasher.hash_one(key)` and remaps 0 to 1.
- Add `fn ghost_dec(counts, fp) -> bool`: a saturating decrement that removes the entry when it reaches zero and returns true iff the count was positive. Copy it from v003.
- In `put()`, replace `self.ghost_set.remove(&key).is_some()` with `let fp = self.fingerprint(&key); let ghost_hit = Self::ghost_dec(&mut self.ghost_count, fp);`.
- In `evict_one()`'s `small` eviction path (freq == 0), compute the fingerprint from a borrow of `self.nodes[idx].key` before `map.remove`. Then call `push_ghost(fp)`. Drop the `node.key.clone()`. The `main` eviction path should also remove the key through a borrow instead of a clone.
- Change `push_ghost(fp: u64)` to overwrite `ghost_ring[ghost_head]`. If the old value is non-zero, `ghost_dec` it first. Then increment `ghost_count[fp]` and advance `ghost_head` modulo `ghost_cap`.

Update the tests that touch `ghost_q`/`ghost_set` (`ghost_hit_admitted_into_main`, `ghost_window_expires_after_ghost_cap_plus_one_evictions`, `main_evictions_not_ghosted`, `capacity_bound_under_churn*`, `skewed_churn`) to use a `fn is_ghost(&cache, key)` helper based on `ghost_count`. Also check that the total of `ghost_count` values is at most `ghost_cap`. Keep `small_hits_carry_credit_into_main`, `single_small_hit_enters_main_with_zero_credit` and `freq_saturates_at_max_freq` (MAX_FREQ == 7) unchanged.

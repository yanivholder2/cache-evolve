# H02

Make v001's small-queue size adaptive, ARC-style, driven by ghost hits from the small and main queues, to raise hit rate on workload-a above the fixed 10% split.

## Parent

cycle/0001/v001

## Changes

In `src/lru_cache/mod.rs` (v001's S3-FIFO):

- Add a second ghost for main-queue evictions: `main_ghost_q: VecDeque<K>` and `main_ghost_set: HashMap<K, ()>`, capped at `capacity / 2`. Make `small_target` mutable state bounded to `[max(1, capacity/100), capacity/2]`, starting at `max(1, capacity/10)`. Keep the existing small ghost unchanged.
- In `evict_one()`, main-queue victims (the `else` branch, freq 0) are now pushed into `main_ghost` through a new `push_main_ghost(key)` with the same FIFO-capped logic as `push_ghost`.
- In `put` for a new key:
  - **Hit in the small ghost** (`ghost_set`): the key was evicted from probation too early, so grow the probation queue: `small_target = min(max_small, small_target + max(1, main_ghost_len / small_ghost_len))`, using the current ghost lengths and guarding against division by zero. Admit into main, as v001 does today.
  - **Hit in the main ghost**: main was too small, so `small_target = max(min_small, small_target - max(1, small_ghost_len / main_ghost_len))`. Remove the key from the main ghost and admit it directly into main with `freq = 0`.
  - **Miss in both**: insert into small, as before.
- The `evict_one()` condition `self.small.len() >= self.small_target || self.main.is_empty()` stays the same but now reads the adaptive target. Termination is unchanged.
- Add a unit test that after a churn loop, `small_target` stays within its bounds and `small.len()+main.len()==map.len()`. Update `main_evictions_not_ghosted` so that it asserts the key is absent from the *small* ghost and present in the main ghost.

## Rationale (optional)

workload-a mixes loop and scan phases. A fixed 10% probation is a compromise between the two. ARC-style feedback from two ghost lists lets the split follow the phase. This tests the open question from cycle 1 about how sensitive hit rate is to the small-queue size.

# H01

Shrinking the S3-FIFO ghost window from `capacity - small_target` to `capacity / 2` will raise hit-rate on workload-a, because fewer long-loop keys will skip probation and enter `main` on a ghost hit.

## Parent

cycle/0001/v001

## Changes

Change only the ghost sizing in `src/lru_cache/mod.rs`. Everything else stays exactly as in the parent.

- In `LruCache::try_new`, replace `let ghost_cap = std::cmp::max(1, capacity - small_target);` with `let ghost_cap = std::cmp::max(1, capacity / 2);`. Size the `ghost_q` and `ghost_set` `with_capacity(ghost_cap + 1)` allocations from the new value, and update the `log::info!` line so it reports the new `ghost_cap`.
- Leave all of the following unchanged:
  - `small_target = max(1, capacity / 10)`
  - `MAX_FREQ = 3`
  - the ghost-hit-goes-to-`main` rule in `put`
  - `evict_one`
  - `push_ghost`, whose trimming loop already enforces the new cap
  - the `VecDeque<K>` + `HashMap<K, ()>` ghost representation. Don't introduce fingerprints, so the policy change is tested on its own.
- Invariants to keep: `map.len() <= capacity`, `small.len() + main.len() == map.len()`, and `ghost_q.len() <= ghost_cap`. Evictions from `main` are still not ghosted.
- Tests: the existing tests should still pass, including `ghost_hit_admitted_into_main` at capacity 10, where `ghost_cap` becomes 5 and key 1 is still in the ghost right after one eviction. Add one test checking that after `ghost_cap + 1` small-queue evictions, the first evicted key is no longer in `ghost_set`, so a re-put lands in `small`, not `main`.

## Rationale (optional)

Cycle 2's v001 made the ghost window longer (2×capacity) and lost hit rate (0.7269 → 0.7197). The diagnosis was that ghost hits from loops longer than the cache get admitted into `main` without proving resident reuse. This hypothesis tests the opposite direction on the same axis. If tightening the window raises hit rate, the ghost size is a real tuning knob and the parent's value is too loose. If hit rate drops, `capacity - small_target` is near a local optimum and future cycles can stop tuning the ghost size.

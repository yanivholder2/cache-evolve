# H02

Replacing the doubly-linked recency list with a CLOCK (second-chance) ring, using a one-bit reference flag per node, will cut per-entry metadata from 48 to 24 bytes for `Node<u64,u64>` while keeping hit rate within 1 point of the baseline's 0.6652.

baseline

## Changes

Rewrite the policy in `src/lru_cache/mod.rs` and keep the public surface unchanged: `pub struct LruCache<K, V>`, `pub struct Node<K, V>`, `try_new`, `new`, `get`, `put`, and the `framework::Cache` impl. Do not touch `lru_cache_jni.rs`.

Data layout:
- `Node<K, V>` becomes `{ key: K, value: V, referenced: bool }`. Remove `prev: Option<usize>` and `next: Option<usize>`, which take 32 bytes for `u64` keys and values. With `u64`/`u64` the node should be 24 bytes (8 + 8 + 1, padded). Add a `const _: () = assert!(size_of::<Node<u64,u64>>() <= 24);` or an equivalent unit test.
- `LruCache` drops `head`/`tail` and gains `hand: usize`, the clock hand index into `nodes`. Keep `map: HashMap<K, usize>` and `capacity`.

Behaviour:
- `get`: on a hit, set `nodes[idx].referenced = true` and return the value. There are no list splices.
- `put` with an existing key: overwrite the value and set `referenced = true`.
- `put` with a new key while `nodes.len() < capacity`: push `Node { key, value, referenced: false }` and insert it into the map.
- `put` with a new key while full: run `find_victim()`. Starting at `hand`, while `nodes[hand].referenced` is true, clear it and advance `hand = (hand + 1) % capacity`. The first unreferenced slot is the victim. Remove its key from `map`, overwrite the key and value in place, set `referenced = false`, insert the new key into `map`, and advance `hand` past the slot. The loop runs at most `capacity + 1` steps because it clears bits as it goes.
- Invariants: `map.len() <= capacity` (P1), values round-trip exactly (P2), and only inserted keys are resident (P3). Capacity 1 must work: the hand stays at 0.

Tests: the strict-LRU unit tests in `mod.rs` that assert exact LRU victims (`eviction_removes_lru`, `access_updates_lru_order`, `put_updates_lru_order`, `get_middle_node_promotes_correctly`, `overwrite_mru_at_capacity`, `slot_reuse_after_promotion_and_re_eviction`) must be rewritten for second-chance semantics. Examples: a referenced entry survives one sweep, and the hand evicts the first unreferenced slot. Keep the capacity, overwrite and miss tests.

## Rationale (optional)

The metadata-size dimension is dominated by the two `Option<usize>` links (16 bytes each). CLOCK is a well-known approximation of LRU whose hit rate is usually close to LRU's. A hit also becomes a single store instead of six pointer writes, so get p50 should improve as a secondary effect.

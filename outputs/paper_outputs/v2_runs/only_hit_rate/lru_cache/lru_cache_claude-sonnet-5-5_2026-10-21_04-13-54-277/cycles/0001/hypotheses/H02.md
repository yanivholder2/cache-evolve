# H02

Avoid redundant list relinking and the key clone on the hot paths to lower get/put per-op time.

## Parent

baseline

## Changes

In `src/lru_cache/mod.rs`: (1) add a fast path in `get` and in the existing-key branch of `put`: if `self.tail == Some(idx)` the node is already MRU, so skip `unlink`/`push_back`. (2) Replace the separate unlink+push_back promotion with a single `move_to_back(idx)` that reads prev/next once and does the minimal pointer writes. (3) On eviction in `put`, avoid `evicted_key = key.clone()` plus `key.clone()` for the new node: use `std::mem::replace` on `nodes[head_idx].key` to take out the old key for `map.remove(&old)`, and clone the new key only once for the map insert. (4) Remove the `log::info!` and `debug_assert!` from hot paths where possible, keeping the constructor log. Semantics (strict LRU order, capacity, API) must remain identical.

# H01

Remove the double-counting of each miss in the sketch (record once per miss instead of in both get and put) and re-tune the admit margin to raise hit-rate.

## Parent

cycle/0009/v002

## Changes

In `src/lru_cache/mod.rs`, add a field `last_miss: Option<u64>` to `LruCache`. In `get()` miss path, still call `self.sketch.record(h)` and set `self.last_miss = Some(h)`. In `put()` for a non-resident key, compute `h`; if `self.last_miss == Some(h)` then skip `self.sketch.record(h)` and clear `last_miss`, else record as before. Change the admission rule to `if ve == 0 { ce >= 1 } else { ce > ve }` (margin 0, since counts are now half as inflated). Keep everything else (SLRU, protected_cap 95%, 4-bit sketch, aging sample) unchanged. Invariant: cache semantics (get/put return values) unchanged.

## Rationale (optional)

The trace is get-then-put on miss, so each miss counts twice, which inflates counts and saturates 4-bit counters sooner. Counting once gives finer frequency resolution.

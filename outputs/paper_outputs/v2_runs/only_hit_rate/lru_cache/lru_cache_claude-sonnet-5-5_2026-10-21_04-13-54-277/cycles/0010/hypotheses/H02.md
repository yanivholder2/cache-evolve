# H02

Rotate the rejected-against victim to the probation MRU end on admission rejection to sample different victims and raise hit-rate.

## Parent

cycle/0009/v002

## Changes

In `put()` in `src/lru_cache/mod.rs`, in the `if !admit { return; }` branch, before returning: if the victim came from the probation list and `ve > 0`... specifically, if `self.len[PROBATION] > 1`, call `self.unlink(victim); self.push_back(victim, PROBATION);` so the next candidate faces the next-oldest probation entry instead of the same stuck head. If the victim is the sole probation entry or came from protected, do nothing. Admission rule unchanged (`ve == 0 ? ce >= 1 : ce > ve + 1`). Preserve all other logic.

## Rationale (optional)

A single hot-ish probation head can block admission repeatedly while colder entries behind it stay resident; rotation lets candidates compete against varied victims.

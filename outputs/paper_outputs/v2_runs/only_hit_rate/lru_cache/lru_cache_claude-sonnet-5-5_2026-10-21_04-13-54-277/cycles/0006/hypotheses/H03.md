# H03

Add a protected-segment demotion guard based on sketch frequency to the baseline-derived segmented design is too narrow, so instead apply plain 1-bit CLOCK eviction plus the sketch admission gate to raise hit-rate.

## Parent

baseline

## Changes

Starting from the baseline strict-LRU, implement a single-list CLOCK cache: each entry has one referenced bit, set on hit, with inserts entering unreferenced. Eviction sweeps the hand, clearing referenced bits and evicting the first unreferenced entry. Add a compact TinyLFU-style count-min sketch (4 rows of 4-bit counters, halving every 10 * capacity accesses) as an admission gate: on a full cache, find the hand's victim candidate (first unreferenced entry) and drop the new key if its estimate is strictly lower than the victim's. Sketch is incremented on every lookup (hit or miss). Keep the public cache API and its behaviour on get/put/remove unchanged. This combines the CLOCK and admission wins that have only been tested separately.

# H02

Add a one-bit doorkeeper in front of the sketch in cycle/0005/v001 so first-time keys bypass the counters, targeting hit-rate with lower sketch pressure.

## Parent

cycle/0005/v001

## Changes

Add a small bitset doorkeeper (e.g. 8 * capacity bits, one hash) to the admission code. On each access: if the key's doorkeeper bit is unset, set it and do not touch the sketch (estimate treated as 0 for the first sighting); if already set, increment the sketch as before. Admission estimate = sketch estimate + (1 if the doorkeeper bit is set). Clear the doorkeeper whenever the sketch performs its periodic halving. Keep the segmented LRU with 95% protected share and the gate rule otherwise unchanged. This reduces counter saturation by one-hit scan keys, so the sketch's frequencies better separate reused keys from scan keys.

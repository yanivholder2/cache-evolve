# H02

Adding a small ghost list of recently evicted probation keys that re-admits them at probation MRU (not protected) will raise hit-rate on the scan-heavy trace.

## Parent

cycle/0001/v003

## Changes

Add a bounded FIFO ghost set (capacity equal to the cache capacity, keys only, e.g. a `VecDeque` plus `HashSet`, or reuse the existing map with a ghost flag) to `LruCache`. When eviction removes a probation-LRU entry, push its key onto the ghost list (dropping the oldest ghost when full). On `put` of a key present in the ghost list, remove it from the ghost list and insert it at the MRU end of the probation list (not directly into protected), so that a subsequent hit still promotes it. Ghost entries must never be returned by `get` and must not count toward `len`. Keep everything else from the parent unchanged.

## Rationale (optional)

Cycle 0002's ghost variant sent ghost hits straight to protected and lost hit-rate; this is the gentler policy suggested by that cycle's open questions.

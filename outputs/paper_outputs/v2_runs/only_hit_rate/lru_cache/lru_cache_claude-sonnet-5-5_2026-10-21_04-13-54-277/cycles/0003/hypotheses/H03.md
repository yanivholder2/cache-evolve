# H03

Replacing strict LRU with a 2-bit saturating-frequency CLOCK eviction scheme (insert with count 0, hits increment up to 3, hand decrements) will raise hit-rate on the scan-heavy trace.

## Parent

baseline

## Changes

Rewrite the baseline cache's eviction so that each entry carries a small `freq: u8` (saturating at 3). New entries are inserted with freq 0 into a ring/slot array. On a hit, increment freq (cap 3) without any list manipulation. On eviction, advance a clock hand: if freq > 0, decrement it and move on; if freq == 0, evict that slot. Reuse freed slots for new inserts. Preserve the public API, capacity bound, and update-in-place semantics of `put` on an existing key (treated as a hit).

## Rationale (optional)

Gives frequency information that a one-bit second-chance CLOCK lacks, targeting hit-rate while keeping hit-path work cheap.

# H02

Adding a second-chance reference bit to protected nodes, so a recently re-hit protected node survives one eviction pass, will raise hit-rate by combining CLOCK-style scan resistance with the segmented design.

## Parent

cycle/0003/v001

## Changes

Add a `referenced: bool` field to `Node`. Set it to false on insert, and set it to true in `touch` when the node was already protected. In `put`, the fallback path evicts from the protected head only when probation is empty. In that path, loop: if the protected head has `referenced` set, clear the flag, move the node to protected MRU, and continue. Otherwise evict it. Bound the loop by the protected list length. Also set the flag when `put` updates an existing key. Leave the probation behaviour, the 90% share and the demotion logic unchanged. Demoted nodes get `referenced=false`.

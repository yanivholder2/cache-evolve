# H03

Making a protected-segment hit move the node to MRU only if it sits in the LRU half of protected will cut list-update work without lowering hit-rate, targeting per-op time at neutral or better hit-rate.

## Parent

cycle/0003/v001

## Changes

In `touch` in `src/lru_cache/mod.rs`, add a fast path for nodes that are already protected. Track a monotonically increasing `u64` stamp per node (new field `stamp`, set from a cache-level `clock` counter, incremented on each relink). If the node's stamp is within the newest half of the protected list's recent stamps (`clock - node.stamp < protected_cap / 2`), return without unlinking or relinking. Otherwise do the existing unlink and `push_back` to PROTECTED. Probation-to-protected promotion and demotion stay unchanged. Hit-rate should stay within noise of v001. The change is valid only if the hit-rate does not drop and the work per hit goes down.

# H03

Replacing strict-LRU baseline eviction with CLOCK plus a 4-bit conservative-update sketch admission gate will match or beat the SLRU winner's hit-rate with cheaper hits.

## Parent

baseline

## Changes

Starting from the baseline cache, implement a CLOCK ring (reference bit per entry, hand sweeps clearing bits) in place of the LRU list. New entries are inserted with reference bit unset (scan resistance). On a miss with a full cache, advance the hand to the first unreferenced entry as victim, then admit the new key only if its sketch estimate is at least the victim's. Add a 4-bit saturating count-min sketch (4 rows, width ~ 2× capacity rounded to a power of two) with conservative-update increments, incremented on every access including rejected misses, and halved when total increments reach 10× capacity. Hits only set the reference bit, with no list relinking. Keep the public API and key/value semantics unchanged.

## Rationale (optional)

Answers the open question of CLOCK + sketch versus the segmented incumbent.

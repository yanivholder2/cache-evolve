# H01

Shortening the sketch aging window of the SLRU + conservative-update sketch gate will raise hit-rate by letting stale high counts decay faster.

## Parent

cycle/0008/v003

## Changes

In the overlay's sketch aging logic (the counter that triggers the "halve all 4-bit counters" reset), cut the sample/reset threshold to half its current value (e.g. from 10×capacity to 5×capacity increments, or the equivalent constant). Keep conservative-update increments, the saturating 4-bit counters, the SLRU segmentation and protected share, and the counting of rejected misses unchanged. The halving must still be a full pass over all counters, preserving the existing invariants. Earlier cycles found a longer window was worse, so this tests the other direction.

## Rationale (optional)

Insights say stale high counts cancel the gate's benefit; a shorter window directly attacks that.

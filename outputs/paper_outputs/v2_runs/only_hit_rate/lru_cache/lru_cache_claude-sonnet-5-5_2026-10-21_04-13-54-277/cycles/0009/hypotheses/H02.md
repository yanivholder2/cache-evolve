# H02

Requiring the candidate's sketch estimate to exceed the eviction victim's by a margin of 1 when the cache is full will raise hit-rate on scan-heavy traces.

## Parent

cycle/0008/v003

## Changes

In the admission comparison in the miss/insert path of the v003 overlay (where the candidate's sketch estimate is compared with the probation victim's estimate), change the admit rule from `cand >= victim` (or `>`) to `cand > victim + 1`, except when victim estimate is 0, in which case admit if `cand >= 1`. Rejected misses are still counted in the sketch so recurring keys build frequency across retries. Leave segmentation, protected share, aging and the sketch representation untouched.

## Rationale (optional)

Makes the gate stricter against one-hit scan keys while retry counting still lets genuinely recurring keys through.

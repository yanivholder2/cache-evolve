# H02

Lowering the protected segment share from 80% to 50% of capacity in the segmented LRU will raise hit-rate by giving probation more room to catch second hits.

## Parent

cycle/0001/v003

## Changes

In `src/lru_cache/mod.rs` (v003), change `try_new` so `protected_cap` is `(capacity / 2).max(1)` for capacity > 1 (still 0 for capacity 1) instead of `capacity * 4 / 5`. Touch no other logic. The demotion loop in `touch`, eviction from probation first, and the API stay as in v003. Capacity-one behaviour and existing unit tests must still pass.

## Rationale (optional)

With 80% protected, probation holds only ~20% of slots, so new keys are evicted before a second reference can promote them. 50% tests the opposite end of that tradeoff in a one-constant experiment.

# H03

Replacing strict LRU in the baseline with a CLOCK second-chance eviction scheme will raise hit-rate on scan-heavy traces while cutting per-hit work.

## Parent

baseline

## Changes

In the baseline `src/lru_cache/mod.rs`, replace the linked-list move-to-front on `get` with a per-slot `referenced: bool` bit. Store entries in a fixed `Vec` arena of size `capacity` with a `HashMap<K, usize>` index and a `hand: usize`. `get` only sets `referenced = true` (no list manipulation). On `put` of a new key at capacity, advance the hand: if `referenced` is set, clear it and advance; otherwise evict that slot, reusing it for the new key (new key starts with `referenced = false`). Updating an existing key sets the value and the bit. Remove the prev/next links. Keep the public API, the `framework::Cache` impl, capacity 1 and capacity 0 (panic in `new`) behaviour unchanged.

# H03

A per-bucket one-bit "re-referenced since insertion" flag used to pick the probation victim will raise hit rate by evicting never-reused entries before reused ones that were demoted.

## Parent

cycle/0009/v002

## Changes

Starting from cycle/0009/v002, add a small per-entry bool `reused` (or a per-bucket u64/u128 bitmask indexed by slot, kept in sync when entries move). Set it false on insertion and true on any hit. When a protected-segment entry is demoted into probation, keep its `reused` flag true. On eviction, instead of always taking the probation LRU end, scan the probation segment from the LRU end and evict the first entry whose `reused` is false; if all are true, evict the LRU end as before. Promotion, insertion point and the skip-move rule stay unchanged. This is a frequency-aware admission variant (one bit), distinct from the small-window counter approaches that were flat. Keep the flag array consistent through all shifts/rotates.

# H02

Adding a per-bucket ghost history of recently evicted probationary keys, which admits re-seen keys directly to the protected segment, will raise hit-rate on the LIRS trace.

## Parent

cycle/0002/v001

## Changes

In v001's bucket, add a small fixed-size ring buffer (e.g. 16 entries of key hash or full key, whichever the existing key type allows cheaply) per bucket recording keys evicted from the probationary segment. On insert of a miss: if the key is found in the ghost ring (remove it from the ring), insert it directly into the protected region (evicting the protected LRU entry if protected is full, with that victim chosen only when no probationary entry is better to evict, preserving v001's eviction order otherwise) instead of probation. Otherwise behave exactly as v001. On eviction of a probationary entry, push its key into the ring (overwriting oldest). Keep the hashed-bucket invariant: ghost entries hold no values and never occupy slots, so slot legality is unaffected. Do not change public API or capacity accounting.

## Rationale (optional)

2Q-style A1out history; addresses the open question on ghost-history promotion.

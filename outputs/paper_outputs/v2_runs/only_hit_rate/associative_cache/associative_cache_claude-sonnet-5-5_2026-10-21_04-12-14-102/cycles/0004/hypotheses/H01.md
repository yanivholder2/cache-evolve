# H01

Shrinking the probation segment from 8 to 4 slots per 64-slot bucket will raise hit-rate on the LIRS trace.

## Parent

cycle/0003/v001

## Changes

In the overlay of cycle/0003/v001, find the constant or expression that sets the probationary segment size per bucket (currently 8 of 64 slots). Change it to 4. Leave everything else as is: eviction still takes the LRU end of probation first, a hit in probation promotes to protected, and protected is plain move-to-back LRU. Keep the slot-legality invariant: probation size must stay below bucket capacity, and any code that derives the protected size must be updated to use the new value.

## Rationale

The cycle 0003 insight says the optimum is at or below one eighth of the bucket and asks where the trend turns. This is a one-parameter probe of that question.

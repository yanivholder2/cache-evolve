# H02

Evict the lowest-frequency entry among the oldest few candidates of each full bucket (frequency-aware victim choice) to raise hit-rate over plain LRU.

## Parent

cycle/0001/v001

## Changes

Add a saturating 2-bit (u8) hit counter to each entry in the bucket. Increment it on every hit, keeping the existing move-to-back. On insert into a full bucket, examine the K=4 entries at the front (LRU end) of the Vec and remove the one with the smallest counter (ties broken by position, oldest first). Then halve the counters of the remaining front K entries (aging) so stale frequent entries can be evicted later. Keep 32 buckets x 64 ways. Preserve the public API and capacity.

## Rationale (optional)

The LIRS trace mixes loops and scans. Frequency information protects reused items from scan pollution without touching the hit-path promotion that cycle 0001 found best.

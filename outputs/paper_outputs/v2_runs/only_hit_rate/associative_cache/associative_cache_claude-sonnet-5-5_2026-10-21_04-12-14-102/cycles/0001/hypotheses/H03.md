# H03

Make ClassicLRU promotion scan-resistant by moving a hit item only halfway toward the back (to the midpoint between its position and the back) to raise hit rate on loop/scan-heavy LIRS traces.

## Parent

baseline

## Changes

In `src/shared/eviction_policy.rs`, change `ClassicLRU::get_from_position`: compute `target = position + (len - 1 - position) / 2`; if a first-time-hit item (lfu_counter == 0) use that midpoint, otherwise (lfu_counter >= 1) move to the back as in baseline. Increment `items[..].lfu_counter` (existing Item field) on every hit so it records a second touch. Implement the move with `items[position..=target].rotate_left(1)` and return `target`. Keep `eviction_candidate_index` = 0 and `promotion_candidate_index` = len-1; leave enum/names/indices unchanged. Effect: one-touch items (scan pollution) stay nearer the eviction end, while items hit twice become fully protected, similar to a segmented/2Q-style LRU inside each bucket.

## Rationale (optional)

LIRS traces mix loops and one-shot scans, where plain LRU wastes ways on one-hit items. Targets hit-rate; metadata size unchanged since lfu_counter already exists in Item.

# H01

Repartition the same 2048-slot capacity into fewer, wider buckets (32 buckets x 64 ways) in BaselineGeometry::layout to raise hit rate by reducing hash-imbalance conflict misses.

## Parent

baseline

## Changes

In `src/shared/geometry.rs`, change `BaselineGeometry::layout(&self, total_capacity)` to ignore the harness split and return `(n, total_capacity / n)` with `n = 32` (clamped so n >= 1 and n divides total_capacity; fall back to the harness split otherwise). Keep the `BaselineGeometry` type name, its pub fields and `for_settings` unchanged. Keep ClassicLRU as the policy. Preserve invariants: num_buckets * bucket_size == total_capacity. Expected tradeoff: hit-rate up, per-op-time (get) up because remove/push on a 64-element Vec and linear key scan are longer.

## Rationale (optional)

Baseline has 128 buckets x 16 ways; Zipf/LIRS-like traces suffer when hot keys collide in a 16-way set. Wider sets approach fully associative LRU.

# H03

Admitting a miss when the incoming shared-frequency counter ties the victim's counter, instead of only when it exceeds it, raises workload-a hit-rate above the incumbent's 0.7427.

## Parent

cycle/0005/v001

## Changes

In the miss path of the shared-frequency admission gate, change the admission predicate from strict to non-strict: admit the incoming key when `incoming >= victim` (currently the parent bypasses the insert when `incoming <= victim`). Leave the counter storage, counter increments, probationary-first victim selection, and insert position exactly as the parent has them.

Cycle 0006 v001 showed that tied counters, once saturated at the top of a u8 range, caused extra bypasses and lowered hit-rate. This change tests the tie case directly on the unbounded parent counters, where ties arise only from equal access counts. Admitting ties should let recurring keys that have matched the victim's count displace it. Record the number of admitted-on-tie inserts in the variant notes so the effect can be attributed to ties rather than to other changes.

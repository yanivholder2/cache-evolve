# H03

Replacing the `[Option<K>; 4]` ghost ring on the 1/8-depth LRU reference line (cycle/0005/v002) with four non-zero 16-bit key fingerprints will cut per-bucket ghost metadata from 64 to 8 bytes, while keeping that line's hit rate within noise of 0.723.

## Parent

cycle/0005/v002

## Changes

Only `src/associative_cache/associative_cache_bucket.rs` changes. Port cycle/0007/v001's fingerprint mechanism onto the LRU line.

1. Copy in the private `FpHasher` (FNV-1a with a `write_u64` / `write_i64` fast path) and `fn ghost_fp<K: Hash>(key: &K) -> u16` from cycle/0007/v001. The hash finishes with the 64-bit mix and takes the **top** 16 bits, mapping 0 to 1. Add `use std::hash::Hasher;`.
2. Change `ghosts: [Option<K>; GHOST_LEN]` to `ghosts: [u16; GHOST_LEN]` and initialise it to `[0; GHOST_LEN]` in `new`. Keep `ghost_pos: u8` and `GHOST_LEN = 4`.
3. `record_ghost(&mut self, key: K)` stores `ghost_fp(&key)` at `ghost_pos`, then advances the ring.
4. `in_ghosts(&mut self, key: &K) -> bool` computes `fp = ghost_fp(key)` once and scans for `*g == fp`. On a match it sets `*g = 0` and returns true.
5. Leave everything else in v002 untouched:
   - newcomers insert at `len * 1/8` (index 1 in a full 16-slot bucket), and ghost hits insert at `len * 1/4` (index 3);
   - the ghost lookup runs before the eviction;
   - the eviction runs before the insert, so size never exceeds `max_size`;
   - evicted keys are recorded on the miss path;
   - non-ClassicLRU policies follow the baseline path.
6. **Invariants:** a fingerprint false positive (probability about 4/65535 per miss) only changes insert depth from index 1 to index 3. It never affects which value is stored or returned.

## Rationale (optional)

Cycle 7 showed that on CLOCK the ghost ring only needs to answer a membership question, so fingerprints lost no hit rate. Cross-cycle insights warn that ghost lessons do not transfer cleanly between lines: the LRU ring captures keys with reuse distances just past the bucket, while the CLOCK ring captures long-reuse returners. Whether fingerprinting also holds on the LRU line is still an open question. Answering it settles whether the LRU+ghost reference line can compete on metadata-size once costs are measured. Prediction: hit rate stays at 0.723 ± 0.001. A drop below about 0.721 would mean LRU-line ghost hits are rare enough that collision-driven false promotions show up, so the two lines really do need different ghost representations.

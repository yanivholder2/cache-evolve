# H02

A much longer sketch-aging cadence (capacity × 100 increments) allows the admission gate to decay stale frequency without collapsing signal for long-run hot keys, raising hit rate over the no-aging baseline.

## Parent

baseline

## Changes

This hypothesis is built on the **baseline** (single-LRU TinyLFU, no SLRU) to isolate the effect of sketch aging at the correct cadence, separate from the SLRU structure introduced in v003. v001 already showed that aging at `capacity × 10` is too aggressive; this variant probes `capacity × 100`, which is 10× more conservative.

**CountMinSketch changes:**

1. Add two fields to `CountMinSketch`:
   ```rust
   total_increments: u64,
   reset_threshold: u64,
   ```

2. Update `CountMinSketch::new()` to accept a `reset_threshold: u64` parameter and initialise both fields:
   ```rust
   fn new(width: usize, reset_threshold: u64) -> Self {
       let depth = SKETCH_DEPTH;
       let counts = vec![vec![0; width]; depth];
       Self { width, depth, counts, total_increments: 0, reset_threshold }
   }
   ```

3. In `CountMinSketch::increment()`, after incrementing the counters, append the aging logic:
   ```rust
   self.total_increments += 1;
   if self.total_increments >= self.reset_threshold {
       for row in self.counts.iter_mut() {
           for cell in row.iter_mut() {
               *cell >>= 1;
           }
       }
       self.total_increments = 0;
   }
   ```

**TinyLfuCache::try_new() changes:**

Compute `reset_threshold` and thread it through to the sketch:
```rust
let reset_threshold = (capacity as u64) * 100;
// …
sketch: CountMinSketch::new(width, reset_threshold),
```

No other changes. The single-LRU eviction path, frequency-gate admission, and all list helpers remain exactly as in the baseline.

The rationale: on workload-a the hot/cold cycle is long enough that `capacity × 10` resets fire far too often (every ~10 ops per slot), collapsing frequency distinctions before the trace can replenish them (v001's failure). At `capacity × 100`, a reset fires roughly once per full-population turnover, letting accumulated heat remain visible to the admission gate while still eventually expiring stale counts from items that fall out of the working set.

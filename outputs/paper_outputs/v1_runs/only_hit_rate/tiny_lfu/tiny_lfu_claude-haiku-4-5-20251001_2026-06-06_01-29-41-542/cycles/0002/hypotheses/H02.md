# H02

Increase sketch depth from 4 to 6 to improve hash function independence and reduce frequency estimate variance.

## Parent

baseline

## Changes

Increase SKETCH_DEPTH from 4 to 6 in src/tiny_lfu/mod.rs. The Count-Min sketch uses multiple independent hash functions (one per depth row) to estimate frequencies—the minimum across all rows gives a conservative frequency estimate. More hash functions increase the independence of collision patterns, lowering the probability that a key collides in all rows simultaneously. Six rows will use six different hash seeds, making it harder for two distinct keys to have correlated collision patterns. Increasing depth does not change the admission gate logic, the LRU ordering, or any increment/saturation behavior—only the number of hash table rows in the sketch.

## Rationale (optional)

Cycle 0001's open questions suggested exploring sketch parameters beyond width. Depth controls hash function independence; more independent hashing reduces the variance of frequency estimates even at the same width factor, which could help the admission decision at capacity boundaries where precision determines which items survive.

# H03

Adding cold-first eviction (lfu_counter tracking and counter==0 victim preference) on top of cycle/0002/v003's mid-point insertion without any geometry widening will improve hit-rate and reveal whether the cold-first mechanism depends on wide buckets to be effective.

## Parent

cycle/0002/v003

## Changes

Overlay `src/shared/eviction_policy.rs` with the same cold-first `ClassicLRU` logic that cycle/0002/v002 introduced, applied on top of v003's narrow baseline geometry:

```rust
impl<K, V> EvictionPolicy<K, V> for ClassicLRU
where
    K: Hash + Eq + Copy + Debug,
    V: Eq + Copy + Debug,
{
    fn name(&self) -> &'static str { "ClassicLRU" }

    fn get_from_position(&self, items: &mut Vec<Item<K, V>>, position: usize) -> usize {
        items[position].lfu_counter += 1;   // mark accessed item warm
        let item = items.remove(position);
        items.push(item);
        items.len() - 1
    }

    fn eviction_candidate_index(&self, items: &[Item<K, V>]) -> usize {
        // Prefer the first cold item (counter == 0); fall back to LRU front.
        items.iter().position(|item| item.lfu_counter == 0).unwrap_or(0)
    }

    fn promotion_candidate_index(&self, items: &[Item<K, V>]) -> usize {
        items.len() - 1
    }
}
```

Keep `src/associative_cache/associative_cache_bucket.rs` **unchanged from cycle/0002/v003** — the midpoint insertion `put` override (inserting at `items.len() / 2`) is preserved as-is.

Do **not** overlay `src/shared/geometry.rs` — this variant intentionally retains baseline narrow-bucket geometry (128 × 16 = 2048), which is what cycle/0002/v003 used. Do not copy cycle/0001/v001 or cycle/0002/v002's geometry change.

## Rationale

cycle/0002/v002's insight noted that wide buckets are a "necessary prerequisite" for cold-first eviction because they keep enough cold items resident per bucket to absorb scan traffic. This hypothesis stress-tests that claim directly: if cold-first eviction still delivers a gain on narrow 16-slot buckets (combined with mid-point insertion to partially limit MRU squatting), it suggests the mechanism is robust to geometry. If it fails or regresses relative to v003 alone, it confirms that bucket widening is a genuine prerequisite — an important architectural finding that bounds future exploration.

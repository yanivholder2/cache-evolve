# H02

Replacing baseline ClassicLRU's pure-recency eviction with a cold-first policy that falls back to minimum-frequency (LFU) selection — rather than LRU position 0 — will improve hit-rate on baseline geometry.

## Parent

baseline

## Changes

Modify `src/shared/eviction_policy.rs` only. No changes to `geometry.rs` (use baseline
128 × 16 layout) or `associative_cache_bucket.rs` (use default MRU-tail insertion).

In the `ClassicLRU` implementation:

1. `get_from_position`: add `items[position].lfu_counter += 1;` before the
   `items.remove(position)` / `items.push(item)` sequence, so every GET hit marks the
   item warm. This is the same counter tracking used in cycle/0002/v002 and its
   successors.

2. `eviction_candidate_index`: change the body to a two-stage selection:
   - Stage 1: `items.iter().position(|item| item.lfu_counter == 0)` — return the index
     of the first cold item if any exists (unchanged from the incumbent cold-first
     logic).
   - Stage 2 (fallback when all items are warm): return the index of the item with the
     minimum `lfu_counter` value, breaking ties by taking the earliest-occurring item
     (i.e., `items.iter().enumerate().min_by_key(|(_, item)| item.lfu_counter)
     .map(|(i, _)| i).unwrap_or(0)`).

The LFU fallback differs from the current incumbents' `unwrap_or(0)` by targeting the
*least frequently accessed* warm item rather than the arbitrary LRU front. When the
cold pool is empty, this gives the eviction path a frequency signal it currently lacks.

## Rationale

The cold-first mechanism has been proven on wide-bucket geometry (cycles 0002–0003),
but the warm-pool fallback has never been separately evaluated. On baseline narrow
geometry (128 × 16), cold pool exhaustion is more common because 16-slot buckets warm
up faster. The LFU fallback directly targets the "least useful" warm item rather than
the oldest one, which should be a better choice when all items have survived long enough
to receive at least one access. This hypothesis tests the fallback strategy in isolation
on the baseline, separating its contribution from the geometry and insertion effects.

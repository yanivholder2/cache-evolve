# H03

Widening cycle/0003/v003's narrow-bucket geometry by a factor of 2 (64 buckets × 32 slots) will close the hit-rate gap to cycle/0003/v001's factor-4 wide-bucket configuration, revealing whether the narrow-path's mid-point + cold-first mechanisms benefit as much from incremental geometry widening as the pure-LRU baseline did in cycle 0001.

## Parent

cycle/0003/v003

## Changes

Add a new `src/shared/geometry.rs` overlay to cycle/0003/v003's existing overlay set.
Keep `eviction_policy.rs` and `associative_cache_bucket.rs` from v003 unchanged.

The new `geometry.rs` applies a factor-2 repartition, following the same
capacity-conservation pattern as cycle/0001/v001's overlay but with a smaller factor:

```
let factor = 2usize;
let target_num_buckets = (settings.num_of_buckets / factor).max(1);
let (num_of_buckets, bucket_size) = if total % target_num_buckets == 0 {
    (target_num_buckets, total / target_num_buckets)
} else {
    (settings.num_of_buckets, settings.bucket_size)
};
```

For the standard 128 × 16 = 2048 configuration this produces 64 × 32, halving the
bucket count and doubling each bucket's capacity while keeping total capacity exactly
equal to 2048. The `for_settings` constructor and `BucketGeometry::layout` method
structure must mirror the pattern in cycle/0001/v001's `geometry.rs` so the
construction glue can build the geometry correctly.

v003's `eviction_policy.rs` provides cold-first ClassicLRU (counter increment on GET,
`counter == 0` eviction preference with LRU fallback). v003's
`associative_cache_bucket.rs` provides mid-point insertion (`put` inserts new items at
`len / 2`). Both are retained verbatim.

## Rationale

cycle/0003's insight identified that geometry widening and mid-point insertion are
"substitutable" cold-item concentrators, but it did not test whether they are
*additive* at an intermediate geometry. cycle/0003/v003 had narrow 16-slot buckets
(hit-rate 0.7265) and cycle/0003/v001 had wide 64-slot buckets (hit-rate 0.7277) — a
small gap. Factor-2 (32-slot buckets) sits between these and will show whether the
narrow-path gains as much from modest widening as the pure-LRU path did when widening
from 16 → 64 slots in cycle 0001. If the narrow-path's ceiling is flat after 32 slots,
that confirms mid-point insertion is the dominant mechanism and geometry beyond factor-2
offers no further benefit for it.

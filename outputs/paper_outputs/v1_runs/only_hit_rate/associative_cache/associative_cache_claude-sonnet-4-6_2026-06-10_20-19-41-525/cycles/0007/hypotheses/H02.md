# H02

Adding an ARC-style ghost buffer to the bucket — re-admitting recently evicted keys with an elevated counter and MRU position — will raise hit-rate by converting regret evictions into protected warm entries on their next access.

## Parent

cycle/0005/v003

## Changes

Modify only `src/associative_cache/associative_cache_bucket.rs`; all other overlay files (eviction_policy.rs with counter cap at 4, geometry.rs with factor-4 wide-bucket layout) are inherited unchanged from cycle/0005/v003.

**Struct changes:** add two fields to `AssociativeCacheBucket<K, V>`:

```rust
ghost: std::collections::VecDeque<K>,
ghost_capacity: usize,
```

**`new()` initialisation:**

```rust
ghost: std::collections::VecDeque::new(),
ghost_capacity: settings.bucket_size,  // ghost list is same size as the bucket
```

**`evict_item()` — record evicted keys into the ghost buffer:**

After every call to `self.remove_at(idx)` (both the normal cold path at step 1 and the warm-lock fallback at step 2), push the evicted item's key into the ghost buffer before returning:

```rust
let evicted = self.remove_at(idx);
if self.ghost.len() >= self.ghost_capacity {
    self.ghost.pop_front();  // drop oldest ghost entry to stay bounded
}
self.ghost.push_back(evicted.key);
Some(evicted)
```

**`put()` — ghost-hit re-admission path:**

At the top of the new-key insertion branch (after the existing-key check, before the capacity eviction), probe the ghost buffer:

```rust
if let Some(ghost_pos) = self.ghost.iter().position(|&k| k == item.key) {
    // Ghost hit: this key was evicted recently and is being re-requested.
    // Re-admit it at the MRU back with an elevated counter so it immediately
    // enters the warm-protected pool and is not cold-first-evicted right away.
    self.ghost.remove(ghost_pos);
    let mut re_item = item;
    re_item.lfu_counter = 2;  // warm, survives two decay events before becoming cold
    let evicted_item = if self.is_full() { self.evict_item() } else { None };
    self.items.push(re_item);
    return (&self.items[self.items.len() - 1], evicted_item);
}
// Non-ghost path: continue with the normal mid-point insertion at counter 0.
```

The non-ghost path (mid-point insertion + cold-first eviction + bulk decay) is unchanged from the parent.

**Invariants to preserve:**
- Ghost list length is always `<= ghost_capacity` (enforced by the `pop_front` guard).
- Total bucket capacity is unchanged: the ghost list is metadata only (keys, not values) and does not count toward `max_size`.
- Re-admitted items start at `lfu_counter = 2`, consistent with the counter cap of 4; they will become cold after two decay events if not re-accessed.
- The `VecDeque<K>` import must be added (via `use std::collections::VecDeque;` or inline path).

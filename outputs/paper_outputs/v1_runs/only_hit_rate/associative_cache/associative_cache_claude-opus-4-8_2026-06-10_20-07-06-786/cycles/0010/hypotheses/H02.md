# H02

Collapsing the all-protected put fallback into a single in-place `mem::replace` at index 0 makes every full-bucket admission O(1) while holding hit-rate at 0.7284, closing the one slow branch v003 left untouched on the put per-op-time axis.

## Parent

cycle/0009/v003

## Changes

v003's `put` in `src/associative_cache/associative_cache_bucket.rs` fast-pathed only the boundary-eviction case (`protected_count < len`) with a prefix `rotate_right` + `mem::replace`, and explicitly left the all-protected case (`protected_count == len`) on the slow fallback:

```rust
let evicted_item = self.evict_item();   // remove(0) shifts [1,len) down
self.items.insert(0, item);             // insert at 0 shifts them back up
return (&self.items[0], evicted_item);
```

When every resident item is protected, `eviction_candidate_index` returns `Some(0)` (the protected LRU end), so this branch removes index 0 and reinserts the new item at index 0 — the two O(bucket_size) memmoves exactly cancel: indices `[1, len)` are unchanged and only slot 0 is overwritten. Replace that branch with an O(1) in-place rewrite:

```rust
let evicted = std::mem::replace(&mut self.items[0], item);
self.protected_count -= 1;   // the replaced item was protected
return (&self.items[0], Some(evicted));
```

Preserve invariants: the victim in this branch is always protected (decrement `protected_count` by exactly 1, replicating `evict_item`'s adjustment), the new item is probationary (`Item::new` sets `lfu_counter = 0`), the prefix/suffix partition and vector length are unchanged, and the returned victim is byte-identical to the fallback's. Keep v003's boundary fast path and the get-path no-op fast path exactly as they are. Expected result: exact hit-rate tie (0.7284) with both put-with-eviction branches now O(1).

## Rationale (optional)

This is a brand-new behaviour-preserving rewrite on a branch none of v001/v002/v003 optimized, distinct from H01's consolidation of the existing three. Banking it completes O(1) coverage of the entire full-bucket admission path.

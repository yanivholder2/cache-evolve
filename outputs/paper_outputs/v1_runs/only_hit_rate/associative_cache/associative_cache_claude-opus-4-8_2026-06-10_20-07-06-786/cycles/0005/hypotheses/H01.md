# H01

Grade protection by true reuse frequency so a fully-protected bucket evicts its least-frequently-used member instead of its LRU end, raising hit-rate.

## Parent

cycle/0003/v002

## Changes

The parent promotes on the first probationary hit (`lfu_counter` 0 -> 1) and
thereafter pins protected items at `lfu_counter == 1`, so when every resident
item is protected the eviction fallback blindly returns `Some(0)` (the
protected LRU end). This discards a cold once-promoted key and a genuinely hot
key with equal probability. Strengthen the protection signal instead of
eroding it:

1. In `get_from_position`, on every hit increment `lfu_counter` saturating at a
   high ceiling (e.g. `usize::MAX` or a 16-bit cap) rather than pinning at 1.
   Probationary keys stay at 0; the first hit moves a key to 1 (still the
   promotion event) and is moved to the MRU back; each later hit keeps
   incrementing and keeps moving the item to the MRU back. Recency ordering of
   the vector is therefore unchanged from the parent.

2. In `eviction_candidate_index`, keep the first pass exactly as the parent has
   it — return the oldest (`highest-index`) `lfu_counter == 0` probationary
   item so probation stays FIFO. Only change the fallback that currently returns
   `Some(0)`: scan the resident items, find the minimum `lfu_counter` among the
   protected set (all are `>= 1` in this branch), and break ties toward the
   oldest position (lowest index, i.e. the existing LRU end). Return that index.

Preserve every other invariant: admission at index 0 (probationary front),
promote-on-first-hit, FIFO probation order, and the property that a probationary
victim is always preferred over any protected key. The only behavioural change
is *which* protected key dies under full-protection pressure — the coldest, not
merely the least-recently-touched.

## Rationale (optional)

Cross-cycle insight says "once-hot immortality is a feature" and "earned,
durable protection beats raw recency." This banks the dormant `lfu_counter`
into a live frequency signal exactly where the parent is currently blind (the
fully-protected fallback), without touching the admission or promotion logic
that prior cycles proved must not be tightened.

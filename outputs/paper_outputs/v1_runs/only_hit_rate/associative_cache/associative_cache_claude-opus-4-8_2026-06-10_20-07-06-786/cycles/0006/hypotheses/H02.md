# H02

Inserting a newly-promoted probationary key at the protected-LRU boundary instead of the global MRU back raises hit-rate by shielding long-established hot keys from displacement by one-hit-wonders.

## Parent

cycle/0003/v002

## Changes

Edit only `src/associative_cache/associative_cache_bucket.rs`. Change the
promotion placement in `get_from_position` to make the protected region a true
second LRU stack rather than letting every promotion vault to the absolute MRU
back.

Current layout over the single `items` vector (front -> back): newest
probationary at low indices, aging toward higher indices, then the protected
keys (LRU -> MRU) at the back; `lfu_counter == 0` marks probationary and
`>= 1` marks protected.

New behaviour in `get_from_position(position)`:

- If `items[position].lfu_counter >= 1` (already protected): keep the parent
  behaviour exactly — remove the item and `push` it to the back (protected MRU).
- If `items[position].lfu_counter == 0` (promotion event): set its counter to
  `1`, then `remove(position)`, then **insert it at the protected-LRU
  boundary** — the lowest index `b` such that `items[b].lfu_counter >= 1`
  (scan from the front; this is the first protected slot). Use
  `self.items.insert(b, item)`. If no protected item exists (every remaining
  item is probationary), `push` to the back as before.

Leave `put` (front admission at index 0) and `eviction_candidate_index`
(oldest-probationary-first, falling back to protected index 0) unchanged.
Preserve the invariant that probationary items occupy a contiguous front block
and protected items a contiguous back block, so `eviction_candidate_index`'s
scan semantics still hold.

Rationale: under the parent, a probationary key earns full MRU protection from a
single hit and then outlives genuinely hot keys for a long time. Seating a
freshly promoted key at the bottom of the protected stack forces it to keep
earning to climb, while established hot keys at the MRU back are never displaced
by one promotion — strengthening (not eroding) durable earned protection, which
has been the consistent direction of every win.

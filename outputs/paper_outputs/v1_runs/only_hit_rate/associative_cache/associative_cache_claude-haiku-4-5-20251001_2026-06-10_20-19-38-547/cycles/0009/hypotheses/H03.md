# H03

Couple phase-transition detection with dynamic partition rebalancing—when collision-distribution divergence signals a phase change, adaptively adjust hot/cold tier allocation ratios to suit the emergent workload characteristics.

## Parent

cycle/0006/v002

## Changes

Extend the two-tier stash mechanism with phase-aware dynamic rebalancing. Implement a phase-detection signal based on collision-distribution divergence (reuse the collision-tracking logic from Cycle 0006 v003). When a phase transition is detected (e.g., collision rate divergence exceeds a threshold), trigger partition rebalancing:

**Phase detection**: Track the rolling mean of collision-bucket count over a windowed history (e.g., last 100 operations). When the current window's collision distribution diverges by >15% from the baseline (e.g., collision-heavy buckets increase from 30% to >45% of buckets), classify this as a phase transition.

**Dynamic rebalancing**: On phase detection, recompute the hot/cold partition ratio dynamically. For collision-heavy phases (more buckets with collisions), favor hot-tier capacity (e.g., 25% hot / 0% cold, using all recovery capacity for frequent re-accesses). For collision-light phases, revert to the baseline asymmetric split (20% hot / 5% cold or the cycle 0006 baseline 12.5% / 12.5%).

**Implementation**: 
- In `AssociativeCache<K, V>`, add fields to track `collision_window: VecDeque<usize>` (collision counts per period) and `current_phase: enum { Baseline, Collision }`.
- In `put()`, periodically sample collision-bucket counts and update the window.
- When phase transitions, recalculate `hot_stash_capacity` and `cold_stash_capacity` and re-partition existing stash items if necessary (move excess hot-tier items to cold tier or vice versa during rebalancing).
- Preserve the underlying two-tier promotion-on-hit mechanism from the parent; the change is scoped to partition ratio adaptation during phase transitions.

This tests whether the phase detection that failed with counter manipulation succeeds when coupled with a structural (partition-level) response rather than a probabilistic (counter-level) one.

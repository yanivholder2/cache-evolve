# H03

Add a stash buffer with selective insertion only from high-occupancy buckets to improve hit rate by reducing stash pollution from low-value evictions.

## Parent

baseline

## Changes

Implement a bounded stash mechanism in AssociativeCache with capacity set to 15% of total cache capacity. Unlike the baseline-stash approach, only insert evicted items into the stash when they are evicted from buckets with occupancy exceeding 75% of bucket_size. Track each bucket's current item count; in the put() method, after a bucket eviction, check the bucket's post-eviction occupancy. If occupancy is still >= 0.75 * bucket_size, insert the evicted item into the stash using FIFO eviction logic. This filtering reduces stash churn by avoiding low-value evictions from lightly-loaded buckets while focusing recovery on items lost to actual congestion. Perform secondary stash lookup on primary bucket misses as in the baseline-stash design.

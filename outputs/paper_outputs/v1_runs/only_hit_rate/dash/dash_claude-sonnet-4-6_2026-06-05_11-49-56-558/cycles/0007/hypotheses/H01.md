# H01

Stacking ClassicLRUFreqProtect eviction selectivity with unconditional second-chance stash recovery will compound the separate gains of cycle/0006/v001 and cycle/0006/v002 by simultaneously closing the probing-boundary eviction loss site and the stash-overflow loss site.

## Parent

cycle/0006/v001

## Changes

Starting from cycle/0006/v001 (which uses `ClassicLRUFreqProtect` in all buckets, resets `lfu_counter` on stash demotion, and uses 24/8 normal/stash geometry), add the unconditional second-chance stash-overflow recovery introduced by cycle/0006/v002.

In `src/dash/segments/dash_segment.rs`, override the `put()` method on `DashSegment` so that after calling `self.core.put_at(Slot::Stash, InsertPosition::Back, item)`, the return value is inspected: if `Some(ev)` is returned, immediately call `promote_to_target(&mut self.core, ev, InsertPosition::Front)` instead of discarding the evicted item. This is exactly the change v002 applied, but now applied on top of v001's codebase. Remove any ghost-set logic from the `put()` path if present in the parent.

Keep all other v001 changes intact:
- `ClassicLRUFreqProtect` policy instantiated in `src/dash/dash_bucket.rs`
- `item.lfu_counter = 0` reset when inserting into stash in `src/dash/segments/dash_segment.rs` (already present in v001; preserve it in the same demotion paths where v001 placed it)
- 24/8 normal/stash geometry in `src/shared/geometry.rs`

The two mechanisms are orthogonal: the frequency guard operates at eviction time within normal/probing buckets (protecting confirmed-reuse residents); the second-chance operates at stash overflow to recover items before they are permanently lost from the cache. Neither code path overlaps with or depends on the other.

## Rationale

Cycle 0006's insight explicitly identifies these two gains as additive candidates targeting different pipeline stages. v001 fixed *who* gets evicted from the probing tier; v002 fixed *what happens* to items lost from stash overflow. Combining both on the best-so-far parent tests the direct compounding hypothesis recommended by the cycle analysis.

# H03

Giving the probing (promoted) tier a second salted home so a promotion overflow relocates instead of demoting raises hit-rate by sparing already-warmed hot keys from eviction.

## Parent

cycle/0008/v003

## Changes

Apply the breadth idea that worked on the stash to the *probing* tier, which has
never had more than its single `target_idx + 1` home. The hypothesis under test:
the keys evicted when a promotion overflows the probing bucket are already-warm
residents (they earned promotion), so relocating the overflow victim to a second
probing home is worth more than the stash relocation was — because here the
rescued keys are hotter, not colder.

In `src/dash/segments/dash_segment.rs`:

1. Define a second probing home for a key as `probing_alt = (target_idx + 2) % core.segment_size` (guard the degenerate case where `segment_size < 3` so `probing_alt` collapses onto an existing index — fall back to current single-home behaviour there).
2. In `promote_to_probing`, when `core.put_at(Slot::Probing, ...)` returns an evicted item, first attempt to seat that evicted item into the `probing_alt` bucket **only if** `probing_alt` is distinct from `probing_idx` and `probing_alt` is not full (so the relocation hop never itself evicts — preserving `single_eviction_per_put`). Only if `probing_alt` is unavailable does the evicted item fall through to the existing `demote_from_normal_bucket` cascade. This adds at most one new seat, conserving occupancy.
3. In `promotion_get`, extend the probing lookup: after checking `core.buckets[probing_idx]`, also check `core.buckets[probing_alt]` (when distinct) so a key relocated to its second probing home is still found and served as a hit. Drop the touch entry on a probing hit exactly as today.

Invariants to preserve: occupancy is conserved (one new seat max per promotion),
the wraparound math must stay in bounds for `target_idx == segment_size - 1` and
`segment_size - 2`, and the stash relocation / two-speed promotion / touch
counter inherited from the parent must remain unchanged.

## Rationale (optional)

Stash breadth came back flat because it rescued cold overflow victims already
reclaimed through promotion. The probing tier is the mirror image: its overflow
victims are proven-warm keys, so a breadth-of-homes lever there targets a
distinct, hotter pool of keys than every stash seam tried so far.

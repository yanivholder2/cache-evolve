# H03

Bypassing the target tier for any item found during high stash occupancy relieves demotion backpressure and improves hit retention by preventing demotion cascades.

## Parent

baseline

## Changes

Modify the target-bucket hit path in `promotion_get()` to bypass the target tier and promote directly to probing when stash bucket occupancy is high, reducing cascade evictions.

In `src/dash/segments/dash_segment.rs` at the target-bucket hit branch (around line 165–179), add a pressure-sensing condition:

```rust
if let Some(item_idx) = core.buckets[target_idx].get_position(key) {
    // Check stash pressure: if occupancy > 60%, bypass target filtering
    let stash_occupancy = core.stash_buckets[stash_idx].get_items().len() 
        / core.stash_buckets[stash_idx].capacity();
    let is_hottest = Some(item_idx) == core.buckets[target_idx].promotion_candidate_index();
    
    if stash_occupancy > 0.60 {
        // Under stash backpressure: promote to probing regardless of hotness
        debug!("promotion_get: key={key:?} stash full, bypass target -> probing");
        let data = core.buckets[target_idx].remove_at(item_idx);
        promote_to_probing(core, data, insert_pos);
        // ... return item from probing
    } else if is_hottest {
        // Normal path: promote only the hottest item
        debug!("promotion_get: key={key:?} found in target as hottest -> probing");
        let data = core.buckets[target_idx].remove_at(item_idx);
        promote_to_probing(core, data, insert_pos);
        // ... return item from probing
    } else {
        // Not hottest and stash has room: stay in target
        debug!("promotion_get: key={key:?} found in target item_idx={item_idx} (intra-promote)");
        return Some(core.buckets[target_idx].get_from_position(item_idx));
    }
}
```

This creates a relief valve: when stash is full, even non-hottest items in target are promoted to probing, avoiding demotion cascades that fill the stash.

## Rationale

The demotion cascade (probing → target → stash → out) is a bottleneck when the stash is under pressure. Items demoted to stash may evict recent hot items. This variant tests whether detecting stash fullness and proactively reducing the target population by bypassing it directly to probing can prevent the cascade backpressure. Unlike H02 (which adapts stash-to-probing choice), H03 adapts the target-to-probing condition itself, trading tier filtering for backpressure relief when needed.

# H03

Replacing the incumbent's probationary LRU segment with a 2Q-style FIFO admission front plus a key-only ghost, while keeping the 95% first-hit-promoted protected tier, beats either structure alone on hit-rate.

## Parent

cycle/0008/v001

## Changes

This grafts 2Q's one-hit-wonder admission filter onto the proven 95/5
incumbent — the structural-hybrid arm of the race, built from the
incumbent lineage rather than from 2Q. Keep the incumbent's protected
segment (`prot_head/prot_tail/prot_len`, `protected_cap`,
`push_back_protected`, `enforce_protected_budget`) and its single-hit
promotion exactly as-is. Replace the probationary LRU segment with a 2Q
admission front:

- Turn the probationary list into a FIFO admission queue `A1in` sized
  `a1in_cap = capacity / 20` (the existing `capacity - protected_cap`
  budget). New keys still enter at its MRU/tail, but on a get-hit an A1in
  key is promoted to the protected segment MRU via `push_back_protected`
  (single-hit promotion, unchanged), and A1in is never internally
  reordered on hits — it ages strictly by insertion order.
- Add a key-only ghost FIFO `A1out` (nodes with `value` semantically
  empty; reuse the arena + free list, target `kout = capacity / 2`,
  allocated beyond `capacity`). When `put` admits a new key and A1in is
  over `a1in_cap`, page A1in's FIFO head into A1out instead of evicting
  it outright; trim A1out to `kout` by dropping its oldest ghost.
- On a `put` miss whose key is currently an A1out ghost, promote it
  directly into the protected segment MRU (proven reuse across a full
  admission-queue lifetime), then run `enforce_protected_budget`.
- `enforce_protected_budget` still demotes the over-budget protected LRU
  node, but now demotes it to the A1in tail (FIFO) rather than a
  probationary LRU; the reprieve flag may be dropped since A1in does not
  reorder.

Preserve invariants: resident count `a1in_len + prot_len <= capacity`,
`prot_len <= protected_cap`, ghost nodes hold no live value and are never
returned by `get`, slot reuse via the free list intact, and the
`framework::Cache`/JNI surface unchanged. Confirmed if the admission
filter keeps scan traffic out of the protected tier and hit-rate clears
the incumbent's 0.7313; refuted if the A1in front merely re-treads the
disconfirmed front-window territory and hit-rate stays at or below it.

## Rationale (optional)

The incumbent has no memory of keys evicted from its probationary floor;
2Q's A1in+A1out front is exactly that missing filter. Parenting on the
winner (cycle/0008/v001) and importing only the admission front — not
2Q's plain-LRU main list — tests the combination from the opposite
lineage to H01/H02, satisfying the "cite a cross-cycle winner"
requirement while keeping the cohort's three arms structurally distinct.

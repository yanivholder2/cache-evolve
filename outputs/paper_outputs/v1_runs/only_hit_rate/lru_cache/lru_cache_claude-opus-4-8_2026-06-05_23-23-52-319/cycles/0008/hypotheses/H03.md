# H03

Giving canonical LIRS a reactive resident-HIR floor — the SLRU "probationary drain floor" lesson cast as a minimum, not a wider window — recovers the hits LIRS lost to LIR pollution and tests whether untuned LIRS can finally match the incumbent.

## Parent

cycle/0005/v002

## Changes

Start from the parent's canonical LIRS rebuild (stack S, resident-HIR queue Q,
bounded non-resident-HIR metadata) and keep its policy intact: the
non-resident horizon stays capacity-bound (do NOT widen it — `cycle/0007/v003`
proved widening surfaces long-IRR pollution), the resident-HIR window stays
narrow (do NOT statically enlarge `l_hir` — `cycle/0006/v001` proved the
`l_lir = capacity - l_hir` zero-sum enlargement regresses), and non-resident
reuses still promote straight to LIR (do NOT divert them to the weak tier —
`cycle/0006/v002` proved that defers genuine LIR signals).

The single new mechanism is a *reactive* floor on the resident-HIR queue. Define
`hir_floor = max(1, capacity / 20)`. Leave the LIR budget at its full
`capacity - l_hir` most of the time, but whenever an admission or promotion
would drive the resident-HIR count below `hir_floor`, demote the LIR-LRU block
(the bottom of stack S after pruning) to resident-HIR until the queue is back at
`hir_floor`. This is enforced lazily — only on starvation — so it does not
statically shrink LIR the way `cycle/0006/v001` did; LIR stays maximal except in
the moments the one-hit-wonder drain queue would otherwise collapse to near zero.

Preserve every LIRS invariant: S-pruning of bottom HIR blocks, the resident
bound (`|LIR| + |resident HIR| <= capacity`), and the non-resident metadata
bound. Update the relevant unit tests' comments only where they assert exact LIR
sizing; the observable eviction contract must still hold.

## Rationale (optional)

The parent scored 0.7204, below the 0.7313 incumbent, and the diagnosed cause
across cycles 0005-0007 is that LIRS lacks SLRU's guaranteed drain floor for
fresh second-touch detection, so floods of long-IRR touches crowd out the
queue. Prior floor-shaped attempts all enlarged the HIR *window* statically
(zero-sum against LIR); a floor enforced only on starvation is the untried
form. This is also the clean untuned-LIRS-vs-incumbent test the cross-cycle
notes have called for since cycle 0005 — if it still trails, the LIRS axis can
be closed for good.

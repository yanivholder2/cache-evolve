## Changes

In the `put()` method's eviction logic (the while loop that scans for minimum frequency starting at line 95), modify the tie-breaking strategy within equal-frequency items.

Currently, the code scans left-to-right through the linked list and accepts the first item with a frequency lower than the current minimum:

```rust
if self.nodes[idx].freq < min_freq {
    min_freq = self.nodes[idx].freq;
    victim_idx = idx;
}
```

Change this to use the linked list structure's spatial meaning: when frequencies are tied (equal minimum), prefer the item closest to the head of the list (oldest in LRU order). Implement this by modifying the scan to:

1. First, find the minimum frequency value across all nodes (unchanged)
2. Second, scan again from head-to-tail and select the first (head-most) node with that minimum frequency

This ensures that among items with equal frequency, the eviction choice genuinely reflects recency ordering rather than the scan's encounter order.

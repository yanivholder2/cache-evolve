# H02

Denoise the partition steering with a hysteresis accumulator that only moves the split after agreeing evidence crosses a threshold, raising hit-rate by suppressing single-event thrash.

## Parent

cycle/0008/v001

## Changes

Build on v001's source-steered adaptive split, editing `put()`'s in-ghost
branch in `src/s3_fifo/mod.rs`. Today every individual ghost re-admission moves
`small_size` by 1 in the direction of that one record's `from_main` tag, so a
single isolated reuse event immediately shifts the eviction threshold — a noisy,
per-event controller. Replace it with a counter-gated controller:

1. Add a signed field `steer_accum: i32` to `S3Fifo`, initialized to 0 in
   `try_new()`.

2. In the in-ghost branch, instead of moving `small_size` directly, read
   `from_main` and update the accumulator: `steer_accum += 1` for a weak
   (`from_main == false`) hit — evidence to grow small — and `steer_accum -= 1`
   for a strong (`from_main == true`) hit — evidence to shrink small.

3. Define a threshold constant `const STEER_THRESHOLD: i32 = 4;`. When
   `steer_accum >= STEER_THRESHOLD`, increment `small_size` by 1 (only if below
   `small_upper()`) and reset `steer_accum = 0`. When
   `steer_accum <= -STEER_THRESHOLD`, decrement `small_size` by 1 (only if above
   `small_lower()`) and reset `steer_accum = 0`. Otherwise leave `small_size`
   unchanged this event.

4. After any size change, recompute `main_size = capacity - small_size`.

Keep the rest of the in-ghost branch identical: remove the matched ghost
record, then `if self.main.len() >= self.main_size { self.evict_main(); }` and
`self.main.push_front(...)`. Preserve `small_size + main_size == capacity`,
ghost capacity tracking `main_size`, and the `small_lower()`/`small_upper()`
bounds. Leave `get`, `evict_main`, `evict_small`, and `evict_ghost_one`
unchanged.

## Rationale (optional)

v001 proved the `from_main` signal steers in the right direction, but moving on
every event means brief, mixed bursts of weak and strong reuse jitter the split
back and forth around the center, partly cancelling. A hysteresis band only
commits a move when one direction accumulates a clear majority, so the partition
holds steady through noise and tracks genuine phase changes — a smarter steering
discipline on the same signal rather than a wider orbit.

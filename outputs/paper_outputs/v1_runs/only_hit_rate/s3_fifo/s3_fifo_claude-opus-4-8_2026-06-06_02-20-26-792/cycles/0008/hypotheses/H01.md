# H01

Make the small/main partition adaptive — driven by the source tag of ghost re-admissions — to raise hit-rate by letting the split track the workload's shifting balance instead of sitting at the static ~4/96 optimum.

## Parent

cycle/0007/v002

## Changes

Every prior sizing result came from *static* sweeps; the partition has never
been allowed to move at runtime. Add ARC-style adaptivity that uses the
`from_main` tag already present on ghost records as the steering signal.

Concretely, in `put()`'s in-ghost branch (the block that runs when a key is
found in `self.ghost`), read the matched record's `from_main` flag *before*
removing it, then nudge the partition by a fixed step of 1:

- If `from_main == true` (a proven main-evicted key cooled, was ghosted, and
  is now reused): this is evidence main is undersized. Increment `main_size`
  by 1 and decrement `small_size` by 1.
- If `from_main == false` (a small-queue one-hit-wonder ghost record is reused):
  evidence the admission window is too short. Increment `small_size` by 1 and
  decrement `main_size` by 1.

Maintain the invariant `small_size + main_size == capacity` at all times
(store `capacity` as a new field set in `try_new`, or recompute from the sum).
Clamp `small_size` to the bounded range `[capacity/48 .. capacity/12]` so the
adaptation orbits the proven `capacity/24` center and can never collapse the
admission filter or starve main. The queues are bounded by `small_size` /
`main_size` only at eviction time, so changing these fields simply shifts
future eviction thresholds — no entries need to be moved when the split
changes. Keep everything else identical: the move-to-front main hit logic, the
`evict_main` rotation, main-victim ghosting, and source-aware `evict_ghost_one`
must all remain untouched. Ghost capacity continues to track `main_size`.

## Rationale (optional)

Static sizing converged and every distinct-on-paper retention knob collapsed
into it. Adaptivity is a mechanism never tried: it can capture phase structure
the single fixed ratio cannot, and the `from_main` tag gives a free,
already-computed steering signal.

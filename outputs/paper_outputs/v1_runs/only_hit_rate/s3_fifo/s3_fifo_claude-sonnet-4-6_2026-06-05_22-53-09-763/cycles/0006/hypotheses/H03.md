# H03

Inserting small-promoted items into `main` at a position proportional to their frequency — front for freq > MAX_FREQ/2, midpoint otherwise — will improve hit rate by giving established main residents positional precedence over freshly promoted borderline items while still granting strong promotions immediate recency protection.

## Parent

cycle/0005/v001

## Changes

In `evict_small()`, replace the unconditional `self.main.push_front(tail)` with a frequency-proportional insertion:

Current code in `evict_small()`:
```rust
if tail.freq > 1 {
    if self.main.len() >= self.main_size {
        self.evict_main();
    }
    self.main.push_front(tail);
}
```

New code:
```rust
if tail.freq > 1 {
    if self.main.len() >= self.main_size {
        self.evict_main();
    }
    let insert_pos = if tail.freq > MAX_FREQ / 2 { 0 } else { self.main.len() / 2 };
    self.main.insert(insert_pos, tail);
}
```

With `MAX_FREQ = 5`: `MAX_FREQ / 2 = 2` (integer division), so the threshold is `tail.freq > 2`, meaning:
- `tail.freq >= 3` (freq 3, 4, or 5): inserted at position 0 (front) — same as the current push_front behaviour.
- `tail.freq == 2` (just above the promotion threshold of > 1): inserted at `self.main.len() / 2` (midpoint of the current main queue contents).

The capacity check before insertion (`if self.main.len() >= self.main_size`) ensures `main.len()` is at most `main_size - 1` immediately before the insert, so the post-insert length stays within bounds. The `VecDeque::insert` call at index `self.main.len() / 2` is valid because that index is ≤ `self.main.len()`.

All other methods (`get`, `put`, `evict_main`, ghost handling) and all configuration values (`MAX_FREQ=5`, `small_size=capacity/10`, `ghost_size=main_size/2`) remain identical to cycle/0005/v001.

Rationale: Items promoted from small with freq=2 have just barely cleared the threshold. Currently they land at the very front of main, ahead of all established main residents regardless of those residents' accumulated frequency. Inserting them at the midpoint means they must earn their way to long-term residency through subsequent main-queue accesses; if they are not accessed again before eviction pressure reaches the midpoint, they are correctly identified as cold. Items with higher freq (≥ 3) already demonstrated popularity in small and deserve the full front-of-queue placement.

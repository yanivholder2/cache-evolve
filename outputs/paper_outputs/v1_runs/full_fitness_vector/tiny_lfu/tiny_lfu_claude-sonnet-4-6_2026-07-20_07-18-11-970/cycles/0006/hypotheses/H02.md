# H02

Applying the stricter admission threshold (`incoming_freq > victim_freq.saturating_add(1)`) only on the 1-in-8 amortized eviction path will raise hit rate relative to the plain-threshold parent without the full residency disruption seen when the stricter gate fires on every eviction.

## Parent

cycle/0005/v002

## Changes

Add a `evict_counter: u32` field to `TinyLfuCache`. Initialise it to `0` in `try_new`. In `put()`, in the full-cache eviction branch, keep victim selection as the plain LRU head (unchanged from parent) but modulate the admission threshold by the counter:

```rust
self.evict_counter = self.evict_counter.wrapping_add(1);
let victim_idx = self.head.expect("TinyLfuCache: full cache has no victim");
let victim_key = self.nodes[victim_idx].key.clone();
let victim_freq = self.sketch.estimate(&victim_key);
let incoming_freq = self.sketch.estimate(&key);
let admit = if self.evict_counter & 7 == 0 {
    // Every 8th eviction: require the incoming key to beat the victim by at least 1.
    incoming_freq > victim_freq.saturating_add(1)
} else {
    // Remaining 7 out of 8: standard "> victim" comparison.
    incoming_freq > victim_freq
};
if admit {
    self.map.remove(&victim_key);
    self.unlink(victim_idx);
    self.nodes[victim_idx].key = key.clone();
    self.nodes[victim_idx].value = value;
    self.push_back(victim_idx);
    self.map.insert(key, victim_idx);
}
```

No change to victim selection (still always the LRU head), no best-of-2 probe, and the bijective remix hash functions (`seeded_hash`, `remix`, `increment`, `estimate`) are unchanged.

## Rationale

cycle/0005/v003 showed that `> victim_freq.saturating_add(1)` on every eviction raises hit rate but doubles p50/p99 latency by altering which nodes occupy hot cache lines — a residency effect independent of execution overhead. The cycle insight identified the fix as limiting the gate's firing rate rather than softening the threshold value. Firing the strict gate on only 1-in-8 evictions limits residency churn to one-eighth of its prior frequency while still blocking the most clearly marginal admissions, preserving a portion of the hit-rate signal. No best-of-2 victim comparison is added, so this hypothesis is structurally distinct from H01 even though both add an `evict_counter`.

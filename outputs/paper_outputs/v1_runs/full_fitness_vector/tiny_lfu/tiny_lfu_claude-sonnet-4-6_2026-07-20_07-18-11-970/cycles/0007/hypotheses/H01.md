# H01

Layering best-of-2 victim selection onto cycle/0006/v002's strict admission gate — while reusing the pre-computed candidate estimates as victim_freq to eliminate the redundant estimate call that wrecked cycle/0006/v001 — raises hit rate without measurable latency regression.

## Parent

cycle/0006/v002

## Changes

In `put()`, restructure the eviction block so that best-of-2 candidate ranking and the admission gate comparison share a single set of estimate calls on the every-8th-eviction path. The key constraint: never issue a separate `estimate(&victim_key)` after the best-of-2 selection — reuse the already-computed value.

Concrete implementation of the new `evict_counter & 7 == 0` branch inside the `self.nodes.len() >= self.capacity` arm:

```
self.evict_counter = self.evict_counter.wrapping_add(1);
let head_idx = self.head.expect("TinyLfuCache: full cache has no victim");

let (victim_idx, victim_freq, incoming_freq, strict) = if self.evict_counter & 7 == 0 {
    // 8th eviction: best-of-2 victim selection + strict admission gate.
    // Compute head_freq first; only probe second if it exists.
    // Reuse the winning candidate's already-computed freq as victim_freq
    // (no separate estimate call after the pick).
    let head_freq = self.sketch.estimate(&self.nodes[head_idx].key);
    let incoming_freq = self.sketch.estimate(&key);
    let (victim_idx, victim_freq) = match self.nodes[head_idx].next {
        None => (head_idx, head_freq),
        Some(second_idx) => {
            let second_freq = self.sketch.estimate(&self.nodes[second_idx].key);
            if second_freq < head_freq {
                (second_idx, second_freq)
            } else {
                (head_idx, head_freq)
            }
        }
    };
    (victim_idx, victim_freq, incoming_freq, true)
} else {
    // 7-out-of-8 evictions: plain LRU-head, standard gate.
    let victim_freq = self.sketch.estimate(&self.nodes[head_idx].key);
    let incoming_freq = self.sketch.estimate(&key);
    (head_idx, victim_freq, incoming_freq, false)
};

let admit = if strict {
    incoming_freq > victim_freq.saturating_add(1)
} else {
    incoming_freq > victim_freq
};
```

Then apply the `if admit { ... }` block that already exists in cycle/0006/v002 (map.remove, unlink, rekey, push_back, map.insert) using `victim_idx`.

**Invariants to preserve:**
- No new struct fields. `evict_counter: u32` already exists in cycle/0006/v002; the struct size stays at 160 bytes.
- The non-8th path is unchanged — 2 estimate calls exactly, same as the parent.
- The 8th path now costs 2 estimates when `head` has no neighbour, or 3 when a second-oldest node exists — 1 fewer than cycle/0006/v001 made on the same path (4 calls: head_freq, second_freq, victim_freq re-estimate, incoming_freq).
- The `CountMinSketch::estimate` and `increment` implementations are untouched.
- All unit tests must continue to pass.

## Rationale

cycle/0006/v001 tried best-of-2 on a different parent (cycle/0004/v001) and caused latency to double for two compounding reasons: the parent lacked `evict_counter`, so adding it grew TinyLfuCache from 152 to 160 bytes (likely crossing a cache-line boundary), AND the implementation issued 4 estimate calls on the 8th path (head_freq, second_freq, a redundant victim_freq re-estimate, incoming_freq). Building on cycle/0006/v002 eliminates both problems: the struct is already 160 bytes (no layout change), and the spec above removes the redundant call (3 estimates max on the 8th path). The net extra overhead vs cycle/0006/v002 is at most 1 estimate per 8 evictions.

# H01

Replacing u32 counters with u16 in the 8× width sketch keeps total heap at 64 KB while preserving v003's reduced collision rate, targeting an improvement in hit-rate without the L2-spill tail-latency penalty that v003 incurred.

## Parent

cycle/0007/v003

## Changes

In `src/tiny_lfu/mod.rs` (starting from cycle/0007/v003's overlay), make the following changes to `CountMinSketch`:

1. Change the constant `MAX_COUNT: u32 = u32::MAX;` to `MAX_COUNT: u16 = u16::MAX;`.
2. Change the `counts` field type from `Vec<Vec<u32>>` to `Vec<Vec<u16>>`.
3. In `CountMinSketch::new()`, initialise counts as `vec![vec![0u16; width]; depth]`.
4. In `heap_bytes()`, change `std::mem::size_of::<u32>()` to `std::mem::size_of::<u16>()`. Update the doc-comment from `size_of::<u32>()` to `size_of::<u16>()`.
5. In `increment()`, the existing `if *c < MAX_COUNT { *c += 1; }` pattern continues to work unchanged with `u16` — the type of `c` infers as `&mut u16` and `MAX_COUNT` is now `u16::MAX`.
6. In `estimate()`, the four cell reads must be cast before comparison. Replace the four `c0`–`c3` bindings with: `let c0 = self.counts[0][(h0 as usize) & mask] as u32;` (and similarly for c1, c2, c3). The final `c0.min(c1).min(c2).min(c3)` returns `u32` as before, so the function signature is unchanged.

Leave `SKETCH_WIDTH_FACTOR` at 8 and `SKETCH_DEPTH` at 4. Do not change the admission gate logic, the `TinyLfuCache` struct fields, or the hash computation. The resulting sketch heap for capacity=1024 is `4 × 8192 × 2 = 65 536 bytes` — matching the 4×u32 baseline exactly while halving the expected per-bucket collision rate inherited from v003.

## Rationale

Cycle 0007 established two facts independently: (a) 8× width lowers collision noise enough to raise hit rate (v003, +0.36 pp), and (b) u16 counters at the same width do not automatically improve latency because zero-extension overhead dominates (v002). The compound — 8× width with u16 counters — keeps the total heap at 64 KB (same as the 4×u32 baseline), neutralising the L2-spill pressure that forced v003's p99 to double, while retaining v003's lower collision rate. Neither cycle 7 nor any prior cycle has evaluated this configuration.

# H03

Protect high-frequency items from LRU-based eviction by filtering victim candidates to exclude above-median-frequency items, improving hit-rate through smarter victim selection.

## Parent

baseline

## Changes

In the `put()` method (around line 98), modify the victim selection to implement victim filtering. Before evicting `self.head`, compute the median estimated frequency across all current cache residents. If the LRU head's frequency is above the median, scan the linked list to find a below-median-frequency victim. If no below-median victim exists, fall back to evicting the head anyway.

Pseudocode:
```
// Compute median frequency of current items
let freqs: Vec<u32> = (0..self.nodes.len())
    .map(|i| self.sketch.estimate(&self.nodes[i].key))
    .collect();
freqs.sort_unstable();
let median_freq = freqs[freqs.len() / 2];

// Check LRU head frequency
let head_idx = self.head.expect("full cache has no head");
let head_freq = self.sketch.estimate(&self.nodes[head_idx].key);

// If head is above median, search for below-median victim
let victim_idx = if head_freq > median_freq {
    let mut candidate = head_idx;
    let mut current = self.nodes[head_idx].next;
    
    while let Some(idx) = current {
        let freq = self.sketch.estimate(&self.nodes[idx].key);
        if freq <= median_freq {
            candidate = idx;
            break;
        }
        current = self.nodes[idx].next;
    }
    
    candidate
} else {
    head_idx
};
```

Keep the depth-3 (or baseline) sketch geometry and admission threshold unchanged.

## Rationale

The cycle 0004 insight identifies eviction policy variations as an unexplored lever. Current LRU-only selection can evict items with high frequency simply because they were accessed longer ago. Median-based victim filtering creates a "protected zone" for above-median-frequency items, forcing the cache to evict from the cold pool first. This is orthogonal to victim-selection optimization (H01) and targets hit-rate by preventing unnecessary displacement of genuinely hot items.

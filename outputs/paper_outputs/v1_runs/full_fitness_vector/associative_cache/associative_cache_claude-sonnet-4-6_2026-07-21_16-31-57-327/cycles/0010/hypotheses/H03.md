# H03

Reverting the second-chance scan to LIFO order (newest-cold-first) while keeping all other parameters of cycle/0008/v003 intact isolates whether the LRU-among-cold scan direction is responsible for put p99 latency regressions that have persisted undiagnosed since cycle 0006.

## Parent

cycle/0008/v003

## Changes

Modify `eviction_candidate_index` in the `ClassicLRU` impl inside `src/shared/eviction_policy.rs`.

Change the scan loop from forward order to reverse order. The single-line change is:

```rust
// Before (LRU-among-cold, inner-edge first):
for i in len - scan_depth..len {

// After (LIFO-among-cold, tail first):
for i in (len - scan_depth..len).rev() {
```

Everything else in `eviction_candidate_index` stays the same: `scan_depth = len.min(8)`, the `if items[i].lfu_counter == 0 { return i; }` body, and the `len - 1` fallback when all scanned items are warm.

`get_from_position` is entirely unchanged from cycle/0008/v003: position-0 guard, write-once flag (`lfu_counter` 0→1 on first access), and 3-swap promotion loop with early-break at position 0.

`src/shared/item.rs` must be carried forward verbatim from `cycle/0008/v003` (32-byte `#[repr(C)]` layout with `_pad: u64`).

No other files are changed.

## Rationale (optional)

The put p99 regression first observed in cycle 0006's v003 has been attributed to multiple causes — swap write pressure (falsified in cycle 0007), flag-expiry overhead (introduced in cycle 0009, not cycle 0006), and scan-fallback behaviour — but none has been confirmed. Cycle 0008 v003 changed one thing relative to its parent: the scan direction from `(len - scan_depth..len).rev()` to `len - scan_depth..len`. This variant reverses that single change to create an exact A/B pair: cycle/0008/v003 with LRU-among-cold vs this variant with LIFO-among-cold. If the raw put p99 values differ between the two, scan direction is the source of the regression; if they are identical, that axis is ruled out. Cycle 0008 v003's hit-rate improvement from the forward scan is expected to reverse (a known cost of this diagnostic), but the per-op-time signal is the target dimension for this experiment.

# H01

Reduce per-operation latency overhead of learned insertion positioning by deferring access-pattern tracking to every Nth insertion operation instead of every operation to achieve low-cost insertion bias.

## Parent

cycle/0008/v003

## Changes

Modify the rolling buffer and bias-update logic in `src/associative_cache/mod.rs` to record hit/miss outcomes only every K insertion operations (K=32) instead of on every get/put. Keep the insertion-bias read-only on every put operation (zero cost), but defer the buffer recording and bias computation to trigger only when `insertion_count % 32 == 0`. This amortizes the 40–50% latency overhead observed in v003 across 32 operations, reducing per-operation cost from 40% down to ~1–2% while preserving the +0.43% hit-rate improvement. Maintain the same buffer size and bias-calculation logic; only the update frequency changes.

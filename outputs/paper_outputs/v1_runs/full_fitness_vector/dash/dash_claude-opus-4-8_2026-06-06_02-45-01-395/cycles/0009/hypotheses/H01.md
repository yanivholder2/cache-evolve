# H01

Gate the one-more-chance demotion retry on a non-full true target so the put-p99 cascade vanishes while keeping nearly all the rescued hits, lowering per-op-time without conceding hit-rate.

## Parent

cycle/0007/v001

## Changes

Modify `demote_from_normal_bucket` in `src/dash/segments/dash_segment.rs`.
The parent's `true_target != source_idx` branch unconditionally re-inserts the
foreign resident into its true target with `core.put_at(Slot::Target, ...)`,
and when that target is full it cascades the target's evicted LRU victim down to
the stash with a *second* `put_at`. Cycle 0007 located that double-insert as the
put-p99 bound, and cycle 0008/v003 showed that fully collapsing the retry to a
single stash hop costs ~0.0008 hit-rate (0.6794 → 0.6786) because the rescue
salvages real hits.

Replace the unconditional retry with a guarded one: when
`true_target != source_idx`, first check `core.buckets[true_target].is_full()`
(the `is_full()` method already used in this file's tests). If the true target is
**not** full, perform the existing single `put_at(Slot::Target, ...)` retry —
this can never evict, so the cascade second-insert is structurally impossible. If
the true target **is** full, route the item directly to
`core.put_at(Slot::Stash, insert_pos, item)` instead of retrying. The
`true_target == source_idx` branch (direct-to-stash) is unchanged.

Preserve: `insert_pos` is still honored on every insert (Front for cold, Back for
hot); the function signature is unchanged; demotion still terminates in the stash
in all paths. The hypothesis is that the rescued hits overwhelmingly land in
non-full targets, so this keeps hit-rate at or near 0.6794 while removing the
cascade `put_at` that produces the put-p99 tail — a strictly cheaper
conflict-mitigation step than the parent's full cascade.

## Rationale (optional)

Directly answers cycle 0008's open question: "is there a cheaper
conflict-mitigation step that keeps most rescued hits without the double-hop
tail?" The full-cascade parent (put-p99 ~196) and the collapsed single-hop
(put-p99 ~120, hit-rate 0.6786) bracket this conditional retry, which should sit
near the cheap-latency end while holding the parent's hit-rate.

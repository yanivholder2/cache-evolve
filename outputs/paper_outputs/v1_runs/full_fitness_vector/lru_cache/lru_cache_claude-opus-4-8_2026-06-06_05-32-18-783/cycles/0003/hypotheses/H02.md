# H02

Admit keys seen recently before eviction straight into the protected segment via a bounded ghost-key history, lifting hit-rate above the stuck 0.7241 record on the LIRS trace.

## Parent

cycle/0002/v002

## Changes

Extend v002's SLRU policy in `src/lru_cache/mod.rs` with a small
non-resident "ghost" history that records keys recently evicted, so a key
re-requested within a short reuse distance is re-admitted as already-hot
rather than restarting in probation:

- Add to `LruCache` a bounded FIFO of evicted keys plus a membership set:
  a `ghost_queue: std::collections::VecDeque<K>` and a `ghost_set:
  HashMap<K, (), FastBuildHasher>` (reuse the existing `FastBuildHasher`).
  Bound the ghost capacity to `capacity` (or `capacity / 2`); when the
  queue exceeds the bound, pop the oldest key and remove it from the set.
- In `put`, on the eviction branch (arena full, new key), after choosing
  the victim and cloning `evicted_key`, push that key into the ghost
  structure before reusing its slot.
- In `put`, on the new-key path, consult the ghost set for the incoming
  `key`. If present, insert the new node directly into the **protected**
  segment (set `protected = true`, `push_back`, `prot_len += 1`, and run
  the existing `demote_protected_lru` overflow check) and remove the key
  from the ghost structure; otherwise keep the current probationary
  admission. New keys never seen before are unaffected.

Invariants to preserve: the ghost structures hold **keys only, never
values**, are non-resident, and MUST NOT count toward `capacity` — the
resident entry count (`map.len()`/arena occupancy) must still never
exceed `capacity`, so the universal invariant gate stays green. Leave the
`FastHasher`, both fast paths, probation-first eviction, and `prot_cap`
geometry otherwise intact.

The claim is that LIRS-style reuse-distance re-admission raises hit-rate
above 0.7241; the added ghost map will grow `LruCache`'s metadata-size,
an accepted trade for a hit-rate-targeted Variant.

## Rationale (optional)

Hit-rate has been pinned at 0.7241 since Cycle 0001 and pure SLRU treats
every fresh insert as a one-hit-wonder. The workload is a LIRS trace,
whose defining structure is reuse distance; a ghost history is the
cheapest way to give SLRU LIRS-like admission and is the most plausible
lever left for beating the hit-rate record.

# H03

Caching the last-accessed protected-MRU key lets repeated gets of the hottest key skip the HashMap hash-and-probe entirely, lowering get p50.

## Parent

cycle/0006/v003

## Changes

Attack the actual get hot-path cost named in the cross-cycle insight — the
HashMap hash + probe — rather than a micro-op on an already-free path. Add
two fields to `LruCache`: `last_key: Option<K>` and `last_idx: u32`
(initialized `None` / `NIL` in `try_new`). These live on the cache struct,
not `Node`, so `Node<u64,u64>` stays 24 bytes and the scored metadata-size
is unchanged (only the `LruCache` footprint grows).

At the very top of `get`, before the `self.map.get(key)?` lookup, add a
single-entry fast path:

- If `last_key.as_ref() == Some(key)` and `last_idx != NIL` and
  `self.nodes[last_idx].key == *key` (guards against the slot having been
  reused for another key by eviction) and `self.prot_tail == last_idx`
  (the cached node is still the protected MRU, so the access changes no
  links), return `Some(&self.nodes[last_idx as usize].value)` without ever
  touching the HashMap.

On any normal (non-cached) get that ends with the accessed node sitting at
the protected MRU — both the existing protected-MRU fast-path return and
the promote/refresh paths after `push_back` into the protected segment —
update `last_key = Some(key.clone())` and `last_idx = link(idx)` so the
hottest key stays primed. The slot-reuse key check makes explicit
invalidation on eviction/demotion unnecessary: a stale `last_idx` simply
fails the `nodes[last_idx].key == *key` guard and falls through to the
normal map lookup. Do not change put, eviction, geometry, promotion, or
node layout.

The win is real only when the cached key actually repeats (skewed /
Zipfian-like traces where one key dominates consecutive gets); the guard
compares are a cheap u64 equality plus one node load that the hot path
would incur anyway. The hypothesis is confirmed if get p50 drops below
26 ns with hit-rate held at 0.7291, and refuted if key churn makes the
guard mispredict and regresses get p50.

# H02

Adding a persistent 64-byte CountMin frequency sketch to LruCache and using it to gate probationary graduation — requiring an estimated global frequency of at least 2 before promoting to protected — will improve hit-rate over cycle/0006/v001 by fast-tracking returning items (which have prior sketch history) without the within-window constraint that caused SEEN_BIT to fail.

## Parent

cycle/0006/v001

## Changes

### Struct change

Add one field to `LruCache<K, V>` (after `capacity`):

```rust
freq_sketch: [u8; 64],  // 4-row × 16-col CountMin sketch; zero-initialized
```

64 bytes = one cache line. `Node<K,V>` and `Link` are unchanged (still 16 bytes and 8 bytes respectively).

In `try_new()`, initialise the new field:

```rust
freq_sketch: [0u8; 64],
```

### New private method: `sketch_inc`

Add to the `impl<K,V>` block:

```rust
fn sketch_inc(&mut self, key: &K) -> u8 {
    use std::hash::{Hash, Hasher};
    use std::collections::hash_map::DefaultHasher;
    let mut h = DefaultHasher::new();
    key.hash(&mut h);
    let v = h.finish();
    // Derive four independent column indices (0..16) from one hash
    // by multiplying with four different primes and taking low 4 bits.
    let cols: [usize; 4] = [
        ( v                                   & 0xF) as usize,
        ((v.wrapping_mul(0xbf58476d1ce4e5b9)) & 0xF) as usize,
        ((v.wrapping_mul(0x94d049bb133111eb)) & 0xF) as usize,
        ((v.wrapping_mul(0x9e3779b97f4a7c15)) & 0xF) as usize,
    ];
    let mut min_val = u8::MAX;
    for (row, &col) in cols.iter().enumerate() {
        let slot = &mut self.freq_sketch[row * 16 + col];
        *slot = slot.saturating_add(1);
        if *slot < min_val { min_val = *slot; }
    }
    min_val
}
```

This method increments all four row-cells and returns the post-increment minimum (the CountMin frequency estimate after this access).

### Change to `promote()`

In the probationary branch of `promote()` (the `else` arm, currently starting with `self.unlink(idx); self.prob_len -= 1; ...`), insert a frequency check BEFORE unlinking:

```rust
} else {
    // Probationary hit: consult the frequency sketch.
    // Clone key to satisfy the borrow checker (Copy for u64, cheap for all K).
    let freq = {
        let k = self.nodes[idx].key.clone();
        self.sketch_inc(&k)
    };
    if freq < 2 {
        // Below threshold: item has only been accessed once globally.
        // Leave it in the probationary FIFO (no relinking needed) and return.
        return;
    }
    // freq >= 2: item has recurring access history — graduate normally.
    self.unlink(idx);
    self.prob_len -= 1;
    self.push_back_prot(idx);
    self.prot_len += 1;
    let prot_cap = self.capacity - self.prob_cap;
    if self.prot_len > prot_cap {
        let h = (self.prot_head & IDX_MASK) as usize;
        self.unlink(h);
        self.prot_len -= 1;
        self.push_back_prob(h);
        self.prob_len += 1;
    }
}
```

The protected hit branch (`if protected { ... }`) is unchanged — no sketch access for protected hits.

### Why this differs from SEEN_BIT

SEEN_BIT required a second hit within one contiguous probationary window; the bit was cleared on eviction. The sketch is permanent: an item evicted with freq=1 retains that count, so on its next probationary visit its first hit pushes freq to 2 and it graduates immediately. Only true one-time items (never seen again after eviction) are held back by the two-hit threshold. Workload-a's moderate-frequency Zipfian items cycle in and out of the cache; those should accumulate freq ≥ 2 quickly across visits.

### Invariants to preserve

- `self.prob_len + self.prot_len == self.map.len()` — maintained because the early-return path does not change queue membership.
- `self.prob_len > 0` when evicting from probationary — unaffected; the sketch only changes the graduation rate, not the eviction path.
- No changes to `evict_one()`, `unlink()`, `push_back_prob()`, `push_back_prot()`, or `put()`.

# H01

Marking a first-hit probationary node's SEEN_BIT with a single bitwise OR — without unlinking or relinking it — confines the graduation splice to the rare second-access path and should recover the 0 ns per-op-time tier of cycle/0002/v001 while retaining the two-hit filter's marginal hit-rate benefit.

## Parent

cycle/0002/v001

## Changes

Start from the exact `src/lru_cache/mod.rs` of cycle/0002/v001 and apply the following changes only; leave everything else intact.

**1. Adjust the NULL sentinel and IDX_MASK to free bit 30 for SEEN_BIT.**

Change:
```rust
const NULL: u32 = 0x7FFF_FFFF;
const PROT_BIT: u32 = 0x8000_0000;
const IDX_MASK: u32 = 0x7FFF_FFFF;
```
To:
```rust
const NULL: u32    = 0x3FFF_FFFF;   // bits 0-29 all set; bits 30-31 reserved for flags
const PROT_BIT: u32 = 0x8000_0000;  // bit 31: node is in the protected queue
const SEEN_BIT: u32 = 0x4000_0000;  // bit 30: probationary node has been accessed once
const IDX_MASK: u32 = 0x3FFF_FFFF;  // strips both PROT_BIT and SEEN_BIT
```

**2. Update the capacity guard in `try_new`.**

Change the upper-bound check from `capacity > 0x7FFF_FFFEusize` to `capacity > 0x3FFF_FFFFusize - 1` (i.e., `capacity >= 0x3FFF_FFFF`) to reflect the new, smaller NULL sentinel.

**3. Rewrite the probationary branch of `promote()` to implement lazy SEEN_BIT marking.**

Replace the current else-branch of `promote()` (the probationary path) with:

```rust
} else {
    // Probationary hit: check SEEN_BIT to decide whether to graduate.
    let has_seen = (self.nodes[idx].prev & SEEN_BIT) != 0;
    if !has_seen {
        // First hit: mark as seen with a single bit-OR.
        // Do NOT relink — the node stays at its current FIFO position in
        // the probationary queue, keeping this path a branchless write.
        self.nodes[idx].prev |= SEEN_BIT;
        return;
    }
    // Second+ hit: graduate to protected (SEEN_BIT is cleared automatically
    // when push_back_prot writes PROT_BIT | prot_tail into prev).
    self.unlink(idx);
    self.prob_len -= 1;
    self.push_back_prot(idx);
    self.prot_len += 1;
    // Enforce the protected budget.
    let prot_cap = self.capacity - self.prob_cap;
    if self.prot_len > prot_cap {
        let h = (self.prot_head & IDX_MASK) as usize;
        self.unlink(h);
        self.prot_len -= 1;
        self.push_back_prob(h);
        self.prob_len += 1;
    }
}
```

**4. Preserve SEEN_BIT in `unlink()` when patching the successor's `prev` field.**

In `unlink()`, change the line that updates the successor node's prev from:
```rust
let succ_prot_bit = self.nodes[next as usize].prev & PROT_BIT;
self.nodes[next as usize].prev = succ_prot_bit | prev_idx;
```
To:
```rust
let succ_flags = self.nodes[next as usize].prev & (PROT_BIT | SEEN_BIT);
self.nodes[next as usize].prev = succ_flags | prev_idx;
```
This is necessary because a successor that has itself been accessed once will have SEEN_BIT set in its own `prev` field; clearing it during an unlink of a different node would silently reset its admission state.

**5. No changes to `push_back_prob` or `push_back_prot`.** `push_back_prob` assigns `prev = self.prob_tail` (a raw index with no flags set), which naturally clears SEEN_BIT and PROT_BIT for newly inserted or demoted entries. `push_back_prot` ORs in PROT_BIT only, which leaves SEEN_BIT=0 as desired.

**Invariant to preserve:** at any point, a node with SEEN_BIT set is in the probationary queue at whatever position it occupied when its first access arrived; it must never enter the protected queue with SEEN_BIT still set (graduation via `push_back_prot` clears it because `prot_tail` is a raw index without SEEN_BIT).

## Rationale

cycle/0004/v003 confirmed that encoding SEEN_BIT in bit 30 of `prev` costs nothing in node layout (24 bytes preserved). It failed because the first-access path executed `unlink` + `push_back_prob` + `|= SEEN_BIT` — three pointer operations on the common path instead of zero extra work. By reducing the first-access path to a single bitwise OR, the common path (first probationary hit) becomes as cheap as possible. The splice for graduation fires only on the second access, which is the rare event the filter was designed to target. This matches the restructuring explicitly requested by the cycle 0004 open questions.

# H01

Layering a two-queue (probationary FIFO + protected LRU) eviction policy on top of cycle/0001/v002's u32-sentinel node layout will recover the hit-rate lift seen in cycle/0001/v001 while preserving v002's 24-byte node footprint.

## Parent

cycle/0001/v002

## Changes

Start from v002's `src/lru_cache/mod.rs` and make the following modifications:

**1. Repurpose a sentinel bit to encode the protected flag (Node stays 24 bytes)**

Change the NULL sentinel from `!0u32` to `0x7FFF_FFFF` (bit 31 clear, bits 0-30 all set). Use bit 31 of the `prev` field as the `protected` flag:
- `const NULL: u32 = 0x7FFF_FFFF;`
- `const PROT_BIT: u32 = 0x8000_0000;`
- `const IDX_MASK: u32 = 0x7FFF_FFFF;`

Everywhere `prev` is read as an index, mask it: `(prev & IDX_MASK) as usize`. Everywhere `prev` is written as an index, preserve the protected bit: `self.nodes[idx].prev = (self.nodes[idx].prev & PROT_BIT) | (new_idx as u32)`. Update the capacity guard accordingly: `capacity > (0x7FFF_FFFE as usize)`.

Node layout is unchanged at 24 bytes. The `next` field uses `NULL` as-is (no bit 31 usage there).

**2. Replace single-chain head/tail with two-queue pointers on LruCache**

Remove `head: u32` and `tail: u32`. Add:
```
prob_head: u32,   // LRU end of probationary queue (eviction candidate); NULL if empty
prob_tail: u32,   // MRU end of probationary queue
prot_head: u32,   // LRU end of protected queue; NULL if empty
prot_tail: u32,   // MRU end of protected queue
prob_len: usize,
prot_len: usize,
prob_cap: usize,  // = (capacity / 4).max(1)
```
In `try_new`, set `prob_cap = (capacity / 4).max(1)`.

**3. Implement `push_back_prob(idx)` and `push_back_prot(idx)`**

`push_back_prob`: appends to probationary tail. Clears the PROT_BIT on `prev`. Sets `nodes[idx].next = NULL`.
`push_back_prot`: appends to protected tail. Sets the PROT_BIT on `prev`. Sets `nodes[idx].next = NULL`.

These helpers set/clear the protected bit on insertion so it always reflects the node's current queue.

**4. Rewrite `unlink(idx)` to dispatch on the protected bit**

Read `let protected = (self.nodes[idx].prev & PROT_BIT) != 0;`. Extract prev/next indices with `& IDX_MASK`. Update the correct queue's head or tail pointer depending on `protected`. Clear prev/next on the node after unlinking (preserve PROT_BIT in `prev`, clear the index bits by writing `NULL` without PROT_BIT, i.e., write `NULL` to both fields).

**5. Implement `promote(idx)` called from `get()`**

```
if protected:
    // Protected hit: refresh to protected tail
    unlink(idx); push_back_prot(idx);
else:
    // Probationary hit: graduate to protected queue
    unlink(idx); prob_len -= 1;
    push_back_prot(idx); prot_len += 1;
    // Enforce protected budget: demote protected LRU head back to probationary tail
    let prot_cap = capacity - prob_cap;
    if prot_len > prot_cap:
        let h = (prot_head & IDX_MASK) as usize;
        unlink(h); prot_len -= 1;
        push_back_prob(h); prob_len += 1;
```

**6. Implement `evict_one()` used by `put()`**

Take from `prob_head` if `prob_len > 0`, otherwise from `prot_head`. Remove evicted key from map and call `unlink`. Return the freed slot index.

**7. Update `put()`**

- Existing key (map hit): update value, call `promote(idx)`, return.
- New key + arena full: call `evict_one()` to get a free slot; reuse it.
- New key + arena not full: push a new Node.
- In both new-key cases: call `push_back_prob(idx)`; `prob_len += 1`; `map.insert(key, idx)`.

**Invariants to preserve**: total resident items ≤ capacity at all times; `prob_len + prot_len == map.len()`; all u32 casts/masks use `IDX_MASK`.

## Rationale

v001 demonstrated a 0.720 hit-rate (+8% over baseline) using two-queue semantics, but its `Option<usize>` node layout bloated to 56 bytes and the cross-queue pointer chasing pushed p50 latency to 100 ns. v002's 24-byte u32-sentinel nodes should halve the cache-line footprint vs v001 for the same number of entries, making the cross-queue relinking overhead representationally cheaper. The protected-bit-in-prev trick avoids adding any new field to Node.

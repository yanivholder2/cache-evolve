# H02

Track per-item access frequency alongside recency to improve hit rate by prioritizing frequently accessed items during eviction.

## Parent

baseline

## Changes

Add a `freq: u32` field to the `Node` struct to count access frequency (incremented on each `get()` and on `put()` updates). Modify the eviction logic in `put()`: instead of always evicting the head (LRU), scan from the head and skip nodes with frequency > 1 until finding an evictable node (frequency == 1). If all remaining nodes have freq > 1, evict the absolute LRU anyway.

Decay frequency values periodically: every N evictions, divide all non-evicted nodes' frequency by 2 (integer division) to prevent stale frequency values from dominating. This hybrid approach balances recency (linked-list order) with frequency (access count), reducing cache thrashing on borderline access patterns while preserving O(1) get/put per-operation.

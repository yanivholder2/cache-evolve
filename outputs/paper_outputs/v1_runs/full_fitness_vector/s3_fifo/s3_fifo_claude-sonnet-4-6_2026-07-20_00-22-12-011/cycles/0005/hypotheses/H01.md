# H01

Replacing the `position()` scan in `get()` and `put()` of `cycle/0004/v002` with a side `data: HashMap<K, V>` for O(1) value retrieval and a `freq_map: HashMap<K, u8>` for O(1) frequency access eliminates the dominant O(n) lookup bottleneck identified in cycle 4 and reduces per-op-time.

## Parent

cycle/0004/v002

## Changes

Starting from the `cycle/0004/v002` overlay (`src/s3_fifo/mod.rs`), apply the following changes. Every other aspect of v002 — `small_size = capacity/40`, ghost lazy-deletion via `ghost_set`/`ghost` deque, `MAX_FREQ = 3`, `evict_main()` unbounded second-chance loop, `evict_small()` freq>1 promotion threshold — remains intact.

### 1. Redefine `Entry<K, V>` to hold only the key

Remove the `value: V` field. Add `_phantom: std::marker::PhantomData<V>` so that `Entry<K,V>` remains generic over `V` without storing it. Keep the constructor signature `fn new(key: K, _value: V) -> Self` (accepting but ignoring the value argument so all existing call-sites compile unchanged). After this change `std::mem::size_of::<Entry<u64,u64>>()` = 8.

```rust
#[derive(Debug)]
pub struct Entry<K, V> {
    key: K,
    _phantom: std::marker::PhantomData<V>,
}

impl<K, V> Entry<K, V> {
    fn new(key: K, _value: V) -> Self {
        Self { key, _phantom: std::marker::PhantomData }
    }
}
```

### 2. Add `data` and `freq_map` fields; remove parallel freq deques

In `S3Fifo<K, V>`, remove `small_freq: VecDeque<u8>` and `main_freq: VecDeque<u8>`. Add:

```rust
data: HashMap<K, V>,      // resident key → value; O(1) access
freq_map: HashMap<K, u8>, // resident key → frequency; O(1) access
```

Add `use std::collections::HashMap;` at the top. In `try_new()`, remove the `small_freq`/`main_freq` capacity allocations and add:

```rust
data: HashMap::with_capacity(capacity),
freq_map: HashMap::with_capacity(capacity),
```

### 3. Rewrite `get()` to use O(1) lookups

Replace the entire body of `get()`:

```rust
pub fn get(&mut self, key: &K) -> Option<&V> {
    if let Some(freq) = self.freq_map.get_mut(key) {
        *freq = freq.saturating_add(1).min(MAX_FREQ);
        return self.data.get(key);
    }
    None
}
```

No `position()` calls remain. The borrow of `freq_map` ends after the `*freq` assignment, so the subsequent `self.data.get(key)` borrow is disjoint and compiles under NLL.

### 4. Rewrite `put()` to use O(1) lookups

Replace the update-check and admission logic in `put()`:

```rust
pub fn put(&mut self, key: K, value: V) {
    // O(1) update path: key already resident.
    if self.data.contains_key(&key) {
        self.data.insert(key, value);
        return;
    }

    // Ghost hit: O(1) via ghost_set.
    if self.ghost_set.contains(&key) {
        self.ghost_set.remove(&key);
        if self.main.len() >= self.main_size {
            self.evict_main();
        }
        self.data.insert(key.clone(), value);
        self.freq_map.insert(key.clone(), 0);
        self.main.push_front(Entry::new(key, value));  // value arg ignored
        return;
    }

    // Normal admission into small.
    if self.small.len() >= self.small_size {
        self.evict_small();
    }
    self.data.insert(key.clone(), value);
    self.freq_map.insert(key.clone(), 0);
    self.small.push_front(Entry::new(key, value));  // value arg ignored
}
```

No `position()` calls remain.

### 5. Rewrite `evict_main()` to use `freq_map`

```rust
fn evict_main(&mut self) {
    while let Some(tail) = self.main.pop_back() {
        let freq = self.freq_map.get(&tail.key).copied().unwrap_or(0);
        if freq > 0 {
            self.freq_map.insert(tail.key.clone(), freq - 1);
            self.main.push_front(tail);
        } else {
            self.data.remove(&tail.key);
            self.freq_map.remove(&tail.key);
            break;
        }
    }
}
```

### 6. Rewrite `evict_small()` to use `freq_map`

```rust
fn evict_small(&mut self) {
    if let Some(tail) = self.small.pop_back() {
        let freq = self.freq_map.get(&tail.key).copied().unwrap_or(0);
        if freq > 1 {
            // Hot: promote to main; entry stays in data and freq_map.
            if self.main.len() >= self.main_size {
                self.evict_main();
            }
            self.main.push_front(tail);
        } else {
            // Cold: evict to ghost; remove from data and freq_map.
            self.data.remove(&tail.key);
            self.freq_map.remove(&tail.key);
            while self.ghost.len() >= self.main_size {
                if let Some(evicted_key) = self.ghost.pop_back() {
                    if self.ghost_set.contains(&evicted_key) {
                        self.ghost_set.remove(&evicted_key);
                        break;
                    }
                }
            }
            let k = tail.key;
            self.ghost.push_front(k.clone());
            self.ghost_set.insert(k);
        }
    }
}
```

# H03

Moving the per-entry `freq` counter out of `Entry<K,V>` into parallel `VecDeque<u8>` sibling arrays reduces `mem::size_of::<Entry<u64,u64>>()` from 24 bytes to 16 bytes, targeting metadata-size reduction.

## Parent

baseline

## Changes

All changes are confined to `src/s3_fifo/mod.rs`.

**1. Strip `freq` from `Entry<K,V>`.** Remove the `freq: u8` field and its initialiser:

```rust
pub struct Entry<K, V> {
    key: K,
    value: V,
    // freq removed — tracked in S3Fifo::small_freq / main_freq instead
}

impl<K, V> Entry<K, V> {
    fn new(key: K, value: V) -> Self {
        Self { key, value }
    }
}
```

With this change `mem::size_of::<Entry<u64,u64>>()` drops from 24 to 16 (no padding needed for two 8-byte fields).

**2. Add parallel frequency deques to `S3Fifo`.** One deque per resident queue; indices are kept in lock-step with the corresponding entry deque:

```rust
pub struct S3Fifo<K: PartialEq + Clone, V> {
    small:      VecDeque<Entry<K, V>>,
    small_freq: VecDeque<u8>,
    main:       VecDeque<Entry<K, V>>,
    main_freq:  VecDeque<u8>,
    ghost:      VecDeque<K>,
    small_size: usize,
    main_size:  usize,
}
```

**3. Initialise in `try_new()`.** Mirror the capacity of each entry deque:

```rust
small_freq: VecDeque::with_capacity(small_size),
main_freq:  VecDeque::with_capacity(main_size),
```

**4. Update `get()`.** Find the entry by scanning with `enumerate()`; update the corresponding freq slot:

```rust
pub fn get(&mut self, key: &K) -> Option<&V> {
    if let Some((idx, entry)) = self.small.iter().enumerate().find(|(_, e)| &e.key == key) {
        self.small_freq[idx] = (self.small_freq[idx].saturating_add(1)).min(MAX_FREQ);
        return Some(&self.small[idx].value);
    }
    if let Some((idx, entry)) = self.main.iter().enumerate().find(|(_, e)| &e.key == key) {
        self.main_freq[idx] = (self.main_freq[idx].saturating_add(1)).min(MAX_FREQ);
        return Some(&self.main[idx].value);
    }
    None
}
```

**5. Update `evict_small()`.** Pop from both the entry deque and freq deque together; use the popped freq value for the promotion decision:

```rust
fn evict_small(&mut self) {
    if let Some(tail) = self.small.pop_back() {
        let tail_freq = self.small_freq.pop_back().unwrap_or(0);
        if tail_freq > 1 {
            if self.main.len() >= self.main_size {
                self.evict_main();
            }
            self.main.push_front(tail);
            self.main_freq.push_front(0);
        } else {
            if self.ghost.len() >= self.main_size {
                self.ghost.pop_back();
            }
            self.ghost.push_front(tail.key);
        }
    }
}
```

**6. Update `evict_main()`.** Pop and push both deques together:

```rust
fn evict_main(&mut self) {
    while let Some(tail) = self.main.pop_back() {
        let tail_freq = self.main_freq.pop_back().unwrap_or(0);
        if tail_freq > 0 {
            self.main.push_front(tail);
            self.main_freq.push_front(tail_freq - 1);
        } else {
            break;
        }
    }
}
```

**7. Ghost-hit reinsertion in `put()`.** When promoting from ghost to main, push a fresh zero freq:

```rust
self.main.push_front(Entry::new(key, value));
self.main_freq.push_front(0);
```

**8. Update inline tests.** The test `main_eviction_uses_frequency_second_chance` directly sets `entry.freq`. Replace those accesses with push/pop from `cache.main_freq` in the same positions, e.g.:

```rust
cache.main.push_back(Entry::new(1, 10));
cache.main_freq.push_back(0u8);
cache.main.push_back(Entry::new(2, 20));
cache.main_freq.push_back(2u8);
// … and so on for each entry
```

Similarly update `small_eviction_promotes_to_main_after_multiple_hits` to call `cache.get()` to increment freq (it already does this via the public API, so no structural change needed there).

All existing invariants (capacity bound, value fidelity, no phantom items) are unaffected because the public `get`/`put` interface is unchanged.

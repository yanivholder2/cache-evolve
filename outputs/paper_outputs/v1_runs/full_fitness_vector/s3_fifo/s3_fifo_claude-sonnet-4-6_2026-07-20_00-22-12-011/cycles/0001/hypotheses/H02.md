# H02

Adding a `HashSet<K>` shadow index for the ghost queue reduces ghost-hit detection in `put()` from an O(ghost_size) linear scan to O(1), targeting per-op-time reduction.

## Parent

baseline

## Changes

In `src/s3_fifo/mod.rs`:

**1. Imports.** Add `use std::collections::HashSet;` alongside the existing `VecDeque` import.

**2. Struct definition.** Add a `ghost_set` field and tighten the `K` bound to include `Eq + std::hash::Hash` (the `Cache` trait impl already requires these, so the bound is already valid for all callers):

```rust
pub struct S3Fifo<K: PartialEq + Eq + std::hash::Hash + Clone, V> {
    small: VecDeque<Entry<K, V>>,
    main: VecDeque<Entry<K, V>>,
    ghost: VecDeque<K>,
    ghost_set: HashSet<K>,   // shadow membership index
    small_size: usize,
    main_size: usize,
}
```

**3. `try_new()`.** Initialise the new field:

```rust
ghost_set: HashSet::with_capacity(main_size),
```

**4. `put()` — ghost lookup.** Replace the O(n) scan:

```rust
// before
let in_ghost = self.ghost.iter().any(|ghost_key| ghost_key == &key);
```

with:

```rust
// after
let in_ghost = self.ghost_set.contains(&key);
```

**5. `put()` — ghost hit path.** Keep the existing `ghost.retain(...)` for deque ordering but also remove the key from the set:

```rust
self.ghost.retain(|ghost_key| ghost_key != &key);
self.ghost_set.remove(&key);
```

**6. `evict_small()` — ghost insertion.** Replace the bare `ghost.push_front` / `ghost.pop_back` block with set-synced versions:

```rust
// when evicting the oldest ghost to stay within size cap:
if self.ghost.len() >= self.main_size {
    if let Some(evicted) = self.ghost.pop_back() {
        self.ghost_set.remove(&evicted);
    }
}
// when admitting the new ghost key:
self.ghost_set.insert(tail.key.clone());
self.ghost.push_front(tail.key);
```

The `ghost` deque continues to own eviction ordering; `ghost_set` is a pure membership oracle that is always kept in sync with the deque. No other code paths touch the ghost queue, so no further changes are needed.

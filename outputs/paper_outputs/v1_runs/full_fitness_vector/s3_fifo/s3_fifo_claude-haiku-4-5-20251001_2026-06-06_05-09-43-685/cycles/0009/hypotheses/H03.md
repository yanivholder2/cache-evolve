# H03

Preserve ghost-queue frequency depth with amortized batch decay (every 32 evictions) to capture warm candidates without per-operation overhead.

## Parent

baseline

## Changes

Introduce frequency-depth tracking to the ghost queue and amortized decay computation to preserve more warm-candidate re-admission opportunities. Modify the ghost structure from `VecDeque<K>` to `VecDeque<(K, i8)>` and add a `small_evict_count: usize` field. In `evict_small()`, always store items in ghost as `(key, ghost_freq)` where `ghost_freq = (tail.freq as i8) - 1` (removing the current `if tail.freq > 1` gate), and retain items if `ghost_freq > -3`. After each small-queue eviction, increment `small_evict_count`; when it reaches 32, iterate through the ghost queue and decrement all frequencies by 1 (in-place, O(ghost.len())), then reset the counter to 0. This batches the decay cost onto a cold path (eviction time, amortized once per 32 evictions) rather than spreading it across hot paths. On ghost hit, boost re-admission by `ghost_freq + 2` (clamped to MAX_FREQ). This design preserves the zero-hot-path-overhead philosophy that made v002 and v001 successful while extending candidate diversity beyond cycle 0008/v001's strict freq > 0 filtering.

## Rationale

Cycles 0001–0008 consistently confirm that per-operation overhead kills latency, while cold-path computation (at eviction time) is free. Cycle 0008/v001 proved that ghost filtering at eviction time delivers latency without cost, but its freq > 0 threshold was too pure. This hypothesis decouples frequency *tracking* (necessary for accurate re-admission signals) from frequency *decay* (expensive if done per-eviction), moving decay to a batch-amortized schedule. The 32-eviction window balances decay freshness against amortization: at typical hit/miss ratios, small-queue evictions occur roughly once per 50 operations, making amortized decay negligible overhead while keeping frequency information within 2–3 "generations" of accuracy. This tests whether the lean-design philosophy (v002) can be enhanced with richer ghost state if decay cost is pushed far enough into the cold path.

# H01

Replace the quadratic occupancy-responsive re-admission boost formula with linear scaling to recover hit-rate while retaining latency gains.

## Parent

cycle/0009/v002

## Changes

In the ghost-hit re-admission path (around line 128 of `src/s3_fifo/mod.rs`), replace the quadratic boost formula with linear occupancy scaling:

**Current (quadratic):**
```rust
let boost = (2.0 + occupancy_ratio * occupancy_ratio).min(MAX_FREQ as f64) as u8;
```

**New (linear):**
```rust
let boost = (1.5 + 2.0 * occupancy_ratio).min(MAX_FREQ as f64) as u8;
```

This change reduces the magnitude of the re-admission protection signal. The quadratic formula provides excessive boost (2.0–5.0 range) that crowds out small-queue working-set items by re-admitting ghost entries at freq 2–3. Linear scaling (1.5–3.5 range) provides gentler adaptation that preserves frequency depth without overwhelming the main queue's low-frequency items. The change preserves the cold-path-computation architecture that gives v002 its latency advantage.

## Rationale (optional)

Cycle 0009 identified that v002's quadratic formula (2.0 + occupancy_ratio²) is "miscalibrated, providing excessive re-admission protection (freq 2–3) that crowds out small-queue working-set items, causing a 1.55% hit-rate regression." Linear scaling addresses this directly by reducing the boost magnitude while maintaining occupancy responsiveness. The 19% latency improvement of v002 should be preserved since it comes from the cold-path computation placement, not the boost magnitude.

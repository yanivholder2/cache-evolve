# H03

Replacing the promote-on-second-hit SLRU with a pure CLOCK / second-chance scheme — a reference bit that grants one eviction reprieve without ever moving a key to a protected tier — will raise hit-rate by shielding warm keys while keeping the bucket free of permanently-immortal protected entries.

baseline

## Changes

Re-implement the `Bucket` trait for `AssociativeCacheBucket` in
`src/associative_cache/associative_cache_bucket.rs` as a CLOCK (second-chance)
policy, using `lfu_counter` as a single reference bit (0 or 1). There is no
protected segment and no move-to-back on hit — this is a deliberately different
family from the SLRU lineage, to test whether a reprieve bit beats tier
promotion on this collision-bound trace.

- `put` (new key): if the bucket is full, evict via the CLOCK scan below, then
  push the new item at the **back** (so items keep insertion/FIFO order, oldest
  at index 0). `Item::new` already sets `lfu_counter == 0`. Update-in-place on
  key match is unchanged.
- `get_from_position` (hit path): set the hit item's `lfu_counter = 1` (the
  reference bit) and return it **in place** — do not reorder the vector. This is
  the key contrast with the parent SLRU, which removes and re-pushes on hit.
- Override `evict_item` (not just `eviction_candidate_index`, because the scan
  must mutate reference bits) to run the CLOCK hand: scan items from the front
  (index 0) upward; if an item has `lfu_counter == 1`, clear it to 0 (consume
  its second chance) and continue; the first item found with `lfu_counter == 0`
  is removed and returned as the eviction candidate. If a full pass clears every
  reference bit without finding a 0 (all were 1), the front item (index 0) is
  now 0 on the second look — evict it. Guarantee termination and that exactly
  one item is removed.

Preserve every bucket invariant the gate checks: occupancy never exceeds
`max_size`, eviction happens only on a full `put`, `get`/`get_from_position`
return a reference to the accessed item, and `put` returns
`(&inserted, Option<evicted>)` with the evicted item being the CLOCK victim.

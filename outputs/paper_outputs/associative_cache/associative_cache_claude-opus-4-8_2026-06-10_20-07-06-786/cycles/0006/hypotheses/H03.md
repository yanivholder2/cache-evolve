# H03

Pairing wider buckets with a stricter two-hit promotion threshold raises hit-rate, because in a larger collision set a single hit is weaker evidence of reuse than at baseline geometry.

## Parent

cycle/0003/v002

## Changes

This hypothesis tests the geometry x promotion *interaction* the cross-cycle
notes flag as untested: two-hit promotion regressed at baseline geometry, but it
has never been retried in a wider bucket where a key has more neighbours and one
access is a noisier signal. Edit two overlay files; do not touch the
gate-integrity surface.

1. `src/shared/geometry.rs` — widen the buckets exactly as in H01: in
   `BaselineGeometry::layout`, if `self.num_of_buckets` is even and `> 1`, return
   `(self.num_of_buckets / 2, self.bucket_size * 2)`; otherwise return the
   identity split. Preserve the capacity invariant `nb * bs` and keep the
   `BaselineGeometry` type name and `for_settings` entry point.

2. `src/associative_cache/associative_cache_bucket.rs` — promote on the *second*
   hit instead of the first, using `lfu_counter` as a 0/1/2 tier:
   - `put`: unchanged (new keys admitted at index 0 with `lfu_counter == 0`).
   - `get_from_position`: increment `lfu_counter` saturating up to a cap of `2`
     on every hit (so 0 -> 1 -> 2, then stays 2), and move the item to the MRU
     back as today. A key is "protected" once `lfu_counter >= 2`; `lfu_counter`
     of 0 or 1 is still probationary.
   - `eviction_candidate_index`: prefer the *oldest* item whose
     `lfu_counter < 2` (highest such index, preserving the FIFO-probation lap
     that has been load-bearing). Only when every item has `lfu_counter >= 2`
     fall back to evicting protected index 0 (the protected LRU end), exactly as
     the parent does for its fully-protected case.

Keep probationary items as a contiguous front block and protected as a back
block so the index scans remain valid. Do not add aging/decay (ruled out) — the
counter only ever increases.

Rationale: this is deliberately a known-bad lever (the 2-hit threshold) revived
*only* in combination with the one untested geometry change, isolating whether
the regression was intrinsic to demanding more proof, or merely an artifact of
the narrow baseline bucket where probation laps are too short to collect a
second hit before eviction.

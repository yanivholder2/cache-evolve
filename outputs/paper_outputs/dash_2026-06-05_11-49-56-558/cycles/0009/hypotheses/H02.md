# H02

Combining cycle/0008/v001's 7/8 normal/stash geometry with a two-hit target-to-probing promotion gate (lfu_counter >= 2) raises hit rate by stacking two orthogonal mechanisms that each target a distinct pipeline loss site.

## Parent

cycle/0008/v001

## Changes

Keep all overlay files from cycle/0008/v001 unchanged (`geometry.rs` with 7/8 split, `eviction_policy.rs` with `ClassicLRUFreqProtect`, `dash_bucket.rs` factory) **except** `src/dash/segments/dash_segment.rs`.

In `dash_segment.rs`, in `promotion_get()`, inside the `if let Some(item_idx) = core.buckets[target_idx].get_position(key)` branch, add a counter read and extend the promotion condition from the current single predicate to a two-part guard. Change:

```rust
let is_hottest = Some(item_idx) == core.buckets[target_idx].promotion_candidate_index();
if is_hottest {
    // promote to probing
    let data = core.buckets[target_idx].remove_at(item_idx);
    promote_to_probing(core, data, insert_pos);
    ...
} else {
    return Some(core.buckets[target_idx].get_from_position(item_idx));
}
```

to:

```rust
let is_hottest = Some(item_idx) == core.buckets[target_idx].promotion_candidate_index();
let counter = core.buckets[target_idx].get_items()[item_idx].lfu_counter;
if is_hottest && counter >= 2 {
    // promote to probing
    let data = core.buckets[target_idx].remove_at(item_idx);
    promote_to_probing(core, data, insert_pos);
    ...
} else {
    return Some(core.buckets[target_idx].get_from_position(item_idx));
}
```

Items that are hottest but hold counter < 2 fall through to `get_from_position`, which increments their counter and moves them to MRU — allowing them to accumulate the required evidence before qualifying for probing.

Do not alter the stash-hit promotion path, second-chance recovery, `lfu_counter` reset on demotion, or any geometry parameter.

## Rationale

Cycle/0008/v003 tested the counter >= 2 gate on the 3/4 geometry (24+8) and measured 0.7223 — marginally below v001's 0.7229 at 7/8 geometry (28+4). Since the two mechanisms target distinct sites (capacity allocation vs. promotion selectivity), their gains may be additive: wider geometry captures more of the hot set, while the stricter gate keeps marginal single-access items from consuming probing slots. If independent and non-interfering, the combined result should exceed both v001 and v003.

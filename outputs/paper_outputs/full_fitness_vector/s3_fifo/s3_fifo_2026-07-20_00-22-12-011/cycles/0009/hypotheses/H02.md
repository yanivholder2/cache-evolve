# H02

Replacing the default SipHash hasher with a custom FNV-1a hasher for all internal `HashMap` and `HashSet` structures reduces per-probe hash computation cost and lowers get p50 latency.

## Parent

cycle/0005/v001

## Changes

Add a zero-external-dependency FNV-1a hasher implementation directly in `src/s3_fifo/mod.rs`
and change every `HashMap` and `HashSet` in the struct to use it.

**Add before the `Entry` struct definition**:

```rust
use std::hash::{BuildHasher, Hasher};

/// FNV-1a 64-bit hasher — faster than SipHash for small integer keys.
struct FnvHasher(u64);
impl Hasher for FnvHasher {
    #[inline]
    fn write(&mut self, bytes: &[u8]) {
        for &b in bytes {
            self.0 ^= b as u64;
            self.0 = self.0.wrapping_mul(0x0000_0100_0000_01B3);
        }
    }
    #[inline]
    fn write_u64(&mut self, i: u64) {
        self.0 ^= i;
        self.0 = self.0.wrapping_mul(0x0000_0100_0000_01B3);
    }
    #[inline]
    fn finish(&self) -> u64 { self.0 }
}

#[derive(Clone, Default)]
struct FnvBuildHasher;
impl BuildHasher for FnvBuildHasher {
    type Hasher = FnvHasher;
    #[inline]
    fn build_hasher(&self) -> FnvHasher { FnvHasher(0xcbf2_9ce4_8422_2325) }
}
```

The `write_u64` override matters: `u64` keys invoke it directly via `Hash::hash`, bypassing the
byte-loop in `write`. One xor + one multiply replaces SipHash's multi-round mixing.

**Struct field types**: Change all three hash collections to the typed forms:
```rust
data: HashMap<K, V, FnvBuildHasher>,
freq_map: HashMap<K, u8, FnvBuildHasher>,
ghost_set: HashSet<K, FnvBuildHasher>,
```

**`try_new()`**: Replace each `with_capacity(n)` call with the corresponding hasher-aware form:
```rust
data:      HashMap::with_capacity_and_hasher(capacity, FnvBuildHasher),
freq_map:  HashMap::with_capacity_and_hasher(capacity, FnvBuildHasher),
ghost_set: HashSet::with_capacity_and_hasher(main_size, FnvBuildHasher),
```

Do not change the `ghost: VecDeque<K>` field — it uses no hasher.

**No logic changes**: All other code (get, put, evict_main, evict_small, tests) is unchanged.
Preserve all invariants from cycle/0005/v001: `MAX_FREQ = 3`, `small_size = capacity / 40`,
`freq > 1` promotion gate, `freq = 0` on ghost-hit admission, lazy ghost tombstoning.

## Rationale

Every `get()` call hashes the key twice (once into `freq_map`, once into `data`). Every `put()`
call hashes it at least twice (resident check + ghost check). The default SipHash hasher was
designed for DOS-resistant string hashing and applies a 128-bit keyed permutation — significant
overhead for an 8-byte integer key where collision resistance is irrelevant. FNV-1a reduces each
u64 hash to one xor and one multiply, which is substantially cheaper and keeps the full hash
computation in register arithmetic. This should lower the marginal cost of each hash lookup on
both the get and put hot paths, directly targeting get p50 without altering any cache policy.

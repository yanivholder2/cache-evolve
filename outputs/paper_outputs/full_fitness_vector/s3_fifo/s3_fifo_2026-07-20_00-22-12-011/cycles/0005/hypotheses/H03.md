# H03

Replacing the `position()` scan in `cycle/0004/v001` with a single `resident_map: HashMap<K, (V, u8)>` that stores both value and frequency per resident key eliminates all O(n) lookups in `get()` and `put()` via one cache-local hashmap lookup instead of two separate maps, reducing per-op-time.

## Parent

cycle/0004/v001

## Changes

Starting from the `cycle/0004/v001` overlay (`src/s3_fifo/mod.rs`), which has `small_size = capacity/20`, parallel `small_freq`/`main_freq` deques, O(1) ghost via `ghost_set`, lazy ghost deletion, and a bounded `SCAN_CAP = 16` in `evict_main()`. Apply the following changes. `small_size = capacity/20` and all ghost logic are preserved; the bounded scan cap is removed (the cycle 4 insight showed it is falsified on Zipfian workloads).

### 1. Redefine `Entry<K, V>` to hold only the key

Remove the `value: V` field from `Entry<K,V>`. Keep the constructor accepting `(key: K, _value: V)` so all existing call-sites compile without modification. Add `_phantom: std::marker::PhantomData<V>` to retain the generic parameter. After this change `std::mem::size_of::<Entry<u64,u64>>()` = 8.

```rust
#[derive(Debug)]
pub struct Entry<K, V> {
    key: K,
    _phantom: std::marker::PhantomData<V>,
}

impl<K, V> Entry<K, V> {
    fn new(key: K, _value: V) -> Self {
        Self { key, _phantom: std::marker::PhantomData }
    }
}
```

### 2. Replace parallel freq deques with `resident_map`; remove bounded scan constant

In `S3Fifo<K,V>`, remove `small_freq: VecDeque<u8>` and `main_freq: VecDeque<u8>`. Add:

```rust
/// Maps every resident key to its (value, frequency) pair. O(1) access for
/// both get() value retrieval and frequency updates. A single lookup covers
/// both fields, avoiding a second hashmap round-trip.
resident_map: HashMap<K, (V, u8)>,
```

Add `use std::collections::HashMap;` at the top. In `try_new()`, remove the two `VecDeque::with_capacity` calls for freq deques and add:

```rust
resident_map: HashMap::with_capacity(capacity),
```

Remove the `const SCAN_CAP: usize = 16;` line and the `scanned` counter logic from `evict_main()` (see §5 below).

### 3. Rewrite `get()` with a single O(1) lookup

```rust
pub fn get(&mut self, key: &K) -> Option<&V> {
    if let Some((val, freq)) = self.resident_map.get_mut(key) {
        *freq = freq.saturating_add(1).min(MAX_FREQ);
        return Some(val);  // &mut V coerces to &V; lifetime bound to &mut self
    }
    None
}
```

No `position()` calls remain. A single `HashMap::get_mut` covers hit detection, frequency increment, and value retrieval in one lookup.

### 4. Rewrite `put()` with O(1) update and admission

```rust
pub fn put(&mut self, key: K, value: V) {
    // O(1) update path: key already resident.
    if let Some((v, _)) = self.resident_map.get_mut(&key) {
        *v = value;
        return;
    }

    // Ghost hit: O(1) via ghost_set; lazy deletion preserved.
    if self.ghost_set.contains(&key) {
        self.ghost_set.remove(&key);
        if self.main.len() >= self.main_size {
            self.evict_main();
        }
        self.resident_map.insert(key.clone(), (value, 0));
        self.main.push_front(Entry::new(key, value));  // value arg ignored by Entry
        return;
    }

    // Normal admission into small.
    if self.small.len() >= self.small_size {
        self.evict_small();
    }
    self.resident_map.insert(key.clone(), (value, 0));
    self.small.push_front(Entry::new(key, value));
}
```

### 5. Rewrite `evict_main()` — unbounded second-chance, no SCAN_CAP

Remove `const SCAN_CAP` and the `scanned` counter entirely:

```rust
fn evict_main(&mut self) {
    while let Some(tail) = self.main.pop_back() {
        let freq = self.resident_map.get(&tail.key).map_or(0, |&(_, f)| f);
        if freq > 0 {
            if let Some((_, f)) = self.resident_map.get_mut(&tail.key) {
                *f = freq - 1;
            }
            self.main.push_front(tail);
        } else {
            self.resident_map.remove(&tail.key);
            break;
        }
    }
}
```

The unbounded scan terminates quickly on Zipfian workloads because cold entries accumulate naturally at the tail of main (confirmed in cycle 4).

### 6. Rewrite `evict_small()` to use `resident_map`

```rust
fn evict_small(&mut self) {
    if let Some(tail) = self.small.pop_back() {
        let freq = self.resident_map.get(&tail.key).map_or(0, |&(_, f)| f);
        if freq > 1 {
            // Hot: promote to main; entry stays in resident_map.
            if self.main.len() >= self.main_size {
                self.evict_main();
            }
            self.main.push_front(tail);
        } else {
            // Cold: evict to ghost; remove from resident_map.
            self.resident_map.remove(&tail.key);
            while self.ghost.len() >= self.main_size {
                if let Some(evicted_key) = self.ghost.pop_back() {
                    if self.ghost_set.contains(&evicted_key) {
                        self.ghost_set.remove(&evicted_key);
                        break;
                    }
                }
            }
            let k = tail.key;
            self.ghost.push_front(k.clone());
            self.ghost_set.insert(k);
        }
    }
}
```

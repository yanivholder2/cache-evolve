# H02

Compose v002's frequency-aware eviction policy with v003's proven 75/25 geometry and adaptive divisor formula to test whether implementation efficiency (in-place frequency counting) can be combined with geometry-parameter co-optimization for improvements across both hit-rate and latency.

## Parent

cycle/0009/v003

## Changes

Start from v003's overlay (75/25 geometry with `compute_promotion_threshold` divisor formula). Adopt the eviction policy changes from v002 by modifying `src/dash/dash_settings.rs` to change the default `eviction_policy` field from `ClassicLRU` to `FrequencyAwareLRU`. Additionally, apply v002's debug-mode setting change (set `debug_mode: 0` instead of the default). This replaces the LRU-only eviction candidate selection with a composite (timestamp, frequency) ranking in `src/shared/eviction_policy.rs`, where eviction prefers items with both old recency and low frequency (see `FrequencyAwareLRU::eviction_candidate_index` implementation).

The composition pairs v003's proven 75/25 geometry and adaptive divisor threshold (which controls *what* gets promoted) with v002's frequency-aware selection logic (which controls *what* gets evicted). These are orthogonal concerns: promotion controls tier movement, while eviction determines who leaves the cache when capacity is exhausted. The hypothesis tests whether frequency awareness provides decision value when applied to a properly-tuned geometric allocation, given that frequency awareness *within* a single tier may be more effective than across unbalanced geometries.

## Rationale

Cycle 0009 identified two divergent optimization paths: v002 achieved 57% get-latency improvement via implementation efficiency without hit-rate change, and v003 achieved best-in-class hit-rate (0.7169) via geometry-parameter co-optimization. The cycle insight explicitly asks: "Can v002's implementation efficiency and v003's geometry-aware formula be combined?" This hypothesis tests that composition directly. v002's frequency awareness was tested on baseline 25/75 geometry; applying it to v003's proven 75/25 allocation provides both a geometrically sound foundation and a test of whether frequency awareness is fundamentally ineffective (as the cycle insight suggests) or merely mis-calibrated for baseline geometry. If composition succeeds, the result combines latency efficiency with hit-rate superiority. If it fails, the evidence confirms that frequency is not a decision-improvement axis on this workload, closing that exploration branch permanently.

# H01

Stacking vacancy-gated probing re-entry on top of cycle/0005/v001's LFU-minimum eviction and vacancy-gated target promotion yields additive hit-rate improvement without introducing new latency regressions.

## Parent

cycle/0005/v001

## Changes

Start from the full cycle/0005/v001 three-file overlay (`src/shared/item.rs`, `src/shared/eviction_policy.rs`, `src/dash/segments/dash_segment.rs`). Carry `item.rs` and `eviction_policy.rs` forward unchanged. Modify only `dash_segment.rs`.

In `promotion_get`, replace the probing-hit block (currently a plain in-place touch):

```rust
if let Some(item_idx) = core.buckets[probing_idx].get_position(key) {
    debug!("promotion_get: key={key:?} found in probing bucket={probing_idx}");
    return Some(core.buckets[probing_idx].get_from_position(item_idx));
}
```

with the vacancy-gated probing re-entry logic from cycle/0005/v002:

```rust
if let Some(item_idx) = core.buckets[probing_idx].get_position(key) {
    core.buckets[probing_idx].get_items_mut()[item_idx].lfu_counter += 1;
    let counter = core.buckets[probing_idx].get_items()[item_idx].lfu_counter;
    let target_has_space = !core.buckets[target_idx].is_full();
    if counter >= 2 && target_has_space {
        debug!("...(vacancy-gated probing re-entry)");
        let data = core.buckets[probing_idx].remove_at(item_idx);
        promote_to_target(core, data, InsertPosition::Back);
        let item_new_idx = core.buckets[target_idx]
            .get_position(key)
            .expect("promote_to_target must leave key in target");
        return Some(&core.buckets[target_idx].get_items()[item_new_idx]);
    }
    debug!("...(intra-probing stay)");
    return Some(core.buckets[probing_idx].get_from_position(item_idx));
}
```

Every other mechanism from v001 is preserved: LFU-minimum eviction scan in `ClassicLRU::eviction_candidate_index`, `InsertPosition::Back` for MRU-end insertion, vacancy-gated target promotion (lfu_counter >= 2 AND probing has space), and the timestamp-free `Item` struct. No other files are touched.

The combined set is: LFU-minimum eviction + vacancy-gated target promotion + vacancy-gated probing re-entry — the full three-way stack described as the natural convergence target in the cycle/0005 insight.

## Rationale

The cycle/0005 insight confirmed that probing re-entry (v002) and LFU-minimum eviction with vacancy-gated promotion (v001) are independently effective and operate on orthogonal code paths. Additive stacking has held up in every prior cycle when mechanisms are structurally non-overlapping. The probing re-entry gate fires only when target has space (zero cascade risk) and operates on the probing-hit branch, which is disjoint from the eviction-scan path. The expected outcome is a small additional hit-rate lift on top of v001's 0.6901 baseline.

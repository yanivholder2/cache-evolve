# H02

Extending the second-chance scan by two additional positions only when the primary 8-slot scan finds all candidates warm improves hit rate in steady-state by finding rare cold victims before falling back to LRU-tail eviction.

## Parent

cycle/0008/v003

## Changes

Modify `eviction_candidate_index` in the `ClassicLRU` impl inside `src/shared/eviction_policy.rs`.

After the existing 8-slot forward scan (`for i in len - scan_depth..len`) finds no cold item, add a secondary scan of 2 positions immediately above the primary window — positions `len - scan_depth - 2` through `len - scan_depth - 1` — before falling back to `len - 1`. Guard the secondary scan with `if len > scan_depth + 2` to prevent underflow on small buckets.

Concrete replacement for the current body of `eviction_candidate_index`:

```rust
let len = items.len();
let scan_depth = len.min(8);
// Primary LRU-among-cold scan (unchanged).
for i in len - scan_depth..len {
    if items[i].lfu_counter == 0 {
        return i;
    }
}
// Secondary expansion: 2 positions just above the cold window,
// only when the primary scan found all warm and the bucket is large enough.
if len > scan_depth + 2 {
    for i in len - scan_depth - 2..len - scan_depth {
        if items[i].lfu_counter == 0 {
            return i;
        }
    }
}
// All candidates warm: fall back to the LRU tail.
len - 1
```

`get_from_position` is unchanged (3-swap promotion with write-once flag and position-0 guard).

`src/shared/item.rs` must be carried forward verbatim from `cycle/0008/v003` (32-byte `#[repr(C)]` layout with `_pad: u64`).

The secondary scan loop MUST be a separate `for` loop (not a combined range) so it is only entered after the primary scan completes without returning. The scan direction in both loops is inner-to-outer (forward), consistent with the parent's LRU-among-cold ordering.

## Rationale (optional)

The cross-cycle insights confirm that 8 is the optimal constant scan depth — expanding to full depth always added unbounded cost with zero hit-rate return. But that finding was for an unconditional expansion. The secondary 2-slot scan here fires only on the subset of evictions where every candidate in the primary window has already been accessed, which is the scenario where warm-item eviction is most harmful. The cost (2 extra comparisons on warm-all evictions) is bounded and low; the benefit is a modest reduction in unnecessary eviction of warm items during steady-state operation when the hot set has grown to fill the primary cold window.

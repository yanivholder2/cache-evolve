# H03

Optimize ClassicLRU on 32×64 geometry by implementing early-exit bucket scanning and cache-line alignment to reduce tail latency.

## Parent

cycle/0003/v003

## Changes

Modify ClassicLRU's `get()` path to return immediately upon locating an entry, without completing a full scan of the bucket. Additionally, align bucket memory layout to 64-byte cache-line boundaries to improve spatial locality and reduce memory access latency during linear scans. Keep the 32×64 bucket geometry (32 buckets × 64 items per bucket) and ClassicLRU eviction policy unchanged. The goal is to reduce the p99 tail latency spike observed in v003 (p99=300 ns) while preserving its hit-rate win (0.664).

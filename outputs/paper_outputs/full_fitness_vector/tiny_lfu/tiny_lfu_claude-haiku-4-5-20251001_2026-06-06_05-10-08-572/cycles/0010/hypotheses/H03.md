Test asymmetric admission with symmetric relative gate (no additional frequency buffer) to isolate whether hit-rate gains derive from entry-type semantics alone or require threshold tightening.

## Changes

In `src/tiny_lfu/mod.rs`, in the `put()` method where the admission check occurs (around line 102), replace the simple frequency comparison with asymmetric admission logic but using the same relative comparison for both entry types:

```rust
// Old (baseline):
if incoming_freq > victim_freq {
    // admit and evict victim
}

// New (asymmetric entry-type gate, symmetric threshold):
let is_existing = self.map.contains_key(&key);
let admission_ok = if is_existing {
    true  // Always admit updates to existing items
} else {
    incoming_freq > victim_freq  // New items use same relative gate
};

if admission_ok {
    // admit and evict victim
    self.map.remove(&victim_key);
    self.unlink(victim_idx);
    self.nodes[victim_idx].key = key.clone();
    self.nodes[victim_idx].value = value;
    self.push_back(victim_idx);
    self.map.insert(key, victim_idx);
}
```

Keep sketch geometry (SKETCH_DEPTH=4, SKETCH_WIDTH_FACTOR=4 from baseline), victim selection (LRU-only, N=1), and all other mechanics unchanged from baseline.

## Rationale

Cycle 0009 v003 applied asymmetric admission with a frequency-advantage requirement (`incoming_freq > victim_freq + 1` for new items) and achieved hit-rate=0.7374 vs. baseline's 0.736. However, it remains unclear whether the improvement derives from the semantic insight (update vs. new entry distinction) or from the stricter +1 threshold. This hypothesis isolates the asymmetry mechanism by applying the entry-type distinction without tightening the frequency gate: updates always admitted (hot path), new items use the same relative comparison as baseline. If hit-rate improves over baseline with this weaker gate, it confirms asymmetry is the key leverage point; if it fails, it indicates v003's threshold tightening is essential. This provides an independent validation checkpoint for the asymmetry insight, orthogonal to cycle 0009's v003 which confounds mechanism with threshold strictness.

# H02

Layering a 20%-capacity protected LRU segment onto `cycle/0007/v003`'s amortised-gate and 8× sketch combination will push hit rate above the 0.7409 ceiling that either mechanism achieved alone.

## Parent

cycle/0007/v003

## Changes

Starting from `cycle/0007/v003` (8× sketch width, u32 counters, bijective remix hash, amortised strict gate), add the following protected-segment split using a compact `Vec<u64>` bitset for flag storage (so `Node<u64,u64>` stays at 48 bytes):

**Struct additions** — add five fields to `TinyLfuCache`:

```rust
prot_head: Option<usize>,
prot_tail: Option<usize>,
prot_count: usize,
prot_capacity: usize,
prot_flags: Vec<u64>,   // packed bitset, one bit per node slot
```

**`try_new` additions** — initialise alongside existing fields:

```rust
prot_head: None,
prot_tail: None,
prot_count: 0,
prot_capacity: (capacity / 5).max(1),
prot_flags: vec![0u64; (capacity + 63) / 64],
```

**Add two chain-management helpers** operating on `prot_head`/`prot_tail` (structurally identical to the existing `unlink`/`push_back` methods but updating `prot_head`/`prot_tail` instead of `head`/`tail`):

```rust
fn prot_unlink(&mut self, idx: usize) { ... }
fn prot_push_back(&mut self, idx: usize) { ... }
```

Use inline bit-test `(self.prot_flags[idx/64] >> (idx%64)) & 1 != 0` to check membership; `|= 1u64 << (idx%64)` to set; `&= !(1u64 << (idx%64))` to clear.

**`get` method** — replace `self.unlink(idx); self.push_back(idx)` with:

1. If the bit for `idx` is set (already protected): `prot_unlink(idx)` then `prot_push_back(idx)` (re-position at MRU end; `prot_count` unchanged).
2. If clear (probationary): `self.unlink(idx); prot_count += 1`. If `prot_count > prot_capacity`, demote the LRU protected node (`prot_unlink(prot_head)`, clear its bit, `push_back(prot_head_idx)`). Then `prot_push_back(idx)` and set the bit.

**`put` method — existing-key branch** — apply the same flag-based promotion logic as in `get` (unlink from whichever chain the existing node is in, promote/re-position in protected chain).

**`put` method — full-cache eviction branch** — keep the existing `evict_counter`-based amortised gate logic unchanged. Add one guard before reading `self.head`: if `self.head.is_none()` (all slots in protected chain), force-demote `prot_head` (prot_unlink, clear bit, push_back, prot_count -= 1) so the probationary chain is non-empty before the gate comparison.

New node insertions (filling empty slots) always enter via `push_back` (probationary) with flag bit = 0.

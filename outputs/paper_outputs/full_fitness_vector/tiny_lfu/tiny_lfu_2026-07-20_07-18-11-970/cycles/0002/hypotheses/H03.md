# H03

Reducing CountMinSketch depth from 4 rows to 2 rows halves sketch heap size and per-sketch-operation cost while testing whether 2-row counter accuracy is sufficient to preserve hit rate on this stable Zipfian-like workload.

## Parent

baseline

## Changes

The baseline uses `SKETCH_DEPTH = 4`, meaning each `increment` and `estimate` call performs 4 hash computations and 4 counter reads/writes. Halving the depth cuts that to 2 operations per call and halves the sketch heap allocation.

**Single-line constant change:**

In `CountMinSketch`, change:
```rust
const SKETCH_DEPTH: usize = 4;
```
to:
```rust
const SKETCH_DEPTH: usize = 2;
```

That is the only required edit. All downstream code already parametrizes on `self.depth`:
- `CountMinSketch::new` builds `vec![vec![0; width]; depth]` — now allocates 2 rows instead of 4.
- `heap_bytes` returns `self.depth * self.width * size_of::<u32>()` — now reports 32768 bytes instead of 65536 for a capacity-2048 cache.
- `increment` loops `for row in 0..self.depth` — now 2 iterations.
- `estimate` maps over `self.counts.iter().enumerate()` — now takes min of 2 values instead of 4.
- `position` is unchanged.

No other code touches `SKETCH_DEPTH` directly. Node layout, admission logic (`get`, `put`), LRU link management, and the JNI boundary are all unchanged.

## Rationale

With sketch width = 8192 (for capacity 2048) and depth 2, each row has 8192 slots shared across all keys. For a Zipfian-like LIRS workload where the hot working set is small relative to the sketch width, collision probability per row is low, and the min of 2 independent rows is likely still a reliable frequency estimator. The hypothesis tests whether the frequency signal is redundant enough at depth 4 that depth 2 is sufficient — and simultaneously wins both metadata-size (sketch heap halved to ~32 KB) and per-op-time (2 hash/counter ops instead of 4) dimensions. If hit rate regresses, that is evidence the 4-row redundancy is load-bearing for this trace; if it holds, depth-2 is a strict improvement on all three axes.

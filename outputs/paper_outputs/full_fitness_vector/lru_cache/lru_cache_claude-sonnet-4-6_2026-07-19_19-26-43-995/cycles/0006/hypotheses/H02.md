# H02

Composing the SEEN_BIT two-hit admission filter with an enlarged protected quota (capacity/8) on top of the link-array structural baseline raises hit-rate by ensuring that items graduating through the stricter gate are shielded from demotion long enough to accumulate further hits.

## Parent

cycle/0005/v002

## Changes

Apply three layered changes to the cycle/0005/v002 overlay (`src/lru_cache/mod.rs`):

**1. Extend sentinel and flag constants to accommodate SEEN_BIT in `Link.prev`:**

```rust
const NULL: u32     = 0x3FFF_FFFF;  // bits 0-29 all set; bits 30-31 reserved
const PROT_BIT: u32 = 0x8000_0000;  // bit 31: in protected queue
const SEEN_BIT: u32 = 0x4000_0000;  // bit 30: probationary node accessed once
const IDX_MASK: u32 = 0x3FFF_FFFF;  // strips PROT_BIT and SEEN_BIT
```

Update the capacity range check in `try_new()` to `capacity > 0x3FFF_FFFFusize - 1` (matching the narrower index space of the 30-bit field).

**2. Change the probationary quota in `try_new()`:**

```rust
let prob_cap = (capacity / 8).max(1);
```

**3. Add two-hit admission logic to `promote()`:**

In the probationary branch of `promote()`, before calling `unlink()`, check SEEN_BIT in `self.links[idx].prev`:

```rust
} else {
    let has_seen = (self.links[idx].prev & SEEN_BIT) != 0;
    if !has_seen {
        // First probationary hit: mark as seen with a single bit-OR.
        // Do NOT relink — node stays at its FIFO position.
        self.links[idx].prev |= SEEN_BIT;
        return;
    }
    // Second+ hit: graduate to protected.
    self.unlink(idx);
    self.prob_len -= 1;
    self.push_back_prot(idx);
    self.prot_len += 1;
    // Enforce protected budget (unchanged) ...
}
```

**4. Preserve SEEN_BIT in `unlink()` when fixing the successor's backward link:**

In the `unlink()` successor fixup, preserve both flags:

```rust
let succ_flags = self.links[next as usize].prev & (PROT_BIT | SEEN_BIT);
self.links[next as usize].prev = succ_flags | prev_idx;
```

**5. `push_back_prob()` already clears both flags** because it assigns `self.prob_tail` (a raw index with no flag bits) directly to `prev`. No change needed there.

**6. `push_back_prot()` already sets only PROT_BIT** (`PROT_BIT | self.prot_tail`), so SEEN_BIT is naturally cleared on graduation. No change needed.

No other structural changes. The `Link` struct's memory layout (`prev: u32, next: u32`) is unchanged; only the bit interpretation of `prev` is extended.

## Rationale

cycle/0005/v001 proved that the SEEN_BIT first-hit path costs nothing (bit-OR only, no relink). Its hit-rate loss stems from single-access items that sit at the probationary LRU head and get evicted before earning a second hit. A larger protected pool (cycle/0005/v003's direction) reduces demotion pressure, keeping the items that do survive the two-hit gate resident longer. The cycle insight explicitly calls out this composition as the most actionable open thread. Building it on v002's 16-byte Node layout brings all three improvements together without adding any new node fields.

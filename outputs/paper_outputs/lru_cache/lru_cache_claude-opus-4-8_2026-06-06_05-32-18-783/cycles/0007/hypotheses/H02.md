# H02

Requiring two probationary hits before promotion to the protected segment filters one-hit-wonders more aggressively and raises hit-rate, using a free bit so node size stays 24 bytes.

## Parent

cycle/0006/v003

## Changes

Add a "warm" reference bit to each probationary node by repurposing the
currently-unused high bit of the `next` link word (the comment notes
`next` never carries the segment flag, and arena indices stay well under
`2^31`, so the high bit is free). Define `WARM_MASK: u32 = 1 << 31` and
route all `next` access through the existing `next_link` / `set_next_link`
helpers so they mask `WARM_MASK` off the link portion exactly as
`prev_link` / `set_prev_link` already mask `PROT_MASK` — this keeps `slot`
/ `link` decoding and the `NIL` sentinel correct and preserves the 24-byte
node layout (no new field).

Change the promotion logic in `get`'s probationary branch (the `else`
arm that today unconditionally promotes on the first probationary hit):

- On a probationary hit where the warm bit is clear: set the warm bit,
  refresh the node to the probationary MRU via the existing
  `unlink` + `push_back` pair, and do NOT promote (leave it
  probationary, `prot_len` unchanged).
- On a probationary hit where the warm bit is already set: clear the warm
  bit, then perform the existing promotion exactly as today
  (`set_protected(true)`, `push_back`, `prot_len += 1`, and the
  `prot_len > prot_cap` demotion check).

Ensure the warm bit is cleared whenever a slot is reused for a new key in
`put` (the eviction/reuse path already calls `set_protected(false)`; also
clear the warm bit there) and whenever a node is demoted back to
probation in `demote_protected_lru` (start demoted entries warm-clear so
they must re-earn promotion). Keep eviction victim selection, geometry,
and the protected-MRU fast path unchanged. The hypothesis is confirmed if
the stricter admission lifts hit-rate above 0.7291 on workload-a; it is
refuted if the extra probation dwell drops hit-rate (short reuse
distances drained before the second hit) or if the added per-hit
bookkeeping moves get p50.

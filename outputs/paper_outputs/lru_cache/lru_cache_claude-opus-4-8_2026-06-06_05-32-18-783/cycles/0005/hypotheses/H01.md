# H01

Fold v002's gated reuse-distance ghost admission onto v001's 24-byte SLRU base to lift hit-rate while holding the 24-byte node and low latency.

## Parent

cycle/0004/v001

## Changes

Port the non-resident ghost history from cycle/0004/v002 onto the v001
24-byte (`u32`-link, packed-flag) SLRU base, keeping v001's `Node` layout
byte-for-byte so metadata-size stays at 24. Concretely:

- Add the `GHOST_PROMOTE_HITS: u8 = 2` constant and three new
  `LruCache` fields (the ghost state lives in the cache, never in
  `Node`, so the node footprint is untouched): `ghost_queue:
  VecDeque<K>`, `ghost_set: HashMap<K, u8, FastBuildHasher>`, and
  `ghost_cap: usize`. Initialize `ghost_cap = capacity` in `try_new`
  alongside the existing `prot_cap` computation.
- Port the `ghost_remember(&mut self, key: K)` and `ghost_admit(&mut
  self, key: &K) -> u8` methods verbatim from v002: `ghost_remember`
  inserts the evicted key with count 0 (skipping duplicates) and trims
  the FIFO to `ghost_cap`; `ghost_admit` bumps and returns the retained
  per-key hit count, returning 0 on a miss.
- Add a `push_front(&mut self, idx: usize)` that mirrors v001's
  `push_back` but links at the segment LRU end. It MUST go through
  v001's `slot`/`link`/`set_prev_link`/`set_next_link`/`set_head`/
  `set_tail` helpers and `NIL` sentinel so the packed `PROT_MASK`
  segment flag in `prev`'s high bit is preserved — do not reintroduce
  `Option<usize>` links.
- In `put`, on the new-key path call `let ghost_hits =
  self.ghost_admit(&key)` before victim selection, and call
  `self.ghost_remember(evicted_key)` when a victim is evicted. After the
  arena slot `idx` is obtained, branch exactly as v002 does: if
  `ghost_hits >= GHOST_PROMOTE_HITS`, `set_protected(true)`,
  `push_front(idx)`, `prot_len += 1`, and demote on overflow; otherwise
  `set_protected(false)` and `push_back(idx)`.

Preserve every v001 invariant: `FastHasher`, the 80% `prot_cap`
geometry, probation-first victim selection, and the protected-MRU fast
paths in `get`/`put` stay unchanged. Ghosts remain non-resident and
never count toward `capacity`.

## Rationale (optional)

The cycle-0004 and cross-cycle insights both name this fold as the next
move: v001 (small node) and v002 (gated admission) touch disjoint
structures (node layout vs. external ghost store), so stacking them
should keep v001's metadata-size=24 and per-op-time=27 while capturing
v002's 0.7242 hit-rate.

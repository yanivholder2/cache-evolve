# H01

Add lightweight frequency counters to cache nodes and evict based on lowest frequency (with ties broken by recency) to improve hit rate on access-skewed workloads.

## Parent

baseline

## Changes

Add a `freq: u8` field to the `Node` struct in `src/lru_cache/mod.rs`, initialized to 0 for each new node. This field tracks how many times each item has been accessed via `get()`.

In the `get()` method, increment the accessed node's `freq` counter (saturating at 255) immediately after the hash map lookup and before promotion to MRU.

Modify the eviction logic in `put()` when `self.nodes.len() >= self.capacity`: instead of blindly evicting `self.head` (the LRU item), scan all nodes in the arena and select the node with the minimum `freq` value as the victim. Break ties in frequency by selecting the node closest to `self.head` (earliest in the order). This ensures that items rarely accessed are evicted first, even if they were accessed more recently.

Preserve all other invariants: the doubly-linked list structure, capacity bounds, and the value-fidelity of stored keys and values. The promotion logic on get/put remains unchanged — items accessed or inserted still move to the tail (MRU).

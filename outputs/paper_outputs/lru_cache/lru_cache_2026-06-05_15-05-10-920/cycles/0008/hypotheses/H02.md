# H02

Test hybrid frequency-recency scoring with decay using one-pass victim selection to isolate whether hybrid scoring's benefit depends on two-pass LRU tie-breaking.

## Parent

cycle/0004/v003

## Changes

The parent variant implements one-pass victim selection: find and evict the first item encountered with the minimum frequency. It includes the proven frequency decay mechanism (0.75× multiplicative decay at capacity × 16 intervals) but lacks the two-pass refinement introduced in Cycle 0006.

Replace the one-pass eviction logic with hybrid frequency-recency scoring while maintaining all other characteristics:

1. For each node in the cache, compute an eviction score combining frequency value and recency position
2. Score formula: `score = (frequency × 100) + position_from_head` where position increases from 0 (head/oldest) toward tail
3. Select and evict the node with the minimum score

Implementation (replace eviction scan in the `put()` method):

```rust
let mut victim_idx = self.head.expect("non-empty list has a head");
let mut victim_score = (self.nodes[victim_idx].freq as u8 as u32 * 100) + 0;

let mut position = 1u32;
let mut current = self.nodes[victim_idx].next;
while let Some(idx) = current {
    let score = (self.nodes[idx].freq as u8 as u32 * 100) + position;
    if score < victim_score {
        victim_score = score;
        victim_idx = idx;
    }
    position += 1;
    current = self.nodes[idx].next;
}
```

Keep the frequency decay mechanism intact (0.75× multiplicative decay at capacity × 16 intervals) and maintain the frequency counter field as u8.

## Rationale

H01 tests hybrid scoring + decay + two-pass selection. H02 tests hybrid scoring + decay + one-pass selection on the same parent cycle/0004/v003 used in Cycle 0007. Comparing results between H01 and H02 isolates whether hybrid scoring's benefit (if any) is independent of or dependent on the two-pass refinement. If hybrid scoring improves hit-rate equally on both one-pass and two-pass bases, the improvement comes from the scoring signal itself; if it improves only with two-pass, the interaction matters. This design choice illuminates whether hybrid scoring is a standalone eviction signal or primarily a refinement to two-pass tie-breaking.

# H01

Integrate frequency-recency hybrid eviction scoring into the decay mechanism to improve victim discrimination and raise hit-rate beyond two-pass LRU tie-breaking.

## Parent

cycle/0007/v001

## Changes

The parent variant uses a two-pass victim selection: find the minimum frequency across all nodes, then scan from head (oldest) to tail (newest) to select the first item with that minimum frequency. This approach captures temporal locality within equal-frequency tiers but ignores recency position as an eviction signal.

Replace the two-pass victim selection logic (lines 89-104) with hybrid frequency-recency scoring:

1. For each node in the cache, compute an eviction score combining frequency value and recency position
2. Score formula: `score = (frequency × 100) + position_from_head` where position increases from 0 (head/oldest) toward tail
3. Select and evict the node with the minimum score

Implementation (replace eviction loop):

```rust
let mut victim_idx = self.head.expect("non-empty list has a head");
let mut victim_score = (self.nodes[victim_idx].freq as u32 * 100) + 0;

let mut position = 1u32;
let mut current = self.nodes[victim_idx].next;
while let Some(idx) = current {
    let score = (self.nodes[idx].freq as u32 * 100) + position;
    if score < victim_score {
        victim_score = score;
        victim_idx = idx;
    }
    position += 1;
    current = self.nodes[idx].next;
}
```

Keep the frequency decay mechanism intact (0.75× multiplicative decay at capacity × 16 intervals).

## Rationale

Cycle 0007 v003 demonstrated that hybrid frequency-recency scoring improved hit-rate (0.7098 vs 0.665 baseline) but was tested only on the baseline without the decay mechanism. The cross-cycle insight explicitly identifies this as the top-priority unexplored dimension: "Does v003's frequency-recency hybrid scoring perform when combined with the 0.75× decay mechanism and two-pass LRU tie-breaking?" This hypothesis directly tests whether hybrid scoring delivers additive gains when layered into the proven decay-based eviction stack, or whether decay already captures the frequency-recency benefit.

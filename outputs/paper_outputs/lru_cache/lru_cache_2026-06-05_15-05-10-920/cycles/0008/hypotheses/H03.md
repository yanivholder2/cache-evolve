# H03

Test hybrid frequency-recency scoring with reduced frequency weighting to determine if the coefficient needs adjustment when decay is active.

## Parent

cycle/0007/v001

## Changes

The parent variant uses hybrid eviction scoring with a fixed coefficient of 100 multiplying the frequency value. Cycle 0007 v003's hybrid scoring formula was tuned on the baseline without decay; the 100× weight may be over-weighted for frequency when decay is active, giving recency insufficient influence in victim selection decisions.

Replace the hybrid scoring formula (from H01's proposed implementation) with a lower frequency coefficient:

1. For each node in the cache, compute an eviction score combining frequency value and recency position with adjusted weighting
2. Score formula: `score = (frequency × 25) + position_from_head` where position increases from 0 (head/oldest) toward tail
3. Select and evict the node with the minimum score

Implementation (modified victim selection loop):

```rust
let mut victim_idx = self.head.expect("non-empty list has a head");
let mut victim_score = (self.nodes[victim_idx].freq as u32 * 25) + 0;

let mut position = 1u32;
let mut current = self.nodes[victim_idx].next;
while let Some(idx) = current {
    let score = (self.nodes[idx].freq as u32 * 25) + position;
    if score < victim_score {
        victim_score = score;
        victim_idx = idx;
    }
    position += 1;
    current = self.nodes[idx].next;
}
```

Keep the frequency decay mechanism intact (0.75× multiplicative decay at capacity × 16 intervals) and maintain the two-pass LRU structural pattern.

## Rationale

Cycle 0007 v003 achieved 0.7098 hit-rate on baseline using the hybrid formula (freq × 100 + position). The 100× coefficient was optimized for baseline eviction without decay's frequency normalization effect. When periodic decay is active, frequency values are compressed more frequently, potentially making the 100× multiplier too aggressive and suppressing recency's influence below optimal. By reducing the frequency weight to 25×, recency position gains proportional influence in victim selection: an item one position newer has eviction value equivalent to a frequency difference of 25. This tests parameter sensitivity for the hybrid approach and explores whether the coefficient requires recalibration for the decay-active environment, supporting coefficient optimization if H01 shows hybrid scoring has measurable promise.

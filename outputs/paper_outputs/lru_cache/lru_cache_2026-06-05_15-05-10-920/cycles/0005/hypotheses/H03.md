# H03

Replace linear multiplicative decay with exponential decay to create a smoother forgetting curve that may better preserve mid-range frequency items across phase transitions.

## Parent

cycle/0004/v003

## Changes

Modify the frequency decay in `check_and_perform_frequency_reset()` to use an exponential decay pattern instead of the linear multiplicative approach. Replace:

```
node.freq = (node.freq as u16 * 3 / 4) as u8;
```

With exponential decay using a decay constant α ≈ 0.32 to achieve a similar long-term rate of forgetting but with a non-linear curve:

```
node.freq = ((node.freq as f32 * (-0.32_f32).exp()).ceil() as u8).max(0);
```

Or, using integer-only arithmetic to avoid floating-point:

```
let decayed = (node.freq as u32 * 74) / 100;  // Approximate e^(-0.32) ≈ 0.725
node.freq = decayed as u8;
```

The decay interval remains `capacity * 16`. This hypothesis tests whether an exponential decay pattern—which forgives high-frequency items more than low-frequency ones—better preserves the relative ordering of access frequencies across reset cycles compared to the uniform multiplicative scaling.

## Rationale (optional)

The Cycle 0004 insights explicitly recommend exploring "different decay patterns (e.g., exponential curves, piecewise linear decay)" to test whether the multiplicative 0.75× approach is optimal or if a non-linear decay shape could capture further gains. Exponential decay naturally decelerates the rate of forgetting (high-frequency items decay by a smaller absolute amount than low-frequency items), potentially maintaining better discrimination of truly hot items through phase transitions. This represents an orthogonal dimension of exploration from the coefficient sensitivity tests (H01, H02).

# H02

Decrease multiplicative decay coefficient to 0.7× to accelerate forgetting of ancient hotspots and improve adaptation to workload phase shifts.

## Parent

cycle/0004/v003

## Changes

Modify the frequency decay in `check_and_perform_frequency_reset()` to use a 0.7× (7/10) multiplicative coefficient instead of the current 0.75× (3/4). This means each node's frequency will be scaled by multiplying by 7 and dividing by 10:

```
node.freq = (node.freq as u16 * 7 / 10) as u8;
```

Replace the line:
```
node.freq = (node.freq as u16 * 3 / 4) as u8;
```

The decay interval remains `capacity * 16`. The hypothesis tests whether slightly more aggressive multiplicative decay—by lowering the decay coefficient from 0.75× toward 0.5×—accelerates the forgetting of ancient hotspots while still maintaining relative frequency discrimination. This explores the opposite sensitivity direction from H01.

## Rationale (optional)

Cycle 0004 demonstrated that multiplicative decay is superior to right-shift decay because it provides a better balance between forgetting and discrimination. Testing 0.7× (between 0.75× and the previous 0.5× right-shift baseline) explores whether more rapid convergence to new access patterns—via faster decay of old frequencies—could improve hit-rate on this trace where phase shifts may occur but are not abrupt.

# H03

Introduce frequency-recency hybrid eviction scoring that combines frequency value with recency position to make victim selection more sensitive to both access patterns simultaneously, raising hit-rate through finer discrimination at eviction time.

## Parent

baseline

## Changes

The baseline uses a single-pass scan to find and evict the item with the minimum frequency, with no explicit consideration of recency ordering during victim selection (though LRU ordering is preserved via list manipulation).

Replace the eviction logic in the `put()` method with a hybrid scoring approach:

1. For each node in the cache, compute an eviction score combining frequency and recency position
2. Select and evict the node with the minimum score
3. Score formula: `score = (frequency_value × 100) + position_from_head`

Implementation (replace the current eviction scan around line 95 in baseline):

```rust
let mut victim_idx = self.head.unwrap();
let mut victim_score = (self.nodes[victim_idx].freq as u32 * 100) + 0;

let mut position = 1u32;
let mut current = self.nodes[victim_idx].next;
while let Some(idx) = current {
    let score = (self.nodes[idx].freq as u32 * 100) + position;
    if score < victim_score {
        victim_score = score;
        victim_idx = idx;
    }
    position += 1;
    current = self.nodes[idx].next;
}
```

Keep all other logic intact, including frequency increment on access and MRU promotion behavior.

## Rationale

Cycle 0006's cycle-insight explicitly identifies "frequency-recency hybrids" as an unexplored tie-breaking lever for equal-frequency items. The hybrid scoring approach extends this concept: instead of only considering minimum frequency, compute a combined metric where frequency dominates (×100 multiplier) but recency position provides secondary discrimination. This gives the algorithm fine-grained control over which items are evicted when access patterns create clusters of similar frequencies, potentially capturing temporal locality better than frequency alone while preserving the frequency-primary eviction strategy.

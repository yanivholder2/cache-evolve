# H01

Combine the incumbent's frequency-decay mechanism with two-pass LRU tie-breaking to refine victim selection precision while preserving proven decay tuning, raising hit-rate by ensuring oldest items are evicted at equal frequencies.

## Parent

cycle/0004/v003

## Changes

The parent variant v003 uses a one-pass scan to find the minimum frequency and selects the first victim encountered during that scan. This scan-order bias can cause newer items to be selected when older items share the same minimum frequency.

Replace the one-pass victim selection in the `put()` method's eviction logic with a two-pass scan:

1. First pass: find the minimum frequency across all nodes (unchanged from parent)
2. Second pass: scan from head (oldest) to tail (newest) and select the first item with that minimum frequency

Specifically, replace the eviction loop (lines 91-102 in the parent) with:

```rust
let min_freq = self.nodes.iter().map(|n| n.freq).min().unwrap_or(0);

let mut victim_idx = self.head.expect("non-empty list has a head");
let mut current = self.head;
while let Some(idx) = current {
    if self.nodes[idx].freq == min_freq {
        victim_idx = idx;
        break;
    }
    current = self.nodes[idx].next;
}
```

Keep all other logic intact, including the frequency-reset mechanism (0.75× multiplicative decay at capacity × 16 intervals) and the MRU promotion behavior on access.

## Rationale

Cycle 0006 demonstrated that the two-pass LRU approach (v002) captures temporal locality within equal-frequency groups more accurately than scan-order bias. However, v002 was tested on the baseline (no decay), which regressed to 0.7255. The incumbent (v003) with its 0.7334 hit-rate has proven frequency-decay mechanics. Combining the two-pass tie-breaking refinement with the decay mechanism should preserve the decay's frequency discrimination while sharpening eviction precision within equal-frequency tiers, potentially yielding additive gains.

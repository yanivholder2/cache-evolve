# H01

Bound eviction search to the first N nodes to prevent pathological O(N) scans on high-frequency clusters, reducing put p99 latency.

## Parent

cycle/0001/v002

## Changes

Modify `find_evictable_node()` to scan at most `min(capacity / 4, 256)` nodes from the head (LRU end) instead of the entire list. Return the first node encountered with `freq <= 1`; if none is found within the search window, fall back to evicting the LRU node in that window even if its frequency is higher. This bounds worst-case eviction time and directly addresses the put p99 spike observed when most cached items accumulate high frequency during steady-state operation. Preserve the frequency decay mechanism and hit-rate benefits of V002; only change the scanning strategy's depth.

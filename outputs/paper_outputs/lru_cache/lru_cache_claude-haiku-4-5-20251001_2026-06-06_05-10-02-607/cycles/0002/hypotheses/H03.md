# H03

Apply frequency-selective eviction only to the main zone while preserving V001's structural partitioning to combine hit-rate gains with latency robustness.

## Parent

cycle/0001/v001

## Changes

Extend the zone partitioning from V001 (30% hot, 70% main) by adding a `freq: u32` field to Node and tracking frequency only for items in the main zone. Modify main-zone eviction to prefer items with `freq <= 1` (using a bounded scan of at most the first 20 nodes in main-zone order), falling back to LRU if no low-frequency candidate is found. Keep hot-zone items frequency-unaware and evict them only if main zone is empty, preserving zone structure's latency benefits. This hybrid approach gives V001's structural simplicity and put latency robustness while adding selective eviction intelligence to the larger main zone, targeting both hit rate and per-op-time (put) simultaneously.

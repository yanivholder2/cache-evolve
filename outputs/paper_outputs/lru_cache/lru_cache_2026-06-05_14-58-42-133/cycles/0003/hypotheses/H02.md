# H02

Adding a small LRU admission window in front of the SLRU (W-TinyLFU layout) raises hit-rate by giving bursty/short-reuse keys a recency buffer before the frequency gate judges them.

## Parent

cycle/0002/v002

## Changes

Restructure v002 from a two-segment (probationary/protected) SLRU into the
Caffeine-style W-TinyLFU three-region layout, reusing the existing count-min
sketch unchanged. Add a third intrusive list — the *window* — sized at
`window_cap = (capacity / 100).max(1)` (~1% of capacity), with the remaining
`main_cap = capacity - window_cap` split into protected (`(main_cap * 4) / 5`)
and probationary as today. Give `Node` a region tag (`Window` / `Probationary` /
`Protected`) replacing the bare `protected: bool`, and add `window_head/
window_tail/window_len` endpoints. New keys (the arena-full and arena-has-room
branches of `put()`) now land at the window MRU tail, NOT probationary. On a get
hit in the window, move the node to the window MRU tail (pure LRU, no promotion).
When the window exceeds `window_cap`, its LRU "victim" is a *candidate* for the
main region: compare `estimate(candidate_key)` against `estimate(main_probationary
_LRU_key)`; if the candidate out-ranks (>=) the main victim, move the candidate
into the main probationary MRU tail and evict the main probationary-LRU from the
arena, otherwise evict the candidate itself from the arena. Promotion from main
probationary→protected stays the existing second-touch rule. Keep `bump()` on
every access and the periodic halving exactly as v002 has them. Invariants:
`window_len <= window_cap`, `prot_len <= prot_cap`, total residents `<= capacity`,
eviction never removes a window node while the main region is over budget, and
the JNI/public surface (`try_new/new/get/put`) is unchanged.

## Rationale (optional)

v002's bare TinyLFU admission can reject a key that is genuinely about to be
reused before the sketch has warmed to it. A short recency window is exactly the
fix W-TinyLFU adds over plain TinyLFU, and it attacks a different failure mode
than H01's promotion gate — making the two cohort-distinct.

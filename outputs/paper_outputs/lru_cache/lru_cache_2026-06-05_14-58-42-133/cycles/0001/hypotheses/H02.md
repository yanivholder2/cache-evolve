# H02

Add a ghost queue of recently-evicted keys (2Q) so that returning items are admitted straight to the hot main queue, raising hit-rate on reuse-distance-heavy traces.

## Parent

baseline

## Changes

Implement the full 2Q policy over the existing arena. Partition residents into
two resident lists plus one value-less ghost list:
- `A1in`: a FIFO queue for first-time keys, sized `kin = capacity / 4`.
- `Am`: an LRU queue for proven keys, holding the remaining capacity.
- `A1out`: a bounded FIFO of **ghost keys only** (no values), sized
  `kout = capacity / 2`, stored in a separate `HashMap<K, ()>` plus a small
  ring/`VecDeque<K>` for FIFO eviction. Ghosts occupy **no** arena slot.

Add a per-node `in_am: bool` flag and second head/tail pair so `A1in` and `Am`
are distinct intrusive lists sharing the arena and splice helpers
(`unlink`/`push_back` generalised per segment).

Behaviour:
- `get(key)`: if resident in `A1in`, return the value **without** moving it
  (2Q leaves A1in in FIFO order). If resident in `Am`, promote to `Am` MRU tail.
  On miss return `None` (ghosts are not resident and must read `None`).
- `put(key, value)` (called on miss): if `key` is in `A1out`, remove it from the
  ghost set and insert into `Am` MRU tail with `in_am = true`. Otherwise insert
  into `A1in` MRU tail with `in_am = false`.
- Eviction when the arena is full: if `A1in.len() > kin`, evict the `A1in` head
  (FIFO) and record its key into `A1out` (evicting the oldest ghost if
  `A1out.len() >= kout`); otherwise evict the `Am` head (LRU) and drop it without
  ghosting. Reuse the freed arena slot in place as the baseline does.

Preserve invariants: ghosts carry no value and never appear resident, so
`map.len()` (resident keys) stays `<= capacity`, value fidelity holds for all
residents, and no never-put key becomes resident.

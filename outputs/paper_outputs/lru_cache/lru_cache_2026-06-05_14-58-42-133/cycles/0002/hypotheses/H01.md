# H01

Add a value-less ghost queue of keys evicted from the probationary segment and readmit a returning ghost key directly into the protected segment to raise hit-rate on reuse-distance-heavy traffic.

## Parent

cycle/0001/v001

## Changes

Extend the SLRU in `LruCache` with a bounded "ghost" directory that
remembers keys recently evicted from the **probationary** segment but
stores no value and consumes no arena slot. Concretely:

- Add two fields: `ghost: HashMap<K, ()>` (or a `HashSet<K>`) plus a
  FIFO ordering structure (e.g. `ghost_order: std::collections::VecDeque<K>`)
  bounded to `ghost_cap = capacity` entries. Initialise both in
  `try_new`.
- In `put`, in the arena-full branch where the probationary-LRU victim
  is chosen and removed (the `victim`/`evicted_key` logic around lines
  98–116 of the parent), after `self.map.remove(&evicted_key)` and only
  when the victim was **not** protected, record `evicted_key` into the
  ghost queue: push to `ghost_order`, insert into `ghost`, and if
  `ghost_order.len() > ghost_cap` pop the front key and remove it from
  `ghost`. Do not record protected victims.
- At the top of `put` for a genuinely new key (the path that allocates
  or reuses a slot — i.e. the key is absent from `self.map`), check
  `self.ghost`. If the incoming key is present in the ghost directory,
  remove it from `ghost`/`ghost_order` and insert the new node directly
  into the **protected** segment (set `protected = true`, `push_back`,
  `prot_len += 1`, and run the existing `demote_one` overflow check)
  instead of landing it in probationary. Otherwise keep the current
  probationary-insert behaviour.

Preserve all existing invariants: arena slot reuse in place, the
`prot_len <= prot_cap` cap enforced via `demote_one`, eviction still
prefers the probationary-LRU and falls back to protected only when
probationary is empty, and `map.len() <= capacity`. The ghost directory
must never hold a key that is currently resident in `map`.

## Rationale (optional)

v001 confines one-hit-wonders to probationary but discards the signal
that an evicted key later returns. v002 showed a ghost (A1out) readmission
captures exactly those returning keys; layering it onto the proven SLRU
base should compound the scan-resistance gain.

# H02

Replace 8-bit precise frequency counters with 3-bit quantized frequency buckets to reduce counter noise and sharpen hot-item discrimination by mapping the full frequency range into distinct access-intensity tiers.

## Parent

cycle/0007/v001

## Changes

The parent variant tracks per-node frequency using 8-bit counters (0–255 range) with periodic 0.75× decay. This fine-grained precision may introduce noise: small frequency differences have little eviction impact, while the 0.75× decay compresses all values into a narrow range anyway during operation.

Replace the `freq: u8` field with `freq_bucket: u8` (representing a 3-bit bucket index 0–7) and modify frequency update logic:

1. Define a quantization function that maps frequency increments into discrete buckets:
   ```rust
   fn quantize_frequency(current_bucket: u8) -> u8 {
       // Buckets: 0 (0 accesses), 1 (1 access), 2 (2-3 accesses), 3 (4-7 accesses),
       // 4 (8-15 accesses), 5 (16-31 accesses), 6 (32-63 accesses), 7 (64+ accesses)
       (current_bucket + 1).min(7)
   }
   ```

2. In `get()`, update frequency with: `self.nodes[idx].freq_bucket = quantize_frequency(self.nodes[idx].freq_bucket);`

3. In eviction logic, find minimum `freq_bucket` instead of `freq`, breaking ties by recency (head-most position within the same bucket)

4. During periodic decay (capacity × 16 intervals), decay buckets using: `bucket = (bucket * 3 / 4).max(0)` (bucket-aware decay)

This reduces per-counter memory overhead and focuses discrimination on coarse-grained access intensity (rarely vs. frequently accessed) rather than exact frequency values that decay makes irrelevant.

## Rationale

The 0.75× multiplicative decay compresses precise frequencies into narrow ranges, making fine-grained counter precision wasteful; many distinct frequency values map to the same eviction behavior after decay. Cycle 0004's finding that counter saturation capping had neutral impact suggests the workload doesn't benefit from high precision. Quantization explicitly trades fine-grained precision for clarity of hot-set identification, potentially reducing eviction-time decision noise while maintaining the frequency-based protection strategy.

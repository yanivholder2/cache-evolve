# H03

Placing a small LRU admission window in front of the 90/10 SLRU, so new keys must earn a hit in the window before entering the main cache, adds scan resistance that filters one-hit-wonders and raises hit-rate.

## Parent

cycle/0003/v001

## Changes

Introduce a W-TinyLFU-style admission window ahead of the existing SLRU,
a fundamentally different lever from the protected/probationary ratio.
Partition `capacity` into `window_cap` and `main_cap` with
`window_cap + main_cap == capacity`; set `window_cap = capacity / 64`
(about 32 slots at `capacity == 2048`, flooring to 0 for tiny capacities
so the policy degrades gracefully to plain SLRU). Apply the existing 90%
protected split to `main_cap` (not `capacity`).

Add a third arena-backed LRU list for the window with its own
`win_head`/`win_tail`/`win_len`, sharing the same `nodes` arena and `map`
(tag each node with which region it occupies, extending the existing
`protected` flag into a small region enum or a second bool).

- `put` of a brand-new key: insert at the window MRU end. If the window
  is over `window_cap`, evict the window LRU **entirely** (drop it from
  `map` and reuse its slot) — this is the scan-resistance: a burst of
  never-reused keys dies in the small window without ever displacing a
  protected key in main.
- `get`/`put` hit on a key currently in the window: this is its second
  touch, so promote it out of the window into the **main probationary**
  MRU end (then the normal SLRU promotion-on-next-hit applies). If main
  is full, evict main's probationary LRU first, exactly as the parent's
  eviction path does today.
- `get`/`put` hit on a key already in main: unchanged parent SLRU
  behaviour (promote to protected MRU, `enforce_protected_budget`).

Preserve: `win_len + prob_len + prot_len == map.len()`,
`map.len() <= capacity`, a victim always exists when the arena is full,
and in-place slot reuse with no free list. Update the existing
debug_assert on segment lengths to include `win_len`.

## Rationale (optional)

Promotion and ratio are near-tuned; the cross-cycle open question asks
whether an untapped non-recency signal remains. A front admission window
is the canonical scan-resistance mechanism and is structurally
orthogonal to ratio tuning — it attacks one-hit-wonder pollution before
the SLRU machinery ever sees those keys, rather than re-ordering eviction
after the fact (which prior cycles found near-inert).

# H01

Giving a demoted-from-protected key one bounded second chance in probationary before eviction raises hit-rate by rescuing the warm band without ghost metadata.

## Parent

cycle/0005/v003

## Changes

Stay entirely within the parent's converged 95/5 SLRU geometry, single-hit
promotion, and capacity bound — change only the probationary eviction *order*,
which is the one lever every durable gain has come from.

Add a `reprieve: bool` field to `Node` (default `false`). In
`enforce_protected_budget`, when a protected-LRU node is demoted, keep placing
it at the probationary MRU end (the `cycle/0004/v001` `push_back_probationary`
position, NOT the `push_front_probationary` next-victim position the parent
`cycle/0005/v003` uses), and set its `reprieve = true`. This marks a key that
was already proven hot (it earned protection at least once) but has now aged out.

Change the probationary victim selection in `put`'s eviction branch: instead of
unconditionally evicting `prob_head`, inspect it first. If `prob_head` is a
reprieved node *and* there is at least one non-reprieved probationary node
(track this with a `prob_reprieved_len` counter so the check is O(1): the guard
is `prob_reprieved_len < prob_len`), clear its `reprieve` flag, move it to the
probationary MRU end via `push_back_probationary`, and re-take `prob_head` as
the victim. Otherwise evict `prob_head` as today. A node's reprieve is consumed
the first time it reaches the head, so each demoted key gets at most one extra
probationary lap, and the reprieve is never honored when it would leave zero
fresh one-hit-wonders to drain.

Reset `reprieve = false` whenever a node is (re-)promoted to protected or its
slot is reused for a new key. Update `prob_reprieved_len` on every probationary
insert/unlink/flag-clear and assert `prob_reprieved_len <= prob_len`. Preserve
all existing `debug_assert`s on `prob_len + prot_len == map.len()` and the
capacity bound; no slot is added or freed.

## Rationale (optional)

The proven binding constraint is the probationary drain floor for one-hit-wonders.
A reprieve that is (a) limited to a single lap and (b) suppressed whenever it
would starve that floor spends almost none of the floor while still letting a
recently-demoted hot key get re-promoted on a fast second touch — targeting the
exact warm-but-evicted band that ghost variants found too thin to rescue
economically, but doing it in residency instead of metadata.

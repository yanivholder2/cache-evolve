# H03

Requiring two probationary hits (not one) before promoting a key to the protected segment raises hit-rate by reserving the protected tier for genuinely hot keys and keeping it purer.

## Parent

cycle/0001/v001

## Changes

Raise the promotion threshold in the SLRU parent from one access to two by adding a per-node access counter.

1. Add a field `hits: u8` to `Node`, initialized to `0` for every new node created in `put`'s allocate branch and reset to `0` whenever a slot is reused for a new key in the eviction branch.
2. Introduce a constant promotion threshold `const PROMOTE_AT: u8 = 2;` (the number of hits in probation required before promotion).
3. Change the on-access logic shared by `get` and the update-existing branch of `put`. Replace the unconditional `self.unlink(idx); self.push_back_protected(idx); self.enforce_protected_budget();` with this gating:
   - If `self.nodes[idx].protected` is already true: refresh by `unlink` then `push_back_protected` (move to protected MRU); leave `hits` as is.
   - Else (node is probationary): increment `self.nodes[idx].hits`. If `hits >= PROMOTE_AT`, `unlink`, `push_back_protected`, then `enforce_protected_budget()`. Otherwise `unlink` then `push_back_probationary` (refresh to probationary MRU so it survives a bit longer but stays unprotected).
4. Ensure `push_back_protected`/`push_back_probationary` continue to set the `protected` flag correctly (they already do). A node demoted by `enforce_protected_budget` re-enters probationary; leave its `hits` counter unchanged so it can re-promote on its next hit.

Preserve all parent invariants: `prob_len + prot_len == map.len()`, `map.len() <= capacity`, probationary-first eviction order, and the 80/20 segment split.

## Rationale (optional)

v001 promotes on the very first hit, so any key touched twice total occupies the large protected tier. On a reuse-heavy trace this may admit transient keys that crowd out the hottest ones. Gating promotion on a second probationary hit tests whether a stricter protection signal — orthogonal to the segment ratio probed in H01 — yields a purer, higher-hit protected set.

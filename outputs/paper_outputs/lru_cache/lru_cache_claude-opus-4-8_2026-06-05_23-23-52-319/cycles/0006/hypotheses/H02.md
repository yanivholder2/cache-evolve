# H02

Re-admitting a non-resident-HIR reuse into the weak HIR-resident tier instead of promoting it straight to LIR stops stale re-admits from demoting hot LIR residents and raises hit-rate.

## Parent

cycle/0005/v002

## Changes

In `insert_reuse`, when a `HirNonResident` block is referenced again the
LIRS rebuild currently promotes it directly into the LIR set:

```rust
if self.l_lir > 0 {
    self.s_move_top(idx);
    self.nodes[idx].status = Status::Lir;
    self.lir_count += 1;
    self.enforce_lir_budget();   // demotes the bottom LIR block
} else { ... HirResident ... }
```

Because the LIR set is essentially always full on this trace, every such
re-admission immediately demotes the bottom LIR block — i.e. a single
post-eviction reuse evicts a genuinely-hot LIR resident from protection.
That is exactly the failure mode the cross-cycle record documents:
routing re-admitted/ghost hits straight into the hot tier regressed
(cycle 2 H02), while routing them to the weak/probationary tier recovered
the signal (cycle 3 v003).

Apply that lesson inside LIRS: re-admit a non-resident-HIR hit as
`HirResident` (the weak tier), never straight to LIR. Replace the
`l_lir > 0` LIR-promotion branch in `insert_reuse` so that, regardless of
LIR budget, the re-admitted block becomes resident-HIR at the MRU end of
both S and Q:

```rust
self.nodes[idx].status = Status::HirResident;
self.s_move_top(idx);
self.q_move_back(idx);
```

Do not increment `lir_count` and do not call `enforce_lir_budget` on this
path (no LIR block was added). Keep the `nr_unlink`, the `value = Some(..)`
restore, the `nonresident_count -= 1` / `resident_count += 1` updates, and
the trailing `if self.resident_count > self.capacity { self.evict_one(); }`
exactly as they are. The block can still earn LIR status later through the
normal `touch_resident` HIR-to-LIR promotion on its next hit, so genuine
low-IRR reuse is still captured — just one access later, via the weak
tier, rather than by instantly displacing a hot resident.

## Rationale (optional)

This keeps LIRS's recency classification but changes only where a
re-admitted block lands, directly transplanting the proven ghost-placement
lesson from the SLRU line onto the LIRS line.

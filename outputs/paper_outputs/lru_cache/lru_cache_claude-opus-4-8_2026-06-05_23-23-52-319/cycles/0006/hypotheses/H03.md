# H03

Pushing the SLRU protected ratio from 95/5 to 97/3 settles whether the protected-residency lever has a final sliver before the probationary floor breaks, targeting hit-rate.

## Parent

cycle/0005/v003

## Changes

The cross-cycle record lists one geometry question still formally open:
"Has the protected-ratio lever hit its ceiling at 95/5, or is there a
sliver left before the probationary floor breaks the eviction path?" Every
prior ratio step (80/20 to 90/10 to 95/5) beat its parent with a shrinking
margin, and 95/5 was the last measured win — but the interval between 95/5
and the floor where probationary can no longer host the eviction path has
never been probed. This hypothesis resolves that question definitively in
one direction: either a sliver remains or 95/5 is confirmed as the ceiling.

In `try_new`, change the protected budget from 95% to 97% of capacity:

```rust
// was: let protected_cap = (capacity * 19) / 20;   // 95%
let protected_cap = (capacity * 97) / 100;          // 97%
```

At capacity 2048 this leaves a ~61-slot probationary segment (down from
~102). Keep the probationary budget as `capacity - protected_cap` so the
two segments still sum to exactly `capacity`, preserving the P1 capacity
bound. Change nothing else: new keys still enter at the probationary MRU
end, hits/updates still promote to the protected MRU end, eviction still
takes the probationary LRU first and falls back to the protected LRU only
when probationary is empty, and `enforce_protected_budget` still demotes
the protected LRU to the probationary front (v003's placement). The single
edit is the `protected_cap` formula (and its log line).

The eviction path requires a non-empty victim segment; verify the
probationary segment stays non-empty in steady state at this ratio (it
does for capacity 2048, where 3% is ~61 slots), so the
`prob_head`-then-`prot_head` victim selection is unaffected.

## Rationale (optional)

This is the cleanest test of the one remaining geometry open question and
cites the proven 95/5 incumbent directly. If it wins, the ceiling is not
yet reached; if it regresses or is inert, 95/5 is confirmed as the
converged optimum and the geometry axis can be closed for good.

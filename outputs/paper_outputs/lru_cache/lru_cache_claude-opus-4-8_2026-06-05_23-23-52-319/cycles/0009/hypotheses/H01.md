# H01

Add a bounded ghost list to the 95/5 SLRU incumbent that re-admits post-eviction-reuse keys at the protected segment's MRU (warmest) end to raise hit-rate.

## Parent

cycle/0004/v001

## Changes

Extend the SLRU incumbent in `src/lru_cache/mod.rs` with a key-only ghost
list tracking keys recently evicted from the probationary segment. When a
probationary key is chosen as the eviction victim in `put` (the
`prob_head` branch), instead of dropping its key entirely, record it in a
bounded ghost structure (a `HashMap<K, ()>` plus an arena-backed LRU list,
capped at `capacity` entries, reusing slots in place and dropping the
ghost-LRU head when full). Ghosts carry no value, so resident count and the
P1 capacity bound are unchanged.

Then, in `put`, before the normal "new key enters probationary" path, check
whether the incoming key is present in the ghost list. If it is, remove it
from the ghost list and admit the new node **directly at the protected
segment's MRU end** via `push_back_protected`, then call
`enforce_protected_budget`. A key that was evicted from probationary and
re-requested soon after has demonstrated genuine reuse, so it skips the
probationary "prove yourself" lap.

The critical distinction from prior ghost/re-admission probes — which the
cross-cycle notes record as "marginal" — is the **placement**: earlier
attempts routed re-admitted keys to the probationary segment or to the
protected-LRU (cold) end, recovering only a thin band. This hypothesis
routes them to the protected-MRU (warmest) end, giving them maximum
protection from the recency churn that the 95/5 split otherwise drains.

Preserve all existing invariants: `prob_len + prot_len == map.len()`,
in-place slot reuse for residents, the 95% `protected_cap` floor, and the
probationary-first eviction order for non-ghost misses.

## Rationale (optional)

The incumbent is a converged 95/5 optimum on every axis tried *except*
warm-end re-admission placement; isolating that one untested variable keeps
the proven skeleton intact while testing whether fast post-eviction reuse
is worth direct protection.

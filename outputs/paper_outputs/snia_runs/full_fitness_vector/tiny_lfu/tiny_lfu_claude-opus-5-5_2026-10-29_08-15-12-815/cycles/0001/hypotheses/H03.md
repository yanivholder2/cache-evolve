# H03

Replacing the eight SipHash computations per access (four in `increment`, four in `estimate`) and the SipHash-keyed `HashMap` with a single fast 64-bit mix hash per key and a flat counter array will cut get p50 per-op-time well below the baseline's 102 ns without changing hit-rate.

## Parent

baseline

## Changes

Only change hashing and memory layout. The replacement and admission semantics must stay identical to the baseline, so that hit-rate stays within noise.

- In `CountMinSketch`, replace `counts: Vec<Vec<u32>>` with one flat `Vec<u32>` of length `depth * width`, indexed as `row * width + col`.
- Add a `fn key_hash<K: Hash>(key: &K) -> u64` that hashes the key once using a cheap hasher: an FxHash-style multiply-rotate `Hasher` written inline in `mod.rs`, with no new crate dependency, because `Cargo.toml` is off-limits. Finish with a splitmix64 avalanche step.
- Derive the four row indices from that one 64-bit hash. For example, row `i` uses `((h >> (16 * i)) as usize) & (width - 1)` when `width <= 65536`. Otherwise use double hashing: `(h1 + i * h2) & (width - 1)`, with `h1` and `h2` being the low and high 32 bits of `h` and `h2` forced odd.
- Add `increment_hashed(h)` and `estimate_hashed(h)`. In `TinyLfuCache::put` at capacity, compute the incoming key's hash once and reuse it for both the increment and the estimate. Compute the victim's hash once for its estimate.
- Replace `HashMap<K, usize>` with `HashMap<K, usize, BuildHasherDefault<FastHasher>>`, using the same inline hasher. Update `HashMap::with_capacity` to `with_capacity_and_hasher`.
- Leave the sketch width formula, `SKETCH_DEPTH`, and `MAX_COUNT` unchanged, so that metadata-size and the admission decisions match the baseline as closely as possible. Hash collisions will differ, which is acceptable.

## Rationale (optional)

Every `get` currently runs SipHash four times for the sketch plus once for the map lookup. Every `put` that reaches the contest runs it about fifteen times. Hashing almost certainly dominates the ~100 ns get cost. This hypothesis targets the per-op-time dimension on its own, independent of H01 (region structure) and H02 (sketch freshness).

# H01

Making the residency layer use u32 throughout (u32 map values, u32 `RegionList` fields, and bounds-check-free node indexing) will bring the 24-byte-node line's get p50 from 58 ns back to the ~35 ns of the 40-byte-node line, lowering per-op-time while metadata stays at 24.

## Parent

cycle/0004/v002

## Changes

Change only the residency layer in `src/tiny_lfu/mod.rs`. Leave `CountMinSketch` byte-identical to the parent so any change comes from link codegen alone.

1. **Remove widen/narrow round-trips.** Today every link access goes u32 → `usize` (`prev_idx`, `next_idx`) and back (`set_prev_idx`, `set_next_idx`), with `NIL_USIZE` compares in between. Make `RegionList { head: u32, tail: u32, len: u32 }`. Make the `map` value type `u32` (`HashMap<HashedKey<K>, u32, _>`). Have `unlink`, `push_back`, `on_hit` and `evict_one` take and return `u32` indices, compared against `NIL: u32` directly. Widen to `usize` only at the point of indexing `self.nodes`. `evict_one` returns `(u32, u64)`.
2. **Remove the masked read-modify-write on `prev` in `push_back`.** Today it calls `set_region(r)` and then `set_prev_idx(tail)`, which is two dependent mask/or sequences. Replace them with one store: `n.prev = ((r as u32) << REGION_SHIFT) | tail; n.next = NIL;`. In `unlink`, write the neighbour's `prev` as `(nodes[next].prev & REGION_MASK) | prev`. Reset the unlinked node with one store, `nodes[idx].prev = (nodes[idx].prev & REGION_MASK) | NIL`, or skip the reset entirely, because `push_back` always overwrites both links.
3. **Remove bounds checks in the link paths.** In `unlink`, `push_back` and `on_hit`, index `self.nodes` through a small `#[inline(always)] fn node_mut(&mut self, i: u32) -> &mut Node<K,V>` that uses `get_unchecked_mut`. Put a `debug_assert!((i as usize) < self.nodes.len())` in front of it, plus a `// SAFETY:` comment saying indices come only from the map or from list links, which always point at live slots. Index `self.lists[r]` with `r & 3` (or keep the lists array at length 4) so that check folds away too.
4. Keep the `capacity >= NIL_USIZE` guard in `try_new`, the `Node<u64,u64> <= 24` const assert, and every existing test. Add one test that runs 10k mixed get/put ops at capacity 64. After each op it walks all three lists and checks that the lengths sum to `nodes.len()` and that every node's region tag matches the list it was found in.

## Rationale (optional)

Cycle 0004 confirmed in a same-run comparison that the u32-link slowdown lives in the residency layer, not the sketch. The diff from the 40-byte line consists only of the link types and their conversions, so this change tests the "bounds checks / mask-widen sequences" explanation directly. If the hypothesis holds, the line gets the 24-byte metadata win without paying latency for it.

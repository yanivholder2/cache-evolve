**What changed, following `## Changes`:**
- **New lookup table.** The `HashMap<HashedKey<K>, u32>` lookup is replaced by `IndexTable`, a linear-probing table of packed `u64` slots. Each slot is either empty or holds the low 32 bits of the key hash in the top half and the node index in the bottom half.
  - Size is `(capacity*2).next_power_of_two()`, minimum 8, so the table is never more than half full.
  - A key's home slot is the low hash bits masked to the table size.
- **`find`** walks forward from the home slot and stops at an empty slot. When the stored hash bits match, it compares keys directly in the node array. It skips bounds checks.
- **`insert`** stores the entry in the first empty slot.
- **`remove`** finds the slot by its exact packed value, so it needs no key compare. It then shifts later entries back to fill the gap instead of leaving markers. `len` is a counter.
- **`get`** looks the key up directly, without cloning it.
- **`put`** uses the new lookup for the update path and `insert` on the fill path. On eviction it removes the old entry, overwrites the node's key and value, then inserts the new key. The fill path no longer clones the key.
- **Removed:** `HashedKey`, `PrehashedHasher`, `PrehashedBuildHasher` and the non-test `HashMap` import.

# H01

Skipping the duplicate sketch increment on a missed-`get`→`put` of the same key while still advancing `additions` by one raises hit-rate at the small cache size without the large-size web_0 loss that cycle 0007 v003 suffered.

## Parent

cycle/0006/v001

## Changes

All edits are in `src/tiny_lfu/mod.rs`. This splits cycle 0007 v003's dedup into its two effects. The dedup stays on, and the aging clock goes back to the parent's rate.

1. Add one field to `TinyLfuCache`: `last_get_h: u64`, initialised to `0` in `try_new`.
2. `get`: keep the parent's exact shape, including the `?` early return on a miss. Do **not** rewrite it as a `match`. Add one store, `self.last_get_h = h;`, right after `let h = key_hash(key);` and before `increment_hashed`. The store happens on hits and misses alike, so `get` gets no new branch. v003's latency regression is suspected to come from its `match` that writes `self` on both arms, and this layout avoids that.
3. `CountMinSketch`: add `#[inline(always)] fn tick(&mut self)`. It does `self.additions += 1; if self.additions >= self.sample_size { self.reset(); }` and nothing else.
4. `put`: replace `self.sketch.increment_hashed(key_h);` with:
   `if key_h == self.last_get_h { self.sketch.tick(); } else { self.sketch.increment_hashed(key_h); } self.last_get_h = 0;`
   On a matched miss the counters are not bumped, but the aging clock still advances once, as it did in the parent. Clearing `last_get_h` stops a stale match from carrying over to a later `put`.
5. Leave `evict_one`, the strict `cand_freq > victim_freq` test, `window_size`, the pairwise conservative update, `reset()` and every residency path unchanged.

Invariants: the node stays at 24 bytes, and the sketch geometry is unchanged. The struct grows by 8 bytes. Every existing test must pass. Add a unit test: on an empty cache, `get(&k)` (a miss) followed by `put(k, v)` leaves `estimate_hashed(key_hash(&k)) == 1` and `additions == 2`.

## Rationale

Cycle 0007 v003 gained at the small size (hm_0 16384: 0.4846→0.4886). It lost at web_0 131072 (0.5884→0.5716), and its insight blamed two coupled side effects: a slower aging clock and the lost newcomer bonus. This variant brings back the clock alone. If web_0 at the large size recovers, aging was the cause. If it does not, the tie-break was (H02 tests that side).

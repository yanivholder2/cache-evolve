# H01

Scanning for keys from the MRU end of LRU-ordered buckets, instead of from index 0, will cut get p50 (the per-op-time summary) without changing hit rate.

## Parent

cycle/0002/v001

## Changes

Edit only `src/associative_cache/associative_cache_bucket.rs`. In the parent, `AssociativeCacheBucket` keeps items ordered from the LRU end (index 0) to the MRU end (`len-1`). Under ClassicLRU, a hit is moved to the back by `eviction_policy.get_from_position`, and BIP puts its periodic admissions at the back too. Recently used, hot keys therefore sit at the back. But the inherited trait-default `get_position` scans forward from index 0, so it reaches them last.

1. Override `get_position` in `impl Bucket for AssociativeCacheBucket`. Use a reverse scan, `self.items.iter().rposition(|it| it.key == *key)`, when `self.lip` is true. For every other policy, keep the forward `position` scan, so their behaviour is unchanged. Mark it `#[inline]`. Keys are unique within a bucket, so either scan direction returns the same index.
2. Keep everything else in the parent as it is: quarter-depth LIP insertion, `BIP_MRU_PERIOD = 32`, the `bip_tick` counter, and the `put` / `get_from_position` paths. The `put` existing-key check calls `self.get_position`, so it picks up the reverse scan automatically.
3. Do not add side arrays or any extra fields.

Invariants: the returned index must be the unique position of the key, or `None`. Eviction order and insertion positions must be unchanged, so all four hit-rate cells should match the parent exactly. If the hit-rate cells differ from the parent, the change has broken an invariant.

## Rationale (optional)

Cross-cycle insights say get p50 is set by the linear lookup, not by the reordering. Under recency ordering on skewed MSR traces, most hits land in the last few slots. Reversing the scan should shorten the average hit-scan length from about half the bucket to a few slots, at no cost to memory or policy. Misses still scan the whole bucket, so the expected effect is a lower get p50, with get p99 (mostly misses) roughly flat.

# H01

Keeping v003's two-hit stash gate but removing the per-hit counter writes in target/probing and the victim comparison at admission will cut median get per-op-time toward v002's level while keeping most of v003's hit-rate gain.

## Parent

cycle/0001/v003

## Changes

Edit `src/dash/segments/dash_segment.rs` (v003's version), function `promotion_get`:

1. Target-hit branch (`core.buckets[target_idx].get_position(key)`): delete the
   block that does `item.lfu_counter = item.lfu_counter.saturating_add(1)`. The
   `is_hottest` check, the `promote_to_probing` path and the `get_from_position`
   path stay as they are.
2. Probing-hit branch: delete the same `saturating_add(1)` block, so a probing hit
   is just `get_from_position(item_idx)`.
3. Stash-hit branch: keep the stash counter increment and the
   `count >= PROMOTE_THRESHOLD` test (`PROMOTE_THRESHOLD = 2` unchanged). Delete the
   whole `if promote && core.buckets[target_idx].is_full() { ... eviction_candidate_index() ... victim_count > count ... }`
   block. Any stash item reaching the threshold is promoted with
   `remove_at` + `lfu_counter = 0` + `promote_to_target`, as now.
4. `demote_from_normal_bucket`: keep the `lfu_counter >>= 1` lines. Once normal-tier
   counters stay at 0 they cost nothing, and leaving them in keeps the diff small.
   (The implementer may remove them instead. Behaviour is the same, because
   normal-tier items always have counter 0.)

Update or remove the test `candidate_below_full_target_victim_stays_in_stash`,
which the victim comparison no longer supports. Replace it with a test showing
that a 2-hit stash item gets into a full target and the target's LRU is demoted.
Keep all other tests. Do not touch the gate-integrity files.

## Rationale (optional)

This answers the cycle-0001 open question about where v003's median get penalty
comes from. v003's insight credits the hit-rate gain mainly to keeping one-hit
scan keys out of the normal tier, which is the stash threshold. The victim
comparison and the counters on every normal-tier hit are fixed costs on the
common path. If p50 get drops a lot and hit-rate stays near 0.396, the threshold
alone does the work. If hit-rate falls back toward 0.387, the victim comparison
was protecting the reused residents.

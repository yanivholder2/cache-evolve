# H03

Replacing the `Option<usize>` prev and next links with `u32` arena indices and a `u32::MAX` sentinel will shrink `Node<u64,u64>` from 48 to 24 bytes while keeping strict LRU order, so hit rate is unchanged.

## Parent

baseline

## Changes

Keep the exact strict-LRU policy in `src/lru_cache/mod.rs` and change only how links are represented. Do not touch the JNI file or the public API.

- In `Node`, change `prev: Option<usize>` and `next: Option<usize>` (16 bytes each) to `prev: u32` and `next: u32`. Add `const NIL: u32 = u32::MAX;`. With `K = V = u64`, the node is then 8 + 8 + 4 + 4 = 24 bytes.
- In `LruCache`, change `head` and `tail` to `u32` with `NIL` as the empty value.
- In `try_new`, return `None` with a `log::error!` if `capacity >= u32::MAX as usize`. This keeps every valid index below `NIL`. Keep the existing zero-capacity check.
- Change `map` to `HashMap<K, u32>`. Cast to `usize` only when indexing `nodes`.
- Rewrite `unlink` and `push_back` to test `== NIL` instead of matching on `Option`. The logic stays the same:
  - `unlink`: if prev is `NIL`, set `head = next`; otherwise set `nodes[prev].next = next`. Do the same for next and tail.
  - `push_back`: if tail is `NIL`, set `head = idx`.
- In `put`'s eviction branch, use `head` (non-`NIL`) as the victim, as the baseline does. Keep the `debug_assert` on head being non-`NIL` when the arena is full.
- All existing `#[cfg(test)]` unit tests in `mod.rs` must still pass unmodified, because eviction order is identical. Add one test that asserts `std::mem::size_of::<Node<u64,u64>>() == 24`.

## Rationale (optional)

The metadata-size summary is exactly `size_of::<Node<u64,u64>>()`, which is 48 bytes today. Half of that is two `Option<usize>` values, which carry discriminant padding. Indices of 32 bits are enough for any realistic capacity; the largest MSR size is 131072. This isolates metadata-size as the target with the policy unchanged, so hit rate should match the baseline exactly. Smaller nodes may also help per-op time slightly through better cache-line density.

# H03

Remove the victim's key from the stock HashMap before inserting the new key on evicting puts, so hashbrown's freed slot gets reused instead of leaving tombstones, and per-op-time (get p50 and p99) improves under steady-state churn.

## Parent

cycle/0004/v002

## Changes

Change only the eviction branch of the `Entry::Vacant` arm in `put`. The `Occupied` arm, the filling phase, `get`, `on_hit`, `unlink`, `push_back` and `Node` all stay unchanged.

1. When `self.nodes.len() == self.capacity`, call `let key = v.into_key();` to end the `VacantEntry` borrow and get the key back without hashing.
2. Pick the victim as now: the probation head, else the protected head. Swap the new key into the victim node with `let old_key = std::mem::replace(&mut node.key, key.clone());` and assign `value`. That is one clone, the same count as the parent's `v.key().clone()`. The map owns `key` and the node owns the clone.
3. Call `self.map.remove(&old_key)` **before** `self.map.insert(new_key, victim)`. The victim's bucket is then freed before the new key probes, so the same group can reuse the slot rather than leaving a DELETED marker.
4. Then `unlink(victim)`, `set_protected(false)`, `push_back(victim, false)` as before.
5. Because the map never holds `capacity + 1` entries now, pre-size it with `HashMap::with_capacity(capacity)` and update the comment. Keep the `churn_does_not_resize_map` test passing.

The evicting put now does three SipHashes (entry, remove, insert) instead of two. That is an accepted put-p50 cost. The claim is about get latency, which is the summary metric.

Invariants: eviction order must be identical, so hit rate must exactly equal 0.53785, and `Node<u64,u64>` must stay 24 bytes.

## Rationale (optional)

c6 v002's custom table showed that remove-before-insert removes the get-p99 rise the insert-before-remove order caused in c4 v002. That variant lost get p50 only because of its scalar probing. Applying the same ordering to hashbrown is the clean, policy-neutral test the c6 insight recommends: it keeps the SIMD group probing and drops the tombstone churn.

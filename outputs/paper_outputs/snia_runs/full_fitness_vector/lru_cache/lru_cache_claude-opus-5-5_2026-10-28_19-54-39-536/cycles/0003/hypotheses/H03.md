# H03

Adding a TinyLFU-style admission filter, where a compact count-min sketch rejects new keys whose estimated frequency does not exceed the probation victim's, will raise hit-rate above v003 on the MSR traces.

## Parent

cycle/0002/v003

## Changes

Base: `src/lru_cache/mod.rs` from cycle/0002/v003. Do not change the `Node` layout. `Node<u64,u64>` must stay at 24 bytes.

1. **Sketch.** Add a private `struct FreqSketch { table: Vec<u8>, mask: usize, additions: u32, reset_at: u32 }`. Make the table width `next_power_of_two(capacity)` bytes per row, with 4 rows stored in one flat `Vec<u8>` of length `4 * width`. Hash a key once with a deterministic hasher: `std::collections::hash_map::DefaultHasher::new()` with `key.hash(&mut h)`, then finish to `u64`. Derive the 4 row indices from that hash as `(h.rotate_left(16*r) ^ (h >> 32)).wrapping_mul(0x9E3779B97F4A7C15) as usize >> shift & mask`, or any equivalent independent mixing. `increment(h)` saturates each of the 4 counters at 15. `estimate(h)` returns the minimum of the 4 counters. Aging: after every increment, `additions += 1`. When `additions >= reset_at` (`reset_at = 10 * capacity`, capped to `u32`), halve every counter (`c >>= 1`) and halve `additions`.
2. **Recording.** Record frequency only on the `put` path, which in the benchmark and trace driver is the miss path. On every `put` of a new key, call `increment` for that key. Do not touch the sketch in `get`, so the get-p50 summary keeps v003's hit path. Put on an existing key also skips the sketch.
3. **Admission.** In `put`, when the arena is full and the chosen victim is the probation LRU (`prob_head != NIL`), compare `estimate(candidate)` with `estimate(victim_key)`. If the candidate's estimate is `<=` the victim's, reject the candidate and return without inserting. The victim stays, and the map, lists and arena are unchanged. Otherwise evict as v003 does and insert the candidate at probation MRU. If probation is empty (the victim would come from protected), or the arena is not yet full, always admit. To break ties so that keys that have never been seen can enter a cold cache, admit when both estimates are 0.
4. Invariants: rejection must leave `check_segments()` valid and `map.len()` unchanged. Add unit tests for: a one-hit scan cannot displace a key that has been put several times; the sketch halves after `reset_at` additions; and the existing random workload stays consistent.

## Rationale (optional)

SLRU only filters keys after admission. Every new key still evicts the probation LRU, even when the probation entry is the more valuable of the two. A frequency-based admission gate decides each probation eviction on history rather than recency. That is a different lever from both H01's ghost history and GCLOCK's per-node counters, which helped only hm_0 at the large size. The sketch is per-cache state, so the per-node metadata summary does not change. It also stays off `get`, so the get-p50 summary should hold near v003's 32 ns.

# H02

Adding an S3-FIFO-style probation ring to cycle 0002 v003's GCLOCK bucket raises hit-rate by giving the GCLOCK lineage the cold insertion that wins in the LRU lineage. The first quarter of the slots becomes a FIFO for new items, and only items hit during probation move into the GCLOCK main region.

## Parent

cycle/0002/v003

## Changes

Edit only `src/associative_cache/associative_cache_bucket.rs`, starting from
cycle/0002/v003 (in-place GCLOCK, `GCLOCK_MAX = 3`, `hand` field,
`lfu_counter` as the reference counter). No ghost ring: cycle 0003 showed
ghost admission did nothing at bucket-local sizing.

1. **Layout.** One `Vec` is kept so that `get_items` / `get_position` still
   work.
   - Add `small_len: usize`, set to `max(1, max_size / 4)` in `new`. Use
     `0` when `max_size < 4`; in that case the bucket behaves exactly like
     v003.
   - Once the bucket is full, slots `[0, small_len)` are the probation FIFO
     and slots `[small_len, len)` are the GCLOCK main region.
   - Add `small_hand: usize` (in `[0, small_len)`) and keep `hand` as the main
     hand, which stays in `[small_len, len)` when the bucket is full.
2. **Hits** (`get_from_position`, `put` on an existing key): unchanged. Apply
   `gclock_bump` with no movement, in either region.
3. **Miss, bucket not full:** `push` with `lfu_counter = 0`, as in v003. During
   fill-up the first `small_len` pushes form the FIFO, and that is acceptable.
4. **Miss, bucket full**, with `p = small_hand`:
   - If `items[p].lfu_counter == 0`: the probation item was never hit.
     `std::mem::replace` it with the new item (`lfu_counter = 0`) and return it
     as evicted.
   - Otherwise the probation item was hit, so promote it. Run v003's
     decrementing sweep restricted to `[small_len, len)` (wrap from `len - 1`
     back to `small_len`) to find a main victim `m` with counter 0. Then:
     1. Move the victim out with `std::mem::replace(&mut items[m], promoted)`,
        where `promoted` is `items[p]` with `lfu_counter = 0`. The victim is
        the evicted item.
     2. Advance `hand` past `m`.
     3. Write the new item into slot `p` with `lfu_counter = 0`.
   - In both cases, advance `small_hand = (p + 1) % small_len`.

   At most one item is evicted per miss. A new item survives exactly
   `small_len` misses unless it is hit, which is the same probation depth as
   the LIP lineage's `len/4`.
5. **`eviction_candidate_index`** must predict step 4 exactly:
   - If `items[small_hand].lfu_counter == 0`, return `small_hand`.
   - Otherwise return v003's min-counter-from-hand scan restricted to the
     main region.

   If the bucket is not full or `small_len == 0`, fall back to v003's
   whole-vector scan.
6. **`evict_item` / `remove_at`:** keep v003's removal. Afterwards clamp
   `small_hand < max(small_len.min(len), 1)` and `hand` into the main region,
   or 0 if the region is empty. Region boundaries may blur after an external
   removal; that is acceptable as long as indices stay in bounds.
7. Update the file's own `clock_tests`:
   - `candidate_matches_sweep` must still pass under the new rule.
   - Add a test that a never-hit item is evicted after `small_len` misses.
   - Add a test that an item hit while in probation survives into main.

Invariants: `items.len() <= max_size`; unique keys; `lfu_counter <= GCLOCK_MAX`;
both hands in bounds; at most one eviction, returned only on a full-bucket
miss. No per-item fields are added. Measure per-op-time. A promotion costs
one main sweep, the same bound as v003.

## Rationale (optional)

In v003 a new item replaces the victim at the hand and is the *last* slot the
hand revisits, so every new item gets a full rotation of lifetime. That is
the MRU insertion that cycles 0001–0003 showed loses to cold insertion. A
small FIFO in front of GCLOCK is the CLOCK-native form of cold insertion
(S3-FIFO / 2Q). One-touch web_0 blocks drain from the FIFO without ever
touching the frequency-ranked main region. GCLOCK already scaled best to
1024-slot buckets, where the LIP lineage has stalled since 0001, so the
predicted gain is largest at 131072 on both traces. Refutation: if hit-rate
at 131072 doesn't beat v003's 0.5451 / 0.7290, cold insertion doesn't
transfer to CLOCK at this probation depth.

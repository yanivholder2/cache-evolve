# H02

Making the ghost remember each dropped key's frequency, and re-admitting a ghost hit with `lfu_counter = min(remembered + 2, 15)` instead of a flat 1, will raise hit-rate on hm_0 by making the admission bonus large enough to survive one halving and to rank returning keys by their history.

## Parent

cycle/0004/v002

## Changes

Start from cycle/0004/v002's overlay. Keep ghost size (64 slots), the linear ring and FIFO overwrite, the recording sites (only keys dropped out of the stash), topology, the tail scan, the cap and ageing, and landing positions all unchanged. Only what a ghost entry stores and the admission counter derived from it change. All edits are in `src/dash/segments/dash_segment.rs`.

1. **Packed entry.** Keep `slots: [u16; GHOST_SLOTS]`, but pack each `u16` as `(fp12 << 4) | count4`:
   - `fp12` is the top 12 bits of `hash(key)`, with 0 remapped to 1 so that a whole word of 0 still means empty.
   - `count4` is the dropped item's `lfu_counter`, clamped to 15. `LFU_COUNTER_CAP` is 15, so 4 bits are exact.
   - Rename or adjust `fingerprint()` to return the 12-bit value, and add `pack(fp, count)` and `unpack(word) -> (fp, count)` helpers.
2. **Record.** In `put_into_stash`, record `pack(fingerprint(&dropped.key), dropped.lfu_counter.min(15))` instead of the bare fingerprint.
3. **Take.** `Ghost::take(fp) -> Option<u8>` scans the ring and compares only the `fp12` part of each non-empty word. On a match it clears the slot and returns the stored count.
4. **Admission.** In `DashSegment::put`, on `Some(c)` set `item.lfu_counter = (c as usize + 2).min(LFU_COUNTER_CAP)`. On `None` the item stays at 0. Import `LFU_COUNTER_CAP` from `crate::shared::eviction_policy`. The +2 means the return counts as one re-reference, plus one extra step so that a bucket-wide halving (2→1) does not drop the key back to the level of one-touch arrivals.
5. **Tests.** Update the unit tests:
   - The existing re-put test now expects counter 2, since a freshly dropped stash item had count 0.
   - Add a test where a dropped item had `lfu_counter = 5` and is re-admitted at 7.
   - Add a test that admission is clamped at 15.
   - Add a test that pack/unpack round-trips and that a packed word is never 0.
6. **Reporting.** Note the false-positive rate: with 12-bit fingerprints and 64 slots it is about 1.6% per `put`, versus about 0.1% with 16 bits. Report this alongside hit-rate. Metadata-size and per-op-time should be unchanged from the parent: same ring, same scan, plus a shift and mask.

## Rationale (optional)

Cycle 0004's insight called the one-step bonus "fragile under ageing". A counter of 1 halves to 0 on the next stash-bucket ageing, so the returning key loses its edge. This variant changes only the strength and content of the bonus and leaves reach alone, so it pairs cleanly with H01 (reach only) to show which factor binds. Keys demoted from the protected tier with real history, then pushed out of the stash, come back ranked above keys that were touched once.

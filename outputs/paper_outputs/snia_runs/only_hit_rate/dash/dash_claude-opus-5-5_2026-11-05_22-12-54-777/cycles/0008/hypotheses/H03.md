# H03

When a ghost-hit bypass forces a cascade, send a displaced resident whose halved counter reaches 0 straight to the ghost instead of the stash, to raise hm_0 hit-rate at both sizes by keeping stash capacity for new arrivals.

## Parent

cycle/0007/v002

## Changes

In v002, a ghost-hit `promote_to_target(..., Front)` into a full target bucket
runs `demote_from_normal_bucket`. That function picks the tail-scan victim,
halves its `lfu_counter` (the cycle 0006 rule), and inserts it into the stash.
That stash insert can in turn evict a newer stash item, so one ghost hit can
cost two stash-resident keys.

1. Only on the cascade path started by a ghost-hit bypass: after halving the
   demoted victim's counter, if the result is 0, do not insert the victim into
   the stash. Record its fingerprint in the direct-mapped ghost table, using
   the same insert routine the stash-drop path uses, and drop it. If the
   halved counter is 1 or more, keep the current behaviour (insert into the
   stash).
2. Ordinary stash→target promotions and every other demotion path stay
   exactly as in v002. Pass a flag or use a separate call site so that only
   the ghost-bypass cascade uses this rule.
3. Because the victim is recorded in the ghost, it can return via a later
   ghost hit straight to target. So cold residents are not lost for good;
   they just give up their stash slot.
4. Keep everything else unchanged: window 8, ageing rules, ghost size and
   fingerprint width, counter 1 at Front for ghost hits.

Expected effect: hm_0 goes up, mostly at 16384 where stash churn from cascades
costs the most. web_0 stays flat or goes up slightly at 16384. Per-op-time
should go down on the cascade path, because a ghost write is cheaper than a
stash insert plus a possible stash eviction. Report per-op-time and
metadata-size.

## Rationale (optional)

This applies the "age only what is already judged cold" rule (c6) to placement
instead of counters. The cycle 0007 insight names cascades in a contended
target as the remaining cost of the bypass. H02 changes whether the bypass
happens; this hypothesis changes where the displaced resident goes.

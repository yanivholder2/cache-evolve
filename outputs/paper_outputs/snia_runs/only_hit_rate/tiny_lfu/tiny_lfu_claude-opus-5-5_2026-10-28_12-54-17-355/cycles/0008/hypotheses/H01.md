# H01

Pairing periodic sketch halving with single counting for miss-then-put keeps the admission bar level while adding real recency, and raises the hit-rate summary above cycle/0005/v003 (gaining hm_0 small without losing web_0 large).

## Parent

cycle/0005/v003

## Changes

Work in `src/tiny_lfu/mod.rs` and change only the sketch accounting. Leave the strict `cand_freq > victim_freq` contest, the coldest-of-4 `sampled_main_victim`, the climbers and the independent per-row hashing in `CountMinSketch::position` as they are.

1. **Single counting on miss-then-put.** Add a field `last_miss: Option<K>` to `TinyLfuCache`, initialised to `None`. In `get`, after `self.sketch.increment(key)`, set `self.last_miss = Some(key.clone())` on a miss and `self.last_miss = None` on a hit. In `put`, call `self.sketch.increment(&key)` only when `self.last_miss.as_ref() != Some(&key)`. Clear `last_miss` to `None` at the start of every `put`, after the check, so a second `put` of the same key without a `get` still counts. Each logical access is then counted once. Update-path puts (existing key) still increment unless they directly follow a miss on the same key.
2. **Periodic halving.** Add `ops_since_reset: u64` and `reset_period: u64` to `TinyLfuCache`. Set `reset_period = 10 * capacity as u64`, with a floor of 1024. Increment `ops_since_reset` once per `get`, not per sketch increment. When it reaches `reset_period`, call a new `CountMinSketch::halve(&mut self)` that does `*c >>= 1` for every counter in every row, then set `ops_since_reset` to 0.
3. Add a unit test showing that a `get` miss followed by `put` of the same key leaves `estimate == 1`. Add another showing that `halve` maps counts {1,2,3,4} to {0,1,1,2}. Keep all existing tests passing; adjust `sampled_victim_picks_coldest_of_lru_sample` only if its expected victim depends on the double count.

## Rationale

Cycle 0007 v001 showed that halving alone zeroes the cold probation tail while window candidates still get the free +2 from the double count, so post-reset contests became free admissions. Cycle 0006 v001 showed that single counting alone removes newcomers' only recency weight. Doing both together means a new key starts at 1, and so do the victims' post-halving counts, so the contest stays balanced. Halving then acts as a true recency signal and does not bias the contest toward newcomers. The cross-cycle insights name this exact pairing as the top open question.

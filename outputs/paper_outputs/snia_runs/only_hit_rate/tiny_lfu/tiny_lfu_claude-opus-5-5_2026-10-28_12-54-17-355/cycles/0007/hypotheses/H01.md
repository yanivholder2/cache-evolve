# H01

Adding periodic halving of the count-min sketch, triggered after a fixed 10×capacity `get` calls, to the coldest-of-4 SLRU lineage will raise hit-rate on web_0 small and hm_0 small by giving recent keys a real recency weight, while keeping web_0 large within 0.001 of the parent.

## Parent

cycle/0005/v003

## Changes

Change only the frequency sketch's aging. Leave the window and protected climbers, the coldest-of-4 `sampled_main_victim`, the strict `>` admission in `evict_for_insert`, and the double counting on a miss followed by `put` exactly as they are.

1. Add a `reset` method to `CountMinSketch` that halves every counter in place (`*c >>= 1` across all rows). There is no counter cap: keep `MAX_COUNT = u32::MAX`.
2. Add `aging_ops: u64` and `aging_period: u64` fields to `TinyLfuCache`. In `try_new`, set `aging_period = (capacity as u64 * AGING_FACTOR).max(MIN_AGING_PERIOD)`, with new constants `AGING_FACTOR: u64 = 10` (the value Caffeine uses) and `MIN_AGING_PERIOD: u64 = 1024`.
3. Count aging time in `get` calls only, never in sketch increments, so a miss followed by `put` does not advance the clock twice. In `get`, after `self.sketch.increment(key)`, do `self.aging_ops += 1`. When `aging_ops >= aging_period`, call `self.sketch.reset()` and set `aging_ops = 0`. `put` does not touch `aging_ops`.
4. Add a unit test: build a cache of capacity 8, call `get` on one key 50 times, run enough `get` calls on other keys to pass `aging_period`, and assert that the key's estimate has dropped to at most half its peak. Keep `check_structure` and every existing test passing.

## Rationale (optional)

Two cycle 0006 variants independently found the unaged sketch to be the root cause: newcomers only win through the inflated double count, and ties only happen among cold keys. Halving was last tested in cycle 0003, before SLRU and the coldest-of-4 victim existed. This test is aging on its own. The period of 10×capacity is long (≈1.3M gets at 131072), so at the large size halving should fire rarely enough to keep web_0's frequency filter. At the small size it lets stale probation/protected residents lose their lead.

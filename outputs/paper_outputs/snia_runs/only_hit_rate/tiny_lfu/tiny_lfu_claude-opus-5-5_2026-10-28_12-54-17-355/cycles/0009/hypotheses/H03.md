# H03

Pairing single counting with periodic sketch halving that rounds up (so a resident's count of 1 never becomes 0) adds recency to the frequency filter and raises hit-rate without reopening the admission bar on web_0 large.

## Parent

cycle/0005/v003

## Changes

Change the sketch accounting and add aging, as one coupled unit; leave the window/protected climbers, SLRU, coldest-of-4 victim sampling and strict `>` admission as in cycle/0005/v003.

1. Single counting: in `put()`, remove the `self.sketch.increment(&key)` call on the new-key insertion path (both the not-full and the full branch), because the harness always calls `get()` (which already increments) before inserting a missed key. Keep the increment on the existing-key update path (`if let Some(&idx) = self.map.get(&key)`) unchanged.
2. Aging: add `ops_since_reset: u64` and `reset_period: u64` to `CountMinSketch` (or `TinyLfuCache`). `reset_period = 10 * capacity` (the standard W-TinyLFU sample size), with a floor of 1024. Increment `ops_since_reset` once per `get()` call (not per sketch increment). When it reaches `reset_period`, call a new `CountMinSketch::halve()` and reset the counter to 0.
3. `halve()` walks every counter and sets `c = (c + 1) >> 1` — ceiling halving — so 1 stays 1, 2→1, 3→2, 4→2. This is the "round in the resident's favour" rule from the cycle 0008 insight: a probation resident seen once keeps estimate 1 after a reset, so a once-seen newcomer (estimate 1 under single counting) still loses the tie under strict `>` and post-reset free admissions do not appear.
4. Zero counters stay zero. No change to `estimate()` or `position()`; keep independent per-row hashing.
5. Add a unit test that increments a key 1, 2, 3 and 5 times, calls `halve()`, and checks estimates 1, 1, 2, 3. Make sure the existing tests (in particular `eviction_prefers_hot_items` and `hot_candidate_wins_contest`, which rely on relative counts) still pass with single counting; adjust test setup by adding explicit `get()` calls only if a test was relying on the put-time increment.

## Rationale (optional)

Cycle 0007 showed aging with double counting hands newcomers a free estimate of 2 against zeroed residents; cycle 0008 showed single counting + floor halving rounds residents from 1 to 0 and reopens the bar one count lower. Ceiling halving with single counting is the combination the open questions name: newcomers and once-seen residents stay tied at 1 (victim wins), while long-stale high counts finally decay so that demoted, no-longer-hot keys stop blocking real newcomers.

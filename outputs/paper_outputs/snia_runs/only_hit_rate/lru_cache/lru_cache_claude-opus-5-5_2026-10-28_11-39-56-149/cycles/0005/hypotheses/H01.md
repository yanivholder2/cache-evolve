# H01

Lowering the hill climber's sample-period cap from 50,000 to 20,000 accesses, with the step cap unchanged, will raise hit-rate by letting the window reach its useful size sooner and track phase changes faster in both web_0 cells.

## Parent

cycle/0004/v002

## Changes

Change only one line in `LruCache::try_new` in `src/lru_cache/mod.rs`:
`let sample_period = capacity.saturating_mul(10).clamp(2_000, 50_000);`
becomes
`let sample_period = capacity.saturating_mul(10).clamp(2_000, 20_000);`.

At both test sizes (16384 and 131072), `10 * capacity` is above the cap. Both sizes therefore move from a 50,000-access period to a 20,000-access period. Each climb round then happens 2.5x as often, so the window can grow 256 entries every 20k gets instead of every 50k.

Leave everything else exactly as it is in v002:
- `step_init = min(max(1, capacity / 64), 256)`, the 2% decay, and the reset-to-`step_init` rule
- `min_win` (1% floor) and `max_win` (40%)
- the `climb()` logic, including flip-on-drop and `prev_hit_rate` starting at 0.0
- all sketch settings: width 4x capacity, `reset_at = 16 * capacity`, doorkeeper, miss-then-put dedup
- the admission duel and the grow-path `victim_est <= 1` rule

Update the header comment to say 20,000. The unit test `climber_keeps_window_in_bounds` uses capacity 1000, so its expected `sample_period` of 10,000 stays correct. Do not change that test.

Optional: add one `log::info!` line in `climb()` that reports `win_cap` and the sampled hit rate every round. That answers cycle 0004's open question about how far the window moves in each cell. It must not change behaviour.

## Rationale

Cycle 0004 could not tell whether the period cap or the step cap produced v002's gains, because both sizes hit both caps. This variant changes only the period cap. A 20k sample is still large enough to keep hit-rate noise low: at a hit rate of about 0.4, the standard error is about 0.35%. If web_0@16384 rises further, adaptation speed was the binding factor. If hm_0 drops, the shorter samples are making the climber flip direction on noise.

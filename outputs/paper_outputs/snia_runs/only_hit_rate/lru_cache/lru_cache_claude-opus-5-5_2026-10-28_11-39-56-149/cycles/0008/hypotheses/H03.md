# H03

Halving the climber's step magnitude on every direction flip at large capacity, so it overshoots less after the larger initial step, will recover hit-rate on hm_0 @ 131072 while keeping the web_0 @ 131072 gain.

## Parent

cycle/0007/v001

## Changes

v001's insight attributes the small hm_0 @ 131072 loss to overshoot. The 1024 initial step pushes the window past its best size on the scan-heavy trace, and at 2% decay per round it takes many rounds to settle again. This hypothesis keeps the large first step, which helps web_0 reach its recency set fast, and damps oscillation once the climber reverses. It is a damping rule, not another change to the step size or period, which earlier cycles have used up.

Concrete edits, all in `climb()`:

1. Add a field `damp_floor: usize` set in `try_new` as `if capacity > 32_768 { max(2, step_init / 8) } else { 0 }` (128 at 131_072). `0` means damping is disabled.
2. In `climb()`, record `let flipped = hr < self.prev_hit_rate;` before negating the step. Compute `mag` as today (×98/100, reset to `step_init` when ≤ 1). Then, if `flipped && self.damp_floor > 0`, set `mag = max(self.damp_floor, mag / 2)`. The floor keeps the magnitude above 1, so a flip never triggers the reset to `step_init`. The existing reset path still applies through ordinary decay.
3. Keep the sign logic, the clamp to `[min_win, max_win]`, the `prot_cap` rebalance and the demotion loop unchanged. For capacity ≤ 32_768 the climber must be bit-identical to the parent.
4. Leave the sketch, the doorkeeper, the duel, the protected split and `step_init` untouched.
5. Tests: the existing `climber_keeps_window_in_bounds` (capacity 1000, so damping is off) must still pass unchanged. Add a test at capacity 65_536 that drives a few sample periods of the same alternating workload and asserts that `step.unsigned_abs() >= damp_floor` after any flip and that `min_win <= win_cap <= max_win`.

Expected effect: hm_0 @ 131072 returns toward its pre-cycle-0007 value, because the window oscillates less around its best size. web_0 @ 131072 keeps most of v001's gain, because the first rounds before any flip are unchanged. Small cells should not change.

# H02

Replacing the doubly-linked LRU list with a CLOCK (second-chance) ring that only sets a reference bit on a hit will cut per-op-time for `get` and shrink `Node<u64,u64>` metadata-size from 48 to 24 bytes, with hit-rate staying close to LRU.

## Parent

baseline

## Changes

Rewrite the core of `LruCache` in `src/lru_cache/mod.rs` as a CLOCK cache while keeping the public API (`try_new`, `new`, `get`, `put`, the `framework::Cache` impl, and the `LruCache<K, V>` / `Node<K, V>` type names the JNI and the metadata binary use):

- `Node<K, V>` becomes `{ key: K, value: V, referenced: bool }`. Remove `prev`/`next`. Remove `head`/`tail` from `LruCache` and add `hand: usize`.
- `get(&mut self, key)`: look up `idx` in `map`, set `nodes[idx].referenced = true`, return `&nodes[idx].value`. Do no other pointer writes.
- `put` on an existing key: overwrite the value and set `referenced = true`.
- `put` on a new key while `nodes.len() < capacity`: push a new node with `referenced = false` and insert it into `map`.
- `put` on a new key when full: sweep. While `nodes[hand].referenced` is true, clear it and advance `hand = (hand + 1) % capacity`. Once `hand` lands on a node with `referenced == false`, remove its key from `map`, overwrite the slot with the new key/value (`referenced = false`), insert the new key into `map`, and advance `hand` once. The sweep always ends within one full revolution because it clears bits as it passes.
- Keep `map.len() <= capacity` and make sure every key in `map` points to a slot that holds that key (P1–P3).
- Update the order-specific unit tests in `mod.rs` to CLOCK semantics where needed; do not touch `tests/` or `src/test_utils/`.

## Rationale (optional)

On a baseline hit, `get` does an unlink and a push_back, writing up to four nodes that are usually scattered across the arena (cache misses). CLOCK writes one byte in the node it already touched. Dropping two `Option<usize>` fields (16 bytes each) halves the node size, and the summary metadata-size metric is that node size. CLOCK typically lands within a point or two of LRU's hit rate on block traces, so this tests the trade-off between cost and hit rate.

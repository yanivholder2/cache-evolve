# H03

Tying the climber's sample period to capacity (one capacity's worth of accesses, floored at the current 50_000) will lengthen rounds only at the large size and raise large-size hit-rate without changing small-size behaviour.

## Parent

cycle/0004/v002

## Changes

Change only the sample-period formula in `LruCache::try_new` in `src/lru_cache/mod.rs`.

- Replace `let sample_period = capacity.saturating_mul(10).clamp(2_000, 50_000);`
  with `let sample_period = capacity.clamp(50_000, 400_000);`.
  - At capacity 16_384 the period stays 50_000, so this is a controlled no-op at the small size.
  - At capacity 131_072 the period becomes 131_072 accesses (2.6x longer). One round then covers
    about one full turnover of the cache, so a resize has time to fill before it is judged.
- Keep everything else from the parent unchanged: `step_init` min(max(1, cap/64), 256), the 2%
  decay with reset, the single-drop flip rule, the 1% floor, the 40% ceiling, the sketch (4x
  width, doorkeeper, dedup, reset at 16x capacity), and both duel paths.
- `sample_accesses` and `sample_hits` are `u32`, which is enough for 400_000. Keep them as they
  are.
- Update the in-file unit test `climber_keeps_window_in_bounds`. For capacity 1000 the period is
  now 50_000, so replace `assert_eq!(cache.sample_period, 10_000)` with `50_000`. The loop runs
  `5 * sample_period` iterations, so it stays valid but takes longer. Shrinking the loop to a
  fixed `5 * 10_000` is fine as long as the bounds assertions are kept. Update the header comment
  that describes the period.

## Rationale

Cycle 0005 showed that a shorter period hurts because rounds measure half-filled resizes. It
proposed the opposite test: a period tied to capacity, meaning fill time. Both test sizes
currently share the same 50_000 cap. At 131_072 that is under half a cache turnover, so
large-size rounds are probably the noisiest relative to how long a resize takes to settle. This
variant changes the large size only, which keeps the result easy to attribute. It tests the
measurement period, while H01 tests the step magnitude and H02 tests the flip rule.

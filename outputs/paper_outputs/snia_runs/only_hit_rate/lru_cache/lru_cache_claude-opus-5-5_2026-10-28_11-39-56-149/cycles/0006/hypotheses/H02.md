# H02

Making the hill climber reverse direction only after two sample-rate drops in a row, not after a single drop, will stop noise-driven reversals of window growth and raise hit-rate, most on small-size web_0.

## Parent

cycle/0004/v002

## Changes

Change only the flip rule in `climb()` in `src/lru_cache/mod.rs`.

- Add a field `consecutive_drops: u8` to `LruCache` and set it to `0` in `try_new`.
- In `climb()`, replace
  `if hr < self.prev_hit_rate { self.step = -self.step; }`
  with:
  - if `hr < self.prev_hit_rate`, set `self.consecutive_drops += 1` (saturating). Then, if
    `self.consecutive_drops >= 2`, flip with `self.step = -self.step` and reset
    `self.consecutive_drops = 0`.
  - otherwise (hr >= prev), set `self.consecutive_drops = 0`.
- Keep the rest of `climb()` exactly as it is: the 2% magnitude decay, the reset to `step_init`
  at magnitude 1, the target clamp to `[min_win, max_win]`, `prev_hit_rate = hr`, the sample
  counter reset, and the `prot_cap` rebalance with demotion. Keep every parameter of the parent
  unchanged: `sample_period` clamp(10*cap, 2_000, 50_000), `step_init` min(max(1, cap/64), 256),
  the 40% ceiling, the 1% floor, the sketch settings, the tie-admitting duel, and the duel
  during window growth.
- The in-file unit tests should still pass, because the bounds invariants are unchanged. Add a
  small unit test that calls `climb()` with synthetic `sample_hits`/`sample_accesses` and checks
  two things: a single drop keeps the step sign, and two drops in a row flip it.

## Rationale

The cycle-0005 diagnosis is that resizes land lazily as misses fill the window, so one sample
can show a transient drop from a half-applied move. Flip-on-drop then reverses growth that would
have paid off. This hypothesis leaves the period and the step alone and tests only how sensitive
the reversal decision is. It is a different lever from H01, which changes the step magnitude.
If the result is positive, the gain should appear on small-size web_0, the climber's main
beneficiary, and hm_0 should stay flat.

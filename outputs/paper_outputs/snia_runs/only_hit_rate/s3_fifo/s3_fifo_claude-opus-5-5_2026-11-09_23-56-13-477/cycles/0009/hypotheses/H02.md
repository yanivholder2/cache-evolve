# H02

Raising cycle/0008/v001's decoupled main-victim ghost budget from `small_size` to `main_size` will lift web_0 hit-rate at the 131072 size, because hit main victims that return over a main-sized horizon go straight back to main, while the small-victim ghost's freq-0 window stays protected.

## Parent

cycle/0008/v001

## Changes

All edits are in `src/s3_fifo/mod.rs`.

1. Add `const MAIN_GHOST_BUDGET_MULT: usize = 1;` and change `main_ghost_budget()` to return `(MAIN_GHOST_BUDGET_MULT * self.main_size).max(1)` instead of `self.small_size.max(1)`.
2. In `try_new`, compute `main_ghost_budget` the same way. Size `main_ghost` as `VecDeque::with_capacity(2 * main_ghost_budget + 1)` and `index` as `HashMap::with_capacity(capacity + main_size + main_ghost_budget)`.
3. Leave everything else exactly as in the parent:
   - the small-victim `ghost` with its `main_size` bound and its `next_stamp` clock (only small→ghost inserts advance it);
   - the `main_hit` flag semantics (set on a main hit, reset when an entry enters main);
   - main-ghost returnees going straight into main with freq 0;
   - lazy deletion and the `2 * budget` compaction in `main_ghost_insert`;
   - the drop-before-`evict_main` ordering in the `Loc::MainGhost` arm of `put()`.
4. Update the in-file tests. Make `Reference::main_ghost_push` use `main_size.max(1)`. Rewrite `main_ghost_budget_evicts_oldest_main_ghost_only` for the new budget (capacity 4 → budget 3: ghost four hit main victims and check that the first is evicted while the small ghost is untouched). Adjust the re-entrancy test `main_ghost_returnee_into_full_main_with_full_main_ghost_keeps_accounting` so the main ghost is actually at budget (capacity 8 → budget 6), or pick a capacity where that holds. `assert_accounting`, `ghost_compaction_bound_holds` and the oracle test must pass.

## Rationale (optional)

web_0 at the large size has only ever moved when hit main victims were remembered (0007 v001, 0008 v001). Cycle 0008 concluded that these keys return over a horizon closer to `main_size` than to `small_size`. Because the ghost is decoupled, a larger budget cannot shrink the freq-0 recency window that hm_0 depends on, so this tests the open question directly. Metadata grows by up to `main_size` keys.

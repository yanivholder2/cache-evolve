**What changed, following H01's `## Changes`:**
1. **Lap field:** each `Entry` now has a `lap: u8`. There are three values: `LAP_FRESH = 0`, `LAP_RELAPPED = 1` and `LAP_GHOST_RETURNEE = 2`. `Entry::new` starts every entry at `LAP_FRESH`.
2. **Ghost returns:** a weak, old ghost returnee goes back into small with freq 1, as before, and is now also marked `LAP_GHOST_RETURNEE`, so it can never relap. The strong-returnee path straight into main is unchanged.
3. **`evict_small`:** it is now a `while let Some(idx) = self.small.pop_back()` loop, and each call still removes exactly one entry from small.
   - **Graduate to main** if `freq >= threshold`, or if the entry is relapped and `freq >= 1`. Freq resets to 0, and main evicts first if it is full.
   - **Relap** if main is full, `freq == 1` and the entry is fresh: lap becomes relapped, freq resets to 0, the entry goes to the front of small, and the loop continues.
   - **Ghost** otherwise. The new rule is that a relapped entry is ghosted at `freq.max(1)`, so a failed relap still goes straight back to main on a later ghost hit.
   - **Termination:** an entry can relap only once, so the loop always ends.

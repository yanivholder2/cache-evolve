# H01

Adding cycle 0005 v001's one-time small relap onto the age-gated ghost path, with a failed relap ghosted at freq 1 so it keeps its direct ghost→main return, raises hit-rate on web_0 @ 131072 while keeping v002's gains on hm_0 @ 16384.

## Parent

cycle/0005/v002

## Changes

Port the lap mechanism from cycle/0005/v001 into v002's `src/s3_fifo/mod.rs`. Change only what is needed to stop the relap from erasing the "reused once" signal.

1. Add `lap: u8` to `Entry`, initialised to `LAP_FRESH = 0` in `Entry::new`. Add the constants `LAP_RELAPPED = 1` and `LAP_GHOST_RETURNEE = 2`.
2. In `put`, on the weak/old ghost-returnee branch (the `Some(Loc::Ghost { .. })` arm that re-admits into small with `GHOST_RETURN_SMALL_FREQ`), also set `lap = LAP_GHOST_RETURNEE`, so ghost returnees never relap. Leave the strong-returnee arm (`freq >= GHOST_TO_MAIN_FREQ || age <= recent`) unchanged.
3. Rewrite `evict_small` as a `while let Some(idx) = self.small.pop_back()` loop, following v001:
   - Graduate when `freq >= threshold || (lap == LAP_RELAPPED && freq >= 1)`. Set freq to 0, re-point the index to `Main`, push to the front of main, call `evict_main` first if main is full, then return.
   - Else, if `main_full && freq == 1 && lap == LAP_FRESH`: set `lap = LAP_RELAPPED`, set `freq = 0`, push to the front of small and `continue`.
   - Else ghost the entry and return. **New rule:** the ghosted freq is `if lap == LAP_RELAPPED { freq.max(1) } else { freq }`. A relapped key that failed its extra lap was still reused once, so a later ghost hit uses the strong path straight into main, as it did before the relap existed.
4. Termination: each entry relaps at most once, so the loop ends within `small.len() + 1` iterations. Exactly one entry leaves small per call.
5. Update the linear `Reference` oracle in the tests to the same rules: a lap field, the relap branch, freq-1 ghosting for failed relaps, and the age gate. Keep `hit_miss_identical_to_linear_reference` and `ghost_compaction_bound_holds` passing. Add a unit test: a relapped key that gets no hit is ghosted with `ghost_freq_of == Some(1)`, and on `put` it goes straight to main.

Invariants to preserve: `index.len() == resident + ghost_live`, `ghost_live <= main_size`, and the capacity bound.

## Rationale

In cycle 0005, v001 (relap) scored 0.5811 on web_0 @ 131072, the best in that cell, against v002's 0.5789. v002 won hm_0 @ 16384 and hm_0 @ 131072. v001's insight attributes its flat hm_0 @ 16384 result to the relap resetting freq to 0, which sent failed relaps down the weak path when they returned from ghost. Ghosting them at freq 1 should let the two mechanisms stack.

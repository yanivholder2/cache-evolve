# H01

Porting cycle/0002/v001's policy onto an O(1) HashMap index with lazy-deleted ghost stamps will cut per-op-time well below the baseline's 227 while keeping hit-rate identical to v001.

## Parent

cycle/0002/v001

## Changes

Rewrite `src/s3_fifo/mod.rs` of cycle/0002/v001 so the data structures follow the cycle/0001/v002 refactor, and keep v001's policy exactly as it is:

- Storage: `slab: Vec<Entry<K,V>>` plus a `free: Vec<u32>` free list. `small: VecDeque<u32>` and `main: VecDeque<u32>` hold slab indices. `ghost: VecDeque<(K, u64)>` holds keys with stamps. `index: HashMap<K, Loc>` with `enum Loc { Small(u32), Main(u32), Ghost(u64) }`. Also `ghost_live: usize` and `next_stamp: u64`. Change the `S3Fifo` bounds to `K: Eq + Hash + Clone`; the `framework::Cache` impl already requires these.
- `get`: look up through `index`. Bump freq (capped at `MAX_FREQ = 3`) only for `Small` and `Main` locations. A `Ghost` location is a miss.
- `put`: if the key is resident, update its value in place. On a `Ghost(stamp)` hit, decrement `ghost_live` and leave the deque slot stale (lazy deletion). If main is full, call `evict_main`, then allocate and push the index to the main front with `Loc::Main`. Otherwise call `evict_small` if small is full, then allocate and push to the small front.
- `evict_small`: keep v001's exact rule. The threshold is `GRADUATE_FREQ_MAIN_FULL = 2` when `main.len() >= main_size`, else `GRADUATE_FREQ_MAIN_ROOM = 1`. A graduate gets `freq = 0`, runs `evict_main` first if main is full, and is relinked with `Loc::Main` (reuse the same slab slot; don't move the value). A non-graduate goes to `ghost_insert(key)` and its slab slot returns to `free`.
- `evict_main`: the same second-chance loop over indices. When the victim is found, remove it from `index` and free its slot.
- `ghost_insert`: once `ghost_live >= main_size`, pop from the back until one live entry is evicted. An entry is live if `index[key] == Ghost(stamp)` matches; skip stale ones. Compact with `retain` when `ghost.len() > 2 * main_size.max(1)`.
- Size the HashMap and slab with `with_capacity(capacity + main_size)` so they don't rehash.

Invariants to keep: resident count ≤ capacity, ghost live count ≤ `main_size`, and every hit/miss decision identical to v001's on any trace. Carry over all of v001's unit tests, and add one for the ghost compaction bound.

## Rationale (optional)

Per-op-time and metadata-size have gone unmeasured for two cycles, and the cross-cycle insights rank them as the highest-priority gap. v001 still does linear scans over small, main and ghost, plus a `retain` on every ghost hit, which costs O(capacity) per op. The 0001/v002 refactor showed the index doesn't change policy behaviour. So any hit-rate difference here signals a bug, and the experiment isolates the cost dimension. Metadata-size will probably rise because of the index and stamps; this measures by how much.

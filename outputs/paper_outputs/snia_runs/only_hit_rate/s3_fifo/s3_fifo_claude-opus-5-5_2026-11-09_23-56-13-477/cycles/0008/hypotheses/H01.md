# H01

Moving the ghosts of hit main victims into their own FIFO, with its own budget and without advancing the shared ghost stamp clock, will keep v001's large-size hit-rate gains and remove its web_0 small-size loss.

## Parent

cycle/0007/v001

## Changes

Split the ghost into two independent structures in `src/s3_fifo/mod.rs`:

- Keep the existing `ghost: VecDeque<(K, u64)>`, `ghost_live`, `next_stamp` and the `main_size` bound for **small-queue victims only**. `evict_small` keeps calling `ghost_insert(key, freq)` unchanged, so the freq-0 recency window (`next_stamp - stamp <= small_size`) again counts only small→ghost insertions. This is exactly the cycle 0005 v002 clock.
- Add a second FIFO `main_ghost: VecDeque<(K, u64)>` with its own `main_ghost_live: usize` and its own counter `main_ghost_stamp: u64`. Its budget is `MAIN_GHOST_BUDGET = max(1, small_size)`: one small-queue's worth of keys, which is a small fraction of the main ghost. Add a new `Loc` variant `Loc::MainGhost { stamp: u64 }` (stamped with `main_ghost_stamp`), or reuse `Loc::Ghost` with a 1-bit tag. Pick whichever keeps `Loc` at 16 bytes or less.
- In `evict_main`, a victim with `main_hit == true` calls a new `main_ghost_insert(key)` instead of `ghost_insert(key, GHOST_TO_MAIN_FREQ)`. It pops stale or overflow entries from `main_ghost`'s back, using its own stamp match, and lazily compacts once `main_ghost.len() > 2 * budget`. It must not touch `next_stamp`, `ghost_live` or `ghost`.
- In `put`, add a match arm for `Loc::MainGhost { .. }`. Remove the index entry, decrement `main_ghost_live`, `evict_main()` if main is full, then push the key to main's front with freq 0 and `main_hit = false`, as the strong-returnee arm does now. Keep the "remove the index entry before evicting" ordering for re-entrancy, because `evict_main` can itself insert into `main_ghost`.
- `get` must return `None` for `MainGhost`.
- Invariants: `index.len() == resident + ghost_live + main_ghost_live`; `ghost_live <= main_size`; `main_ghost_live <= budget`.
- Update the in-file `Reference` oracle so that it keeps a separate `main_ghost` list with the same budget, and so that its `ghost_push` stamps advance only for small victims. Adjust the unit tests for main-victim ghosts to assert `MainGhost`.

## Rationale (optional)

Cycle 0007 found that v001's small-size loss came from main-victim ghosts taking up the shared ghost budget and advancing the stamps. This shrank the freq-0 age window, which cycles 6 and 7 showed is a local optimum at 1×. Decoupling restores the parent's window exactly while keeping the only mechanism so far that moved web_0 at the large size. The experiment is direct: compare this variant's four cells against v001 and cycle 0005 v002.

# H03

Doubling the ghost budget from `main_size` to `2 * main_size`, with the age-gate stamp clock unchanged, will raise hit-rate by giving more long-gap returnees the freq-1 small path instead of being treated as never-seen first admissions.

## Parent

cycle/0005/v002

## Changes

In `src/s3_fifo/mod.rs`, change only the ghost capacity:

- Add `const GHOST_BUDGET_MULT: usize = 2;` and a field (or helper) `ghost_cap = (GHOST_BUDGET_MULT * main_size).max(1)`.
- In `ghost_insert`, change the live-ghost eviction check from `self.ghost_live >= self.main_size` to `self.ghost_live >= ghost_cap`. Change the lazy compaction trigger from `ghost.len() > 2 * main_size` to `ghost.len() > 2 * ghost_cap`, and size the initial `ghost` deque and `index` capacities to match.
- Do **not** change how `next_stamp` advances or how the recency window is computed (`small_size / GHOST_RECENT_AGE_DIVISOR`). The age gate measures ghost insertions, not ghost occupancy, so the quick freq-0 → main path keeps exactly the same population. Only keys whose ghost record would previously have expired gain from the change:
  - freq-0 keys go back to small with freq 1;
  - freq ≥ 1 keys go straight to main.
- Leave graduation, freq reset and main eviction as in the parent. Do not add main-victim ghosting.
- Update the `Reference` oracle's `ghost_push` bound to `2 * main_size`. Extend `ghost_compaction_bound_holds` to assert `ghost_live <= ghost_cap` and `ghost.len() <= 2 * ghost_cap`.

## Rationale (optional)

The ghost's size has never been varied in seven cycles. It is the remaining first-admission lever. Today a key that returns after more than `main_size` ghost insertions is indistinguishable from a never-seen key. A larger ghost separates "seen once long ago" from "brand new" without touching the tuned age window or the shared clock. Those are the two couplings that broke the cycle 6 and 7 ghost-path variants. The 2× ghost costs extra metadata, but metadata-size is not currently scored. If web_0 punishes late rereferences again, the result should show it cleanly in the large-size web_0 cell.

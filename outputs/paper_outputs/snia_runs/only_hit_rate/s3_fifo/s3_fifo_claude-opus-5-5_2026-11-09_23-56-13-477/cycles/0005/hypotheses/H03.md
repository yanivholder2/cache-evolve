# H03

Porting cycle-0004 v002's cost-only changes (a fast multiply-shift hasher, an 8-byte `Loc` with u32 ghost stamps, and fewer index lookups and key clones) onto v001's freq-gated ghost policy will reduce per-op-time and metadata-size with hit-rate bit-identical to v001.

## Parent

cycle/0004/v001

## Changes

Start from cycle/0004/v001's `src/s3_fifo/mod.rs` and keep its policy exactly as it is: the occupancy-gated graduation threshold, the freq reset on graduation, and `GHOST_TO_MAIN_FREQ` / `GHOST_RETURN_SMALL_FREQ` routing. Apply the mechanical changes from cycle/0004/v002's overlay:

1. **Hasher.** Copy v002's `FastHasher` (multiply-rotate `step`, the folded `finish`, and the `write_*` overrides for u8/u16/u32/u64/i32/i64/usize, plus the byte `write` fallback that tags the length) and the `FastBuild` `BuildHasher`. Change `index` to `HashMap<K, Loc, FastBuild>`, built with `HashMap::with_capacity_and_hasher(capacity + main_size, FastBuild)`.
2. **Compact `Loc`.** Change `Loc::Ghost { stamp: u64, freq: u8 }` to `Loc::Ghost { stamp: u32, freq: u8 }`, and change `next_stamp` and the ghost deque element to `(K, u32)`, incrementing `next_stamp` with `wrapping_add(1)`. Add `const _: () = assert!(std::mem::size_of::<Loc>() == 8);`. If rustc does not pack the tag, freq and u32 stamp into 8 bytes, fall back to `Ghost(u32)`, with the freq kept in the top 2 bits of the stamp (freq ≤ MAX_FREQ = 3) and masked out on comparison. Stamps are only compared for equality, and the deque holds at most `2 * main_size + 1` slots, so wrapping cannot alias a live stamp.
3. **Fewer lookups and clones.** In the strong ghost-hit branch of `put()`, follow v002: run `evict_main()` first (it removes only resident keys, so this key's ghost entry survives), `alloc(key, value)` without cloning, then re-point the existing index entry in place through `get_mut(&self.slab[idx].key)` instead of `insert(key.clone(), ..)`. Keep v001's weak-returnee branch ordering (remove the index entry *before* `evict_small()`). In `evict_small()`, read the tail's freq once into a local and reuse it. Mark `alloc` `#[inline]`.
4. Leave the tests module's `Reference` oracle unchanged: the policy is unchanged, so `hit_miss_identical_to_linear_reference` must still pass as written. Update the test helpers only where the `Loc` type changes (`ghost_freq_of`, `live_ghosts_in_deque`).

Invariants: hit/miss behaviour must match cycle/0004/v001 exactly on every trace and size. The oracle test enforces this.

## Rationale

The cross-cycle insights and the cycle-0004 continuation both ask for these cost changes to be ported onto the policy winner. The leaderboard now lists per-op-time and metadata-size, held by the baseline. This variant gives those dimensions a candidate from the winning lineage at zero hit-rate risk, so it can win on cost alone while H01 and H02 explore policy.

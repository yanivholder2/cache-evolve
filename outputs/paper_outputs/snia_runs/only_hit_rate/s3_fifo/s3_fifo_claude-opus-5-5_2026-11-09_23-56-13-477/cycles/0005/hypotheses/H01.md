# H01

Adding cycle-0004 v003's one-time small-queue relap for single-reuse tails on top of v001's freq-gated ghost path, without letting weak ghost returnees relap, will raise hit-rate at the 16384 size on both hm_0 and web_0.

## Parent

cycle/0004/v001

## Changes

Start from cycle/0004/v001's `src/s3_fifo/mod.rs`. Keep the `Loc::Ghost { stamp, freq }` freq-gated ghost path in `put()` exactly as it is.

1. Add a `lap: u8` field to `Entry`, with three values: `0` = fresh, `1` = already relapped in small, `2` = weak ghost returnee. `Entry::new` sets `lap = 0`, so slab slots reused through `alloc()` never inherit a stale value.
2. In the weak-returnee branch of `put()` (`Some(Loc::Ghost { .. })` with ghost freq < `GHOST_TO_MAIN_FREQ`), set `lap = 2` as well as `freq = GHOST_RETURN_SMALL_FREQ`. A returnee has already had its second chance through the ghost, so it must not also get a relap. It keeps v001's behaviour: it graduates with one more hit (freq reaches 2) or is ghosted again with freq 1.
3. Rewrite `evict_small()` as a loop, following cycle-0004 v003. Pop the tail and compute `threshold` from main occupancy as now. Then:
   - **Graduate** if `freq >= threshold || (lap == 1 && freq >= 1)`. Call `evict_main()` first if main is full, set freq to 0, re-point the index to `Loc::Main(idx)`, push the entry to the front of main, and return.
   - **Relap** if `main_full && freq == 1 && lap == 0`. Set `lap = 1` and `freq = 0`, push the entry to the front of small (the index stays `Loc::Small(idx)`), and `continue`.
   - **Ghost** in every other case, using `ghost_insert(key, freq)` with the tail's current freq (as in v001), and return.
   Each entry relaps at most once, so the loop ends within `small.len() + 1` iterations, and exactly one entry leaves small per call.
4. Update the linear `Reference` oracle in the tests to follow the same rules: a `lap` value on its entries, weak returnees set to 2, and the same loop in its `evict_small`. Keep `hit_miss_identical_to_linear_reference` and `ghost_compaction_bound_holds` passing. Add unit tests for these cases:
   - a freq-1 tail relaps exactly once while main is full;
   - a relapped entry that gets one more hit graduates on its next tail visit;
   - a weak returnee (lap 2, freq 1) with no further hit is ghosted, not relapped, and carries ghost freq 1.

Invariants to keep: `index.len() == resident + ghost_live`, `resident <= capacity`, and the ghost deque stays `<= 2 * main_size`.

## Rationale

The cycle-0004 insight calls v001 (freq-gated ghost path) and v003 (relap) complementary: they move different populations (freq-0 ghost returnees and freq-1 small tails), and each gained slightly at 16384. Keeping returnees out of the relap stops the two mechanisms from double-protecting the same weak keys and competing for the few small slots.

# H03

Narrowing the freq-0 ghost-returnee recency window from one small-queue turnover to half a turnover (`GHOST_RECENT_AGE_DIVISOR = 2`) raises hit-rate on web_0 by cutting out more of its one-off rereferences, while keeping most of hm_0's quick-return gain.

## Parent

cycle/0005/v002

## Changes

This is the single narrower-window probe that the cycle 0006 continuation asked for. Cycle 0006's v002 already showed that widening the window to 2× costs hit-rate on web_0. This tests the other side of the 1× boundary.

1. Change `const GHOST_RECENT_AGE_DIVISOR: usize = 1;` to `2`. `ghost_recent_window()` already computes `(small_size / GHOST_RECENT_AGE_DIVISOR).max(1)`, so freq-0 ghost returnees go straight to main only when their ghost age (`next_stamp - stamp`) is at most `small_size / 2`. Older freq-0 returnees take the existing path back into small with `GHOST_RETURN_SMALL_FREQ`.
2. Leave every other branch and constant unchanged: the freq ≥ 1 ghost→main path, graduation thresholds, freq reset, `evict_main`, and ghost capacity and compaction.
3. Tests: the `Reference` oracle already reads `GHOST_RECENT_AGE_DIVISOR`, so `hit_miss_identical_to_linear_reference` needs no change. The unit tests use capacity 4 (`small_size = 1`), where `.max(1)` keeps the window at 1, so `recent_freq_zero_ghost_returnee_goes_to_main` and `old_freq_zero_ghost_returnee_goes_to_small_with_freq_one` should still pass unchanged. Add one test at a larger capacity (for example capacity 16, so `small_size` is 4 and the window is 2): a freq-0 ghost aged 2 returns to main, and one aged 3 returns to small with freq 1.
4. Update the header comment to record the divisor change.

## Rationale

The ghost-age split separates hm_0's quick real reuse from web_0's late one-off rereferences. If web_0's harmful returns are spread through the second half of the turnover window and hm_0's useful ones cluster early, a half window keeps hm_0's gain and drops some web_0 pollution. If hit-rate falls on hm_0 without improving web_0, that shows 1× is already at the optimum and closes the ghost-age axis.

# H03

Implement adaptive frequency-gating threshold scaled to stash bucket count to enable robust composition across all geometries.

## Parent

baseline

## Changes

1. In `src/shared/geometry.rs`, export the computed stash bucket count from `BaselineGeometry::for_settings()` so it is accessible to the segment layer. Ensure the Dash struct (or its configuration) can access `num_of_stash_buckets` at initialization time.

2. In `src/dash/segments/dash_segment.rs`, modify the `promotion_get()` function to compute an adaptive threshold at initialization:

   - Add a threshold calculation function:
   ```rust
   fn compute_promotion_threshold(stash_buckets: usize) -> u16 {
       ((stash_buckets / 4).max(1)) as u16
   }
   ```

   - Store the computed threshold as a field in the DashSegmentCore struct (or pass it as a parameter to promotion_get):
   ```rust
   promotion_threshold: u16 = compute_promotion_threshold(stash_buckets)
   ```

   - Replace the hardcoded `PROMOTION_THRESHOLD: u16 = 2` constant with the adaptive value in the gating check (around line 166–170):
   ```
   if is_hottest && core.buckets[target_idx].get_items()[item_idx].lfu_counter >= core.promotion_threshold {
       // proceed with promotion to probing
   }
   ```

3. Stash→target promotion remains ungated (all stash hits promote immediately to target).

4. Keep all other promotion logic, demotion cascades, and baseline geometry (25/75) unchanged.

## Rationale

Cross-cycle analysis reveals that frequency-gating selectivity depends critically on geometry tuning: threshold=2 succeeded on concentrated geometry (62.5/37.5+, cycles 0002–0004) by filtering mostly false-positives in the smaller stash tier, but failed on balanced 50/50 geometry (cycle 0003 v001) by filtering legitimate candidates. The threshold is not generic across allocation profiles. An adaptive threshold scaled to stash bucket count (e.g., threshold = max(1, floor(stash_buckets / 4))) could stabilize the gate's selectivity across all geometries: on 50/50 geometry (8 stash buckets), this yields threshold=2; on 75/25 (8 stash), threshold=2; on 85/15 (5 stash), threshold=1; on 25/75 (24 stash), threshold=6. By scaling the filter strength with the stash size, frequency-gating could become orthogonal to geometry allocation, unlocking clean composition and enabling robust wins across parameter space. This tests whether adaptive parameter tuning can overcome the composition complexity observed in cycles 0001–0004.

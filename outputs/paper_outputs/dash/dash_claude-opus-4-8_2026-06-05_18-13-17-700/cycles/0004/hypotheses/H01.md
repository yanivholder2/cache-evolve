# H01

Relaxing the target→probing promotion gate from strict-hottest to top-quarter raises hit-rate by widening the protected probing tier's resident warm set.

## Parent

cycle/0003/v002

## Changes

The incumbent v002 keeps the baseline promotion gate: in `promotion_get`
(`src/dash/segments/dash_segment.rs`), the target-hit branch promotes a key to
its probing bucket only when it is the single hottest resident
(`is_hottest = Some(item_idx) == core.buckets[target_idx].promotion_candidate_index()`).
On the high-skew trace this lets at most one key per target reach the
second protected (probing) slot, so the probing tier is under-filled by warm
keys.

Relax the gate so a hit promotes to probing when the key ranks in the
**top quarter** of its target bucket under the policy's recency ordering,
not only when it is the single hottest. Concretely, for the recency-ordered
policies in use (ClassicLRU / Fifo / Swap, where `promotion_candidate_index`
is the last vector index and freshness increases toward the back), compute
`let len = core.buckets[target_idx].get_items().len();` and treat the key as
promotable when `item_idx >= len - len / 4` (i.e. within the freshest quarter),
with a guard `len < 4` that falls back to the original hottest-only test so
small/colliding buckets behave exactly as today. When the gate fires, run the
existing `promote_to_probing` path unchanged.

Preserve everything else: keep v002's `InsertPosition::Back` on the hit path,
keep the stash→target promotion, the `demote_from_normal_bucket`
one-more-chance cascade, slot legality (probing index `= (target_idx + 1) %
segment_size`), and capacity conservation. Update the in-file unit tests that
assert single-hottest promotion (e.g. `target_hit_not_hottest_promotes_within_bucket`)
to reflect the widened gate.

## Rationale (optional)

Cycles 0001–0003 exhausted capacity split and promotion *position* but never
touched the promotion *gate* itself; v002's MRU insert makes keys reach the
freshest region in one access, so a top-quarter gate should compound with it by
admitting the whole warm set into probing instead of a single winner.

# H01

Pushing the normal/stash split past v001's 3:1 toward roughly 4.3:1 (26 normal / 6 stash) brackets the hit-rate peak that sits between v001 (3:1, 0.714) and baseline (7:1, 0.663).

## Parent

cycle/0002/v001

## Changes

In the overlaid `src/shared/geometry.rs`, change `BaselineGeometry::layout`
to repartition the seeded topology one step further toward the normal
(promotion-protected) tier than v001's `total_buckets * 3 / 4`. Compute
`total_buckets = self.topology.num_of_normal_buckets + self.topology.num_of_stash_buckets`,
then set `num_of_normal_buckets = (total_buckets * 13 / 16).clamp(2, total_buckets - 1)`
and `num_of_stash_buckets = total_buckets - num_of_normal_buckets`. For the
default 32-bucket budget this yields 26 normal / 6 stash (≈4.3:1), a point
strictly between v001's 24/8 and baseline's 28/4, so it tests whether the
still-rising curve turns over before the baseline ratio. Leave
`num_of_segments` and `bucket_size` exactly as seeded so
`segments * (normal + stash) * bucket_size` is unchanged (P6 capacity
conservation holds), and keep the `clamp(2, total_buckets - 1)` so the
minimal 2/1 proptest topology stays valid.

## Rationale (optional)

The measured points (16/16→0.698, 24/8→0.714, 28/4→0.663) put the optimum
between 3:1 and 7:1; sampling ~4.3:1 is the most informative single probe to
bracket the maximum the cycle-0002 continuation asked for.

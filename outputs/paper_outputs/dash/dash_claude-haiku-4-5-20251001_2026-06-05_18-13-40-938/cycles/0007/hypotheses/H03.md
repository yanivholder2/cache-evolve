# H03

Increase stash bucket capacity from 4 to 6 while reducing normal buckets proportionally to extend filtering window and improve access pattern characterization.

## Parent

baseline

## Changes

Modify `src/shared/geometry.rs` in the `BaselineGeometry::for_settings()` method to rebalance bucket allocation toward the stash:

The baseline currently returns settings unchanged, preserving the default 4 stash buckets and 28 normal buckets (total 32 buckets × 16 slots per default = 512 total slots). Rebalance to 6 stash buckets and 26 normal buckets, keeping the total capacity constant at 32 buckets.

Specifically, in the `for_settings()` function:

1. Add 2 to `settings.num_of_stash_buckets` to expand stash
2. Subtract 2 from `settings.num_of_normal_buckets` to maintain total bucket count
3. Return a `BaselineGeometry` with these adjusted values

For example: a configuration with default 4 stash + 28 normal becomes 6 stash + 26 normal (total 32 buckets unchanged). For test configurations, apply the +2/-2 adjustment only when it maintains the invariant that num_of_normal_buckets >= 2 (required for probing); if adjustment would violate this, pass settings through unchanged.

This tests whether expanding the stash tier's filtering window—giving items more opportunity to prove hotness before elevation to target—can better characterize access patterns and improve hit rate. The expanded stash shifts capacity allocation from the promotion tiers toward the entry point, potentially improving filtering signal quality.

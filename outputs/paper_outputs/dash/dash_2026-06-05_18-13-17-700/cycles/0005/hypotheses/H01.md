# H01

Replacing the champion's top-quarter promotion gate with a top-half gate that engages on small buckets will raise hit-rate by letting the widened-gate lever actually fire on this heavily-hashed trace.

## Parent

cycle/0004/v001

## Changes

In `src/dash/segments/dash_segment.rs`, modify the `is_in_top_quarter`
helper (the promotion gate consulted on a target hit inside
`promotion_get`). Today it falls back to the hottest-only test whenever
`len < 4` and otherwise promotes only the freshest quarter
(`item_idx >= len - len / 4`). v001's own insight shows the `len < 4`
guard caps the lever: on this trace target buckets seldom hold four-plus
residents, so the widened branch almost never engages and the gate
degenerates to baseline.

Widen and lower the threshold so the gate engages on the small buckets
that dominate this trace:

- Keep the strict hottest-only fallback only for `len < 2` (a
  single-resident bucket has nothing to rank), using
  `Some(item_idx) == bucket.promotion_candidate_index()`.
- For `len >= 2`, promote when the key ranks in the **freshest half**
  (rounding up): `item_idx >= len - len.div_ceil(2)`. This makes the
  gate fire on len-3 buckets (top 2 promotable) and len-4 buckets (top 2),
  where the quarter rule was silent, while len-2 still promotes only the
  hottest so it cannot over-admit.

Rename the helper to `is_in_top_half` for clarity and update its callers
and doc comment. Preserve the recency-ordering assumption already baked
into v001 (freshness increases toward the back for ClassicLRU / Fifo /
Swap). Do not touch the stash→target path, the demotion cascade, the
`InsertPosition::Back` hit-path landing, or the 3:1 geometry overlay —
this is a single-knob change to gate width. Keep all existing invariants
(slot legality, capacity conservation) intact; update the gate's unit
tests (`target_hit_below_top_quarter_*` / `target_hit_in_top_quarter_*`)
to the new threshold.

## Rationale (optional)

v001 confirmed the gate direction is correct but bottlenecked by bucket
occupancy. A fractional rule that engages below len 4 is exactly the
unlock its insight called for, isolating gate-width from every other
lever.

# H03

Making promotion two-speed — stash→target lands at the LRU end while target→probing lands at the MRU end — will raise hit-rate by forcing newly admitted keys to re-prove warmth before they can reach the protected probing tier.

## Parent

cycle/0004/v001

## Changes

v001 uses a single `insert_pos` (`InsertPosition::Back`) for every
migration, so a key admitted from the stash lands at its target's MRU
end and, under the widened gate, can rocket straight into probing on its
very next access — letting briefly-spiking cold keys displace the genuine
hot set from the most-protected tier.

Split the promotion landing into two speeds in
`src/dash/segments/dash_segment.rs`:

- In `promotion_get`, when promoting a stash hit, call
  `promote_to_target(core, data, InsertPosition::Front)` so the
  freshly-admitted key lands at the target LRU end and must earn its way
  up (be re-accessed and reordered toward the freshest fraction) before
  it satisfies the promotion gate.
- Keep the target→probing promotion at `InsertPosition::Back`
  (`promote_to_probing(core, data, InsertPosition::Back)`) so a key that
  has already proven warmth in its target promotes fast.
- Leave demotion landings as v001 has them (Back / MRU) so the
  working-set tail is still protected on the way down; this change only
  slows the *first* hop (stash→target), not demotion recency.

This isolates a promotion-recency lever distinct from the global Back
flip cycle 0003 explored and the demotion-MRU of cycle 0004 v003: it
tests whether the protected probing tier should be reserved for keys with
two demonstrated accesses rather than one. Preserve the unreachable
post-conditions in `promotion_get` (key must remain resident after each
promote), the cascade logic, the widened gate, the geometry, and all
slot-legality / capacity invariants. Update the affected promotion-path
unit tests to the asymmetric landing positions.

## Rationale (optional)

Every recent lever returns slivers; two-speed promotion is a fresh axis
that guards the top tier against one-hit cold spikes while keeping
proven-warm keys on the fast path.

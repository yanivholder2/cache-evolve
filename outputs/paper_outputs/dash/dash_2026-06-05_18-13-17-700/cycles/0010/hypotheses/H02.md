# H02

Escalating a repeatedly-ghosted key straight into the protected probing tier (instead of target) strengthens the short-reuse-distance signal and lifts hit-rate.

## Parent

cycle/0009/v002

## Changes

Make the ghost ring frequency-graduated rather than binary. Today `Ghost`
stores keys only and `put` fast-tracks any ghost hit into target MRU via
`promote_to_target(.., Back, Back)`, then `Ghost::record` is a no-op for a
key already present. Change two things:

- Replace the `VecDeque<K>` / `HashSet<K>` membership ring with a bounded
  structure that also tracks a small per-key ghost-hit count (e.g. a
  `HashMap<K, u8>` paired with the FIFO `VecDeque<K>` for eviction order),
  keeping it keys-only so it adds no resident capacity and
  `capacity_conservation` is untouched. In `record`, when a key is already
  ghosted, increment its count and refresh its age instead of the current
  early-return no-op; cap the count with `saturating_add`.
- In `put`, on a ghost hit, branch on that count: a key ghosted exactly
  once still fast-tracks to target MRU as today
  (`promote_to_target(.., Back, Back)`); a key whose ghost count has
  reached 2 or more is a persistently-recurring key, so fast-track it one
  tier higher straight into probing MRU via `promote_to_probing(core,
  ghost, item, InsertPosition::Back, InsertPosition::Back)`. Remove the
  key from the ghost on consumption in both branches, and keep
  `target_touches.insert(key, 0)` only on the target-landing branch.

Preserve all other v002 behaviour: the cold first-touch path through
`stash_insert` is unchanged, the ghost is still recorded only at the
`stash_insert` drop branch, and `single_eviction_per_put` holds because
`promote_to_probing` already conserves occupancy by cascading exactly one
victim.

## Rationale (optional)

v002's gain is small because the dropped-then-recurring population is thin;
a key that gets dropped and re-requested more than once is a stronger
recurrence signal than a single ghost hit, so it deserves a longer-lived
seat. This tests whether grading the signal recaptures more of that thin
population without disturbing the conservative single-ghost case.

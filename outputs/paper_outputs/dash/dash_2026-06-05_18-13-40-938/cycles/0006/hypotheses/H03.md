# H03

Revisit stash-hit tier-skip acceleration (promote directly from stash to probing) combined with cycle/0003's proven demotion-back-insertion, testing whether tier-skip + asymmetric demotion MRU synergize when isolated from cycle/0004's experimental combinations.

## Parent

cycle/0003/v003

## Changes

Modify the stash-hit path in `src/dash/segments/dash_segment.rs` in the `promotion_get()` function to implement direct promotion to probing (tier-skip) instead of promoting to target first.

**Specific implementation:**
1. Locate the stash-hit handling block (around line 174–182 in the current baseline promotion_get)
2. Change the call from `promote_to_target(core, data, insert_pos)` to `promote_to_probing(core, data, InsertPosition::Back)`
3. Update the index lookups: instead of checking `core.buckets[target_idx]` for the newly promoted item, check `core.buckets[probing_idx]` (since item now lands in probing directly)
4. Keep all demotion logic unchanged—preserve cycle/0003/v003's back insertion for all demotion paths (target→stash, probing→target→stash cascades)
5. Keep the `insert_pos` parameter as `Front` for the stash-hit promotion call (use Back only in the promote_to_probing function itself)

**Invariant to preserve:**
- All demotion cascades continue to use Back insertion (promotion_age = 1 for demoted items)
- Only the stash→probing direct path is added; target-tier promotions remain unchanged (hottest items in target still promote to probing via normal path)

## Rationale

Cycle 0002's v001 validated that deterministic stash-hit tier-skip improves hit-rate (0.678), but cycle 0004's v003 failed when combining tier-skip with demotion-back-insertion. Cycle 0004's insight interpreted this as a filtering-discipline conflict: "tier-skip assumes filtered items, but back-insertion demotions give unfiltered items a shortcut." However, that insight was drawn from a broader combination test (v003 also modified intra-tier positioning). This hypothesis isolates tier-skip + demotion-back-insertion in their purest form: cycle/0003/v003 provides the proven demotion foundation, and this variant adds only the tier-skip lever. If hit-rate improves over cycle/0005/v002's 0.684, it confirms synergy; if it drops, it confirms the incompatibility is fundamental, not experimental-interference. This is the last credible tier-advancement architecture test before accepting 0.684 as optimal.

# H02

Applying back insertion to accessed items remaining within stash buckets improves hit rate by maintaining MRU ranking within stash for rapid re-access locality.

## Parent

baseline

## Changes

Extend the MRU positioning principle to intra-tier stash operations. In `src/dash/segments/dash_segment.rs`, modify the stash-hit path in `get_from_position()` and related bucket access methods to reposition accessed items at the back (MRU end) of their stash bucket:

When a key is found in a stash bucket via `stash_buckets[stash_idx].get_position(key)` and does not trigger promotion (line ~150 in `promotion_get()`), instead of returning the item at its current position, reposition it at back before returning:

```rust
if let Some(item_idx) = core.stash_buckets[stash_idx].get_position(key) {
    // Item found in stash and will not promote; reposition for MRU ranking
    debug!("promotion_get: key={key:?} accessed in stash, repositioning to MRU");
    let data = core.stash_buckets[stash_idx].remove_at(item_idx);
    core.stash_buckets[stash_idx].insert_at(InsertPosition::Back, data.clone());
    // Now item is at back; return reference to its new position
    let Some(new_idx) = core.stash_buckets[stash_idx].get_position(key) else {
        unreachable!("just inserted")
    };
    return Some(&core.stash_buckets[stash_idx].get_items()[new_idx]);
}
```

This preserves all existing tier-advancement logic while changing only the insertion position of accessed items that remain in stash, keeping them ranked as recently-used within their bucket.

## Rationale

Cycles 0001–0003 consistently validated that MRU positioning improves hit rate when applied to tier-advancing items (promotions) and cascading items (demotions). The cross-cycle insight asks: "Does the universal MRU principle extend to other insertion sites (e.g., fresh evictions in intra-tier operations...)?" This hypothesis tests whether the MRU benefit extends to items accessed within stash but not yet promoted. In a stash bucket with multiple items, keeping frequently-accessed items ranked at MRU (back) ensures their promotion candidacy and reduces the chance they fall to eviction before next access, improving hit rate on workloads with bursty access patterns within stash.

# H03

Combining stash-hit tier-skip acceleration with back insertion for demoted items improves hit rate by synergizing fast-path promotion with efficient demotion recovery.

## Parent

cycle/0003/v003

## Changes

Build on v003's proven demotion MRU strategy by re-introducing the deterministic tier-skip for stash hits that succeeded in cycle 0002/v001. Modify the stash-hit promotion path in `promotion_get()` (around line 154–157 in `src/dash/segments/dash_segment.rs`):

```rust
if let Some(item_idx) = core.stash_buckets[stash_idx].get_position(key) {
    debug!("promotion_get: key={key:?} found in stash");
    let data = core.stash_buckets[stash_idx].remove_at(item_idx);
    
    // Restore deterministic tier-skip: promote directly to probing (hot tier)
    // with MRU positioning, skipping the intermediate target tier
    debug!("promotion_get: key={key:?} stash hit -> skip to probing+Back");
    promote_to_probing(core, data, InsertPosition::Back);
    
    let Some(item_new_idx) = core.buckets[probing_idx].get_position(key) else {
        unreachable!("...")
    };
    return Some(&core.buckets[probing_idx].get_items()[item_new_idx]);
}
```

Keep v003's demotion-path back insertion (all cascade paths insert demoted items at Back) intact. This removes the intermediate target-tier step for stash hits, giving them immediate access to the probing tier while maintaining MRU positioning on both promotion and demotion paths.

## Rationale

Cycle 0002's v001 (deterministic tier-skip for stash hits) achieved 0.678 hit-rate, and cycle 0003's v003 (demotion back insertion) achieved 0.6839—currently the highest overall. Cycle 0001 and 0002 both validated that stash-hit acceleration and MRU positioning improve hit rate on this workload. However, cycle 0003 did not test whether tier-skip (proven in 0002) combines with demotion MRU (proven in 0003). This hypothesis explores whether fast-pathing stash-hit promotion (skip to probing) synergizes with efficient demotion recovery (back insertion) to outperform either strategy alone. The combination targets both promotion speed and demotion resilience, addressing potential imbalance in the current v003 which optimizes demotion but retains the baseline's tier-by-tier stash-hit progression.

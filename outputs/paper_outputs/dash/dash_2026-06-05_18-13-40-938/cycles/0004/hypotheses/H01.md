Combining back insertion for demoted items AND target-tier promotions improves hit rate by universalizing MRU positioning across all tier-advancing transitions.

## Parent

cycle/0003/v003

## Changes

Build on v003's proven demotion MRU strategy by adding v002's target-tier back insertion. Modify the target-tier hottest-item promotion path in `promotion_get()` (around line 165–180 in `src/dash/segments/dash_segment.rs`):

```rust
if let Some(item_idx) = core.buckets[target_idx].get_position(key) {
    let is_hottest = Some(item_idx) == core.buckets[target_idx].promotion_candidate_index();
    if is_hottest {
        debug!("promotion_get: key={key:?} found in target as hottest -> probing={probing_idx}");
        let data = core.buckets[target_idx].remove_at(item_idx);
        // Use Back insertion for target-tier hottest items, not the parameter-based insert_pos
        promote_to_probing(core, data, InsertPosition::Back);
        
        let Some(item_new_idx) = core.buckets[probing_idx].get_position(key) else {
            unreachable!("...")
        };
        return Some(&core.buckets[probing_idx].get_items()[item_new_idx]);
    } else {
        debug!("promotion_get: key={key:?} found in target item_idx={item_idx} (intra-promote)");
        return Some(core.buckets[target_idx].get_from_position(item_idx));
    }
}
```

Keep v003's demotion-path back insertion intact. The combination applies MRU positioning consistently across both the promotion path (target→probing) and demotion path (all cascades), testing whether the successful MRU principle from v002 (0.6709) and v003 (0.6839) synergize when both applied together.

## Rationale

Both v002 and v003 independently improved hit rate by applying back insertion to different code paths: v002 to target-tier promotions, v003 to demotion cascades. The cycle-insight explicitly recommends testing these two strategies stacked together to measure synergy. This addresses an open question: do they combine additively or saturate a single underlying mechanism? By applying both changes to v003's proven demotion foundation, we test whether consistent MRU positioning across all tier transitions (both up and down) amplifies the benefit beyond either strategy alone.

# H01

Combining occupancy-adaptive promotion destination with back insertion improves hit rate by synergizing responsive tier selection and MRU positioning.

## Parent

cycle/0002/v001

## Changes

Extend v001's winning strategy by adding occupancy-adaptive destination selection to its deterministic back insertion. Modify the stash-hit path in `promotion_get()` (around line 154–157 in `src/dash/segments/dash_segment.rs`):

```rust
if let Some(item_idx) = core.stash_buckets[stash_idx].get_position(key) {
    debug!("promotion_get: key={key:?} found in stash");
    let data = core.stash_buckets[stash_idx].remove_at(item_idx);
    
    // Compute stash bucket occupancy ratio
    let occupancy_pct = core.stash_buckets[stash_idx].size() as f64 
        / core.stash_buckets[stash_idx].get_max_size() as f64;
    
    if occupancy_pct >= 0.75 {
        // Under stash pressure: aggressive skip to probing with MRU positioning
        debug!("promotion_get: key={key:?} stash {:.1}% >= 75%, probing+Back", occupancy_pct * 100.0);
        promote_to_probing(core, data, InsertPosition::Back);
    } else {
        // Stash has room: conservative tier-by-tier filtering with MRU positioning
        debug!("promotion_get: key={key:?} stash {:.1}% < 75%, target+Back", occupancy_pct * 100.0);
        promote_to_target(core, data, InsertPosition::Back);
    }
    // ... rest of insertion and return logic
}
```

This preserves v001's proven back insertion while testing v002's adaptive destination selector. Both successful variants from the prior cycle are unified: when stash is congested, behave like v001 (deterministic skip); when stash has capacity, conservatively filter through target (like v002 explored), but crucially, use back insertion in both paths.

## Rationale

Cycle 0002 showed that v001's deterministic stash-hit acceleration (always skip to probing+back) beat v002's occupancy-adaptive destination (skip vs filter based on 75% threshold). However, v002 didn't implement back insertion—it used front insertion regardless. This hypothesis tests whether the real gap was the missing back insertion in v002. By combining adaptive destination with back insertion, we ask: do the two strategies synergize when properly paired? If adaptive destination matters under peak load but back insertion matters universally, this combination may handle both steady-state and congested scenarios better than either alone.

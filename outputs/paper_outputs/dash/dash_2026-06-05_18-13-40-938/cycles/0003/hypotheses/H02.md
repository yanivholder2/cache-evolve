# H02

Extending MRU back insertion to target-tier hits improves hit rate by consistently prioritizing all tier-advancing items as immediately eligible for next-tier promotion.

## Parent

baseline

## Changes

Modify the target-tier hit path in `promotion_get()` (around line 165–180 in `src/dash/segments/dash_segment.rs`) to apply back insertion when promoting target-tier items to probing. Replace the front-based `insert_pos` parameter with explicit `InsertPosition::Back`:

```rust
if let Some(item_idx) = core.buckets[target_idx].get_position(key) {
    let is_hottest = Some(item_idx) == core.buckets[target_idx].promotion_candidate_index();
    if is_hottest {
        debug!("promotion_get: key={key:?} found in target as hottest -> probing={probing_idx}");
        let data = core.buckets[target_idx].remove_at(item_idx);
        // Use Back insertion for target-tier hits, not the parameter-based insert_pos
        promote_to_probing(core, data, InsertPosition::Back);
        
        let Some(item_new_idx) = core.buckets[probing_idx].get_position(key) else {
            unreachable!("...")
        };
        return Some(&core.buckets[probing_idx].get_items()[item_new_idx]);
    } else {
        debug!("promotion_get: key={key:?} found in target item_idx={item_idx} (intra-promote)");
        return Some(core.buckets[target_idx].get_from_position(item_idx));
    }
}
```

This applies the back insertion strategy that successfully improved hit rate for stash-hit promotions (v001, cycle 0002) to all tier-advancing items, not just stash hits. Items proven hot enough to advance from target to probing receive MRU positioning, giving them immediate candidacy for further advancement or protection from eviction.

## Rationale

v001 demonstrated that MRU back insertion significantly improves hit rate for stash-hit promotions. The success of this pattern suggests recency and immediate promotion eligibility matter for hot items. Currently, only stash hits receive back insertion; target-tier hits that qualify as hottest still use front insertion. By extending back insertion to target-tier promotions, we test whether the benefit of MRU positioning applies consistently across all promotion paths. Items that have survived to target and proven themselves hot enough for probing deserve the same MRU advantage as stash survivors.

# H02

Eliminate target-tier retry step in demotion cascade to simplify eviction flow and reduce cascade depth for probing evictions.

## Parent

cycle/0004/v001

## Changes

Modify `src/dash/segments/dash_segment.rs` in the `demote_from_normal_bucket()` function to bypass the target-tier one-more-chance retry when items are evicted from the probing bucket as foreign residents:

Currently, when an item is evicted from probing (where `source_idx != true_target`, indicating it was placed there as someone else's probing slot), the code inserts it back into its true target tier via `core.put_at(Slot::Target, InsertPosition::Back, item)`. If that insertion also causes eviction, the cascade continues.

Change this behavior: for foreign residents evicted from probing, demote directly to stash (Slot::Stash) instead of retrying in target. Specifically:

1. In the `else` branch of `demote_from_normal_bucket()` (when `true_target != source_idx`)
2. Change from: `core.put_at(Slot::Target, InsertPosition::Back, item)` 
3. Change to: `core.put_at(Slot::Stash, InsertPosition::Back, item)`
4. Remove the cascade eviction check that follows (the `if let Some(cascade)` block is no longer needed since we're demoting to terminal stash, not to another normal tier)

This eliminates the possibility that a probing eviction cascades into a target eviction, which could degrade target tier quality. Keep the direct target→stash demotion path unchanged (when `true_target == source_idx`).

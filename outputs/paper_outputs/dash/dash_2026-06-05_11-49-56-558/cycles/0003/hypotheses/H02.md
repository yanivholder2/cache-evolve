# H02

Combining MRU re-entry (stash→target insert at `InsertPosition::Back`) with v002's proven 75/25 topology will raise hit rate above either improvement alone by accelerating re-promoted items' path to probing-tier eligibility within the enlarged normal-bucket pool.

## Parent

cycle/0002/v002

## Changes

Add an overlay for `src/dash/segments/dash_segment.rs` on top of v002's existing `src/shared/geometry.rs` overlay (the 75/25 split; that file is kept exactly as in v002 and must not be modified further).

In `src/dash/segments/dash_segment.rs`, the sole change is in the `Segment::get` implementation — pass `InsertPosition::Back` instead of `InsertPosition::Front` to `promotion_get`:

```rust
impl<K, V> Segment<K, V> for DashSegment<K, V>
where
    K: Hash + Eq + Copy + Debug + 'static,
    V: Eq + Copy + Debug + 'static,
{
    fn core(&self) -> &SegmentCore<K, V> { &self.core }
    fn core_mut(&mut self) -> &mut SegmentCore<K, V> { &mut self.core }

    fn get(&mut self, key: &K) -> Option<&Item<K, V>> {
        promotion_get(&mut self.core, key, InsertPosition::Back)
    }
}
```

All other functions in `dash_segment.rs` — `promote_to_target`, `promote_to_probing`, `demote_from_normal_bucket`, and `promotion_get` — must be copied verbatim from the baseline without any modification. The files `src/shared/eviction_policy.rs`, `src/dash/dash_bucket.rs`, and `src/shared/item.rs` are not overlaid and remain at baseline.

The net effect is that stash-to-target promotions land at the MRU end of the target bucket, so a reactivated cold item qualifies for probing-tier promotion after one additional access instead of after climbing through the full bucket under LRU ordering.

## Rationale

MRU re-entry was confirmed as a real, additive, non-interfering gain in both cycle 1 (v001 on 50/50) and cycle 2 (v001 on 50/50). The combination of MRU re-entry with the current best topology (75/25) has never been tested directly. The cross-cycle insight explicitly identifies this as the highest-priority low-risk compound to run. With more normal-bucket slots available, items that re-enter at MRU have longer dwell time before eviction, so the benefit of instant promotion eligibility is expected to persist or grow relative to the 50/50 baseline where it was first observed.

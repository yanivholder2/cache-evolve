# H03

Inserting newly-promoted items into their probing bucket at `Front` (LRU/probationary end) instead of `Back` (MRU end) will improve hit-rate by creating a probationary zone in probing where recently-graduated items must earn at least one additional access before being protected from eviction, filtering stale one-off promotions.

## Parent

cycle/0003/v002

## Changes

In `src/dash/segments/dash_segment.rs`, locate the `promotion_get` function. Inside the branch that fires when an item is found in its target bucket as the hottest item (`is_hottest == true`), there is a call to `promote_to_probing`:

```rust
if is_hottest {
    let data = core.buckets[target_idx].remove_at(item_idx);
    promote_to_probing(core, data, insert_pos);   // ← change this argument
    ...
}
```

Change the `insert_pos` argument to hard-coded `InsertPosition::Front`:

```rust
if is_hottest {
    let data = core.buckets[target_idx].remove_at(item_idx);
    promote_to_probing(core, data, InsertPosition::Front);  // ← Front
    ...
}
```

No other changes: stash→target promotion continues to use `InsertPosition::Back` (MRU re-entry, inherited from cycle/0003/v002), demotions continue to use the inherited `insert_pos`, and the geometry (75/25 normal/stash split) is unchanged. The `promotion_candidate_index` and `unreachable!` assertion inside the probing-promotion path are also unchanged.

When a newly-promoted probing item is subsequently accessed in probing, ClassicLRU's `get_from_position` already moves it to `Back` (MRU), so a single re-access rescues it to full MRU protection. If it is not re-accessed, it evicts from the LRU end of probing first, which is the desired probationary behaviour.

## Rationale

The cross-cycle open question "intra-normal-tier eviction ordering: scan resistance or segmented LRU within the hot tier" has not yet been probed. Inserting newly-promoted items at LRU of probing mimics the probationary segment of a segmented-LRU: items that were only transiently hot (promoted once but not revisited) are evicted before durable hot residents. Items that continue to be accessed earn MRU protection through ClassicLRU's move-to-back on their next probing hit. The stash→target MRU re-entry gain (from cycle/0003/v002) is fully preserved, and this change is orthogonal to both the ghost-set experiments (H01) and the demotion-path experiments (H02).

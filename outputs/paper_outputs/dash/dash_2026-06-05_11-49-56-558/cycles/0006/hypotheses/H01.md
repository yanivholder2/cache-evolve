# H01

Add a `ClassicLRUFreqProtect` eviction policy to `eviction_policy.rs` and apply it to all buckets via `dash_bucket.rs`, resetting `lfu_counter` to zero before any stash insertion in `dash_segment.rs`, to improve hit-rate by protecting probing and target residents that have confirmed reuse from eviction over never-accessed newcomers.

## Parent

cycle/0004/v002

## Changes

### eviction_policy.rs

Add a new concrete struct `ClassicLRUFreqProtect` (do **not** add it to the `EvictionPolicyKind` enum — instantiate it directly in `dash_bucket.rs`):

```rust
/// ClassicLRU variant that protects items with at least one in-tier access
/// from eviction when an unaccessed item (lfu_counter == 0) exists as an
/// alternative victim.
#[derive(Debug)]
pub struct ClassicLRUFreqProtect;

impl<K, V> EvictionPolicy<K, V> for ClassicLRUFreqProtect
where
    K: Hash + Eq + Copy + Debug,
    V: Eq + Copy + Debug,
{
    fn name(&self) -> &'static str { "ClassicLRUFreqProtect" }

    /// Move to MRU (same as ClassicLRU) AND increment lfu_counter to record
    /// that this item has been accessed at least once since entering its
    /// current tier.
    fn get_from_position(&self, items: &mut Vec<Item<K, V>>, position: usize) -> usize {
        items[position].lfu_counter += 1;
        let item = items.remove(position);
        items.push(item);
        items.len() - 1
    }

    /// Prefer to evict an item with lfu_counter == 0 (never touched in this
    /// tier). Fall back to position 0 (LRU front) if all residents have been
    /// accessed at least once.
    fn eviction_candidate_index(&self, items: &[Item<K, V>]) -> usize {
        items.iter()
            .enumerate()
            .find(|(_, item)| item.lfu_counter == 0)
            .map(|(i, _)| i)
            .unwrap_or(0)
    }

    fn promotion_candidate_index(&self, items: &[Item<K, V>]) -> usize {
        items.len() - 1  // same as ClassicLRU: MRU end
    }
}
```

### dash_bucket.rs

Add `use crate::shared::eviction_policy::ClassicLRUFreqProtect;` to the imports, then change `new_bucket` to ignore the harness-supplied policy and always construct with `ClassicLRUFreqProtect`:

```rust
pub fn new_bucket<K, V>(
    max_size: usize,
    _eviction_policy: Box<dyn EvictionPolicy<K, V>>,  // harness policy ignored
) -> Box<dyn Bucket<K, V>>
where
    K: Hash + Eq + Copy + Debug + 'static,
    V: Eq + Copy + Debug + 'static,
{
    Box::new(DashBucket::new(max_size, Box::new(ClassicLRUFreqProtect)))
}
```

This applies the new policy to both normal and stash buckets. Stash is safe because stash items are never touched via `get_from_position` in the promotion path (they are removed by `remove_at`) — their `lfu_counter` stays at 0, so `ClassicLRUFreqProtect` falls back to position 0 and behaves identically to `ClassicLRU` for stash.

### dash_segment.rs (identical to parent cycle/0004/v002, with two additions)

Keep `get` using `InsertPosition::Back`, keep ghost-set logic, keep geometry overlay — all inherited from cycle/0004/v002 unchanged.

Add one mutation in `demote_from_normal_bucket` before each `core.put_at(Slot::Stash, ...)` call: reset the item's `lfu_counter` to zero so that demoted items enter stash with a clean counter. This prevents hot items demoted to stash from "protecting" stash slots from genuine cold newcomers.

```rust
// Before the direct-to-stash path:
item.lfu_counter = 0;
core.put_at(Slot::Stash, insert_pos, item);

// Before the cascade-to-stash path:
cascade.lfu_counter = 0;
core.put_at(Slot::Stash, insert_pos, cascade);
```

No other changes to `dash_segment.rs`. The `get_from_position` increment in `ClassicLRUFreqProtect` fires automatically when target (non-hottest hit) and probing hits call `core.buckets[...].get_from_position(item_idx)`.

## Rationale

The winner (cycle/0004/v002) uses ClassicLRU uniformly: any single access moves an item to MRU, and eviction always removes the LRU-position item. Items that just entered probing via fast-track (stash→target at Back, immediately hottest, promotes to probing with lfu_counter=0) compete equally with established probing residents that have been re-accessed multiple times. `ClassicLRUFreqProtect` introduces a single guard: when probing overflows, newly-arrived zero-access items are sacrificed before items with confirmed reuse. In the degenerate case (all probing items have lfu_counter>0), behaviour is identical to ClassicLRU.

# H02

Replacing ClassicLRU with LFU eviction across all buckets improves hit rate on frequency-skewed workloads by protecting high-frequency items from displacement by recently-inserted but rarely-accessed items.

## Parent

baseline

## Changes

In `src/dash/dash_bucket.rs`, modify the `new_bucket` factory function to ignore the caller-supplied `eviction_policy` argument and always install `Lfu` instead. Add the import for `Lfu` from `crate::shared::eviction_policy`:

```rust
use crate::shared::eviction_policy::Lfu;
```

Then replace the body of `new_bucket`:

```rust
pub fn new_bucket<K, V>(
    max_size: usize,
    _eviction_policy: Box<dyn EvictionPolicy<K, V>>,
) -> Box<dyn Bucket<K, V>>
where
    K: Hash + Eq + Copy + Debug + 'static,
    V: Eq + Copy + Debug + 'static,
{
    Box::new(DashBucket::new(max_size, Box::new(Lfu)))
}
```

The underscore prefix on `_eviction_policy` suppresses the unused-argument warning. `DashBucket::new` already accepts `Box<dyn EvictionPolicy<K, V>>`, so the signature is unchanged. The `Lfu` implementation in `eviction_policy.rs` increments `Item::lfu_counter` on every `get_from_position` call and evicts the item with the minimum counter; it elects the item with the maximum counter as `promotion_candidate_index`. Because `Item::lfu_counter` is carried through tier moves (the item is removed and reinserted with its accumulated counter intact), frequency history persists across stash→target→probing promotions — LFU benefits compound the longer an item survives in the cache.

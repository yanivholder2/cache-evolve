# H03

Raise hit-rate by lifting the second-chance frequency ceiling so demonstrably hot keys survive more main-eviction passes, while holding metadata at 8.

## Parent

cycle/0009/v003

## Changes

Today `MAX_FREQ = 3` caps how many second chances a main-resident key can
bank. In `evict_main`, a tail key with `freq > 0` is decremented and
recirculated to the front; a key gets at most `MAX_FREQ` rotations before
eviction. Raising that ceiling lets keys that the trace re-touches many
times accumulate more protection and ride out more eviction sweeps, which
the cross-cycle history flags as a recurring (small but real) hit-rate
win: "Reward demonstrated reuse ... a higher freq ceiling for already-hot
keys gave small, real, split-orthogonal gains."

Concretely:
- Change `const MAX_FREQ: u8 = 3;` to `const MAX_FREQ: u8 = 7;`. The freq
  counter lives in the map slot as a `u8` (range 0..=255), so this does
  **not** change `size_of::<Entry<u64,u64>>()` — metadata-size stays at 8.
- Leave `get`'s `saturating_add(1).min(MAX_FREQ)` as-is (it now climbs to
  7), and leave `evict_main`'s decrement-by-1 second-chance loop unchanged
  so the higher ceiling simply grants more rotations to genuinely hot
  keys.
- Do not touch the small→main promotion gate (`freq > 1`), the ghost
  re-admission path (still enters main at freq 0), the small split, or the
  ghost bound. The strict admission filter is load-bearing per prior
  cycles and must not be loosened — only the *retention* ceiling for keys
  that have already proven reuse changes.

Success = hit-rate climbs above the long-standing 0.7312 (toward the
0.7320 seen once in cycle 7) with metadata-size held at 8. Risk: an
over-high ceiling could retain keys that went cold; if 7 regresses,
intermediate values (5) are the fallback.

## Rationale (optional)

This is the one scored axis with demonstrated historical headroom
(hit-rate touched 0.7320 once). It targets retention strength, orthogonal
to H01 (field layout) and H02 (get-path store), so the three cohort
members exercise three independent mechanisms on three different scored
dimensions.

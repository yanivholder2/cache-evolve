# H01

Eagerly promote a small-queue entry to main the moment its `freq` reaches `MAX_FREQ` on access, rather than waiting for small eviction, to lift hit-rate by protecting proven-hot keys sooner and freeing admission slots faster.

## Parent

cycle/0009/v001

## Changes

In `S3Fifo::get`, change the small-queue hit branch (currently at the
`if let Some(pos) = self.small.iter().position(...)` block). Today it bumps
`entry.freq` in place (clamped to `MAX_FREQ`) and returns
`&self.small[pos].value`, leaving the key in small until eviction. Modify it so
that **after** the saturating `freq` bump, if the new `freq == MAX_FREQ`, the
entry is removed from `small` and inserted into main exactly the way
`evict_small`'s promotion path does it: if `self.main.len() >= self.main_size`
call `self.evict_main()` first, then `self.main.push_front(entry)`, and return a
reference to `self.main.front().expect(...).value`. If `freq < MAX_FREQ` after
the bump, keep the existing in-place behaviour (no reorder, return the small
value).

Rationale and invariants to preserve: a key that reaches `MAX_FREQ` in small
already satisfies the `freq > 1` promotion test, so it would be promoted at
small eviction anyway — this changes only the *timing* and does not enlarge the
set of keys admitted to main (do NOT lower the promotion threshold). Net
resident count is unchanged (one removed from small, one added to main, with a
main eviction only when main was full). Do not touch the main move-to-front hit
path, the adaptive-split controller in `put`, ghost tagging, or `evict_main`'s
rotation. Keep `small_size + main_size == capacity` intact.

## Rationale (optional)

The incumbent's wins are "protect hot residents with recency" and "quick
demotion of cold admissions." A key that proves itself hot while still sitting
in the FIFO small queue currently keeps occupying an admission slot until it
ages out, and only then enters main's recency-protected structure. Eager
promotion delivers both incumbent wins earlier without changing admission
volume — a pure timing lever on a mechanism not yet probed.

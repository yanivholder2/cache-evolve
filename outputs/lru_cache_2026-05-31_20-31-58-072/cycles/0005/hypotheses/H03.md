# H03

A 4-level segmented LRU (S4LRU) skeleton, finally evaluated at matched capacity, can match or beat the CLOCK-Pro-lite plateau on hit-rate.

## Parent

baseline

## Changes

Replace the entire contents of `src/lru_cache/mod.rs` (keeping
`pub mod lru_cache_jni;` and the `framework::Cache` impl so the JNI ABI
in the contract-protected `lru_cache_jni.rs` is unchanged) with an
S4LRU implementation built on top of the baseline's arena-slot-reuse
pattern.

Skeleton:

- Four levels `L0..L3`, each a doubly-linked list backed by the existing
  arena (`Vec<Option<Entry>>` with `prev`/`next` `usize` indices and
  per-level `head`/`tail`). Total resident count across all levels
  stays bounded by `capacity`.
- Per-level capacity: `cap_i = capacity / 4` for `L0..L2`; `L3` gets
  the remainder (`capacity - 3 * cap_i`) so the sum equals `capacity`
  exactly.
- `put(key, value)` for a brand-new key: insert at the head of `L0`. If
  `L0` is over its per-level cap, evict from `L0`'s tail — that key
  leaves the cache entirely (no ghost ring, no demotion to anywhere).
- `put(key, value)` for a resident key: update the value, then run the
  same promotion path as `get`.
- `get(key)`: if the key is at level `Li` with `i < 3`, remove it from
  `Li`'s tail-side position and insert at `L(i+1)`'s head; if `L(i+1)`
  is now over its per-level cap, demote `L(i+1)`'s tail to `Li`'s head.
  If the key is already at `L3`, move to `L3`'s head (true LRU within
  the top level). Return `Some(&value)`.
- Resident-count invariant: every promotion that overflows the
  destination level is paired with a demotion to the source level, so
  total residence is conserved and `len <= capacity` always holds.

Drop entirely: the CLOCK-Pro-lite ring, the `hand`, the
`SlotState` enum, the ghost ring, and `ghost_set`. The struct shrinks
to `{ map: HashMap<K, usize>, arena: Vec<Option<Entry<K,V>>>, l_head:
[usize;4], l_tail: [usize;4], l_len: [usize;4], capacity: usize,
free_head: usize }`.

Preserve invariants P1/P2/P3 the baseline relied on: `map.len() ==
sum(l_len)`, every `Some` arena slot's key is in `map`, no key appears
in two levels.

Do not modify `src/lru_cache/lru_cache_jni.rs` (contract-protected).

## Rationale (optional)

Cycles 1–2 attempted SLRU twice and each time the result was
uninterpretable because variant and baseline were sampled at disjoint
capacities; cycle-4's three-way parity confirms current framework
sampling is matched (three variants all scored 0.4946 to four
decimals against the same parent), so an S4LRU-vs-CLOCK-Pro-lite
delta is finally measurable. The cycle-4 cycle-insight calls the
current skeleton's plateau "strongly confirmed" and recommends pivot
away from further single-knob tweaks of it; a true skeleton swap is
the cleanest such pivot, and segmented LRU is the canonical alternative
recency-segmenting policy that does not depend on a ghost ring.

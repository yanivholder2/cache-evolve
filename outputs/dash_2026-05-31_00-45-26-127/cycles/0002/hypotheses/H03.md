# H03

Add periodic in-bucket counter decay to v003's cold-quartile scan so stale `lfu_counter` values stop protecting "historically warm but currently cold" items on lirs:multi1.

## Parent

cycle/0001/v003

## Changes

Start from v003's `src/shared/eviction_policy.rs` (cold-quartile victim scan with per-hit `lfu_counter` increment plus strict move-to-back). Make exactly two targeted changes to the `ClassicLRU` impl; leave every other policy untouched.

1. Modify `ClassicLRU::get_from_position`:
   - Keep the existing `items[position].lfu_counter = items[position].lfu_counter.saturating_add(1)` and the strict move-to-back (`remove(position)` + `push(item)`).
   - After the push, inspect the counter of the just-moved item (now at `items.len() - 1`). If it has reached a decay threshold of `16`, walk the entire bucket and right-shift every `lfu_counter` by one (`items[i].lfu_counter >>= 1`). This bounds the counter's effective window to the most recent ~16 hits to the hottest item in the bucket and decays everyone else proportionally — a per-bucket Caffeine-style aging step.
2. Leave `ClassicLRU::eviction_candidate_index` exactly as v003 wrote it: scan the front quartile `window = ((items.len() + 3) / 4).max(1)`, return the index of the lowest `lfu_counter`, break ties by lowest index, fall back to `0` on empty windows.
3. Leave `promotion_candidate_index` returning `items.len() - 1`.

Do not change `Item` or `DashBucket`. Do not alter the `EvictionPolicy` trait. Keep the saturation arithmetic in `get_from_position` (`saturating_add`) so the threshold check is well-defined even if the counter is already large.

## Rationale (optional)

The variant-insight on v003 named the exact failure mode: lifetime counters mis-rank items whose hit history is no longer predictive. A halve-on-threshold decay is the smallest mechanical change that turns v003's lifetime counter into a windowed one without adding any new per-item state — it directly tests whether v003's cold-quartile scan is good *given a recency-bounded counter*, isolating the counter-staleness hypothesis from the scan-shape hypothesis.

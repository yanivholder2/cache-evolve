# H01

Replacing pure LRU with a two-queue (2Q) policy — a fixed-capacity FIFO queue for first-time items and a separate LRU queue for promoted multi-hit items — will improve hit rate on lirs:multi1.trace.gz by shielding frequently reused items from scan-driven eviction.

## Parent

baseline

## Changes

Rewrite `src/lru_cache/mod.rs`. All changes stay within `LruCache<K, V>` and `Node<K, V>`; the JNI file is untouched.

### Node struct

Add one field:

```rust
promoted: bool,  // false → resident in A1 (FIFO cold); true → resident in Am (LRU hot)
```

### LruCache struct

Replace the single `head`/`tail` pair with four pointers and two occupancy counters:

```rust
a1_head: Option<usize>,   // LRU (eviction) end of the FIFO cold queue A1
a1_tail: Option<usize>,   // MRU (insertion) end of A1
am_head: Option<usize>,   // LRU end of the protected hot queue Am
am_tail: Option<usize>,   // MRU end of Am
a1_len: usize,
am_len: usize,
```

Also add `a1_cap: usize` and `am_cap: usize`, computed once in `try_new` as:
`a1_cap = (capacity / 4).max(1)`, `am_cap = capacity - a1_cap`.

### `unlink`

Generalise to patch whichever sub-list the node belongs to. Inspect `nodes[idx].promoted` to decide whether to update `a1_head`/`a1_tail` or `am_head`/`am_tail`. Decrement the matching counter after unlinking.

### `push_back`

Split into `push_back_a1(idx)` and `push_back_am(idx)` that append to the respective tail and increment the matching counter.

### `put` (new key path)

Set `nodes[idx].promoted = false`. Before linking the new node into A1 check the relevant cap:

1. If `a1_len == a1_cap`: evict `a1_head` — unlink it from A1, remove its key from `map`, and reuse that arena slot (index becomes `idx` for the new key; overwrite `key`, `value`, `promoted = false`).
2. If `a1_len < a1_cap` and total occupancy `a1_len + am_len < capacity`: allocate a fresh arena slot (`nodes.push(…)`).

Then call `push_back_a1(idx)` and `map.insert(key, idx)`.

### `get` (hit path)

Look up `idx` as before, then branch on `nodes[idx].promoted`:

- **Not promoted (A1 hit)**: unlink from A1. Now promote to Am:
  - If `am_len == am_cap`: evict `am_head` — unlink it, remove its key from `map`. The freed slot is `am_evicted_idx`.  Reuse `am_evicted_idx` for the promoted node: copy the A1 node's key and value into `am_evicted_idx`, update `map` to point the key to `am_evicted_idx`, set `promoted = true`, call `push_back_am(am_evicted_idx)`.
  - Otherwise: set `nodes[idx].promoted = true`, call `push_back_am(idx)`.
- **Already promoted (Am hit)**: unlink from Am, call `push_back_am(idx)` (standard LRU move-to-tail within Am).

### Invariants to preserve

- `a1_len + am_len == map.len()` at all times.
- `a1_len <= a1_cap` and `am_len <= am_cap` at all times.
- `map.len() <= capacity` at all times.
- All three proptest invariants (P1 capacity_bound, P2 value_fidelity, P3 no_phantom_items) must continue to hold.

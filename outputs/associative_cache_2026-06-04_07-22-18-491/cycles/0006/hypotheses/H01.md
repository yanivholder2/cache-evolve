# H01

Composing the probationary probe zone with a FIFO stash and LFU-weighted eviction raises hit rate by eliminating both spurious admission (probe zone handles cold inserts) and premature eviction of warm items (stash handles re-access items displaced by cold bursts).

## Parent

cycle/0005/v003

## Changes

Two overlay files require changes.

### `src/shared/eviction_policy.rs`

Override the file to make `ClassicLRU::eviction_candidate_index` use LFU-weighted selection:

```rust
fn eviction_candidate_index(&self, items: &[Item<K, V>]) -> usize {
    items
        .iter()
        .enumerate()
        .min_by_key(|(i, item)| (item.lfu_counter, *i))
        .map(|(i, _)| i)
        .unwrap_or(0)
}
```

This is identical to cycle/0003/v003's `eviction_policy.rs`. All other policies (`TimestampLRU`, `Lifo`, `Lfu`, `Fifo`, `Swap`, `EvictionPolicyKind`) remain unchanged.

### `src/associative_cache/associative_cache_bucket.rs`

Start from the cycle/0005/v003 bucket (probe zone at half primary capacity) and add the stash mechanism from cycle/0003/v003. Concrete changes:

**New fields** (add alongside existing `probe` and `probe_max_size`):

```rust
/// Second-chance stash: items evicted from primary wait here for re-access.
stash: Vec<Item<K, V>>,
/// Maximum stash size (≈ quarter of primary capacity).
stash_max_size: usize,
```

**`new()` initialisation** (add to existing `Self { … }`):

```rust
stash: Vec::new(),
stash_max_size: (settings.bucket_size / 4).max(1),
```

**New private helper methods** (add inside the `impl AssociativeCacheBucket` block, after `new`):

```rust
fn stash_push(&mut self, item: Item<K, V>) {
    if self.stash.len() >= self.stash_max_size {
        self.stash.remove(0);
    }
    self.stash.push(item);
}

fn evict_to_stash(&mut self) {
    if self.items.is_empty() {
        return;
    }
    let idx = self.eviction_policy.eviction_candidate_index(&self.items);
    let evicted = self.items.remove(idx);
    self.stash_push(evicted);
}
```

**`get()` method**: After the existing primary-hit and probe-hit branches, add a stash-hit branch before returning `None`:

```rust
// Stash hit — promote to primary with +2 credit.
if let Some(stash_pos) = self.stash.iter().position(|i| &i.key == key) {
    let mut stash_item = self.stash.remove(stash_pos);
    stash_item.lfu_counter += 2;
    if self.items.len() == self.max_size {
        self.evict_to_stash();
    }
    self.items.push(stash_item);
    let back = self.items.len() - 1;
    return Some(&self.items[back]);
}
```

**`put()` method**: In Case 3 (brand-new key), replace the raw `self.probe.remove(0)` FIFO drop with `evict_to_stash` when primary is full during probe-to-primary promotion. Also add a stash-hit check between the probe-hit branch (Case 2) and the brand-new-key path (Case 3):

```rust
// Case 2b: key found in stash — promote to primary with +2 credit.
if let Some(stash_pos) = self.stash.iter().position(|i| i.key == item.key) {
    let mut stash_item = self.stash.remove(stash_pos);
    stash_item.lfu_counter += 2;
    if self.items.len() == self.max_size {
        self.evict_to_stash();
    }
    self.items.push(stash_item);
    let back = self.items.len() - 1;
    return (&self.items[back], None);
}
```

In the probe-hit promotion path (Case 2 in the original probe code — when `get()` promotes from probe to primary), replace the raw `self.eviction_policy.eviction_candidate_index` + `self.items.remove` pair with a call to `self.evict_to_stash()` so the displaced primary item enters the stash rather than being discarded.

**Invariants to preserve**:
- `get_items()` returns only primary items; probe and stash remain internal.
- `evict_item()`, `remove_at()` (if present in the trait) continue to operate on `self.items` only.
- Probe-zone semantics from cycle/0005/v003 are unchanged: new inserts still enter probe, promotion to primary still requires a confirming `get` hit.
- Stash semantics from cycle/0003/v003 are unchanged: evicted primary items enter the FIFO stash, stash promotions award +2 `lfu_counter`.

## Rationale

cycle/0005/v003 showed that admission control (probe zone) is a stronger lever than any eviction-side refinement. cycle/0003/v003 showed that LFU eviction and the stash compose additively. These two mechanisms target different failure modes — the probe zone prevents cold items from ever entering primary, while the stash prevents warm items from being permanently discarded on first eviction. Both cycle 5 and the cross-cycle insights identified their composition as the highest-priority unresolved hypothesis.

# H03

Replacing strict LRU victim selection in the protected segment with a single second-chance mechanism — where a recently-accessed protected entry is moved to the tail and given one reprieve before demotion — will improve hit-rate over cycle/0002/v003 by shielding hot protected entries from premature eviction due to their LRU head position.

## Parent

cycle/0002/v003

## Changes

Modify `src/lru_cache/mod.rs` to add a second-chance bit to the protected segment. All ghost admission and probationary logic remains identical to cycle/0002/v003:

1. **Add `referenced: bool` to `Node<K, V>`** — initialized to `false` wherever nodes are created or reused (both the fresh-allocation path and the eviction-slot-reuse path in `put()`).

2. **Change the protected-hit path in `get()`** — in the `Segment::Protected` branch, instead of `self.unlink_prot(idx); self.push_back_prot(idx);`, simply set `self.nodes[idx].referenced = true` and leave the node in place. The node's position in the list is NOT updated; its second-chance bit records that it was accessed.

3. **Replace `demote_prot_head()` with a second-chance sweep**:
   ```rust
   fn demote_prot_head(&mut self) {
       if let Some(h) = self.prot_head {
           if self.nodes[h].referenced {
               // Give one second chance: clear the bit, move to protected tail.
               self.nodes[h].referenced = false;
               self.unlink_prot(h);
               self.push_back_prot(h);
           }
           // Demote the current prot_head (which now has referenced == false).
           if let Some(h) = self.prot_head {
               self.unlink_prot(h);
               self.prot_count -= 1;
               self.nodes[h].segment = Segment::Probationary;
               self.push_back_prob(h);
               self.prob_count += 1;
           }
       }
   }
   ```
   This gives at most one second chance per demotion call, keeping the operation O(1) worst-case (two list pointer updates for the reprieve, then one for the actual demotion).

4. **Probationary promotion path in `get()`** — when a probationary node is promoted into protected, initialize `referenced = false` on the node (it enters protected with a clean slate; it must earn its second chance through a subsequent access).

5. **Ghost admission path in `put()`** — when a ghost-hit entry is admitted directly into protected, also initialize `referenced = false` on the node.

Do not change the 80/20 split, the ghost set size or logic, or the probationary eviction path.

## Rationale

In a working set where protected entries are accessed at varying rates, the strict LRU head is not always the best demotion victim: an entry that was promoted long ago but accessed again recently sits near the head because it has not been touched since that recent access moved it forward. The second-chance bit detects this case cheaply — the bit is set on every protected hit without any pointer movement — and gives the entry one cycle to age out of the LRU head position before it is demoted. This is structurally distinct from frequency counting (H02): it requires no arithmetic, no scan, and no persistent counter; it is a pure recency signal expressed as a single bit.

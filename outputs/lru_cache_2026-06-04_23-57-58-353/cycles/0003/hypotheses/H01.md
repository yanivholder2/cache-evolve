# H01

Adding a ghost admission set to the cycle-1 SLRU variant will improve hit-rate by capturing cross-residency warmth that the vanilla two-segment structure discards, isolating the marginal contribution of ghost admission from SLRU segmentation.

## Parent

cycle/0001/v001

## Changes

cycle/0001/v001 is a clean two-segment SLRU (80/20 split) with no ghost tracking. Apply the following additions to its `src/lru_cache/mod.rs`:

1. **New imports** — add `use std::collections::{HashSet, VecDeque};` (HashMap is already present).

2. **New struct fields** — add three fields to `LruCache<K, V>`:
   ```
   ghost: VecDeque<K>,
   ghost_set: HashSet<K>,
   ghost_cap: usize,
   ```

3. **`try_new`** — after computing `prob_cap`, set `ghost_cap = prob_cap`; initialize `ghost` and `ghost_set` with `with_capacity(ghost_cap + 1)`.

4. **`put()` eviction path** — in the branch that evicts the probationary LRU (when `prob_count > 0` or `prob_head` is chosen), after calling `self.map.remove(&evicted_key)` and unlinking the node, call `self.add_to_ghost(evicted_key)` before reusing the slot. Protected evictions must NOT be recorded in the ghost set.

5. **`put()` admission path** — after acquiring the arena slot and before linking into probationary, check `self.ghost_set.contains(&key)`. If true:
   - Remove the key from `ghost_set` and `ghost` (`ghost.retain(|k| k != &key)`).
   - Set the node's segment to `Segment::Protected` (or `in_protected = true`, matching v001's field name).
   - Link into protected MRU (`push_back_prot(idx)`, `prot_count += 1`).
   - Trigger overflow demotion if `prot_count > prot_cap`.
   - Insert into `map` and return early — skip the probationary link.

6. **New helper** `fn add_to_ghost(&mut self, key: K)`:
   ```
   if ghost_cap == 0 { return; }
   if ghost.len() >= ghost_cap {
       if let Some(oldest) = ghost.pop_front() { ghost_set.remove(&oldest); }
   }
   ghost_set.insert(key.clone());
   ghost.push_back(key);
   ```

Do not change the 80/20 split, the demotion logic, or any other part of the cycle-1 SLRU structure. The goal is a minimal graft of ghost admission onto the existing design so the gain (or lack thereof) can be attributed cleanly to the ghost set alone.

## Rationale

cycle/0002/v003 bundles SLRU segmentation and ghost admission in one jump from the plain-LRU baseline, so its measured gain conflates both mechanisms. This variant applies ghost admission on top of the already-established SLRU winner (cycle/0001/v001), giving a direct read on the ghost set's marginal value. If hit-rate rises above cycle/0002/v003's 0.721, the ghost set contributes more than the v003 measurement implies; if it stays near cycle/0001/v001's 0.717, the bulk of v003's gain is attributable to implementation differences from the baseline rather than the ghost mechanism itself.

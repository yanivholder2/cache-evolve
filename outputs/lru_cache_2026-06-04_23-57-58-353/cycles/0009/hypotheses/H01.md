# H01

Replace the inert referenced-bit tie-breaker in `demote_prot_head()` with IRR as the secondary eviction criterion to improve hit rate by demoting cold-but-equally-frequent protected entries before recently-warm ones.

## Parent

cycle/0006/v001

## Changes

cycle/0006/v001 uses `(freq, referenced)` as the two-key demotion score in `demote_prot_head()`. The referenced bit was empirically confirmed inert (cycle 6 insight): equal-frequency collisions almost never occur at the narrow LRU-quarter scan window on this trace. IRR, however, differs among entries at any frequency level and carries genuine recency-of-recency information.

### Additions to Node<K, V>

Add two new fields alongside the existing `freq` and `referenced` fields:

```rust
last_access: u64,   // op_clock value at most recent get hit; 0 if never hit
prev_access: u64,   // op_clock value at second-most-recent get hit; 0 if fewer than 2
```

### New field on LruCache<K, V>

Add `op_clock: u64`, initialized to `1` in `try_new()`.

### New helper method

```rust
#[inline]
fn irr(&self, idx: usize) -> u64 {
    if self.nodes[idx].prev_access == 0 {
        u64::MAX
    } else {
        self.nodes[idx].last_access - self.nodes[idx].prev_access
    }
}
```

### Changes to `get()`

Before any segment-specific logic, update the IRR timestamps for every cache hit:

```rust
self.nodes[idx].prev_access = self.nodes[idx].last_access;
self.nodes[idx].last_access = self.op_clock;
self.op_clock += 1;
```

Also set `self.nodes[idx].referenced = true` for protected hits (unchanged from parent), but the bit is now redundant — it can be retained for test compatibility or removed; the demotion logic no longer reads it.

### Changes to `demote_prot_head()`

Replace the victim score from `(freq, referenced_bit_as_u32)` to a two-key comparison that evicts the entry with the lowest frequency first, then among equal-frequency entries the one with the highest IRR (coldest):

```rust
// Old:
let r = if self.nodes[idx].referenced { 1u32 } else { 0u32 };
let score = (freq, r);
if score < victim_score { ... }

// New (victim_irr: u64 alongside victim_freq: u32):
let cur_freq = self.nodes[idx].freq;
let cur_irr  = self.irr(idx);
// Prefer lower freq; break ties with higher IRR (colder = higher value)
if cur_freq < victim_freq
   || (cur_freq == victim_freq && cur_irr > victim_irr)
{
    victim_freq = cur_freq;
    victim_irr  = cur_irr;
    victim_idx  = Some(idx);
}
```

Initialize `victim_irr` to `0` (so the first candidate unconditionally sets the victim). Alternatively, start with `victim_score = (u32::MAX, 0u64)`.

### Everything else preserved

Ghost admission, frequency halving on demotion (`freq /= 2`), MAX_FREQ cap, probationary half-scan minimum-frequency victim selection, and all linked-list mechanics are unchanged from cycle/0006/v001.

## Rationale

The referenced bit targets frequency-equal collisions that are rare at the quarter-scan width. IRR fires continuously: every pair of entries at the same frequency level has distinguishable IRR values, so the tie-breaker actually selects a different (colder) victim on nearly every demotion. This preserves cycle/0006/v001's proven frequency signal as the outer key while adding real discrimination inside each frequency bucket.
